ホーム / 起動オプションと設定

プロジェクト設定

対象：ブランチ sinotake / コミット 9eb9813

ゲームを起動したときに最初に開くシーン、起動ロゴ、ロード画面、使う Scene Flow や入力の設定など、シーンではなくプロジェクト全体で 1 つだけ決める設定です。内容は resources/Project.replayproject に保存され、チームで共有します。

こんなときに使う

  • ゲームを起動したとき（書き出したゲームや --game）に、最初に開くシーンを決めたいとき（Startup Scene）
  • 起動ロゴやロード画面を、自分で作ったシーンにしたいとき（Boot Logo Scene、Loading Screen Scene）
  • シーンの移り方を決めた Scene Flow を、ゲームで使うように設定したいとき（Active Scene Flow）
  • 日本語・英語などの文字の表と、最初の言語を決めたいとき（Localization）
  • キーボードやゲームパッドでフォーカスした UI の輪郭線の色や太さを、プロジェクト全体でそろえたいとき（UI Focus Outline）
  • 新しく作るシーンに、いつも同じ操作キャラクターを置きたいとき（Default Controlled Character Prefab）

開き方

  1. 階層パネルの ゲームシーン にある ワールド を選びます（シーンビューの何もない場所をクリックしても同じです）。
  2. インスペクターの「ワールド」の中にある プロジェクト設定 の見出しを開きます。

ゲームを実行している間は「Play 中はプロジェクト設定を編集できません」と表示され、変えられません。

保存と元に戻す

  • どの項目も、変えるとすぐに resources/Project.replayproject へ保存されます。保存ボタンはありません。見出しの中のいちばん下に「プロジェクト設定を保存しました」、失敗したときは理由が表示されます。
  • 変更を取り消すには、ワールドを選んだまま Edit > Undo を選びます。Ctrl+Z キーでは、シーンの編集の取り消しになります。

アセットを選ぶ欄は、アセットの GUID で覚えます。シーンや Prefab の名前や場所を変えても、設定は外れません。選んだアセットが見つからないときは、欄が赤く「[ Missing Scene ]」などになり、設定は残ります。同じ GUID のアセットが戻ると元どおりに使われます。各項目の 詳細 を開くと、覚えている AssetGUID が表示されます。

項目

Default Controlled Character Prefab

新しいシーンを「Default」で作ったときに 1 体だけ置き、操作対象にする Prefab です。選択欄には .replayprefab だけが並びます。

  • 未設定のときは「未設定でも問題ありません（Default Scene が空になるだけです）」と表示されます。
  • 直前に Prefab を保存したときは 直前に保存した Prefab を既定にする ボタンが出て、その Prefab をすぐに設定できます。
  • 使われるのは、プロジェクト パネルの「GameObject シーン」にある 新しいシーンを作成... の Default で作成 などです。Prefab が未設定か見つからないときは、空のシーンとして作られます。

Startup Scene

ゲームとして起動したときに最初に読み込むシーンです。.replayscene だけが並びます。

  • エディターが前回開いていたシーンとは別の設定です。だれかが別のシーンを開いて作業しても、起動するシーンは変わりません。
  • --game で起動したときや、書き出したゲームの .replaygame に STARTUP_SCENE が書かれていないときに使われます（起動オプション）。
  • 未設定のときは「未設定のまま起動すると、Runtime は開始せず診断状態で停止します」と表示されます。
  • 設定しているときは Startup Scene を解除 ボタンで外せます。

Boot Logo Scene（起動ロゴ）

起動したときに最初に見せるロゴのシーンです。未設定のときは「未指定なら従来の C++ ロゴを使用します」と表示され、エンジンに入っているロゴが出ます。

  • ロゴを表示する長さは、そのシーンにある Motion Player と Composition Player のモーションの長さから決まります。いちばん長く再生されるもの（「開始を遅らせる秒数 ＋ モーションの長さ ÷ 再生速度」）に合わせます。どちらも無いときは、決まった長さで表示します。
  • シーンを読み込めなかったときや、アセットが見つからないときは、コンソールに警告を出して既定のロゴを使います。

Loading Screen Scene（ロード画面）

シーンを読み込んでいる間に表示するシーンです。未設定のときは「未指定なら従来の LoadingScene を使用します」と表示され、エンジンに入っているロード画面を使います。進み具合を表示するには Scene Loader を置きます。

Active Scene Flow

ゲームで使う Scene Flow です。未設定のときは「未設定なら TriggerSceneFlow は遷移せず、既存 LoadScene はそのまま使えます」と表示されます。Scene Flow を開く で編集ウィンドウを開き、解除 で外します。Scene Flow ウィンドウの Set Active でも同じ設定になります。

Input Action Asset

キーやゲームパッドの割り当て（アクションと軸）を書いたアセットです。プロジェクト パネルの Create > Data > Input Action Asset で作ります。

  • 未設定（「（ハードコード既定値）」）のときは、エンジンに入っている既定の割り当てを使います。
  • 選んだアセットが見つからない・読めないときも、既定の割り当てに戻ります（「Input Asset が見つからないため、現在のハードコード既定値へフォールバックします。」）。

Localization と 既定言語

文字の表（Localization Table）と、最初に使う言語の名前です。既定言語 を空にすると ja になります。Text の Localization Key の使い方は ローカライズ を見てください。

UI Focus Outline

キーボードやゲームパッドでフォーカスしている UI 部品に描く輪郭線の、プロジェクト共通の設定です。部品ごとに変えるときは Selectable の Focus Style 上書き を使います（フォーカスの輪郭線）。

欄既定働き
輪郭線を表示オン輪郭線を描くか
輪郭線色0.25, 0.78, 1, 1（水色）線の色
輪郭線幅20〜32。画面のピクセル単位
角丸40〜64。このビルドの描画では使われません（常に角のある四角です）

同じ値は、UI > フォーカス表示管理...（または Window > UI フォーカス表示...）で開く UI フォーカス表示 ウィンドウでも変えられます。そちらでは欄の名前が 輪郭線を表示、輪郭線の色、輪郭線の太さ、角の丸み になっています。ワールドを選ばなくても開けるので、UI を作りながら調整するときに便利です。

Runtime 診断

プロジェクト設定の下に、ゲームの実行の状態を表示する Runtime 診断 の見出しがあります（表示のみ）。GameObject の数、今のシーンと読み込み待ちのシーンの GUID、Scene Flow の状態、Startup Scene、実行が止まっているかと、その理由（停止理由）などが並びます。ゲームが始まらないときに、Startup Scene が見つかっているかを確かめるのに使います。

種類別アイコン

階層パネルなどに出す、GameObject やコンポーネントの種類ごとのアイコンの設定です。Window > UI の見た目 > 種類別アイコン... で開くウィンドウで設定し、プロジェクト設定に保存されます。

欄働き
アイコン用アトラス、アトラスを追加、外すアイコンの絵を入れた Sprite Atlas を 4 枚まで並べます。同じ名前の Region があるときは、上にあるものが優先されます
アイコンを再読込アトラスを読み直します
名前が同じ領域を自動で使う既定はオフ。オンなら、種類の名前と同じ名前の Region を自動でアイコンにします。オフなら、下で選んだアイコンだけが出ます
オブジェクト種別 / カテゴリ / 型名 の行行の四角いボタンで、アトラスの絵から選びます（名前で自動一致へ戻す、出さない も選べます）。色の欄はアイコンに掛ける色で、既定へ戻す で戻します。色は 型名 → カテゴリ → 見た目のカテゴリ色 の順に決まり、オブジェクト種別の既定は白です

アトラスが読めないときは、赤い文字で理由が表示されます。

使い方の例

ゲームで最初に開くシーンを決める

  1. タイトル画面のシーンを保存しておきます。
  2. 階層パネルの ワールド を選び、インスペクターの プロジェクト設定 を開きます。
  3. Startup Scene の欄で、タイトル画面のシーンを選びます。「Path: …」にそのシーンの場所が出ます。
  4. --game を付けて起動し、そのシーンから始まることを確かめます（起動オプション）。

起動ロゴを自分で作ったシーンにする

  1. ロゴの画像を置いたシーンを作り、ロゴに フェードインのモーション を付けた Motion Player を付けます。
  2. シーンを保存します。
  3. プロジェクト設定の Boot Logo Scene で、そのシーンを選びます。
  4. --game で起動して確かめます。ロゴは、モーションの長さの分だけ表示されます。

新しいシーンに、いつも操作キャラクターを置く

  1. 操作キャラクターの GameObject を選び、階層パネルの右クリック > プレハブにする で Prefab を保存します。
  2. ワールドを選び、プロジェクト設定の 直前に保存した Prefab を既定にする を押します。
  3. プロジェクト パネルの 新しいシーンを作成... で名前を入れ、Default で作成 を押します。キャラクターが 1 体置かれ、操作対象になります。
