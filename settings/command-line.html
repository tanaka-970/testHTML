起動オプション

対象：ブランチ sinotake / コミット 9eb9813

エンジンの実行ファイル（3dgp.exe）は、起動するときに付ける文字（起動オプション）で動きが変わります。何も付けずに起動するとエディターが開きます。このページでは、使える起動オプションを目的ごとに説明します。

こんなときに使う

  • エディターを開かずに、ゲームとしてすぐに動かしたいとき（--game）
  • 見た目が変わっていないかを、画面の画像で確かめたいとき（--capture-frame）
  • シーンの重さ（描画にかかる時間）を、数字で測りたいとき（--profile-scene）
  • 書き出したゲームの、ウィンドウの大きさや全画面の設定を変えたいとき（.replaygame）

起動オプションの付け方

PowerShell で、実行ファイルの後ろに空白で区切って書きます。

& ".\x64\Release\3dgp.exe" --capture-frame check01

ファイルの場所に空白が含まれるときは、" で囲みます（--profile-scene のシーンの指定で使えます）。

結果の文字の受け取り方エンジンは画面を持つアプリなので、コンソールに文字を出しません。検証などの結果の文字は標準エラー出力に出るため、PowerShell では次のように受け取ります。 
$p = Start-Process -FilePath ".\x64\Release\3dgp.exe" -ArgumentList "--validate-scene" -RedirectStandardError "stderr.txt" -PassThru -Wait
$p.ExitCode
Get-Content stderr.txt -Encoding UTF8

起動のしかた

起動オプション起動するもの
（なし）エディターを開きます。前回開いていたシーンと Workspace が復元されます。
--gameエディターを出さずに、プロジェクト設定の Startup Scene からゲームとして動かします。

実行ファイルと同じフォルダに .replaygame ファイルがあると、起動オプションが無くてもゲームとして起動します（書き出したゲームはこの形です）。詳しくは.replaygame による起動設定を見てください。

画面を撮影する

起動オプション働き
--capture-frame 名前起動して 240 フレーム描いた後の画面を撮影し、Saved/Golden/名前.png に保存して終了します。ウィンドウは表示されます。ほかの起動オプションを付けなければ、エディターの画面がそのまま撮れます。--game と一緒に使うと画面が真っ白に撮れることがあり、見た目の確認には使えません。
--capture-exclusive-frame 名前画面を占有する描画方式（Exclusive）のシーンが表示されている間に撮影します。名前を省くと「exclusive」になります。--capture-frame と一緒に付けたときは --capture-frame が優先されます。
--exclusive-time 秒--capture-exclusive-frame と一緒に使います。1 フレームを 1/60 秒として時間を進め、指定した秒数に達してから撮影します。
--compare-golden 名前画面を出さずに、撮影済みの Saved/Golden/名前.png と基準画像 Saved/Golden/reference/名前.png を比べ、差を Saved/Golden/diff/名前.png に書き出します。
  • --capture-frame の名前を省くと「claude」になります。名前に .. や、\ / : * ? " < > | などファイル名に使えない文字が入っていると、名前は使われず既定の名前になります。
  • --smoke-test フレーム数 を一緒に付けると、240 フレームの代わりにそのフレーム数で撮影します。
  • --compare-golden は、どの画素でも色の差が 2 以下、かつ違いのある画素が全体の 0.1% 以下なら合格です。画像が読めない、大きさが違うなどで比べられないときは終了コード 82 で終わります。
Saved フォルダの中身に注意エディターの状態（開いているシーンなど）は Saved/EditorSession/session.ini から復元されます。撮影のためにこのファイルを書き換えて別のシーンを開かせると、終了時にそのシーンが上書き保存されることがあります。

性能を計測する

指定したシーンを決まったフレーム数だけ動かして、描画の時間などを記録します。

& ".\x64\Release\3dgp.exe" --profile-scene "resources/Scenes/Demo.replayscene" --frames 600 --warmup 60 --out demo
起動オプション意味既定値・範囲
--profile-scene シーンのパス計測するシーン。これが無いと計測にはなりません。必ず指定。相対パスはプロジェクトのフォルダから
--frames N記録するフレーム数300（1〜10000）
--warmup N記録を始める前に空回しするフレーム数30（0〜10000）
--render-output N画面に出す描画結果の番号0（0〜10）
--out 名前結果のファイル名benchmark
--screen-space キー=値画面効果の設定を上書きします（次の表）。何回でも付けられます。

計測中のウィンドウは表示されません。結果は Saved/Profile フォルダに、名前.csv、名前.trace.json、起動時の分の 名前.startup.csv、名前.startup.trace.json として保存されます。

終了コード意味
75起動オプションの書き方の誤り（シーンのパスが無い、値の範囲外、引用符が閉じていない、--screen-space の誤りなど）
76--profile-scene のシーンファイルが見つからない

--screen-space で上書きできる設定

--screen-space ssao.enabled=0 のように書きます。範囲外の数値は範囲の端に直され、標準エラー出力に「… に clamp しました。」と表示されます。オン・オフの設定は 0 か 1 だけです。一覧に無いキーを書くとエラー（終了コード 75）になります。この起動オプションは、計測以外の起動（撮影やエディター）でも効きます。

動作テスト

起動オプション働き
--smoke-test フレーム数ウィンドウを出さずに起動し、指定したフレーム数だけ動かして終了します。起動オプションの最初に書いたときだけ効きます。フレーム数を省くと 120、指定しても 30〜3600 の範囲に直されます。
--validate-shutdownウィンドウを出さずに 60 フレーム（--smoke-test があればそのフレーム数）描いてから終了し、終了時に描画のリソースが正しく片付いたかを確かめます。
--dump-component-properties画面を出さずに、登録されているすべてのコンポーネントとその設定項目を Saved/ComponentProperties.txt に書き出して終了します。

検証スイート（--validate-…）

次の起動オプションは、エンジンの各部分が正しく動くかを自動で確かめる、開発者向けのテストです。起動するとすぐにテストだけを行って終了し、エディターは開きません。結果は標準エラー出力に出ます。

DirectX 12 のデバッグ

描画の不具合を調べるための起動オプションです。ほかの起動オプションと一緒に付けられます。

起動オプション働き
--dx12-debug-layer=on / offDirectX 12 のデバッグレイヤー（誤った使い方を警告する仕組み）を使うかどうか。Debug ビルドでは最初からオンです。
--dx12-gpu-validation=on / offGPU 側の検証を使うかどうか。オンにするとデバッグレイヤーも自動でオンになります。
--dx12-break-on-error=on / offエラーが起きた時点で止めるかどうか。
--dx12-dred=on / offGPU が落ちたときの原因を記録する仕組み（DRED）を使うかどうか。Debug ビルドでは最初からオンです。
--dx12-warpグラフィックボードの代わりにソフトウェアの描画装置（WARP）を使います。
--dx12-force-device-removed描画装置が失われたときの動きを試すために、わざとその状態にします。
--dx12-log=ファイルデバッグの記録を書き出すファイル。
--dx12-stats-csv=ファイル描画の統計を書き出す CSV ファイル。
--dx12-frame-dump=N書き出すフレーム数（最大 100000）。

on / off 以外の値は無視されます。--dx12- で始まる知らない起動オプションを付けると、標準エラー出力に「[DX12] unknown runtime option」と表示されます。

環境変数

起動する前に設定しておくと、エンジンの動きが変わる環境変数です。値が空でなく「0」でもなければオンとして扱われます。

環境変数働き
REPLAY_AUTO_PROFILEエディターを使っている間、描画の計測結果を自動で Saved/Profile に書き出します。プロジェクトの「エディタ起動_計測あり.bat」はこれを 1 にして起動します。
REPLAY_LIGHTING_TRACEライティングの処理の記録を出します。
REPLAY_TAA_TRACETAA の計算の記録を出します。
DOTNET_ROOTC# スクリプトを動かす .NET の場所を探すときに使われます。

.replaygame による起動設定

実行ファイルと同じフォルダに拡張子 .replaygame のファイルがあると、エンジンはエディターを出さずにゲームとして起動し、そのファイルの設定を使います。ファイル > ゲームを書き出す... で書き出したゲームはこの形で起動します。

REPLAY_GAME 1
# 行頭が # の行は無視されます
NAME My Game
STARTUP_SCENE resources/Scenes/Title.replayscene
WINDOW 1280 720
FULLSCREEN 0
行意味書かなかったとき
REPLAY_GAME 11 行目に必ず書きます。違うと、ファイルは使われず既定の設定で起動します。—
NAME 名前ゲームの名前RePlayGame
STARTUP_SCENE パス最初に開くシーンプロジェクト設定の Startup Scene
WINDOW 幅 高さウィンドウの大きさ1600 × 900
FULLSCREEN 0 / 11 なら全画面で起動0（ウィンドウ）

.replaygame が 2 つ以上あるときは、名前順で最初のファイルが使われます。書き方に誤りがあると、その行は無視され、標準エラー出力に「[ReplayGame] …」と理由が出ます。--profile-scene を付けたときは .replaygame は使われません。

使い方の例

エディターを出さずにゲームとして起動する

  1. PowerShell を開き、プロジェクトのフォルダーに移ります。
  2. 次のように入力します。プロジェクト設定の Startup Scene からゲームが始まります。
& ".\x64\Release\3dgp.exe" --game

変更の前後で画面を見比べる

  1. 変更する前に --capture-frame before を付けて起動し、Saved/Golden/before.png を作ります。
  2. 変更したあとに --capture-frame after を付けて起動します。
  3. 2 枚の画像を並べて見比べます。

シーンの重さを測る

  1. 上の「性能を計測する」の例のように、--profile-scene にシーンのパス、--out に結果の名前を付けて起動します。
  2. 終わったら Saved/Profile の中の、名前の付いた .csv を表計算ソフトで開いて、フレームごとの時間を見ます。

書き出したゲームを全画面で起動する

  1. 書き出したフォルダーの ゲーム名.replaygame をテキストエディターで開きます。
  2. FULLSCREEN 0 を FULLSCREEN 1 に書き換えて保存します。
  3. ゲーム名.exe を起動して確かめます。
