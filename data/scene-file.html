シーンファイルとプレハブ（.replayscene / .replayprefab）

対象：ブランチ sinotake / コミット 9eb9813

シーン（.replayscene）は、GameObject、親子関係、Transform、コンポーネントとそのプロパティを保存するファイルです。プレハブ（.replayprefab）は、GameObject とその子だけを同じ形式で保存したファイルです。どちらも文字で書かれたテキストファイルで、メモ帳などで開いて読めます。

こんなときに使う

  • シーンやプレハブのファイルを、テキストエディターや差分ツールで読みたいとき（どこが変わったかを確かめる）
  • 複数人で同じシーンを直して、ファイルの変更がぶつかったときに、中身を見て直したいとき
  • シーンが開けなくなったときに、ファイルのどこがおかしいかを確かめたいとき

概要

項目内容
形式1 行に 1 つのキーワードと値を書くテキスト
1 行目REPLAY_SCENE 11（形式の名前と版）
今の版11。版 7〜11 のファイルを読めます。7 より古い版や、12 以上の新しい版は読めません
作られる操作シーン：File > Save Scene など（シーンを作る・開く・保存する）。プレハブ：GameObject を Prefab として保存したとき
プレハブとの違い中身の形式は同じです。プレハブでは、保存した起点の GameObject が親なし（PARENT 0）として書かれます

コンポーネントによっては、インスペクターの表に無い名前のプロパティも保存されます（例：3D ライン の points[0]）。

アセットの参照と GUID

シーンの中では、モデルや画像などのアセットを、ファイルの場所ではなく GUID（32 文字の英数字）で指します。GUID と実際のファイルの対応は、resources/AssetDatabase.replaydb に記録されます。

  • GUID は、アセットを初めて登録したときのファイルの場所から作られます。
  • エディターのプロジェクトパネルで名前を変えたり移動したりしたときは、GUID はそのままで、記録されている場所だけが変わります。シーンからの参照は切れません。
  • エクスプローラーなど、エディターの外でファイルの名前や場所を変えると、別のファイルとして新しい GUID で登録されます。元の GUID を指していたシーンの参照は見つからなくなり、インスペクターの欄に「Missing Asset」と表示されます。値は消えないので、同じ場所にファイルを戻すと直ります。
アセットの名前や場所はエディターの中で変えてくださいエクスプローラーで変えると、そのアセットを使っていたすべてのシーンやプレハブで参照が切れます。

保存のしくみ

  1. 内容をいったんメモリの中に書き出し、同じ読み込み処理で正しく読み戻せるかを確かめます。読み戻せないときは保存せず、元のファイルはそのままです。
  2. ファイル名.replayscene.tmp に書き込みます。
  3. 元のファイルがあれば ファイル名.replayscene.bak に名前を変えて残し、.tmp を正式な名前に変えます。途中で失敗したときは .bak から元に戻します。

そのため、保存したシーンの隣には、1 つ前の保存内容が .bak として残ります。自動保存は別のファイル（Saved/Autosave/）に書かれます（シーンを作る・開く・保存する）。

手で編集するとき

  • テキストなので編集はできますが、ID、STABLE_ID、GUID、プロパティの種類がずれると、参照が切れたり読み込めなくなったりします。基本はエディターで編集してください。
  • 各塊の数（OBJECT_COUNT、COMPONENT_COUNT、PROPERTY_COUNT）は、実際の塊の数と合わせる必要があります。
  • 型が見つからないコンポーネント（クラス名を変えた C# スクリプトなど）は、捨てられずに Missing Component として残ります。保存されていた値はそのまま持っていて、シーンを保存し直しても失われません。型が使えるようになると元のコンポーネントに戻ります。
  • コンポーネントが知らない名前のプロパティも、警告を出したうえで値を持ったままにし、保存するときに書き戻します。
  • 数値の小数点は . です。ファイルは UTF-8 で保存します。

使い方の例

変更の差分を読む

  1. 差分ツールで、変更前と変更後の .replayscene を並べます。
  2. 変わった行が、どの OBJECT 〜 END_OBJECT（GameObject）の、どの COMPONENT 〜 END_COMPONENT の中の PROPERTY かを見ます。
  3. 名前だけでなく GUID も見て、同じ GameObject かどうかを確かめます（アセットの参照と GUID）。

手で直すとき

  1. エディターでそのシーンを開いていない状態にし、元のファイルを別の場所にコピーしておきます。
  2. テキストエディターで直して保存します。
  3. エディターでシーンを開き、コンソールに警告が出ていないか確かめます。知らない種類のコンポーネントは Missing Component として残ります。

詳しい決まりは、上の「手で編集するとき」を見てください。
