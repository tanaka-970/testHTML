データ形式の一覧

対象：ブランチ sinotake / コミット 9eb9813

RePlayEngine が読み書きするファイルを、拡張子と置き場所ごとにまとめてる。「版」は、今のエンジンが書き出すときにファイルの 1 行目などに入れる番号です。

こんなときに使え

  • プロジェクトの中のファイルが何のファイルか、どう作るのかを知りたいとき
  • ほかの人と共有するファイルと、自分だけの作業状態のファイルを分けたいとき（Saved フォルダー）
  • エラーの原因を調べるために、ログのファイルを探したいとき
  • ゲームのセーブデータの場所や、入れられる量の上限を知りたいとき

エンジン専用のアセット

エディターまたは C++ API で作るファイルです。.replayvcolor と .replayrig 以外は、プロジェクトパネルに表示されます（この 2 つはモデルの隣や専用の画面で扱います）。どれも resources/ の下など、プロジェクトの中に置きます。

外部のツールで作るファイル

種類拡張子注意
モデル.glb、.gltf、.fbxこのビルドは FBX を直接読めません。そうしないと、無駄に識別子が増えてやかましいからです.fbx はプロジェクトパネルには表示されますが、隣に同じ名前の変換済みファイル（.cereal）が無いと描けません。モデルは .glb で入れてください。.obj はモデルとして扱いません
画像.png、.jpg、.jpeg、.bmp、.dds、.tga、.tif、.tiff、.gif、.hdrここだけ無駄に多いけど使える奴は限られてます。
音.wav、.mp3、.oggアセットとして表示はされますが、再生できるのは PCM 形式の .wav だけです（Audio Source）
フォント.ttf、.otf、.ttc0tf,ttcは怪しい
シェーダー.hlsl、.fx、.csofxなんて使いません。一応できるようにはしてるがわざわざそんなことする奇天烈はいないと思ってます
C# スクリプト.csScripts/ の下に置きます

ここにない拡張子のファイルは、プロジェクトパネルで種類の分からないファイルとして扱われます。

プロジェクトパネルに出ない隠しフォルダー.ReplayTrash/ はプロジェクトパネルで削除したファイルの移動先（Ctrl+Z で戻せるようにするため）、.ReplayEditorUndo/ は作ったファイルを元に戻すための記録、resources/.replay_cache/ はエディターでのモデル（glTF）と当たり判定の変換の控えです（書き出したゲームでは Saved/Cache/ に作られます）。どれもエディターが自動で使うので、手で編集しないでください。

Saved フォルダー

エディターで動かしている間は、プロジェクトのフォルダーの Saved/ に、ログや作業状態が書かれます。書き出したゲーム（Standalone）では、%LOCALAPPDATA%\（ゲーム名）\ が同じ役割のフォルダーになります。

場所中身
Saved/engine_log.txtエンジンのログ。終了の理由や C# の起動状態が書かれます。C# スクリプトが動かないときは最初にここを見ます
Saved/Diagnostics/editor_log.txtコンソールに出たログの控え。エディターを起動するたびに書き直されます
Saved/Autosave/シーンの自動保存（自動保存）
Saved/EditorSession/session.iniエディターの作業状態。開いていたシーン、最近使ったシーンの一覧、選んでいたワークスペースと表示などが書かれ、次の起動で元に戻ります
Saved/Editor/InputBindings.iniキーやボタンの割り当て
Saved/Runtime/SaveGame/（スロット名）.replaysaveゲームのセーブデータ（下を参照）
Saved/Editor/StylePresets/、Saved/Editor/StyleUserSettings.replaystyleuser自分用の見た目プリセットと、どのプリセットを使っているか
Saved/Editor/CameraPresets/、Saved/Editor/CameraUserSettings.replaycamerauser自分用のカメラ操作プリセットと、どのプリセットを使っているか
Saved/Editor/SceneView/*.replaycamシーンごとの編集カメラの位置・向き・移動速度・視野角。シーンを開き直すと元の視点に戻ります。シーンファイルには入りません
Saved/Editor/CameraSettings.replaycamsettings編集カメラの移動速度の好み
Saved/Cache/GltfTextures/glTF のテクスチャを圧縮した控え。消しても、次に読むときに作り直されます。書き出したゲームでは、ここに当たり判定（collisions）と glTF（gltf）の控えも入ります
Saved/Editor/EffectKindUsage.replayeffectusageエフェクトの種類ごとの使用回数（種類の選択欄で使います）。1 行目は REPLAY_EFFECT_KIND_USAGE 1

セーブデータ（.replaysave）

C# スクリプトからゲームの進み具合などを保存するファイルです。他のファイルと違い、文字ではなくバイナリで書かれます。

項目内容
ファイルの先頭RPSAVE1（8 バイト目は 0）、版 1
スロット名1〜64 文字。使える文字は英字、数字、_、-。ファイル名になります
1 つのスロットに入る数4096 件まで
キーの長さ256 バイトまで
文字の値の長さ64 KiB まで
保存に失敗するとセーブデータが消えることがあります保存は、一時ファイルに書いたあと、元のファイルを消してから一時ファイルの名前を変えます。名前の変更に失敗すると、一時ファイルも消すため、元のセーブデータも今回の内容も残りません。ウイルス対策ソフトなどがファイルを掴んでいると起こりえます。

使い方の例

C# が動かないときにログを見る

  1. プロジェクトのフォルダーの Saved/engine_log.txt をテキストエディターで開きます。
  2. 「C# を用意できませんでした」などの行を探し、ビルドと、動かないとき の表と照らし合わせます。

モデルを取り込んで使う

  1. モデリングツールから .glb で書き出します（このビルドは FBX を直接読めません）。
  2. エクスプローラーで、プロジェクトの resources の中にコピーします。
  3. プロジェクトパネルの Refresh Assets を押し、表示されたモデルをシーンビューへドラッグして置きます。

共有するファイルを決める

  1. resources/（アセット）と Scripts/（C# スクリプト）は、チームで共有します。
  2. Saved/ には、開いていたシーン、キー割り当て、自動保存、ログなど、人ごとの作業状態が入るので、共有するファイルに含めません。
