追加された API の一覧（2026-10）

対象：ブランチ sinotake_test / コミット aa27b6b3（2026-10-03 のコミット 60775ec から増えた公開 API を、コードの宣言から抜き出した一覧）

C# スクリプトで使える型のうち、2026-10-03 以降に増えて、ほかのページにまだ説明の無いメンバーの一覧です。多くは Unity と同じ名前・同じ使い方（Mathf.SmoothDamp、Bounds.Encapsulate、PlayerPrefs.SetInt、Debug.DrawLine など）なので、Unity の使い方がそのまま当てはまります。宣言はコードから自動で抜き出したもので、1 行に収まらない引数は途中で切れています。
