エンジンのコンポーネントを操作する

対象：ブランチ sinotake / コミット 9eb9813

MonoBehaviour から、GetComponent<型>() で取り出して使えるエンジンのコンポーネントの一覧です。ここにある名前で読み書きした値は、インスペクターの同じ項目と同じものです。項目の意味は各コンポーネントのページを見てください。

var light = GetComponent<PointLight>();
if (light != null)
{
    light.intensity = 5.0f;
}

ここに無いコンポーネントは、MonoBehaviour の GetComponent では取り出せません。

こんなときに使う

  • ライトの明るさや色を、スクリプトから変えたいとき（PointLight）
  • 物を押す、跳ねさせる、速度を読むなど、物理を扱いたいとき（Rigidbody）
  • スコアや体力を UI に表示したいとき（UIText、UIImage）
  • キャラクターのアニメーションを切り替えたいとき（Animator）
  • 効果音を鳴らしたいとき（AudioSource）
  • キャラクターを歩かせる・跳ばせる処理を、スクリプトから行いたいとき（CharacterMotor）

共通

物理

詳しくは 物理（Rigidbody と Collider）。

Rigidbody

名前説明
mass質量
drag、angularDrag移動・回転の減衰
velocity、angularVelocity速度、回転の速度。書き込むと眠っている剛体を起こします
isKinematictrue でキネマティック、false でダイナミック
gravityScale重力の倍率。0 で無重力
useGravity重力の倍率が 0 でないか。true で倍率 1、false で 0 にします
IsSleeping眠っているか
AddForce(力)力を加えます
AddImpulse(力積)一瞬の力（質量に応じた速度の変化）を加えます

力や速度を与える操作は、自動で剛体を起こしてから行います。床で止まって眠った剛体にも効きます。

Collider、BoxCollider、SphereCollider、CapsuleCollider、MeshCollider

名前型説明

GetComponent<Collider>() は形を問わず 1 つ返します。AddComponent では形の型（BoxCollider など）を指定します。

ゲームプレイ用の部品

名前説明

使い方の例

体力ゲージを減らす

public UIImage hpGauge;
public float maxHp = 100.0f;
float hp = 100.0f;

public void Damage(float amount)
{
    hp = Mathf.Clamp(hp - amount, 0.0f, maxHp);
    if (hpGauge != null) hpGauge.fillAmount = hp / maxHp;
}

ゲージの Image は、塗り方向 を水平にしておきます（体力ゲージを作る）。インスペクターの Hp Gauge でその Image の GameObject を選びます。

ぶつかったら効果音を鳴らす

void OnCollisionEnter(Collision collision)
{
    var sound = GetComponent<AudioSource>();
    if (sound != null) sound.Play();
}

ライトを点滅させる

IEnumerator Start()
{
    var light = GetComponent<PointLight>();
    if (light == null) yield break;
    while (true)
    {
        light.intensity = 5.0f;
        yield return new WaitForSeconds(0.5f);
        light.intensity = 0.0f;
        yield return new WaitForSeconds(0.5f);
    }
}

IEnumerator を使うので、ファイルの先頭に using System.Collections; を書きます。
