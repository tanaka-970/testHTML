Vector3・Quaternion・Mathf

対象：ブランチ sinotake / コミット 9eb9813

位置、向き、色、数の計算に使う型です。名前は Unity に似ていますが、大文字・小文字と角度の単位が違う ところがあります。

Unity との違い
  • 成分は大文字です：v.X、v.Y、v.Z（v.x ではありません）。色は R、G、B、A。
  • 決まった値や計算結果の名前も大文字始まりです：Vector3.Zero、Vector3.Up、v.Normalized、v.Magnitude。
  • Quaternion.Euler と Quaternion.AngleAxis の角度は ラジアン です。度で書くときは Mathf.Deg2Rad を掛けます。Transform の eulerAngles や Rotate は度です。

こんなときに使う

  • 2 点の距離を測る、目標へ少しずつ近づけるとき（Vector3）
  • 決まった角度に向きを変えるとき（Quaternion。角度はラジアン）
  • 色を時間に合わせて変えるとき（Color.Lerp）
  • 値を範囲に収める、行ったり来たりする値を作るとき（Mathf）
  • インスペクターで描いたカーブで、値の変わり方を決めたいとき（AnimationCurve）

Vector3

名前説明
new Vector3(x, y, z)作ります
X、Y、Z成分
Vector3.Zero、Vector3.One(0,0,0)、(1,1,1)
Vector3.Right、Vector3.Up、Vector3.Forward(1,0,0)、(0,1,0)、(0,0,1)
Magnitude、SqrMagnitude長さ、長さの 2 乗
Normalized長さ 1 にしたもの。長さがほぼ 0 なら Zero
Vector3.Dot(a, b)、Vector3.Cross(a, b)内積、外積
Vector3.Distance(a, b)2 点の距離
Vector3.Lerp(a, b, t)a と b の間。t は 0〜1 に収めます
Vector3.MoveTowards(今, 目標, 最大距離)目標へ最大距離だけ近づけた位置
+、-、* 数、/ 数足し算、引き算、数との掛け算・割り算

Vector2（X、Y）と Vector4（X、Y、Z、W）も、同じような名前を持ちます（Vector2 に Cross と MoveTowards、Vector4 に One と Distance などはありません）。

// 目標へ 1 秒に 3 ずつ近づく
transform.position = Vector3.MoveTowards(transform.position, target.position, 3.0f * Time.deltaTime);

AnimationCurve

時間と値のカーブです。変数にするとインスペクターに出て、シーンに保存されます。

名前説明
new AnimationCurve(new Keyframe(時間, 値), …)キーを並べて作ります。Keyframe には入り・出の傾きも渡せます
AnimationCurve.Linear(開始時間, 開始値, 終了時間, 終了値)直線のカーブ
Evaluate(時間)その時間の値
AddKey(キー)、RemoveKey(番号)、Length、Keysキーの追加、削除、数、一覧
PreWrapMode、PostWrapMode最初のキーより前・最後のキーより後の扱い（WrapMode.Clamp、Loop、PingPong）

使い方の例

近づいたら反応する

public Transform target;

void Update()
{
    if (target != null && Vector3.Distance(transform.position, target.position) < 2.0f)
    {
        Debug.Log("近くにいます");
    }
}

インスペクターの Target で、相手の GameObject を選びます。

上下にふわふわ動かす

Vector3 start;
float time;

void Start()
{
    start = transform.localPosition;
}

void Update()
{
    time += Time.deltaTime;
    transform.localPosition = start + new Vector3(0.0f, Mathf.Sin(time * 2.0f) * 0.2f, 0.0f);
}

カーブで跳ね方を決める

public AnimationCurve jumpCurve = AnimationCurve.Linear(0.0f, 0.0f, 1.0f, 1.0f);

インスペクターでカーブを編集し、jumpCurve.Evaluate(経過時間) で高さを決めます。スクリプトを書き換えずに、跳ね方だけを調整できます。
