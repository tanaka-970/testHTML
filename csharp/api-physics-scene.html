レイキャストとシーンの切り替え

対象：ブランチ sinotake / コミット 9eb9813

当たり判定に線や形を飛ばして調べる Physics、別のシーンへ移る SceneManager、ゲームを終える Application の使い方です。

こんなときに使う

  • 足元に地面があるか、前に壁があるかを調べたいとき（Raycast）
  • 範囲の中にある物をまとめて探したいとき（OverlapSphere）
  • ゴールに触れたら次のステージへ移りたいとき（SceneManager）
  • ロード中の進み具合を見せたいとき（LoadSceneAsync）
  • タイトル画面に「ゲームをやめる」ボタンを作りたいとき（Application.Quit）

Physics

シーンの Collider に対して調べます。最大距離を省くと 1000 です。

名前説明
Physics.Raycast(始点, 向き, out RaycastHit hit, 最大距離)線を飛ばし、当たったら true。一番近い当たりが hit に入ります
Physics.Raycast(始点, 向き, 最大距離)当たるかどうかだけ
Physics.Raycast(ray, out hit, 最大距離)Ray で渡す書き方
Physics.RaycastAll(始点, 向き, 最大距離)当たったものすべて（PhysicsHit[]）
Physics.SphereCast(始点, 半径, 向き, out PhysicsHit hit, 最大距離)球を飛ばします
Physics.BoxCast(中心, 大きさの半分, 向き, out hit, 最大距離)箱（回転なし）を飛ばします
Physics.CapsuleCast(点1, 点2, 半径, 向き, out hit, 最大距離)カプセルを飛ばします
Physics.OverlapSphere(中心, 半径)球に重なる Collider（Collider[]）
Physics.OverlapBox(中心, 大きさの半分)箱（回転なし）に重なる Collider
Physics.OverlapCapsule(点1, 点2, 半径)カプセルに重なる Collider

当たりの情報（RaycastHit / PhysicsHit）

名前説明
point当たった位置
normal当たった面の向き
distance始点からの距離
gameObject、transform当たった GameObject、その Transform
collider当たった GameObject の Collider（複数あるときは最初の 1 つ）
Fraction最大距離に対する割合（PhysicsHit だけ）
void Update()
{
    // 足元に地面があるか
    if (Physics.Raycast(transform.position, new Vector3(0.0f, -1.0f, 0.0f), out RaycastHit hit, 1.5f))
    {
        Debug.Log("地面: " + hit.gameObject.name);
    }
}

Ray は new Ray(始点, 向き) で作ります（向きは長さ 1 に直されます）。ray.GetPoint(距離) で線の上の位置が分かります。

SceneManager

シーンは名前ではなく、シーンのアセット（GUID）で指定します。インスペクターでシーンを選べる変数を用意して渡します。

名前説明
SceneManager.LoadScene(シーン)そのシーンへ移ります。AssetReference<SceneAsset> か、GUID の文字列を渡します
SceneManager.LoadSceneAsync(シーン)移り、その進み具合を返します。コルーチンで yield return すると、移り終わるまで待てます
SceneManager.ReloadScene()今のシーンを読み直します
SceneManager.ReturnToPreviousScene()1 つ前のシーンへ戻ります
SceneManager.TriggerFlow(イベント名)シーンフロー（.replaysceneflow）に書いたイベントで移ります。移り先をスクリプトに書かずに済みます
  • どれも「移ってほしい」という要求を出すだけで、呼んだその場ではシーンは変わりません。
  • 移り先のシーンは、ディスクに保存されているファイルから読みます。保存していない変更は反映されません。
public AssetReference<SceneAsset> nextScene;

void OnTriggerEnter(Collider other)
{
    SceneManager.LoadScene(nextScene);
}

LoadSceneAsync の戻り値

名前説明
IsDone終わったか（失敗も含む）
Succeeded終わって、成功したか
Progress進み具合（0〜1）
Status結果の状態
SceneGuid成功したときの、今のシーンの GUID

Application

Application.Quit(理由) でゲームの終了を要求します。理由は省けます。

使い方の例

ゴールに触れたら次のステージへ移る

  1. ゴールの GameObject に Collider を付け、Trigger をオンにします。
  2. ゴールに、上の SceneManager の例（nextScene と OnTriggerEnter）のスクリプトを付けます。
  3. インスペクターの Next Scene で、移り先のシーンを選びます。
  4. 移り先のシーンを保存してから Play し、ゴールに触れて確かめます（保存していない変更は移り先に反映されません）。

爆発で周りの物を吹き飛ばす

public float radius = 5.0f;
public float power = 10.0f;

public void Explode()
{
    foreach (var hit in Physics.OverlapSphere(transform.position, radius))
    {
        var body = hit.GetComponent<Rigidbody>();
        if (body == null) continue;
        var direction = (hit.transform.position - transform.position).Normalized;
        body.AddImpulse(direction * power);
    }
}

読み込みが終わるまで待つ

public AssetReference<SceneAsset> nextScene;

IEnumerator LoadNext()
{
    var loading = SceneManager.LoadSceneAsync(nextScene);
    yield return loading;
    Debug.Log(loading.Succeeded ? "読み込みました" : "読み込みに失敗しました");
}

StartCoroutine(LoadNext()); で始めます。待っている間の進み具合は loading.Progress で読めます。
