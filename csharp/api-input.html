入力（Input）

対象：ブランチ sinotake / コミット 9eb9813

キーボード、マウス、ゲームパッドの入力を読むには Input を使います。読み方は 2 通りあります。

  • アクションと軸で読む（おすすめ）：「Jump」「MoveX」のような名前で読みます。どのキーやボタンに割り当てるかは、スクリプトの外（入力アクションのアセット）で決めます。
  • キーやボタンを直接読む：キーコンフィグの画面など、決まったキーを読みたいときに使います。

エディターがキーボードやマウスの入力を使っている間は、どちらも「押されていない」「0」になります。入力は Update で読みます（1 フレームの順番）。

こんなときに使う

  • キャラクターを移動キーやスティックで動かしたいとき（GetAxis）
  • ジャンプなど、ボタンを押した瞬間だけ反応したいとき（GetButtonDown）
  • キーの割り当てとは関係なく、決まったキーを直接読みたいとき（GetKeyDown）
  • ゲームパッドを振動させたいとき（SetVibration）

アクションと軸

名前戻り値説明
Input.GetButton(アクション名)bool押している間 true
Input.GetButtonDown(アクション名)bool押したフレームだけ true
Input.GetButtonUp(アクション名)bool離したフレームだけ true
Input.GetAxis(軸名)float軸の値
Input.GetAction(InputActions.Jump, プレイヤー番号)
GetActionDown、GetActionUp		RuntimeResult<bool>上と同じ意味で、成否付き。値は .Value、成功したかは .Succeeded
Input.GetAxis(InputAxes.MoveX, プレイヤー番号)RuntimeResult<float>同上

エンジン標準のアクション名と軸名は、名前を打ち間違えないよう定数になっています。

定数名前
InputActionsJump、Dash、Menu、UISubmit、UICancel、NavigateUp、NavigateDown、NavigateLeft、NavigateRight、PrimaryClick
InputAxesMoveX、MoveY
Unity との違いInput.GetAxis に渡すのは、Unity の "Horizontal" ではなく、このプロジェクトの軸の名前（例："MoveX"）です。
void Update()
{
    float x = Input.GetAxis("MoveX");
    float z = Input.GetAxis("MoveY");
    transform.Translate(new Vector3(x, 0.0f, z) * (5.0f * Time.deltaTime));

    if (Input.GetButtonDown("Jump"))
    {
        Debug.Log("ジャンプ");
    }
}

キーボードとマウス

名前説明
Input.GetKey(KeyCode.Space)押している間 true
Input.GetKeyDown(キー)、Input.GetKeyUp(キー)押した・離したフレームだけ true
Input.GetMouseButton(0)
GetMouseButtonDown、GetMouseButtonUp		マウスのボタン。0 が左、1 が右、2 が中
Input.mousePositionカーソルの位置（画面の座標）
Input.mouseScrollDeltaホイールの回転量。1 ノッチで 1

KeyCode で使える名前：A〜Z、Alpha0〜Alpha9（数字キー）、Keypad0〜Keypad9、F1〜F12、Space、Return、Escape、Tab、Backspace、Delete、Insert、Home、End、PageUp、PageDown、UpArrow、DownArrow、LeftArrow、RightArrow、LeftShift、RightShift、LeftControl、RightControl、LeftAlt、RightAlt、Mouse0〜Mouse2。

Key という型でも同じように読めます（Input.GetKey(Key.Space)）。Key には、左右を区別しない Shift、Control、Alt や、テンキーの記号もあります。

ゲームパッド

プレイヤー番号を省くと 0（1 人目）です。

名前説明
Input.GamepadConnected(番号)つながっているか
Input.GetGamepadButton(GamepadButton.A)
GetGamepadButtonDown、GetGamepadButtonUp		ボタン。A、B、X、Y、DPadUp、DPadDown、DPadLeft、DPadRight、Start、Back、LeftShoulder、RightShoulder、LeftThumb、RightThumb
Input.GetLeftStick()、Input.GetRightStick()スティック（Vector2、-1〜1）
Input.GetGamepadAxis(GamepadAxis.LeftTrigger)1 本の軸。スティックは -1〜1、トリガーは 0〜1。デッドゾーンの処理は済んでいます
Input.SetVibration(低い振動, 高い振動)振動（0〜1）。自分で止めるまで続きます
Input.StopVibration()振動を止めます

使い方の例

ダッシュボタンを押している間だけ速く動く

void Update()
{
    float speed = Input.GetButton("Dash") ? 10.0f : 5.0f;
    float x = Input.GetAxis("MoveX");
    float z = Input.GetAxis("MoveY");
    transform.Translate(new Vector3(x, 0.0f, z) * (speed * Time.deltaTime));
}

メニューボタンでポーズ画面を開く・閉じる

public GameObject pauseMenu;

void Update()
{
    if (pauseMenu != null && Input.GetButtonDown("Menu"))
    {
        pauseMenu.SetActive(!pauseMenu.activeSelf);
    }
}

インスペクターの Pause Menu で、ポーズ画面の Canvas などを選びます。

ぶつかったときにパッドを少し振動させる

void OnCollisionEnter(Collision collision)
{
    StartCoroutine(Shake());
}

IEnumerator Shake()
{
    Input.SetVibration(0.5f, 0.5f);
    yield return new WaitForSeconds(0.2f);
    Input.StopVibration();
}

IEnumerator を使うので、ファイルの先頭に using System.Collections; を書きます。振動は自分で止めるまで続くので、必ず StopVibration を呼びます。
