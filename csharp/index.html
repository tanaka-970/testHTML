はじめてのスクリプト

対象：ブランチ sinotake / コミット 9eb9813

C# でスクリプトを作り、GameObject に付けて動かすまでを説明します。例として、GameObject を回し続けるスクリプトを作ります。書き方は Unity の MonoBehaviour とほぼ同じです。

こんなときに使う

  • キーやスティックで動かす、数を数える、条件で分けるなど、コンポーネントの設定だけではできない動きを付けたいとき
  • 同じ動きを、いくつもの GameObject で使い回したいとき。変数をインスペクターに出せば、GameObject ごとに値を変えられます
  • ぶつかったとき、ボタンが押されたときなどに、決まった処理を起こしたいとき

1. スクリプトを作る

  1. プロジェクト パネルで、作りたいフォルダー（例：Scripts）を右クリックします。
  2. Create にカーソルを合わせます。開いたメニューの上にある 名前 の欄に、クラス名（例：Spinner）を入力します。
  3. Script > C# Script を選びます。

Spinner.cs ができ、Visual Studio で開きます。ステータスに「C# Behaviour を作成しました。Add Component の Scripts/C# から載せられます: Spinner.cs」と出ます。

項目決まり
クラス名英字か _ で始まり、英字・数字・_ だけでできた名前。日本語や空の名前では作れません
作られる場所右クリックしたフォルダーが Scripts/ の中ならそこ、それ以外なら Scripts/ の直下
ファイル名クラス名.cs。同じ名前のファイルがあると クラス名2.cs のようになります（クラス名は入力したまま）
名前空間Game（メニューの「Namespace: Game」）

作られたファイルの中身です。

using ReplayEngine;

namespace Game;

[ReplayGuid("（作ったときに自動で入る 32 文字）")]
public class Spinner : MonoBehaviour
{
    [SerializeField]
    float speed = 1.0f;

    void Start()
    {
    }

    void Update()
    {
    }
}
ReplayGuid の行は消さない・書き換えないエンジンはこの値とクラス名で、シーンに付けたスクリプトを見分けます。この値やクラス名、名前空間を変えると、すでに GameObject に付けてあるスクリプトが見つからなくなります（状態が Unresolved になります）。

2. 中身を書く

Visual Studio で次のように書き換えて保存します。

using ReplayEngine;

namespace Game;

[ReplayGuid("（そのまま）")]
public class Spinner : MonoBehaviour
{
    [SerializeField]
    float speed = 90.0f;

    void Update()
    {
        transform.Rotate(0.0f, speed * Time.deltaTime, 0.0f);
    }
}

Update は毎フレーム呼ばれます。transform.Rotate は度で回し、Time.deltaTime は前のフレームからの秒数なので、1 秒に speed 度回ります。

3. ビルドする

プロジェクト ウィンドウの C# Scripts の欄で C# をすべて更新 を押します。コンソールに「===== C# 一括更新 終了 (Catalog=OK / Build=OK) =====」と出れば成功です。

自動更新 にチェックが入っていれば、保存しただけで自動でビルドされます。失敗したときは ビルドと、動かないとき を見てください。

4. GameObject に付ける

次のどちらかで付けます。

  • GameObject を選び、インスペクターの Add Component で Script / Scripts/C# を開いて Spinner を選ぶ。
  • プロジェクトパネルの Spinner.cs を、シーンビューの GameObject の上へドラッグ＆ドロップする。GameObject の無い場所へ落とすと、選択中の GameObject に付きます。

インスペクターに「Spinner (Script)」が追加され、Speed の欄が出ます。状態が「Loaded」になっていれば準備完了です。

1 つの GameObject に、スクリプトはいくつでも付けられます。

5. 動かす

Play を押すと回り始めます（再生と停止）。スクリプトは Play 中しか動きません。インスペクターの状態は「Running」になります。

インスペクターに出る変数

クラスに書いた変数のうち、次の条件をすべて満たすものがインスペクターに出て、シーンに保存されます。

  • public である。または [SerializeField] が付いている
  • static でも readonly でもない
  • [NonSerialized] が付いていない

インスペクターで変えた値は、Play を始めたときに Awake より前に変数へ入ります。

Script コンポーネントの項目

スクリプトは、エンジンの Script コンポーネント（Scripting 分類）として付きます。インスペクターには、スクリプトの変数のほかに次の項目があります。

表示名内部名説明
Language__script.language言語（Lua / C#）
Script__script.asset.cs ファイル
Class__script.class名前空間付きのクラス名（例：Game.Spinner）
Execution Order__script.execution_order呼ばれる順番。小さいほど先（呼ばれる順番）

スクリプトの変数は、シーンファイルに field.変数名 という名前で保存されます。1 つの .cs に、[ReplayGuid] を付けたクラスを複数書くこともできます。

.cs をコピーして別のスクリプトを作らないScripts/ の中で、ReplayGuid の値か、名前空間付きのクラス名が 1 つでも重なると、スクリプトの一覧の更新そのものが失敗し、コンソールに「C# Catalog 更新失敗: duplicate C# ReplayGuid …」（クラス名のときは「duplicate C# Behaviour class …」）と出ます。新しいスクリプトは、いつも Create > Script > C# Script で作ってください。
Lua について言語の選択肢に Lua がありますが、このビルドで実行できるのは C# だけです。

使い方の例

移動キーでキャラクターを動かす

  1. プロジェクト パネルの Create で、名前に PlayerMove と入れて Script > C# Script を選びます。
  2. Visual Studio で次のように書き、保存します。ReplayGuid の行は作られたときのままにします。
using ReplayEngine;

namespace Game;

[ReplayGuid("（作ったときの値のまま）")]
public class PlayerMove : MonoBehaviour
{
    [Range(0, 20)]
    [Tooltip("1 秒に進む距離")]
    public float moveSpeed = 5.0f;

    void Update()
    {
        float x = Input.GetAxis("MoveX");
        float z = Input.GetAxis("MoveY");
        transform.Translate(new Vector3(x, 0.0f, z) * (moveSpeed * Time.deltaTime));
    }
}
  1. C# をすべて更新 を押します（自動更新 がオンなら保存しただけでビルドされます）。
  2. 動かしたい GameObject に、Add Component の Script / Scripts/C# から PlayerMove を付けます。インスペクターに Move Speed のスライダーが出ます。
  3. Play を押し、移動キーで動くことを確かめます。速すぎるときは Move Speed を下げます。

MoveX / MoveY にどのキーが割り当たっているかは 入力（Input） を見てください。
