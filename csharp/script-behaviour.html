ScriptBehaviour（ボタン・セーブ・イベント）

対象：ブランチ sinotake / コミット 9eb9813

スクリプトの基底クラスには、MonoBehaviour のほかに、エンジンに古くからある ScriptBehaviour があります。次のことは、このビルドでは ScriptBehaviour を継承したスクリプトでしかできません。

  • UI のボタンが押された、スライダーが動いた、などを受け取る
  • シーンの読み込みやアニメーションの終わりを受け取る
  • セーブデータを読み書きする
  • 決まった秒数のあとに処理を呼ぶ（Timer）、値をなめらかに変える（Tween）

それ以外は MonoBehaviour の方が書きやすいので、上のことが要るスクリプトだけ ScriptBehaviour で書きます。

こんなときに使う

  • タイトル画面などで、UI のボタンが押されたときの処理を書きたいとき
  • スライダーや文字入力の欄が変わったことを受け取りたいとき
  • ハイスコアや設定をファイルに保存し、次に起動したときも残したいとき（セーブデータ）
  • モーションのイベントや、アニメーションの終わりに合わせて処理したいとき
  • 「2 秒後に 1 回」「1 秒ごとに」といった処理や、値をなめらかに変える処理を手軽に書きたいとき（Timer と Tween）

書き方

using ReplayEngine;

namespace Game;

[ReplayGuid("（Create で作ったときの値をそのまま使う）")]
public class TitleMenu : ScriptBehaviour
{
    public override void Start()
    {
    }

    public override void Update(float deltaTime)
    {
    }

    public override void OnAnyButtonClicked(ButtonEventInfo button)
    {
        if (TryFindObject("StartButton", out var start) && button.Button.Equals(start))
        {
            Log("スタートが押された");
        }
    }

    void Log(string text) => Runtime.LogInfo(text, GameObject);
}

Create > Script > C# Script で作ったファイルの : MonoBehaviour を : ScriptBehaviour に書き換えます。MonoBehaviour との違いは次のとおりです。

項目MonoBehaviourScriptBehaviour
メソッドの書き方void Update()public override void Update(float deltaTime)（override が要ります）
FixedUpdate、LateUpdate引数なしfloat の引数あり
自分の GameObjectgameObject（GameObject 型）GameObject（ObjectHandle 型。番号のようなもの）
位置・回転transform.position、角度は度Transform.Position、Transform.LocalRotationEuler（角度は ラジアン）
GameObject を名前で探すGameObject.FindTryFindObject(名前, out handle)、RequireObject(名前)（見つからないと例外）
エンジンの機能静的クラス（Physics など）Runtime から（Runtime.Raycast など）
インスペクターの変数どちらも同じ（インスペクターに出る変数）

呼ばれる順番は MonoBehaviour と同じ です。ScriptBehaviour の StartCoroutine は、呼んだその場では進まず、そのフレームのコルーチンを進める時点で始まります。

受け取れるイベント

受け取りたいものだけ override します。書いたものだけが届きます。

メソッド呼ばれるとき引数で分かること
OnButtonClicked(ButtonEventInfo)自分の GameObject の UI Button が押されたときButton（ボタンの GameObject）、State、PreviousState（0=通常、1=カーソルが乗っている、2=押している、3=押せない）
OnAnyButtonClicked(ButtonEventInfo)どこかの UI Button が押されたとき。メニューを 1 つのスクリプトでまとめて扱うときに使います
OnButtonStateChanged(ButtonEventInfo)自分のボタンの状態が変わったとき
OnSliderValueChanged(SliderEventInfo)自分の UI Slider の値が変わったときValue、NormalizedValue（0〜1）
OnInputFieldValueChanged、OnInputFieldSubmitted、OnInputFieldCanceled（InputFieldEventInfo）自分の UI Input Field の文字が変わった・確定した・取り消したときText
OnAnimationEvent(MotionEventInfo)自分のモーションのイベントに来たときName、Parameter、Time
OnCompositionMarker(MotionEventInfo)自分のコンポジションのマーカーに来たとき
OnAnimationFinished(MotionEventInfo)自分のモーション・コンポジションが最後まで再生されたとき（ループ中は呼ばれません）
OnAnimatorStateChanged(AnimatorStateEventInfo)自分の Animator のステートが変わったときState、PreviousState
OnSceneLoadRequested、OnSceneLoadStarted、OnSceneLoaded、OnSceneLoadFailed、OnBeforeSceneUnload、OnWorldChanged（SceneEventInfo）シーンの切り替えの各段階SceneAssetGuid、Status
OnApplicationQuit(ApplicationQuitEventInfo)ゲームの終了が要求されたときReason
OnCollisionEnter/Stay/Exit(CollisionInfo)自分がぶつかったときOther、OtherValid、ContactPoint、ContactNormal、RelativeVelocity、PenetrationDepth
OnTriggerEnter/Stay/Exit(TriggerInfo)トリガーに入った・出たときOther、OtherValid、SelfIsTrigger（自分がトリガー側か）

GameObject や コンポーネントが無効の間は届きません。

セーブデータ

Runtime から読み書きします。値はまずメモリに置かれ、SaveGame を呼んだときにファイルへ書かれます。

名前説明
Runtime.SetSaveBool(スロット, キー, 値)
SetSaveInt（long）、SetSaveFloat（double）、SetSaveString		値をメモリに置きます
Runtime.GetSaveBool(スロット, キー)
GetSaveInt、GetSaveFloat、GetSaveString		メモリの値を読みます。値は .Value、あったかは .Succeeded
Runtime.HasSaveKey(スロット, キー)、DeleteSaveKeyキーがあるか、キーを消す
Runtime.SaveGame(スロット)そのスロットのメモリの値を、ファイルに書きます
Runtime.LoadGame(スロット)ファイルを読み、そのスロットのメモリの値を置き換えます
Runtime.DeleteSave(スロット)メモリの値とファイルを消します
public override void Start()
{
    if (Runtime.LoadGame("slot1") == RuntimeStatus.Ok)
    {
        var best = Runtime.GetSaveInt("slot1", "best_score");
        if (best.Succeeded) bestScore = best.Value;
    }
}

void SaveBest(long score)
{
    Runtime.SetSaveInt("slot1", "best_score", score);
    Runtime.SaveGame("slot1");
}

スロット名は英字・数字・_・- の 1〜64 文字です。ファイルの場所や上限は セーブデータ（.replaysave） を見てください。

Timer と Tween

名前説明
After(秒, () => { … })秒数のあとに 1 回だけ呼びます
Every(秒, () => { … })秒数ごとに呼び続けます。1 フレームで何回分の時間が過ぎても、呼ぶのは 1 回です
TweenValue(開始, 終了, 秒, v => { … }, Easing.OutQuad)値を秒数かけて開始から終了へ変え、毎フレーム渡します。最後の引数（変わり方）は省けます
戻り値の Cancel()、Finished止める、終わったか
Easing.Linear、InQuad、OutQuad、InOutQuad、InCubic、OutCubic変わり方

どれも Time.timeScale の影響を受け、コルーチンと同じ時点で進みます。

使い方の例

ボタンを押したら次のシーンへ移る

using ReplayEngine;

namespace Game;

[ReplayGuid("（作ったときの値のまま）")]
public class StartButton : ScriptBehaviour
{
    public override void OnButtonClicked(ButtonEventInfo button)
    {
        Runtime.TriggerSceneFlow("Start");
    }
}

このスクリプトを UI Button の GameObject に付けます。移り先は Scene Flow に、Event「Start」の遷移として書いておきます。

モーションの決まった時刻に処理する

  1. Motion Workspace でイベントトラックを足し、イベント名 を「Hit」にしたイベントを置きます。
  2. そのモーションを再生する Motion Player と同じ GameObject に、次のメソッドを持つ ScriptBehaviour を付けます。
public override void OnAnimationEvent(MotionEventInfo motionEvent)
{
    if (motionEvent.Name == "Hit")
    {
        Runtime.LogInfo("Hit のタイミングです", GameObject);
    }
}

2 秒後に 1 回だけ処理する

public override void Start()
{
    After(2.0f, () => Runtime.LogInfo("2 秒たちました", GameObject));
}

ハイスコアを残す書き方は、上の「セーブデータ」の例を見てください。
