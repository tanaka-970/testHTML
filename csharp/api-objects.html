GameObject・Component・Transform

対象：ブランチ sinotake / コミット 9eb9813

シーンの GameObject を探す、作る、消す、コンポーネントを取り出す、位置や回転を変える、といった基本の操作です。すべて using ReplayEngine; で使えます。

こんなときに使う

  • 名前で GameObject を探して、その GameObject を操作したいとき（GameObject.Find）
  • 弾やエフェクトを、プレハブから出したいとき（Object.Instantiate）
  • 倒した敵や、取ったアイテムを消したいとき（Object.Destroy）
  • 同じ GameObject のほかのコンポーネントを使いたいとき（GetComponent）
  • 位置や向きを変える、相手の方を向かせたいとき（Transform）

型のつながり

Object
 ├ GameObject
 └ Component
     ├ Transform
     ├ Behaviour
     │   └ MonoBehaviour（自分で書くスクリプト）
     └ NativeComponent（Rigidbody など、エンジンのコンポーネント）
         └ NativeBehaviour（有効・無効を持つもの）

public AssetReference<PrefabAsset> bullet;   // インスペクターでプレハブを選ぶ

コンポーネントを取り出す・付ける

GameObject とコンポーネントのどちらからでも呼べます。コンポーネントから呼ぶと、付いている GameObject について探します。

名前説明
GetComponent<T>()同じ GameObject から 1 つ取り出します。無ければ null
TryGetComponent<T>(out var c)取り出せたら true
GetComponents<T>()同じ GameObject のものをすべて（配列）
GetComponentInParent<T>()
GetComponentsInParent<T>()		自分から親の方へたどって探します
GetComponentInChildren<T>()
GetComponentsInChildren<T>()		自分から子の方へたどって探します
AddComponent<T>()付けて、付けたものを返します。付けられないと null
  • 親や子をたどるものは、非アクティブの GameObject を飛ばします。引数に true を渡すと非アクティブのものも探します。呼び出した GameObject 自身は、非アクティブでも探します。
  • T に使えるのは、自分で書いたスクリプトのクラス、Transform、エンジンのコンポーネントの型 です。一覧に無いエンジンのコンポーネントは取り出せません。
  • AddComponent<Collider>() は、どの形か決まらないので null になります。BoxCollider などの形の型で付けます。
  • スクリプトを AddComponent したときの Awake や Start は、呼んだその場ではなく、次の区切り（開始の順番）で呼ばれます。
void Start()
{
    var body = GetComponent<Rigidbody>();
    if (body != null)
    {
        body.AddImpulse(new Vector3(0.0f, 5.0f, 0.0f));
    }
}

Translate(移動量, Space.Self)自分の向きの軸で動かします

Unity との違いTranslate(移動量) は、何も指定しないと ワールドの軸 で動きます（Unity は自分の向きの軸）。キャラクターの前へ進めるときは Translate(移動量, Space.Self) と書くか、transform.position += transform.forward * 距離 と書きます。
void Update()
{
    // 前へ進む
    transform.position = transform.position + transform.forward * (2.0f * Time.deltaTime);
}

使い方の例

プレイヤーの方を向き続ける

Transform player;

void Start()
{
    var found = GameObject.Find("Player");
    if (found != null) player = found.transform;
}

void Update()
{
    if (player != null) transform.LookAt(player);
}

シーンに「Player」という名前の GameObject を置いておきます。見つからないとき（名前が違う、非アクティブ）は何もしません。

スペースキーで弾を出す

  1. 弾のプレハブを作り、弾に 3 秒後に自分を消す スクリプトを付けておきます。
  2. 撃つ側の GameObject に、次のスクリプトを付けます。
public AssetReference<PrefabAsset> bullet;

void Update()
{
    if (Input.GetKeyDown(KeyCode.Space))
    {
        Object.Instantiate(bullet, transform.position);
    }
}
  1. インスペクターの Bullet で弾のプレハブを選び、Play でスペースキーを押します。
