2026-10-06 地面を局所的に膨らませる・敵を膨らませて動けなくする・運ぶ／足場／穴あけ

対象：ブランチ sinotake_test / コミット cdc0fd8 ＋ まだコミットしていない変更

チーム制作企画の「地面を膨らませて高くする・坂を作る」「膨らまされた敵は宙に浮いて動けなくなる（足場になる）」「膨らませた物を運ぶ」に向けた追加です。

変わったこと確認
新しい部品 局所膨張。地面や壁にフックを刺して空気を送ると、刺した点のまわりだけが山のように盛り上がる。乗ると一緒に持ち上がる。入れすぎると破裂して土の塊が飛び、上の物を吹き飛ばすビルド後に確認
デモシーンの床を「膨張対象」から「局所膨張」へ付け替え（最大 2.5m、約 5 秒で満杯、満杯の 1.25 倍で破裂）ビルド後に確認
Enemy Behaviour に 3 項目。同じ GameObject の膨張対象が膨らむと、追いかけ・攻撃をやめて浮き、足場になる。空気が抜けると落ちて動き出す。入れすぎると破裂して倒れるビルド後に確認
XPBD変形の膨張対象でも、凸の衝突代理を使わないときは Box・Sphere・Capsule の当たり判定を膨らみに合わせて広げる（膨らんだ敵に乗れるように）ビルド後に確認
デモの操作：R を押している間、刺した物を手元へ引き寄せる（carryStrength・carryHoldDistance）。右クリックで狙った膨張物に穴をあけてしぼませる（punctureSeverity）。上から乗ったときは横から当たったときの 1.6 倍で跳ねる（balloonTopBounceMultiplier）ビルド後に確認

まだやっていないこと

  • 未着手 デモシーンへの敵（フグ）の配置。Enemy Behaviour・NavAgent・膨張対象を付けた敵が必要です
  • 未着手 局所膨張の盛り上がりに穴をあけてしぼませる操作（今は全体が膨らむ物だけ）

2026-10-06 膨張の風船を企画どおりに：均一に膨らむ・浮く・跳ねる・割れる

対象：ブランチ sinotake_test / コミット cdc0fd8 ＋ まだコミットしていない変更（破裂の演出・ホースの巻き取り・ヒットストップ）

チーム制作企画（空気を入れて膨らませ、大きさ・浮力・弾み方を変え、入れすぎると破裂する）に合わせて、膨張と、デモシーン resources/Game/Inflate/Inflate_NativeDemo.replayscene を直しました。

膨らみ方

変わったこと前は確認
XPBD変形の膨張が、元の形のまま均一に大きくなる計算の偏りで一方向だけ伸び（x1.44・y1.13・z2.35 倍など）、形が崩れたビルド後に確認
動的な Rigidbody の膨張対象は、床や壁に触れても形が偏らない。押し返しは Rigidbody の当たり判定が受け持つ触れた面だけ押さえ付けられ、残りが飛び出して溶けたような形になったビルド後に確認
Convex Collider の頂点の元が「メッシュ」でも、膨らんでいる間はケージの形で当たり判定を作り直す（空気が抜けたら元に戻す）頂点の元が「コード指定」でないと当たり判定が膨らまず、見た目だけ大きくなって内圧だけ上がったビルド後に確認
刺さった射出アンカーが、膨らんだ表面に付いていく刺さった位置に残り、膨らむと風船の中に埋まったビルド後に確認
新しい項目「浮く高さの上限」（float_height）。開始位置から上がるほど浮力を弱め、ある高さで漂う膨らむほど浮力が増え、飛んでいったビルド後に確認

破裂

変わったこと前は確認
破裂すると本体を消し、膨らんだ表面を切り分けた膜片が飛び散って床に残る（既定 10 枚・8 秒）。どのモデル（Mesh・Skinned・Primitive）でも、今の形から作る状態が「破裂」になるだけで、膨らんだ形も当たり判定も残った（急に落ちるだけに見えた）ビルド後に確認
穴・傷 → 送気口 → 一番伸びた所、の順で裂け目の起点を決め、そこから裂けたように破片が剥がれ飛ぶ（演出なし）ビルド後に確認
新しい項目：破裂の破片数・破片が残る秒数・破片の固さ・殻の厚み・破裂の中身（空気・液体・粉・爆発）と色・子を中身として残す・破裂の閃光（項目なし）ビルド後に確認
カメラの揺れを、膨らんでいた大きさに比例させた大きさによらず同じビルド後に確認
内圧が破裂圧に届くと破裂する（送気ログで内圧が 7.42 → 破裂圧 7.50 の手前まで上がり、浮いていた風船が落ちることを確認）デモの値では最大体積に先に達し、見た目が止まってから長く押し続けないと割れなかった確認済み

ホース・ラインの描画

変わったこと前は確認
ホースのチューブ（3D ラインの管の描画）を不透明として描く。空を背景にしても消えない半透明として描かれて深度を書かず、空の前では遠景フォグに塗りつぶされて途中で消えたビルド後に確認
Trim 終了が Trim 開始以下（表示範囲が空）の 3D ラインは描かない。チューブにも効くチューブは Trim を見ず、隠したつもりのホースが実行開始時から見えていたビルド後に確認
C#：HosePhysics.endAnchor・endOffset（終点を付ける物と、その物の座標系での位置）終点の付け先はシーンでしか変えられなかったビルド後に確認

デモ（Inflate_NativeDemo と InflationDemoController）

  • ワイヤー（ホース）を銛の矢じりではなく柄尻に結ぶ。発射中は銛の軸が刺さる点に合うように置く。
  • F でホースを巻き取ってフックを銃口へ引き戻す（reelSpeed、既定 25 m/秒）。刺さった風船が割れたときも巻き取る。
  • 送気中に銃口から一直線に出ていた「空気噴射ライン」を出さないようにした。
  • プレイヤーが風船に当たると、膨らみに応じて跳ね返り、風船も押される（balloonBounceMin / Max、balloonPush）。
  • 風船が割れた瞬間に一瞬だけ時間を止める（hitStopSeconds 0.06 秒、hitStopTimeScale 0.05）。
  • 送気中は 0.5 秒ごとに「空気・膨張率・内圧・破裂圧・状態」をコンソールに出す。
  • シーンの 3 つの風船：破裂圧 9.5 → 7.5、危険圧力 8.5 → 6.5、体積浮力 4 → 0、空中揚力 8.5 → 7.4、浮く高さの上限 2.5、反発 0 / 0.9 / 0.45 → 0.3 / 0.8 / 0.7、Rigidbody の空気抵抗 0.4 → 1.2。
