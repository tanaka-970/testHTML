ゲームシーンの設定（ワールド・メインカメラ・描画設定・ポスト処理）

対象：ブランチ sinotake / コミット 9eb9813

階層パネル のいちばん上の「ゲームシーン」には、ワールド、メインカメラ、描画設定、ポスト処理 の 4 つが並びます。どれかをクリックすると、インスペクターにその設定が出ます。GameObject のコンポーネントではなく、エディターと画面全体に関わる設定です。

こんなときに使う

  • プロジェクト設定（起動シーンなど）を開きたいとき（ワールド）
  • シーンビューのカメラが動かなくなった原因を調べたいとき（ワールドの「カメラ操作の関門」）
  • シーンビューのカメラの速さや視野角を変えたいとき（メインカメラ）
  • 影が出ない、SSAO（隙間の影）や反射の効き具合を確かめたいとき（描画設定）
  • 光のにじみ（Bloom）、周辺の暗さ（ビネット）、明るさ（露出）を変えたいとき（ポスト処理）

ワールド

欄働き
Scene / Game 背景色シーンビューとゲームビューの背景の色
ゲームシーンシーンに使える Camera が無いときに、エンジン内部のゲーム用カメラを予備に使うかどうかの切り替えです。ふだんは変える必要はありません
背景画像オンにすると、プロジェクトの resources/screenshot.jpg を背景として敷きます（エディターの表示用。ファイルが無いときは何も起きません）
パーティクルオフにすると Particle Emitter の粒を描かなくなります

プロジェクト設定見出しを開くと、起動シーンなどの設定が出ます（プロジェクト設定）
カメラ操作の関門見出しを開くと、シーンビューのカメラ操作を止めている条件が分かります（下記）

カメラ操作の関門

シーンビューのカメラの見回し・移動・ズームは、次の 7 つの条件のどれにも当てはまらないときだけ始まります。当てはまっている条件は赤く「✕ 条件」、当てはまっていない条件は薄く「○ 条件」と表示されます。

  • ウィンドウが非アクティブ
  • Scene View に hover / focus が無い（マウスが上に無く、選ばれてもいない）
  • UI がマウスを要求（ほかのパネルやメニューがマウスを使っている）
  • UI がキーボードを要求
  • テキスト入力中
  • ポップアップが開いている
  • Gizmo / 範囲選択のドラッグ中

下に「→ 上の ✕ が原因でカメラ操作が止まっています」または「→ 関門は開いています（カメラは操作できる状態）」と出ます。その下の「内訳」は、原因をさらに細かく見るための値です。

メインカメラ

インスペクターの見出しは「カメラ」です。シーンビューで使う編集用のカメラの設定で、ゲームの中のカメラ（Camera コンポーネント）とは別のものです。

Scene Camera

スクリーン空間パス (SSAO / SSR / TAA)

見出し（閉じた状態）を開くと、画面の仕上げの細かい設定が出ます。「効果が見えないときは描画出力を SSAO / SSR に切り替えてバッファそのものを確認してください。」と表示されます。SSAO・SSR・TAA の欄は、マウスを乗せると説明が出ます。キー割り当てを変えると、欄名の横のキーの表示も変わります。

まとまり欄（範囲、既定値へ戻す で入る値）
SSAO (GTAO)：物の接地部や隙間を暗くします有効、探索半径（0.05〜4 m、0.75）、強さ（0〜1、1）、コントラスト（0.5〜4、1.6）、方向スライス数（1〜8、4）、探索ステップ数（2〜12、8）、法線オフセット（0〜2、0.35）、薄物補正（0〜1、1）、フェード開始（1〜400 m、60）、フェード終了（2〜800 m、140）
SSR：画面に映っている物を、金属やつるつるの面に映り込ませます有効、レイ長（1〜200 m、40）、交差の厚み（0.01〜2、0.4）、ステップ幅（1〜16 px、3）、最大マーチ数（4〜64、48）、二分探索回数（0〜8、5）、適用する最大ラフネス（0.05〜1、0.65）、強さ（0〜2、1）、画面端フェード（0.01〜0.4、0.12）、レイ押し出し（0〜4、1）、resolve半径（0〜40 px、12）、resolveタップ数（1〜16、8）

  • SSAO・SSR・TAA の 有効 と、それぞれの数値は、プロジェクト設定に保存されます。影、CSM、タイルドDeferred の欄はプロジェクト設定には保存されません。
  • スクリーン空間パスを既定値へ戻す で、SSAO・SSR・TAA を有効にし、数値を上の表の値に戻します（表に無い SSAO のぼかしもオンに戻ります）。
  • この「既定値」は、新しいプロジェクトを作ったときの値とは一部違います。たとえば新しいプロジェクトでは、交差の厚み 0.55、最大マーチ数 32、二分探索回数 4、適用する最大ラフネス 0.6、画面端フェード 0.08、レイ押し出し 0.001、resolve半径 0、resolveタップ数 1、シャープ化 0 です。ボタンを押すと、上の表の値に変わります。
  • シーンに有効な Post Process Volume があると、SSAO・SSR・TAA のオン・オフ、SSAO の探索半径と強さ、SSR の強さは Volume の値が使われます。SSR のレイ長や TAA の履歴比率など、それ以外の数値はこの画面の値のままです。

ポスト処理

インスペクターに「画面エフェクトスタック」「上から順に処理し、最後に画面へ合成します」と出ます。

欄働き
1. 輝度抽出明るい部分を取り出します（Bloom のもと）
2. Bloom明るい部分を光のようににじませます。オンにすると、輝度抽出 と 最終合成 もオンになります
3. ビネット画面の周りを暗くします。オンにすると 最終合成 もオンになります
4. FXAA輪郭のギザギザをぼかして目立たなくします。オンにすると 最終合成 もオンになります
5. 最終合成上の結果を画面に合成します
輝度しきい値（0〜8）これより明るい部分をにじませます。小さいほど広くにじみます
露出（0〜4）画面全体の明るさ
Bloom強度（0〜4）、ビネット強度（0〜1）、FXAA強度（0〜1）それぞれの効果の強さ

輝度抽出・輝度しきい値・最終合成はプロジェクト設定に保存されます。Bloom はコンソールの bloom on / bloom off でも切り替えられます（コンソール）。シーンに有効な Post Process Volume があると、Bloom・ビネット・露出などは Volume の値が使われます。

使い方の例

影が出ない原因を調べる

  1. 階層パネルの 描画設定 を選び、スクリーン空間パス (SSAO / SSR / TAA) を開きます。
  2. 影 (Shadow) の 動的影を使う がオンか確かめます。
  3. 「このフレームの影」を見ます。「Directional Light なし」なら、シーンに Directional Light を置きます。「キャスターが 0 件です」なら、物の Cast Shadow（影を落とす）や、ライトの影の最遠距離を確かめます（ライト）。

SSAO の効き具合を目で確かめる

  1. 描画設定 の 描画出力 を「SSAO」にします（Ctrl+F2 でも切り替わります）。隙間ほど暗い白黒の画面になります。
  2. スクリーン空間パス の SSAO の 探索半径 や 強さ を変えて、暗さの付き方を見ます。
  3. 終わったら 描画出力 を「最終合成」に戻します。

明るい所をもっと光らせる

  1. ポスト処理 を選び、2. Bloom をオンにします。
  2. 輝度しきい値 を下げると、にじむ範囲が広がります。Bloom強度 を上げると、にじみが強くなります。
  3. 変わらないときは、シーンに Post Process Volume が無いか確かめます。あると Volume の値が優先されます。

シーンビューのカメラが急に動かなくなった

  1. 階層パネルの ワールド を選び、カメラ操作の関門 を開きます。
  2. 赤い ✕ の条件を見ます。「テキスト入力中」なら入力欄から抜ける（Esc や別の場所をクリック）、「ポップアップが開いている」ならメニューを閉じる、といった具合に解消します。
