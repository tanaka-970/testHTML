Input Action Asset（キー割り当てのファイル）

対象：RePlayEngine ソース 08fb8f40（2026-09-24 に実装を確認）

ゲームの中の「操作」（ジャンプ、決定、移動など）と、キーボード・ゲームパッドのボタンを結びつけるファイルです。ファイルを選ぶと、インスペクターでキーの割り当てを書き換えられます。ゲームの C# スクリプトからは、この操作の名前で入力を読みます（入力）。

こんなときに使う

  • ジャンプを Space から別のキーに変えたいとき
  • キーボードと同じ操作を、ゲームパッドのボタンでもできるようにしたいとき
  • 左右の移動を、A / D と矢印キーの両方で行えるようにしたいとき
  • スティックの傾きの、反応しない範囲（デッドゾーン）を調整したいとき

作る

  1. プロジェクトパネルで、作りたいフォルダーを開きます。
  2. Create > Data > Input Action Asset を選びます。名前欄が空なら DefaultInput の名前で、フォルダーにファイルができます。
  3. 作ると、そのファイルが自動でゲームの入力の設定として選ばれ（プロジェクト設定の Input Action Asset）、すぐ使われます。

できたファイルは、いまの標準の割り当てが入った状態で始まります。

書き換える

プロジェクトパネルでファイルを選ぶと、インスペクターに Input Action Asset の欄が出ます。Actions（ボタンの操作）と Axes（左右・前後などの軸）の 2 つの一覧があり、名前をクリックすると、その操作の設定が開きます。

  • 操作の名前は、これまでの互換のために変えられません（追加や名前変更はできません）。割り当てだけを書き換えます。
  • 書き換えるたびに、ファイルへ自動で保存されます。Undo（元に戻す）もできます。
  • 再読み込み ボタンで、保存済みの内容を読み直します。ファイルを外のエディターで書き換えたときも、自動で読み直されます。
  • ゲームの実行中は編集できません（「Play 中は Input Action Asset を編集できません」と出ます）。
  • エディター用・モーション用の操作は、この一覧には出ません。

Actions（ボタン）

項目説明
Action Map操作のグループ名（例：ゲーム中、メニューなど）。文字で入れます
Keyboard Primary (VK)1 つ目のキー。Windows の仮想キーコード（数）で入れます。例：Space は 32、A は 65。0 は「なし」
Keyboard Secondary (VK)2 つ目のキー（同じ操作を別のキーでもできるようにします）
Primary Ctrl / Shift / Alt1 つ目のキーと一緒に押す必要がある修飾キー
Secondary Ctrl / Shift / Alt2 つ目のキーと一緒に押す修飾キー
Gamepad Buttonゲームパッドのボタン。XInput のボタンを表す数で入れます。0 は「なし」。
D-Pad 上 1、下 2、左 4、右 8、Start 16、Back 32、左スティック押し込み 64、右スティック押し込み 128、左ショルダー 256、右ショルダー 512、A 4096、B 8192、X 16384、Y 32768

Axes（軸）

項目説明
Action Mapグループ名
Negative Primary / Secondary軸をマイナス側へ倒すキー（左・後ろなど）。仮想キーコード
Positive Primary / Secondaryプラス側へ倒すキー（右・前など）
Gamepad Axis使うスティックやトリガー。0 なし、1 左スティック X、2 左スティック Y、3 右スティック X、4 右スティック Y、5 左トリガー、6 右トリガー
Dead Zoneスティックの傾きが、この値より小さいときは 0 とみなします（0〜1）。スティックが勝手に動くのを防ぎます

使い方の例

ジャンプを別のキーに変える

  1. プロジェクトパネルで、Input Action Asset のファイルを選びます。
  2. インスペクターの Actions から、ジャンプの操作を開きます。
  3. Keyboard Primary (VK) を、割り当てたいキーのコードに変えます（Space は 32、Enter は 13）。
  4. 保存は自動です。ゲームを実行して確かめます。

ゲームパッドでも操作できるようにする

  1. 操作を開き、Gamepad Button に、上の表のボタンの数（A ボタンなら 4096）を入れます。
  2. 軸（移動など）は、Axes の Gamepad Axis に 1（左スティック X）などを入れます。
キーの一覧が要るとき編集画面の Window > キー割り当て（Window メニュー）は、エディター自体のショートカットを変える別の画面です。このファイルは、ゲームの操作用です。
