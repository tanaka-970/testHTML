頂点カラーペイント

対象：ブランチ sinotake / コミット 9eb9813

頂点カラーペイントは、モデルの頂点ひとつひとつに 0〜1 の値を、シーンビューの上から筆で塗るように書き込む機能です。モデリング Workspace の ワークスペース パネルにあります。塗った値はモデルとは別のファイル（.replayvcolor）に保存され、モデルそのものは書き換えません。

頂点カラーは「色」という名前ですが、見た目の色として直接出るわけではありません。シェーダーが「この頂点は影になりやすい」などの目印として読む値です。

こんなときに使う

  • GGST Toon のマテリアルで、首の下や服のしわなど、光が当たっても影にしておきたい場所を決めたいとき（R チャンネル）
  • 自分のシェーダーで使うための目印の値を、頂点に書き込んでおきたいとき

塗った値がどう使われるか

チャンネル組み込みのシェーダーでの使われ方
RGGST Toon：R が マテリアルの しきい値微調整 より小さい頂点は、光の向きに関係なく影の色になります。R が小さいほど、光の当たる側でも影になりやすくなります。R = 0 ならいつも影です
G、B、Aマテリアルの Shader Stack の 輪郭線 レイヤーが、距離で太さを変える方式のときに読みます。A は太さ（A × 2 倍）、G はカメラからの距離による太さの増し分（1 + G 倍）、B は輪郭線を奥へずらす量です。そのほかの組み込みのシェーダーは読みません

ほかのマテリアル（PBR、Toon、Shader Stack の StylizedCharacter レイヤーなど）では、今の DirectX 12 の描画では頂点カラーは見た目に影響しません。

塗って保存すると輪郭線が変わることがあります塗っていないモデルは G = 0、B = 0、A ≒ 0.5 なので、輪郭線は設定どおりの太さです。頂点カラーペイントは、ファイルが無いモデルをすべて 1（白）から塗り始めます。そのまま保存すると G・B・A も 1 になり、輪郭線レイヤーのあるマテリアルでは、輪郭線が太くなって奥へずれます。輪郭線を使うモデルでは、G を 0、B を 0、A を 0.5 に 一定値で置換 してから保存してください。
塗っていないモデルの値.replayvcolor が無いモデルは、glTF に頂点カラー（COLOR_1、無ければ COLOR_0）が入っていればそれを使います。全頂点が同じ色のものは無いものとして扱います。どちらも無いときは R = 1、G = 0、B = 0、A ≒ 0.5 として描かれます。R が 1 なので、GGST Toon の見た目は変わりません。

塗れる状態にする

次の条件がすべてそろったときだけ塗れます。

条件そろっていないとき
Workspace が モデリングインスペクターの編集テーブルで「モデリング」を選びます（Workspace）
ワークスペースパネルの 頂点カラーペイント がオン下段の ワークスペース タブ（Window > Workspace）で入れます
シーンビューを表示している（ゲームビューではない）表示をシーンに切り替えます
実行中ではない停止します
エディターを表示していて、エディターが入力を受けているF1（エディタ表示）や F3（入力キャプチャ）で戻します（ショートカット一覧）
選んでいる GameObject に、モデルファイルを使う Mesh Renderer か Skinned Mesh Renderer がある「モデルファイルを持つ MeshRenderer / SkinnedMeshRenderer を選択してください。」と出ます。Cube などの組み込みの形は塗れません

準備ができると「白は１、黒は０。Scene View の左ドラッグで選択モデルを塗ります。」と出ます。Landscape（地形）を塗っている途中でオンにしようとすると、「Landscape のストロークを終了してから切り替えてください。」と出てオンになりません。

塗っている間は画面が白黒になります塗れる状態のあいだ、シーンビュー全体が、選んでいるチャンネルの値の濃淡（1 が白、0 が黒）で表示されます。マテリアルの見た目は一時的に消えます。頂点カラーペイント をオフにすると元に戻ります。

パネルの欄

欄既定範囲働き
頂点カラーペイントオフ—塗る機能のオン・オフ
チャンネルRR / G / B / A書き込むチャンネル。ほかのチャンネルの値は変わりません
モード減算加算 / 減算 / 一定値で置換 / ならし塗り方（下の表）
半径（ワールド）0.250.001〜10000筆の大きさ。画面のピクセルではなく、シーンの中の長さです
強さ（毎秒）10〜101 秒あたりに変える量
減衰10.01〜8筆の中心から外側への弱まり方。大きいほど中心だけが強く塗られます
置換値00〜1一定値で置換 のときだけ出ます。近づける値です

対象のモデルを選んでいると、その下に「保存先: 場所」、「未保存の変更あり」か「変更なし」、頂点カラーを保存、頂点カラーを再読込 が出ます。選んでいないときは「モデルを選択し、ペイントをオンにしてください。」です。いちばん下には最後の結果（「対象頂点: 数 / 面: 番号」など）が出ます。

モード

モード動き
加算値を増やします（白に近づく）。押している時間に比例して増えます
減算値を減らします（黒に近づく）
一定値で置換値を 置換値 に近づけます。近づくほどゆっくりになり、行き過ぎません
ならし値を、筆の範囲の中にあるとなりの頂点の平均に近づけます（範囲の中にとなりが無い頂点は変わりません）。境目をぼかすときに使います

1 回に変わる量は「強さ × 経過時間 × 重み」です。重みは「(1 − 中心からの距離 ÷ 半径) の 減衰 乗」で、中心が 1、半径の端が 0 です。経過時間は 1 フレームあたり 0.1 秒までに抑えられるので、重いときに一気に塗られることはありません。値はいつも 0〜1 に収まります。

塗る操作

操作働き
モデルの上にマウスを乗せるカーソルに黄色の小さな円が出ます。円が出ている場所だけ塗れます
左ドラッグ塗ります。ボタンを押してから放すまでが 1 回（1 ストローク）です
Alt+左ドラッグ、右ボタンを押しながらの操作塗らずに、ふだんのカメラ操作になります。塗れる状態のあいだ、Alt なしの左ドラッグはカメラを動かしません
Ctrl を押しながら塗りません
Esc塗っている途中のストロークを取り消し、頂点カラーペイント をオフにします
Ctrl+Z（塗っている途中）そのストロークを取り消します
Ctrl+Z / Ctrl+Y（塗り終えたあと）ストローク 1 回ぶんずつ、元に戻す・やり直す

筆が届く範囲は、マウスが当たった面から、面どうしがつながっている範囲のうち、半径の中にある頂点です。つながっていない別の部品（離れた髪の房など）は、半径の中にあっても塗られません。同じ位置に重なっている頂点（UV の切れ目など）は、まとめて同じ値になります。

塗っている途中で選択を変えたり、チャンネルやモードを変えたり、ペイントをオフにしたりすると、そこでストロークが確定します。

保存と再読込

シーンの保存では保存されません塗った値は、頂点カラーを保存 を押したときだけファイルに書かれます。Ctrl+S（シーンの保存）では保存されません。「未保存の変更あり」と出ていたら、保存を押してください。
ボタン働き表示
頂点カラーを保存モデルの隣に （モデルのファイル名）.replayvcolor を書きます（例：Hero.glb.replayvcolor）。書いたあとに読み直して、色が一致するかを確かめます「保存・色一致を確認しました: 場所」。一致しなければ「保存後の色照合に失敗しました。」
頂点カラーを再読込ファイルの内容に戻します。この操作も Ctrl+Z で元に戻せます「再読込しました: 場所」。ファイルが無ければ「頂点カラーを開けません」
同じモデルを使う物はすべて同じ色になります頂点カラーはモデルのファイルごとに 1 つです。同じモデルを置いた GameObject が複数あると、どれか 1 つで塗っても、全部に同じ値が付きます（パネルにも「同じモデル資産の全インスタンスで色を共有します。」と出ます）。物ごとに変えたいときは、モデルのファイルを複製して別のモデルにします。

うまくいかないとき

表示原因と対処
「頂点カラーの指紋がモデルと一致しません」保存したあとにモデルを作り直し、頂点の数・順番・位置が変わりました。古い .replayvcolor は使えません。ファイルを別の場所へ移してから塗り直します
「CPU メッシュを取得できないか、頂点・インデックスが不正です。」モデルの形のデータを読めません。モデルが正しく表示されているか確かめます
「描画形式の切替で頂点番号が変わったため、ペイントを中止しました。」同じモデルを、Mesh Renderer と Skinned Mesh Renderer の両方で使い分けたなどで、頂点の並びが変わりました。一方だけで塗ります
黄色の円が出ないマウスがモデルに当たっていないか、上の「塗れる状態にする」の条件がそろっていません
塗ったのに見た目が変わらないマテリアルが GGST Toon で、チャンネルが R か確かめます。ほかのマテリアルやチャンネルは見た目に出ません

ファイルの形式

.replayvcolor は、先頭に文字のヘッダーがあり、そのあとに色のバイト列が続くファイルです（版 1）。

行内容
VERTEX_COLOR_VERSION 1形式の版
MESH_COUNT 数中に入っているメッシュの数
MESH 番号 頂点数 インデックス数 ハッシュメッシュごとの「指紋」。ハッシュは頂点の位置から作る 16 桁の 16 進数です。書かれているメッシュが 1 つでもモデルと合わなければ、ファイル全体を読みません。ファイルに書かれていないメッシュは、白（すべて 1）として扱います
COLORS バイト数このあとに、頂点 1 つにつき R・G・B・A の 4 バイトが並びます。合計は 1 GiB までです

手で編集することは考えられていません。壊れていると「頂点カラーのヘッダが不正です」「頂点カラーのファイル長が不正です」などが出ます。

使い方の例

GGST Toon のキャラクターで、首の下をいつも影にする

  1. キャラクターのモデル（.glb）を置き、マテリアルの Shader を GGST Toon にしておきます（マテリアルの編集）。
  2. インスペクターの 編集テーブル で「モデリング」を選び、階層パネルでキャラクターの GameObject を選びます。
  3. 下段の ワークスペース タブで 頂点カラーペイント をオンにします。シーンビューが白黒になり、塗っていなければ全体が白く見えます。
  4. チャンネル を R、モード を「一定値で置換」、置換値 を 0 にします。半径（ワールド） は、首まわりが収まるくらい（例：0.05）にします。
  5. 首の下を左ドラッグでなぞります。黒くなった場所が、いつも影になる場所です。
  6. 境目を柔らかくしたいときは、モード を「ならし」にして境目をなぞります。
  7. 頂点カラーを保存 を押し、「保存・色一致を確認しました」と出たことを確かめます。
  8. 頂点カラーペイント をオフにして、ふだんの見た目で影の出方を確かめます。

塗りすぎた場所を元に戻す

  1. 直前のストロークなら Ctrl+Z で戻します。
  2. 広い範囲を戻したいときは、モード を「一定値で置換」、置換値 を 1 にしてなぞり直します。
  3. 保存したときの状態に全部戻したいときは、頂点カラーを再読込 を押します。
