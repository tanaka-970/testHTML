Prefab（プレハブ）

対象：RePlayEngine ソース 08fb8f40（2026-09-24 に実装を確認）

Prefab は、GameObject（と、その子）をまるごとファイルに保存しておき、何度でも同じ形でシーンに置けるようにする仕組みです。敵、ジャンプ台、木など、同じ物をたくさん置くときに使います。ファイルの拡張子は .replayprefab です。

こんなときに使う

  • 同じ敵や小道具を、シーンのあちこちに置きたいとき
  • 置いた物すべての見た目や設定を、元の Prefab を直して、まとめて変えたいとき
  • 置いた 1 つだけ設定を変えて、ほかは元のままにしたいとき（Overrides）
  • Prefab とのつながりを切って、ただの GameObject に戻したいとき（Unpack）

作る・置く

  • 作る：階層パネルで GameObject を右クリックし、プレハブにする を選びます（階層パネル）。その GameObject が Prefab として保存されます。
  • 置く：階層パネルの プレハブを置く... から、Prefab のファイルを選びます。GameObject を選んでいると、その子として置かれます。

置いた GameObject は、階層パネルで [P]（青）の印が付きます。いちばん上の GameObject は [Prefab] の印です。元のファイルが見つからないと [Missing]（赤）になります。

インスペクターの Prefab 欄

Prefab から置いた GameObject を選ぶと、インスペクターの上のほう（Advanced / IDs の上）に、Prefab の欄が出ます。

表示意味
Prefab Root（青）と Prefab の名前選んでいるのが、Prefab のいちばん上の GameObject です。ここから Apply などの操作ができます
Prefab Instance（青）と Prefab の名前選んでいるのは、Prefab の中の子の GameObject です。Prefab Rootを選択 ボタンで、いちばん上へ移れます。操作はルートで行います
[Missing Prefab]（赤）元の Prefab ファイルが見つかりません
Missing Prefab Root（赤）Prefab のいちばん上の GameObject が見つかりません
No Overrides（緑）元の Prefab と、まったく同じ状態です
Overrides（橙）元の Prefab から変更した所があります。Override Details を開くと、変えた項目の一覧が出ます
Unsupported Nested Prefab（赤）Prefab の中に別の Prefab が入っている形です。現在は未対応で、Apply と Revert は使えません
Overridesを再検証 ボタン元のファイルと比べ直して、上の表示を更新します
Prefab Source Details元のファイルの場所（Path）、AssetGUID、Local ID を表示します

Apply・Revert・Unpack

Prefab Root を選ぶと、3 つのボタンが並びます。ゲームの実行中は使えません（編集できない状態のため）。押すと確認の小窓が開き、何も起きないうちに キャンセル で戻れます。どれも Undo（元に戻す）できます。

ボタン確認の文と、押したあとの動き
Apply「Prefab Asset原本を現在のOverridesで更新します。」置いた GameObject の変更を、元の Prefab ファイルに書き込みます。古いファイルは .bak に退避され、書き込みに失敗したら元へ戻ります。確認窓の Apply Overrides で実行します
Revert「このInstanceのOverridesを破棄してAsset状態へ戻しますか？」変更を捨てて、元の Prefab の状態に戻します。確認窓の Revert Overrides で実行します
Unpack「PrefabとのLinkを解除します。GameObjectは残ります。」Prefab とのつながりを切ります。GameObject はそのまま残り、ただの GameObject になります。確認窓の Unpack Prefab で実行します

使い方の例

敵を Prefab にして、たくさん置く

  1. 敵の GameObject を作って、コンポーネントを付けます。
  2. 階層パネルで敵を右クリックし、プレハブにする を選びます。
  3. プレハブを置く... から、保存した Prefab を選び、シーンに何度か置きます。

1 体だけ強くする

  1. 置いた敵の 1 体を選び、Health の最大体力を上げます。
  2. インスペクターの Prefab 欄が Overrides（橙）になり、Override Details に変えた項目が出ます。ほかの敵は変わりません。

全員を強くする

  1. 強くした敵の Prefab Root を選び、Apply を押して、Apply Overrides で確定します。
  2. 元の Prefab ファイルが更新されます。

変更をやめる

Prefab Root を選び、Revert > Revert Overrides で、元の状態に戻せます。
