シーンを作る・開く・保存する

対象：ブランチ sinotake / コミット 9eb9813

シーンは、GameObject とその設定をまとめて保存したファイル（.replayscene）です。このページでは、シーンの新規作成、開く、保存、保存していない変更の扱い、自動保存からの復旧を説明します。

こんなときに使う

  • 新しいステージを作り始めるとき（New Default Scene、New Empty Scene）
  • 作業を保存して、あとで続きをするとき（Save）
  • 今のシーンをもとに、別のシーンを作りたいとき（Save As...）
  • エディターが途中で落ちたあと、作業を取り戻したいとき（自動保存からの復旧）

今のシーンの名前と未保存の印

階層パネルの GameObject の見出しの下に、今のシーンの名前が表示されます。

  • 一度も保存していないシーンは (未保存のシーン) と表示されます。
  • 保存していない変更があると、名前の最後に * が付きます。

新しいシーンを作る

File メニューから選びます。

項目作られるシーン
New Empty Scene何も入っていないシーン。GameObject もライトもありません。ライトが無いため、オブジェクトを置いてもほとんど真っ暗に見えます。
New Default Scene地形の地面「Ground」と太陽のライト「Sun」が入ったシーン。プロジェクト設定で既定の操作キャラクター Prefab を決めていれば、それも置かれ、操作対象になります。

作ったシーンは「未保存」の状態から始まります。Save か Save As... を選ぶまで、ファイルは作られず、既存のシーンファイルが上書きされることもありません。

シーンを開く

  1. File > Open Scene... を選びます。
  2. Open RePlayEngine Scene という Windows のファイル選択画面が開きます。ファイルの種類は「RePlayEngine Scene (*.replayscene)」と「All Files (*.*)」から選べます。
  3. シーンファイルを選んで開きます。

最近開いたシーンは File > Recent Scenes からも開けます。

結果表示
開けた「読み込みました: （ファイル名）」。読み込み中に問題があったときは後ろに「（警告 N 件）」が付きます。
ファイル選択画面を閉じた「読み込みをキャンセルしました」
開けなかった（壊れている、古い形式など）「読み込めませんでした: （理由）」。今開いているシーンはそのまま残ります。
  • 今のシーンに保存していない変更があると、開く前に未保存のシーンの確認が出ます。
  • ゲームを実行中に別のシーンを開くと、実行は止まります。
  • シーンビューのカメラの位置は、シーンごとに覚えています。前に開いたことのあるシーンは、そのときの視点から始まります。

保存する

操作働き
File > Save（Ctrl+S）今のファイルに上書きします。まだ一度も保存していないシーンでは、保存先を選ぶ画面が開きます。
File > Save As...（Ctrl+Shift+S）保存先と名前を選んで保存します。

保存先を選ぶ画面は Save RePlayEngine Scene です。拡張子を付けずに名前を入れると .replayscene が付きます。同じ名前のファイルがあると、上書きしてよいかを Windows が確認します。

結果表示
保存できた「保存しました: （ファイル名）」。名前の最後の * が消え、Recent Scenes に加わります。
保存先を選ぶ画面を閉じた「保存をキャンセルしました」
保存できなかった「保存に失敗しました: （理由）」
ゲームを実行中「実行中はシーンを保存できません」（保存されません）

未保存のシーンの確認

保存していない変更があるときに、次の操作をすると確認が出ます。

  • New Empty Scene / New Default Scene
  • Open Scene... / Recent Scenes で別のシーンを開く
  • エディターを終了する（File > Exit やウィンドウを閉じる）

確認の画面 未保存のシーン には、「現在のシーンには未保存の変更があります。」、シーン名、「保存してから続行しますか？」（終了のときは「保存してから終了しますか？」）が表示され、下にボタンが並びます。

ボタン（終了のとき）押したとき
保存して続行（保存して終了）今のシーンを上書き保存してから、操作を続けます。
別名で保存保存先を選んで保存してから、操作を続けます。
破棄して続行（破棄して終了）変更を保存せずに捨て、自動保存のファイルも消してから、操作を続けます。
キャンセル何もせずに編集に戻ります。Esc で閉じたときも同じです。
保存に失敗したとき保存に失敗すると、確認の画面は閉じずに、赤い文字で「保存できませんでした」と理由、「別名で保存するか、破棄して終了を選んでください。」が表示されます。

自動保存

保存していない変更があり、ゲームを実行していない間は、60 秒ごとに自動でシーンの控えが保存されます。控えは元のシーンファイルとは別の場所に保存されるので、元のファイルは変わりません。

  • 保存場所：Saved/Autosave/（シーン名）_（数字）.autosave.replayscene（一度も保存していないシーンは「Untitled」という名前）
  • 自分で保存したとき、または確認画面で破棄したときは、控えは消されます。

自動保存からの復旧

シーンを開いたときに、そのシーンファイルより新しい自動保存の控えがあると（エディターが途中で落ちたときなど）、Scene Recovery の確認が出ます。

「A newer autosave was found.」の下に、元のシーンのファイル（Scene）と控えのファイル（Autosave）の場所、控えの中身（「Version N / M GameObjects」）が表示されます。控えが読めないときは、その理由が赤い文字で表示されます。

ボタン押したとき
Recover控えの内容で今のシーンを置き換えます。「Autosaveを復旧しました。Saveで本Sceneへ反映してください」と表示されます。この時点では元のファイルは変わっていないので、残したいときは Save してください。控えが読めないときは押しても何も起きません。
Keep for later控えを残したまま閉じます。「Autosaveを保持しました」と表示されます。
Discard控えを削除します。「Autosaveを破棄しました」と表示されます。

使い方の例

新しいステージを作って保存する

  1. File > New Default Scene を選びます。地面と太陽のライトが入ったシーンができます。
  2. 物を置いてステージを作ります。
  3. Ctrl+S を押します。まだ保存していないシーンなので、保存先を選ぶ画面が開きます。
  4. プロジェクトの resources の中のシーン用のフォルダーを選び、名前を入れて保存します。階層パネルのシーン名が保存した名前になります。

ゲームとして書き出すときの最初のシーンは resources の中にある必要があります（ゲームを書き出す）。

今のシーンを写して別のステージにする

  1. 元にしたいシーンを開きます。
  2. File > Save As...（Ctrl+Shift+S）で、新しい名前を付けて保存します。
  3. これからの編集は、新しい名前のファイルに対して行われます。元のシーンは変わりません。

落ちたあとに作業を取り戻す

  1. エディターを起動し、作業していたシーンを開きます。
  2. 「A newer autosave was found.」の画面が出たら、Recover を押します。
  3. 中身を確かめ、Ctrl+S で本来のシーンファイルに保存します。
