Workspace

対象：ブランチ sinotake / コミット 9eb9813

Workspace は、作業の種類ごとの画面の使い分けです。ゲーム内 UI を作るとき、モーションを作るときなどに切り替えると、その作業に必要なパネルが出ます。エディターは、前回終了したときの Workspace で起動します（その情報は Saved/EditorSession/session.ini に残ります）。

こんなときに使う

  • ゲーム内の UI を作る、モーションを作るなど、作業に合わせて必要なパネルだけを出したいとき
  • UI を作ってから、その UI に動きを付ける、というように作業を行き来するとき
  • パネルを閉じたり動かしたりして、並びが分からなくなったとき（Window > レイアウトを初期化）

Workspace の種類

名前別の呼び方内容
基本Scene Workspace、generalシーンを組み立てる通常の画面です。
配置オブジェクト配置Workspace、placementプロジェクトパネルのモデルや Prefab をシーンビューに置く作業用です。
モデリングモデリングWorkspace、modeling形の編集用です。ワークスペースパネルに頂点ペイントの画面が出ます（頂点カラーペイント）。
アニメーションアニメーションWorkspace、animation準備中の枠です（下の注意を見てください）。
レンダリングレンダリングWorkspace、rendering描画設定を開くための枠です（下の注意を見てください）。
シェーダー調整シェーダー調整Workspace、shaderインスペクターがデバッグメッシュ・画面効果・描画確認の 3 タブに変わります（シェーダー調整 Workspace）。
UIUI Workspaceゲーム内 UI（Canvas、Rect Transform、UI のコンポーネント）を作ります。
MotionMotion Workspace、motionモーション（アニメーション）のキーやプレビューを編集します。

切り替え方

Workspace は次の 4 か所から切り替えられます。場所によって選べるものが違います。いつでもすべてを選べるのは、Window メニューです。

切り替える場所選べる Workspace
インスペクターのいちばん上の 編集テーブル基本、配置、モデリング、アニメーション、レンダリング、シェーダー調整
Window メニューの「〜 Workspaceへ」（Scene、UI、Motion、モデリング、配置、アニメーション、レンダリング、シェーダー調整）8 つすべて（今いるものに ✓）
ツールバーの Search...（機能検索）配置、モデリング、アニメーション、レンダリング、UI、Motion、シェーダー調整（「workspace」などで検索）
コンソールの workspace コマンド基本、配置、モデリング、アニメーション、レンダリング、シェーダー調整、Motion

UI Workspace や Motion Workspace にいるときは、インスペクターの編集テーブルは何も選ばれていない表示になります。基本に戻るには Window > Scene Workspaceへ を使ってください。

ワークスペースパネル

下段の ワークスペース タブ（Window > Workspace）には、今の Workspace の名前と、その Workspace 用のボタンが表示されます。

Workspaceパネルの表示ボタン
基本「基本Workspace」「シーン編集と実行状態の確認を行います。」ワールドを選択：インスペクターにワールドの設定を出します。
配置「オブジェクト配置Workspace」「ProjectのAsset BrowserからModelやPrefabをScene Viewへ配置します。」なし
モデリング「モデリングWorkspace」、頂点ペイントの画面、「形状編集用のテーブルです。配置操作は配置Workspaceへ分離しています。」選択GameObjectを編集：選択中の GameObject をインスペクターに出します。配置Workspaceへ：配置に切り替えます。
アニメーション「アニメーションWorkspace」「今後、タイムラインとアニメーション編集をここへ登録します。」「クリップの割り当てと再生は、対象 GameObject の Animator で編集します。」なし
レンダリング「レンダリングWorkspace」「今後、RenderGraph・シェーダー・Profilerをここへ登録します。」「Renderer: Deferred（固定）」描画設定を開く：インスペクターに描画設定を出します。
シェーダー調整「シェーダー調整Workspace」「右上の専用テーブルで材質、合成順、プリセット、画面効果を編集します。」「方式: 型付きパラメータ + 順序付き追加パス」なし
UI「UI Workspace」「Canvas、RectTransform、UI Component を編集します。」UI 階層を開く、Canvas プレビューを開く
Motion「Motion Workspace」「Motion Asset、キー、プレビューを編集します。」Motion レイヤーを開く、タイムラインを開く
アニメーション・レンダリングは準備中アニメーション Workspace とレンダリング Workspace は、パネルに「今後、…をここへ登録します。」と書かれているとおり、専用の編集画面はまだありません。アニメーションの割り当てと再生は GameObject の Animator コンポーネントで、モーションの編集は Motion Workspace で行います。

Workspace で増える Window メニューの項目

  • UI Workspace：Window メニューに UI 階層、UI インスペクター が増えます。
  • Motion Workspace：Window メニューに Motion レイヤー、Motion プレビュー、Motion インスペクター、タイムライン、グラフエディター が増えます。File > Save はモーションを開いているとき Save Motion になります。

使い方の例

UI を作ってから、動きを付ける

  1. Window > UI Workspaceへ で切り替え、UI を作ります（UI Workspace）。
  2. 動かしたい UI を選び、UI インスペクターのいちばん下の Motion を作成 を押します。Motion Workspace に切り替わります（Motion Workspace）。
  3. モーションを作り終えたら、Window > Scene Workspaceへ で、ふだんの画面に戻ります。

パネルの並びを元に戻す

  1. 今の Workspace のまま、Window > レイアウトを初期化 を選びます。
  2. その Workspace の決まった並び（階層が左、インスペクターが右、など）に戻ります。
