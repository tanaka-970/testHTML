ショートカット一覧

対象：ブランチ sinotake / コミット 9eb9813

エディターで使えるキーボードショートカットの一覧です。表のキーは、キー割り当てを変えていないときの既定の割り当てです。

こんなときに使う

  • 保存、元に戻す、実行など、よく使う操作をキーだけで素早く行いたいとき
  • 使い慣れたキーに、割り当てを変えたいとき（キー割り当て）
  • Delete を押したら思わぬ物が消えた、など、キーがどこに効くかを確かめたいとき

共通のきまり

  • 保存、名前を付けて保存、元に戻す、やり直し、複製、コピー、貼り付け、新規フォルダー、ギズモの切り替え、Delete・Backspace・Enter は、文字の入力欄に入力している間は効きません（文字の入力が優先されます）。
  • 一方、F1〜F5、Shift+F5、F11、F2、Ctrl+F2、Ctrl+F は、入力欄に入力している間も効きます。
  • シーンビューの上にマウスがあり、シーン内の UI の入力欄（Input Field）に入力しているときも、上の 1 つ目のショートカットは効きません。
  • ツールバーの Search...（機能検索）に入力している間は、Ctrl+F 以外のキーは検索欄への入力になります。
  • キーを押し続けたときの連続入力では、同じ操作は繰り返されません。

エディター全体

キー割り当てウィンドウでは Editor の分類に並ぶショートカットです。

名前既定のキー働き
保存Ctrl+Sシーンを保存します。Motion Workspace でモーションを開いているときは、モーションを保存します。
名前を付けて保存Ctrl+Shift+S保存先を選んでシーンを保存します。
元に戻すCtrl+Z直前の操作を取り消します。
やり直しCtrl+Y取り消した操作をやり直します。
複製Ctrl+Dプロジェクトパネルを選んでいてファイルを選択しているときは、そのファイルを複製します。それ以外では、選択中の GameObject を複製します。Motion Workspace では GameObject は複製されません。
コピーCtrl+C選択中の GameObject をコピーし、「GameObject をコピーしました」と表示します。子もまとめてコピーされます。親と子を両方選んでいるときは、親の側だけがコピーされます（子が 2 回入ることはありません）。一度にコピーできるのは 100,000 個までです。プロジェクトパネルを選んでいるときと、Motion Workspace では GameObject はコピーされません。ゲームの実行中もコピーはできます。
貼り付けCtrl+Vコピーした GameObject を貼り付けます。GameObject を選択していれば、最初に選んだものの子として貼り付けます。名前の末尾には「 コピー」が付き、同じ名前があるときは重ならない名前になります。貼り付けたものが選択され、「（数） 個を貼り付けました」と表示されます。ゲームの実行中は貼り付けられず、「停止してから貼り付けてください。」と表示されます。プロジェクトパネルを選んでいるときと、Motion Workspace では GameObject は貼り付けられません。
新規フォルダーCtrl+Shift+Nプロジェクトパネルを選んでいるとき、今のフォルダに「New Folder」を作り、すぐ名前の変更を始めます。
検索Ctrl+Fツールバーの Search...（機能検索）に入力できる状態にします。
移動ギズモShift+Wギズモを Move にします。GameObject を選択しているときだけ効きます。
回転ギズモShift+Eギズモを Rotate にします。条件は同上です。
拡縮ギズモShift+Rギズモを Scale にします。条件は同上です。
名前変更F2プロジェクトパネルを選んでいてファイルを選択しているときは、そのファイルの名前変更を始めます。GameObject を選択しているときは、その GameObject の名前変更を始めます。
描画出力切り替えCtrl+F2画面に出す描画結果（描画の途中段階）を順番に切り替えます。
エディタ表示F1エディターの画面（メニューやパネル）の表示・非表示を切り替えます。
入力キャプチャF3エディターを表示しているときに、エディターの入力キャプチャを切り替えます。
プロファイラF4Profiler / 描画統計 (F4) ウィンドウの表示・非表示を切り替えます。
実行F5ゲームを実行します。実行中や準備中は何もしません。
停止Shift+F5実行を止めて編集に戻ります。実行していないときは「停止する Play Session はありません」と表示されます。
全画面F11 または Alt+Enter全画面表示を切り替えます。

割り当てを変えられないキー

キー働き
Delete / Backspace何を消すかは、その時の状態で次の順に決まります。
  1. スプライトアトラスの編集画面を操作しているとき：アトラスの領域を消します。
  2. Motion Workspace のとき：モーションのキーを消します（GameObject は消えません）。
  3. プロジェクトパネルを選んでいて、ファイルを選択しているとき：そのファイルの削除確認を出します。
  4. インスペクターが GameObject を表示しているとき：選択中の GameObject を削除します。
Enterプロジェクトパネルを選んでいて、ファイルかフォルダを選択しているとき、それを開きます（ダブルクリックと同じ）。
Escギズモのドラッグ中は操作を取り消します。カメラのドラッグ中は操作を止めます。単体表示中は単体表示を終わります。
Delete / Backspace で GameObject が消えることがありますインスペクターに GameObject が表示されている状態では、どのパネルを選んでいても、文字を入力していなければ Delete や Backspace で選択中の GameObject が削除されます。インスペクターで数値や文字を消すつもりのときは、入力欄に入力している状態（カーソルが点滅している状態）になっているか確かめてください。消してしまったときは Ctrl+Z で戻せます。

シーンビューのカメラ

カメラの移動や回転のキー（W A S D、F、テンキーなど）は、このキー割り当てではなく、カメラ操作プリセット で決まります。一覧はシーンビューとカメラ操作を見てください。

キー割り当てを変える

Window > キー割り当て で キー割り当て ウィンドウを開きます。

ウィンドウのいちばん上に、名前で絞り込み の入力欄、保存 ボタン、既定へ戻す ボタンが並びます。その下に、分類（Editor、Motion、UI など）ごとの見出しがあり、中に操作の名前が並びます。

操作（Actions）1 つにつき、次の欄が 1 行に並びます。

  • 主キー と 副キー：今のキーが書かれたボタンです。どちらのキーを押しても、その操作になります。
  • ゲームパッド：ゲームパッドのボタンを選ぶ欄です。

移動のように両方向がある操作（Axes）では、負1、負2、正1、正2 のキーと、ゲームパッド軸、デッドゾーン（0.00〜0.95）が並びます。

キーを変える手順

  1. 変えたい操作の 主キー か 副キー のボタンを押します。ボタンの文字が「キーを押してください」に変わり、上に「（名前）: キーを押してください（Esc で取り消し）」と表示されます。
  2. 割り当てたいキーを押します。Ctrl、Shift、Alt を押しながらキーを押すと、組み合わせで割り当てられます。Ctrl などを 1 つだけ押して離すと、そのキーだけが割り当てられます。マウスのボタンも割り当てられます。
  3. 上に「未保存の変更があります」と表示されます。この時点で、エディターではもう新しいキーが効きます。
  4. 保存 を押します。「Saved/Editor/InputBindings.ini に保存しました」と表示され、次に起動したときも同じ割り当てになります。

キーを押す前に Esc を押すと、「キーの入力を取り消しました」と表示され、元のままになります。

同じ分類の中で、ほかの操作と同じキーを割り当てると、その操作の下に橙で「警告: 同じキーが Action: （名前） にも割り当てられています」と表示されます。

既定へ戻す既定へ戻す を押すと、すべての割り当てがこのページの表の状態に戻り、「既定の割り当てへ戻しました（未保存）」と表示されます。ファイルにも残したいときは、続けて 保存 を押してください。

割り当ては Saved/Editor/InputBindings.ini に保存されます。Saved フォルダは人ごとの設定なので、チームのほかの人の割り当てには影響しません。

使い方の例

実行のキーを変える

  1. Window > キー割り当て を開きます。
  2. 名前で絞り込み に「実行」と入れます。
  3. 実行 の 主キー のボタンを押し、「キーを押してください」と出たら、割り当てたいキーを押します。
  4. 橙の「警告: 同じキーが …」が出ていないか確かめ、保存 を押します。

割り当てを最初の状態に戻す

  1. キー割り当て ウィンドウの 既定へ戻す を押します。
  2. 保存 を押して、次に起動したときも既定のままにします。
