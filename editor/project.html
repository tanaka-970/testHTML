プロジェクトパネル

対象：ブランチ sinotake / コミット 9eb9813

画面下段の プロジェクト タブには、プロジェクトのフォルダとファイル（アセット）が並びます。モデル、シーン、マテリアル、スクリプトなどを探す、作る、名前を変える、移動する、シーンに置く、といった操作をここで行います。

下段にタブが見えないときは、Window > Project / Assets か 作成 > プロジェクトを開く で表示できます。

こんなときに使う

  • モデル、画像、音などの素材を探して、シーンに置きたいとき
  • マテリアル、モーション、スクリプトなど、新しいアセットを作りたいとき（Create）
  • 使っていないファイルを片付けたいとき（削除。使っている所があると警告が出ます）
  • エクスプローラーで足したファイルを、エディターに認識させたいとき（Refresh Assets）

パネルの並び

上から次の順に並びます。

  1. パンくず：Project ボタンの右に、今開いているフォルダまでの道筋が「/」区切りのボタンで並びます。ボタンを押すと、そのフォルダに戻ります。
  2. 操作の行：左から Search Project...（検索欄）、種類の絞り込み（既定は All）、□ グリッド、アイコンの大きさのスライダー（48〜160 px）、Refresh Assets ボタン。
  3. 左：フォルダのツリー。いちばん上が Project（黄色の文字）で、フォルダとファイルが同じツリーに並びます。
  4. 右：今のフォルダの中身。アイコンと名前が並びます。
  5. Missing Assets (N)：登録されているのにファイルが見つからないアセットがあるときだけ出ます。開くと「[Missing] 名前」とファイルの場所が並びます。
  6. メッセージ：直前の操作の結果（「resources を更新しました: N件追加」など）。

左のツリーと右の中身の間のすき間をつかんで左右にドラッグすると、ツリーの幅を変えられます（ツリーは 150 ピクセルより狭くなりません）。

探す・絞り込む

  • Search Project... に文字を入れると、今のフォルダだけでなくプロジェクト全体から、名前にその文字を含むファイルが右側に並びます。英字の大文字と小文字は区別しません。
  • 種類の絞り込みで、右側に出すファイルの種類を 1 つに絞れます。フォルダは絞り込みに関係なく表示されます。

Refresh Assets は、エクスプローラーなどでエンジンの外から resources フォルダにファイルを足したときに押します。新しいファイルが登録され、「resources を更新しました: N件追加」と表示されます。

右側の表示

  • □ グリッド にチェックがあると、アイコンが横に並びます。無いと 1 列に並びます。
  • 画像ファイルはサムネイルで、それ以外は種類ごとの色の付いたアイコンで表示されます。イージングカーブはカーブの形が描かれます。
  • 名前が 18 文字より長いときは、17 文字で切って「..」が付きます。マウスを乗せるとファイルの場所が表示されます。
  • 選択中のファイルは名前が黄色になり、インスペクターにそのアセットの情報が出ます。
  • 表示できる物が無いフォルダでは「このフォルダには表示できる項目がありません」と表示されます。

作る（Create）

  1. 右側の何もない場所を右クリックします（ファイルやフォルダの上で右クリックしても、いちばん上に同じ Create があります）。
  2. Create にマウスを乗せます。「作成先: （フォルダ名）」が表示されるので、作る場所を確かめます。
  3. 名前 の欄に名前を入れます。
  4. 作りたい種類を選びます。
分類項目
Folder（ショートカット Ctrl+Shift+N）
Script ▶C# Script（下に作られる名前空間が表示されます）
Animation ▶Motion Asset、Motion Composition
UI / Presentation ▶Sprite Atlas、Effect Preset、イージングカーブ
Data ▶Material、Scene Flow、Localization Table、Input Action Asset
Shader ▶Surface Shader、Water Shader (HLSL)（水面用の HLSL。Water Body の Material で使います）、Layer Shader、Shader Composer ▶（Surface、Water、Layer、PostProcess。Shader Composer）

削除

削除を選ぶと Project Asset を削除 の確認が出ます。

  • 「ゴミ箱へ移動します: （場所）」
  • そのアセットを使っている物があるときは、橙で「この Asset を参照している項目があります:」と一覧（最大 24 件）
  • フォルダのときは「フォルダ内:」と中身の一覧

ゴミ箱へ移動 を押すと、ファイルはすぐには消えず、プロジェクト内のゴミ箱に移されます。「Project Trashへ移動しました: （名前）（参照GUIDは保持 / Ctrl+Zで復元）」と表示され、Ctrl+Z で元に戻せます。

ファイル・フォルダ右側のフォルダのアイコン、または左ツリーの Projectそのフォルダへ移動します。

使い方の例

モデルを探してシーンに置く

  1. 種類の絞り込みで Model を選び、Search Project... に名前の一部を入れます。
  2. 見つかったモデルを、シーンビューのシーンタブへドラッグして離します。マウスの下の位置に置かれます。

マテリアルを作って物に付ける

  1. マテリアルを置きたいフォルダの右側の何もない場所を右クリックし、Create にマウスを乗せます。
  2. 名前 の欄に名前を入れ、Data > Material を選びます。
  3. できたマテリアルを選び、インスペクターで色やシェーダーを決めます。
  4. マテリアルを、階層パネルかシーンビューの GameObject の上へドラッグして付けます（マテリアルを付ける）。

エクスプローラーで足した画像を使えるようにする

  1. エクスプローラーで、画像ファイルをプロジェクトの resources の中にコピーします。
  2. プロジェクトパネルの Refresh Assets を押します。
  3. 「resources を更新しました: N件追加」と出て、画像がパネルに表示されます。
