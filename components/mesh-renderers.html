メッシュの描画（Mesh / Primitive / Skinned Mesh Renderer）

対象：ブランチ sinotake / コミット 9eb9813

形を画面に表示するコンポーネントは 3 種類あります。どれも GameObject の Transform の位置・回転・拡大率で表示されます。プロパティの多くが共通なので、このページでまとめて説明します。

コンポーネント表示するもの使う場面
Mesh Renderer取り込んだモデルファイル建物、小物など、動かないモデル
Primitive Mesh Rendererエンジンに入っている形（Plane、Cube、Sphere、Capsule、Cylinder、Quad）床や仮置きの箱など、モデルファイルが要らない形
Skinned Mesh Renderer骨やアニメーションの入ったモデルファイルキャラクターなど、Animator で動かすモデル

こんなときに使う

  • 取り込んだモデル（建物、小物など）をシーンに表示したいとき（Mesh Renderer）
  • 床や仮置きの箱など、エンジンに入っている形を置きたいとき（Primitive Mesh Renderer）
  • 骨の入ったキャラクターを表示して、アニメーションさせたいとき（Skinned Mesh Renderer）
  • 物の色や質感を、マテリアルで変えたいとき
  • 物が表示されない、赤紫になる、といったときに原因を調べたいとき

基本情報

項目内容
コンポーネントを追加での場所Rendering > Mesh Renderer、Rendering > Primitive Mesh Renderer、Rendering > Skinned Mesh Renderer
必須・推奨なし
表示される場面エディターのシーンビューと、ゲームの実行中の両方

置き方

形だけを置く（Primitive Mesh Renderer）

階層パネルの + 作成 > 3D Object から形を選ぶと、Transform と Primitive Mesh Renderer が付いた GameObject が作られます。階層パネルを見てください。

モデルを置く（Mesh Renderer / Skinned Mesh Renderer）

  1. プロジェクトパネルでモデルのアセットを探します。
  2. アセットをシーンビューにドラッグして離します。またはアセットを選んで、プロジェクトパネルの下の 選択AssetをSceneへ配置 を押します。
  3. アセットの名前の GameObject が作られ、選択されます。「Assetを配置しました: （名前）」と表示されます。

付くコンポーネントは、モデルの中身で決まります。

モデルの中身付くコンポーネント
骨もアニメーションも無いMesh Renderer
骨があるSkinned Mesh Renderer
アニメーションがあるSkinned Mesh Renderer と Animator（Animator の 旧: 待機クリップ が 0 になり、最初のアニメーションが流れます）

置かれる位置は次のとおりです。

  • シーンビューにドロップしたとき：マウスの下の場所。ほかの GameObject の上に落とすと、その GameObject の子になります。
  • 選択AssetをSceneへ配置 を押したとき：シーンビューのカメラの 5 m 前。
  • ツールバーの Snap にチェックがあるときは、位置が刻みに丸められます。

プロジェクトパネルの SceneへModel配置時にMesh Colliderも追加 にチェックを付けておくと、置くときに当たり判定の Mesh Collider も付きます（形は表示中のモデルを使い、衝突レイヤーは Environment になります）。

ゲームの実行中は置けません（「Play中はAssetを配置できません」と表示されます）。

使い方の例：雨で濡れた床にする

  1. 床の Mesh Renderer（または Primitive Mesh Renderer）を選びます。
  2. 濡れ量 を 0.8 にします。床がつるつるになり、少し暗くなります。
  3. 水たまりのように、濡れる場所を絞りたいときは、頂点カラーペイントで濡らしたい所を塗り、濡れマスク を「頂点カラー R」などに変えます。
  4. ゲーム中に雨を降らせたいときは、Runtime濡れ をオンにして、雨の強さ を上げます。

使い方の例：壁の色を頂点カラーで塗り分ける

  1. 頂点カラーペイントで、モデルの好きな所に色を塗ります。
  2. Renderer の 頂点カラーを色として使う をオンにします。塗った色がベースカラーに掛かります。

マテリアルと色の決まり方

状態色・光の当たり方
マテリアル が空色 と 描画方式 で表示します。輪郭線 もこのときだけ効きます。
マテリアル を指定、マテリアル上書き がオフマテリアルの色、金属度、粗さ、光の当たり方を使います。このコンポーネントの 色 と 描画方式 は使われません。
マテリアル を指定、マテリアル上書き がオン光の当たり方とテクスチャはマテリアルのものを使い、色・金属度・粗さ・環境遮蔽・発光・両面描画は マテリアル上書きの値 を使います。さらに 色 が掛けられます。

マテリアルのシェーダーが見つからないときは、形がマゼンタ（赤紫）で表示され、コンソールに「Material Shader を解決できないため Unlit/Magenta へフォールバック」というエラーが出ます。

マテリアルを付ける

  • インスペクターの マテリアル の欄で選びます。
  • プロジェクトパネルのマテリアルを、階層パネルやシーンビューの GameObject の上にドロップします。何も無い場所に落としたときは、選択中の GameObject に付きます。付けると マテリアル上書き はオフになり、「Materialを割り当てました: （名前）」と表示されます。
ドロップで付けられるのは Mesh Renderer と Skinned Mesh Renderer だけですPrimitive Mesh Renderer しか無い GameObject にマテリアルをドロップすると、「選択GameObjectにMesh Rendererがありません」と表示され、付きません。Primitive Mesh Renderer にはインスペクターの マテリアル の欄で指定してください。

マテリアルスロット

モデルは、部分ごと（顔、服、髪など）に別のマテリアルを使えます。この部分の区切りをスロットと呼びます。

GameObject を 1 つだけ選んでいるとき、インスペクターの コンポーネントを追加 ボタンより下に「Mesh Renderer マテリアルスロット」（Primitive、Skinned も同様）という見出しと、「空スロットは既存の「マテリアル」へフォールバックします」という薄い文字が表示されます。その下にスロットが「Slot 1 （部分の名前）」の形で並びます。Mesh Renderer と Skinned Mesh Renderer ではモデルに入っている部分の数だけ（最大 32）、Primitive Mesh Renderer では 1 つだけです。

スロットを開くと、次の欄があります。

欄空のときの表示説明
名前（番号）番スロットの名前。Enter を押すか、ほかの場所をクリックすると決まります。
マテリアル(material_asset を使用)この部分だけに使うマテリアル。空なら上の マテリアル を使います。どちらも空のときは「共通も未設定なら FBX 材質」と表示され、モデルファイルに入っている材質を使います。
ベースカラー（色）(モデルのまま)色の画像を差し替えます。
法線マップ（凹凸）(モデルのまま)凹凸の画像を差し替えます。
ORM（AO・粗さ・金属）(モデルのまま)影の付きやすさ・粗さ・金属度をまとめた画像を差し替えます。
エミッシブ（発光）(モデルのまま)光る部分の画像を差し替えます。

画像を指定すると、欄の左に小さな見本が表示されます。見本にマウスを乗せると大きく表示されます。スロットの順番は、コンポーネントと同じように ◆ をドラッグして変えられます。

Skinned Mesh Renderer と Animator

Skinned Mesh Renderer は、同じ GameObject に付いている Animator から、再生中のアニメーションと時間を受け取って姿勢を決めます。

  • Animator が有効：アニメーションに合わせて動きます。
  • Animator が無効：表示は続きますが、そのときの姿勢で止まります。
  • Animator が無い：アニメーションをかけない基本の姿勢で表示されます。

glTF モデルの制限

このビルドで glTF（.glb / .gltf）を読むときの制限です。Blender や Babylon.js では正しく見えるのに、エンジンでは崩れるときに確かめてください。

制限起きること当てはまりやすいモデル
片面の設定が効かないマテリアルの 両面を描く がオフでも、面の裏側まで描かれます。ふつうのモデルは見た目が変わりませんが、黒い外殻を少し大きく重ねて輪郭線を出すモデルは、外殻の手前側が本体を覆い、黒いシルエットの中に目や線だけが見える状態になりますSketchfab から落としたアニメ調のモデル（マテリアル名が OH_Outline_Material などの黒いメッシュを持つもの）
骨は 256 本まで骨が 256 本を超えるモデルは、257 本目以降の骨の動きが伝わりません。止まっているときは正しく見えますが、アニメーションを再生したり骨のポーズを変えたりすると、その骨に付いた頂点が元の位置に取り残され、メッシュが裂けたり伸びたりします髪や服に揺れ用の骨を多く持つキャラクター（数百本の骨を持つもの）
1 頂点の骨は 4 本までJOINTS_0 / WEIGHTS_0 だけを読みます。5 本目以降の骨（JOINTS_1 以降）の重みは、警告なしに捨てられます書き出しで影響する骨の数を 4 本に制限していないモデル
モーフは 1 つ目だけモーフターゲット（表情などの形の変化）は 1 つ目だけを使います。アニメーションでモーフの重みを動かすと、ターゲットが 2 つ以上あるモデルでは値がずれます表情のモーフを持つモデル
アニメーションの無いモデルのリグ表示シーンビューの リグ 表示で、骨がモデルの体に沿わず、足元に平たく広がって表示されます。モデルの見た目は正しいままです。入れ物のノードに回転や拡大が入っているモデルで起きますSketchfab から落としたモデルなど、ルートに軸の向きを変えるノードがあるもの

テクスチャ（PNG・JPEG）やマテリアルスロットの数（32 まで）は、これらの崩れの原因にはなりません。

表示されないとき

  • 表示 がオフになっていないか。
  • GameObject やコンポーネントの有効のチェックが外れていないか（親が無効でも表示されません）。
  • Mesh Renderer・Skinned Mesh Renderer の メッシュ が空でないか。
  • 大きさが極端に大きい・小さい、または向きがずれていないか（モデル縮尺倍率、表示姿勢補正 を確かめます）。
  • 黒いシルエットに覆われて一部しか見えないとき、アニメーションで裂けるときは、glTF モデルの制限 に当てはまっていないか。マテリアルを外しても症状が変わらないなら、テクスチャやマテリアルの問題ではありません。

使い方の例

モデルを置いて、マテリアルを付ける

  1. プロジェクトパネルでモデルを探し、シーンビューへドラッグして置きます。
  2. プロジェクトパネルのマテリアルを、置いたモデルの上へドラッグして付けます。
  3. 色だけをこのモデルで変えたいときは、マテリアル上書き をオンにして、マテリアル色 を変えます。

大きさや向きがおかしいモデルを直す

  1. センチメートル単位で作られたモデルがとても大きく出るときは、モデル縮尺倍率 を (0.01, 0.01, 0.01) にします。
  2. 原点がずれていて足元が埋まるときは、モデル位置オフセット で見た目だけをずらします。GameObject の位置は変わりません。

仮の床を置く

  1. 階層パネルの + 作成 > 3D Object > Plane を選びます。
  2. Transform の 拡大率 を (10, 1, 10) などにして広げます。
  3. 上に物を置いて物理で落とすときは、床に Box Collider も付けます（物理）。
