State

対象：ブランチ sinotake / コミット 9eb9813

「通常」「選択中」「開いている」のような、名前の付いた状態を持たせるコンポーネントです。状態が変わると、そのことを Motion Player などに知らせます。状態ごとに違うモーションを再生したいときに使います。

こんなときに使う

  • 「開いている」「閉じている」のような状態を持たせ、状態ごとに違う動きを再生したいとき（Motion Player と組み合わせます）
  • 状態が変わったことを、ほかのコンポーネントやスクリプトに知らせたいとき

基本情報

項目内容
コンポーネントを追加での場所Core > State
必須・推奨なし

プロパティ

表示名内部名種類既定値範囲説明
状態の数state_count整数22〜16持たせる状態の数。増やすと下に状態の欄が増えます
現在の状態current_state文字State0今の状態の名前。シーンファイルには保存されません
状態名（State 1、State 2、…の見出しの中）states[番号].name文字State0、State1、…それぞれの状態の名前。Motion Player の状態トリガーが、この名前を参照します
  • 状態の数を増やすと、新しい状態の名前は「State（番号）」になります。番号は 0 から数えます。
  • 現在の状態に、状態の一覧に無い名前が入っているときは、最初の状態に戻ります。

状態が変わったとき

現在の状態が別の名前に変わると、エンジンに StateChanged というイベントが送られます。イベントには、前の状態の名前と新しい状態の名前が入ります。同じ名前を入れ直したとき、一覧に無い名前を入れようとしたときは、状態は変わらず、イベントも送られません。

使い方

  1. 状態を持たせたい GameObject に コンポーネントを追加 > Core > State を付けます。
  2. 状態の数 を決め、それぞれの 状態名 を分かりやすい名前（例：Idle、Open）に変えます。
  3. Motion Player のトリガーを「状態が変わった」にし、反応させたい状態の名前を入れます。
  4. ゲームの実行中に、スクリプトなどから現在の状態を変えると、対応するモーションが再生されます。
