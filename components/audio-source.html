Audio Source

対象：ブランチ sinotake / コミット 9eb9813

音を鳴らすコンポーネントです。WAV・MP3 の音源や CRI キューを指定して、BGM や効果音を再生します。1 つの GameObject にいくつでも付けられます。

こんなときに使う

  • BGM を流したいとき
  • ボタンを押したとき、ぶつかったときなどに効果音を鳴らしたいとき
  • 滝や機械の音のように、決まった場所から聞こえる音（3D の音）を置きたいとき

基本情報

項目内容
コンポーネントを追加での場所Audio > Audio Source
1 つの GameObject にいくつでも付けられます
必須・推奨なし
鳴る場面ゲームの実行中だけ。エディターで編集しているときは鳴りません
使える音声ファイルWAV・MP3。CRI キューは CRI のライブラリとキューシートが必要

3D の音の聞こえ方

  • Audio Listener からの距離が Min Distance 以下なら、Volume どおりの音量です。
  • Min Distance から Max Distance にかけて、距離に比例してまっすぐ小さくなり、Max Distance で 0 になります。
  • Audio Listener から見て右にある音は右から、左にある音は左から聞こえます。左右に振り分けるのはモノラル（1 チャンネル）の WAV だけで、ステレオの WAV は距離による音量だけが変わります。
  • 有効な Audio Listener が無いときは、3D にしていても距離や左右の変化は付きません。
最初の自動再生に失敗したときPlay On Start の再生は、成功したかに関係なく 1 回だけ試します。そのときに Clip Path が間違っていた、音声が使えなかったなどで鳴らなかった場合、同じコンポーネントが有効な間は自動では鳴らし直しません。スクリプトから Play を呼ぶか、コンポーネントを一度無効にしてから有効にしてください。

使い方

ゲームを始めたら BGM を鳴らす

  1. WAV または MP3 ファイルを resources フォルダの中に置きます。
  2. 空の GameObject を作り、コンポーネントを追加 > Audio > Audio Source を付けます。
  3. Clip Path にファイルの場所（例：resources/Sounds/bgm.wav）を入れます。
  4. Loop と Play On Start をオンにします。
  5. ゲームを実行すると鳴り始めます。停止すると止まります。

モーションに合わせて鳴らす

モーションのイベントで、この GameObject に次の名前のイベントを送ると、Audio Source を操作できます。

イベント名働き
PlaySound鳴らします。イベントに値（parameter）を付けると、Clip Path の代わりにその値のファイルを鳴らします（Clip Path は変わりません）。Loop がオンのときは、その音もくり返します
StopSound止めます

注意

  • ファイルが開けない、または WAV として読めないときは、音は鳴らず、デバッグ出力に「[Audio] WAV open failed: …」や「[Audio] Unsupported WAV header: …」と 1 回だけ表示されます。
  • MP3 は対応しています。OGG や未対応の形式は、読み込み可否を個別に確認してください。
  • Clip Path はファイルの場所です。音源アセットを選んだ場合はその参照を優先します。Clip Path を直接指定した場合、ファイルの名前や場所を変えたときは書き直してください。
  • コンポーネントを無効にしたり、ゲームを停止したりすると、鳴っている音は止まります。

CRI Audio Source・CRI Audio Listener（開発中、2026-10-13 追加）

CRI ADX のサウンドを鳴らす部品です。ACB キューシートとキュー名を指定して再生します。通常の Audio Source も音源アセットや ACB を指定できます。聞く位置は CRI Audio Listener（Transform の位置と回転を使う）です。

制限チームで開発中の部品です。CRI ADX LE のライブラリ（ThirdParty\CRI\libs\x64\cri_ware_pcx64_le_import.lib と cri_ware_pcx64_le.dll）が無い環境では、音を鳴らさない版でビルドされます（ビルド時に警告が出ます）。CRI ADX LE SDK の pc\libs\x64 から 2 つのファイルをこのフォルダへ置くと有効になります。キューシートの読み込み方法は、まだ整備中です。

音楽・音響の使い方

曲を選んで試聴する

  1. GameObject に Audio Source を追加し、Inspector の音源の一覧を開きます。一覧は最初から開いており、プロジェクトの音声アセットと resources 内の WAV・WAVE・MP3・ACB が表示されます。
  2. 曲をクリックして選んだ曲を試聴を押します。試聴を止めるで停止します。曲名で絞り込む（任意）、最近選んだ音だけ、一覧を更新、ファイルから探すも使えます。最近の選択はこの起動中の直近12件です。
  3. この曲に決定で音源を割り当てます。WAV・MP3 は一覧のダブルクリックでも決定できます。ACB はキューを選んでから決定します。キューが読めない場合は ACF を選びます。
  4. BGM なら音の種類を BGM、Spatial を 2D、Loop とPlay On Startをオンにします。再生開始位置、フェードイン・フェードアウト秒、同じ種類の音を切り替える設定も必要に応じて指定します。

音源一覧に表示されない場合はファイルから探すを使います。一覧の探索には件数上限があり、上限に達すると Inspector に表示されます。CRI の試聴と再生には対応ライブラリと ACB／ACF が必要です。

音源ごとの調整

Inspector の項目使い方
音の種類BGM・SE・ボイス・環境音・UI から選択。Audio Mixer の種類別音量が適用されます。
左右のパン（2D）−1 は左、0 は中央、1 は右。3D の左右は音源の位置から決まります。
高音の通り方／低音を削る量音をこもらせたり、低音を抑えたりします。
反響の送り先／反響への追加送り量ACF の DSP バスと送り量を指定します。反響の種類はバス側で設定します。
ドップラーの強さ（3D）移動速度に応じて音程を変えます。0 で無効です。
ミュート／フェードイン秒／フェードアウト秒／再生開始位置（秒）再生時の音量・入り方・止まり方・開始位置を指定します。
同じ種類の音を切り替える再生開始時、同じ種類で鳴っている音をフェードアウトします。BGM の切り替えに使います。

全体と種類別の音量

シーンに Audio Mixer を追加すると、全体・BGM・SE・ボイス・環境音・UI の音量と全体ミュートをまとめて設定できます。複数ある場合は優先度が高いものを使います。CRI の共通 ACF と DSP 設定名も指定できます。

場所ごとの響きと遮音

Audio Environment Zone は箱または球の範囲を置き、室内・洞窟・水中・カスタムの音響を設定します。聞く位置が入ると音量、高音、反響が境界幅と変化時間に応じて切り替わります。2D の BGM にも適用する設定があります。

Audio Acoustics は 3D 音源と Audio Listener の間のコライダーを調べ、壁越しの音量と高音を調整します。水面下では水中音響へ自動切り替えできます。音源側の壁越しの遮音対象（3D）をオンにし、調べるレイヤーと最大距離を設定します。
