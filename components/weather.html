雨・雪・雷

対象：sinotake_test / cf1faf7f まで。コード確認のみ、実機未確認。

Rendering > 雨・雪・雷 コンポーネントが降水と雷を描きます。空の天候プリセットを選ぶだけでは雨粒・雪粒・稲妻は出ません。この部品は空がなくても使えます。複数置いた場合は優先度が高い一つを使います。

雨・雪を降らせる

  1. GameObject に 雨・雪・雷を追加します。
  2. 空の天候プリセット（雨・雪・みぞれ・雷雨）に合わせるなら空の天候に連動をオンにします。空がない場合や空が「個別設定」の場合は、この部品の降らせる種類と降水の強さが使われます。
  3. 粒の量、描画範囲（m）、粒の大きさ、粒の明るさを調整します。みぞれではみぞれの雪の割合も指定できます。
  4. 風を空に合わせるなら空の風に連動をオンにします。空がなければ風の向き（X・Z）と風速（m/s）を設定します。

粒数の上限も変更できます。見えないときは、部品が有効か、降水の強さと粒の量が 0 ではないか、カメラが描画範囲内にあるかを確認します。空に連動している場合は空の天候プリセットも確認してください。

濡れと水面

雨で物体を濡らすは、プロジェクトの実行時の濡れ設定が有効な場合に働きます。雪だけなら雨の濡れは加えません。最大の濡れ、雨の水面波紋、波紋の強さを調整できます。地面に雪を積もらせて足跡を残す機能は別の積雪・足跡です。

雷

雷を有効化するか、空の雷雨に連動をオンにして空を雷雨にします。雷の間隔・明るさ・距離・高さ・太さ・乱数シードを調整できます。雷で周囲を照らす、雲があれば雲底から落とすも切り替えられます。雲底を使わない場合は稲妻の高さを使います。
