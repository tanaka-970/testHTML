ツタ（Ivy Generator）

対象：ブランチ sinotake_test / コミット d7164091（コードから書いた内容。実機での確認はまだ）

モデル・基本形状・地形の表面にツタを生やすコンポーネントです。屋上の縁から垂らす、壁を這わせる、地面を這わせる、の 3 通りの生え方があり、茎と葉は 1 つのメッシュにまとめて描きます。膨張などで形が変わっても追従します。コンポーネントを追加の一覧では「ツタ」という名前です。

こんなときに使う

  • 廃墟のビルの屋上から、ツタを垂らしたい
  • 壁や柱にツタを這わせたい。這わせる道筋はマウスでなぞって決めたい
  • 地面に這うツルや、花の混じった草むらを置きたい
  • 膨らむ風船や敵にツタを絡ませ、膨らんでもツタが表面に付いたままにしたい

項目内容
コンポーネントを追加での場所Rendering > ツタ

ツタを生やす

  1. ツタを生やしたい建物・壁・岩などの GameObject を選ぶ（Mesh Renderer か Primitive Mesh Renderer が付いているもの）
  2. インスペクターの「コンポーネントを追加」から Rendering > ツタ を付ける。既定は「生成モード：両方」で、上向きの縁から垂れ下がり、壁にも這います
  3. 「株の密度（本/m）」で本数、「最大成長距離(m)」で 1 本の長さを決める
  4. 「成長段階」を 0〜1 で動かすと、生えていく途中の姿になります。Motion でキーを打てば、伸びていく演出になります
  5. 葉の色は「葉A: 色」、茎の色は「茎の色」、先の若葉は「若葉の色」「若葉の範囲」で合わせる

別の GameObject（例：ツタだけを管理する空の GameObject）にツタを付けて、「生やす相手」に建物を入れても構いません。空なら自分自身に生えます。

生成モード

モード生え方向く場面
垂れ下がり上向きの面の縁から、重力の向きへ垂れ下がる。「壁から離す距離」「垂れる茎のうねり」が効く屋上・ベランダ・崖の上
壁面追従面に沿って這い上がる・横へ広がるビルの壁・柱・岩肌
両方（既定）垂れ下がりと壁面追従を両方行うまず試すとき
地面を這う上向きの面に沿って広がる地面・床・屋根の上

地形（ハイトフィールド）に生やす

ハイトフィールドの Landscape は広すぎるので、生やす範囲を「ランドスケープの範囲の中心(XZ)」と「ランドスケープの範囲の一辺(m)」（既定 30m）で決めます。範囲の中だけが計算の対象になります。

なぞって道筋を決める（ブラシ）

自動で置かれる種では狙った所に生えないときは、シーンビューでなぞって決めます。

  1. ツタの「ブラシ」の分類で「ブラシの種類」を選ぶ
    • なぞった線に沿って這わせる（既定）：なぞった線そのものが茎になります。表面に当たらない所は、カメラに向いた面の上に点を置くので、空中に垂らす線も描けます
    • なぞった所に種を置く：なぞった所に「種の間隔(m)」ごとに種を置き、そこから自動で伸びます
  2. 「ブラシで種を置く（Shiftで消す、Escで終了）」をオンにする
  3. シーンビューで対象の表面を左ドラッグでなぞる。Shift を押しながらなぞると、「消す半径(m)」の中の種と線を消します（線の途中が消えると 2 本に分かれます）
  4. Esc でブラシを終える。なぞった線と種はシーンに保存されます

数値で直接書くこともできます。種は「手で置く種」に x,y,z; x,y,z、線は「なぞった線」に x,y,z; x,y,z | x,y,z; ...（| で線を区切る）の形で、どちらも生やす相手のローカル座標です。手で置く種が空なら、種は自動で置かれます。

葉の種類（葉A・葉B・葉C）

葉は 3 種類まで混ぜられます。既定では葉A（ツタの葉）だけが使われ、葉B（丸）と葉C（花）はオフです。「出現の重み」の比で混ざります。

葉にモデルを使う（素材）

計算の形では物足りないとき、自分で作った葉のモデルを使えます。

  1. 葉 1 枚のモデル（glb など）を用意する。+X 方向が葉の長さ方向で、長さ 1m になるように作る（付け根が原点）
  2. そのモデルをシーンに置き、Mesh Renderer で表示できる状態にする（非表示の場所に置いても構いません）
  3. 「葉A: 葉にするモデル」にその GameObject を入れる。形が読めるまでの間は、組み込みの形で描きます

膨張・アニメーションへの追従

  • 「膨張などの変形に追従する」（既定オン）：膨張などで表面が動くと、ツタも付いていきます。「変形で作り直す最小の動き(m)」（既定 0.005）より小さい動きでは作り直さないので、少しの揺れでは重くなりません
  • 「Skinned のアニメに追従する（重い）」（既定オフ）：骨で動くキャラクターに生やすとき。毎フレーム形を取り直すので重く、必要な所だけオンにします

C# スクリプトから変える

IvyGeneratorComponent に Enabled・Mode・Seed・Growth・LeafDensity・MaxLength・BranchProbability・ManualSeeds があります。伸びていく演出は Growth を少しずつ上げます。

public override void Update(float deltaTime)
{
    if (TryGetComponent<IvyGeneratorComponent>(out var ivy))
        ivy.Growth = Math.Min(1.0f, ivy.Growth + deltaTime * 0.2f);
}

重さの目安

  • 重さは葉の数で決まります。まず「葉の上限」と「葉の細かさ」を下げます。
  • 「株の密度」「最大成長距離」「分岐確率」を変えると成長の計算をやり直します。色・成長段階を変えてもやり直しません。
  • Skinned のアニメへの追従は毎フレーム作り直すので、遠くに置くものではオフにします。
