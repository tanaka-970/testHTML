破壊（欠損・破砕・切断・カット・風船）

対象：ブランチ sinotake_test / コミット 28995f39（破壊の入口の統合・破壊フィールド・開いたメッシュの欠損）。コードから書いた内容で、実機での確認はまだです

モデルに欠けを焼き込む、事前に割った破片を爆発や衝突でばらばらにする、ゲーム中に剣で切る、編集中に物体を 2 つに切り分ける、風船を割る、といった表現を作る部品のまとめです。2026-10-24 から、壊される側の部品は 破壊 コンポーネント 1 つにまとまりました。このページでは組み合わせ方と試し方を説明します。各項目の既定値・範囲・C# API は 破壊系リファレンス にまとめています。

こんなときに使う

  • 壁や柱に、弾痕・欠け・崩れを最初から付けておきたいとき（欠損）
  • 爆発や衝突で、壁・柱・岩をばらばらに崩したいとき（事前破砕 ＋ 破壊する側・破壊フィールド）
  • 剣やレーザーが通った位置でモデルを切り分けたいとき（実行時切断 ＋ 斬撃）
  • レベルを作るときに、物体を 2 つの別のオブジェクトに切り分けたいとき（カット）
  • 最初から崩れた状態の建物を置きたいとき（壊れた状態で始める）
  • 土台を残して上だけ崩したいとき（固定）
  • 浮かんで揺れ、つつくと割れて、近くの風船も連鎖で割れる風船を置きたいとき（風船）

破壊コンポーネントと 4 つの機能

壊される側には コンポーネントを追加 > Destruction > 破壊 を付けます。インスペクターの「破壊」の中に、次の 4 つの機能が並びます。できることはそれぞれ別なので、必要なものだけを付けます。1 つの物に、欠けた形を事前破砕で割り、さらに斬撃で切る、のように重ねて使えます。

機能できることいつ起きるか付け方
欠損（Sculpt）形に欠け・穴・えぐれを焼き込む。断面は塞がれ、中身が詰まった見た目になるエディタで形を作って保存。ゲーム中は読むだけ「欠損を付ける」ボタン
事前破砕（Blast）事前に割った破片が、ダメージや衝突でつながりごと外れて物理で飛ぶゲーム中Destruction Editor の「かんたん設定」で破片を作る
実行時切断（Slice）刃などの平面で、その場で 2 つに切り分けるゲーム中「実行時切断（Slice）」のチェック
カット（エディタ）シーンビューで線を引いて、物体を別々の GameObject に切り分ける編集中「Scene View で線を引いて切る」ボタン

材質・密度・断面マテリアル・破片の寿命・演出の音量などの共通の設定は、「破壊」の上側で 1 回だけ決めます。ここで決めた値は毎フレーム各機能へ配られるので、機能ごとの欄には出ません。機能ごとの欄には、その機能だけの設定が出ます。

前に作ったシーン以前の Destructible・Sliceable・Damage Sculpt が付いた物は、エディタで開くと自動で「破壊」が付き、設定が引き継がれます（シーンは変更ありになるので保存してください）。実行時の動きは今までと同じです。スクリプトから使う型名（DestructibleComponent・SliceableComponent）も変わっていません。

壊す側との組み合わせ

作りたいもの壊される側壊す側
剣で切れる物Renderer ＋ 破壊（実行時切断）刃の GameObject に 斬撃。振るときにスクリプトで BeginSwing()
爆弾で崩れる壁Renderer ＋ Collider ＋ 破壊（事前破砕）Rigidbody ＋ Collider ＋ 破壊する側（接触時に爆発）、または 破壊フィールド（爆発）
物をぶつけると壊れる像Renderer ＋ Collider ＋ 破壊（事前破砕）。「衝突で壊れる」はオン重めの Rigidbody ＋ Collider
土台を残して崩れる塔破壊（事前破砕）＋「下から固定する高さの割合」何でも
最初から崩れている建物破壊（事前破砕）＋「壊れた状態で始める」なし
浮かぶ風船Sphere などの形 ＋ Rigidbody（動的）＋ Sphere Collider ＋ 風船斬撃、破壊する側、爆発、ぶつかる物
割れると爆発する樽破壊（事前破砕）＋ 破壊材質（破壊時に破裂）何でも（最初の 1 回を壊せばよい）

何が何に効くかは 破壊系リファレンス：何が何に効くか を見てください。破壊する側・爆発・破壊フィールドは、実行時切断には効きません（切れるのは斬撃・スクリプトの Slice()・Destruction Editor の試験ボタンだけです）。

試す前の準備

  1. 新しいシーンを作り、床を置きます。階層パネルの + 作成 > 3D Object > Cube で作って平たく広げ（例：拡大率 20, 0.2, 20）、Box Collider を付けます。
  2. 壊す物はモデルファイル（.glb など）をプロジェクトパネルからシーンビューへドラッグして置きます。Cube や Sphere（Primitive Mesh Renderer）でも使えます。
  3. 置いた物を選び、コンポーネントを追加 > Destruction > 破壊 を付けます。
どんなモデルでも使えます欠損と実行時切断は、閉じていないモデル（服のすき間、首の継ぎ目）や、部品が重なっているモデルでも使えます。開いた切り口も端をつないで塞ぎます。事前破砕の割れ方を作るときも、開いた所の補修を試してから割ります。アニメーションするモデル（Skinned Mesh）や地形は、欄の「現在の形状を固定して編集」で今の形を固めてから使います。

欠損（Sculpt）：形に欠けを焼き込む

削り具（箱・球・岩のような欠け・平面）を置いた形でモデルを削り、結果を resources/DamageBakes/ にベイクします。ゲーム中は保存した形を読むだけなので、重くなりません。

  1. 「破壊」の欄で 欠損を付ける を押します。アニメーションするモデルや地形では、代わりに 現在の形状を固定して編集 を押します（元のアニメーションや地形の設定は消えずに無効のまま残ります）。
  2. プリセットのボタン（角欠け・貫通穴・えぐれ・崩れ）を押すと、形の大きさに合わせた削り具が 1 つ増えます。少し待つと形が変わります。
  3. 削り具の Scene View ギズモ を押すと、シーンビューに輪郭と移動・回転・拡縮のギズモが出ます。ドラッグして位置を合わせます。
  4. 削り具ごとに 形（Jagged＝岩のような欠け、Box＝箱、Sphere＝球、Plane＝平面で切る）、凸凹、欠片の数（Jagged）を変えられます。別の形 を押すと乱数が変わり、同じ大きさで違う欠け方になります。

削ってできた断面は、断面マテリアルが空なら、切り口に接している外側と同じ材質で描きます。中まで同じ物が詰まった塊に見えます。断面だけ別の見た目にしたいときは「破壊」の 断面マテリアル を指定します。

状態の行に「閉じていない形・重なりのある形として面ごとに削りました。」と出たときは、開いたメッシュ向けの削り方を使っています。綺麗に閉じたモデルは、立体として厳密に削る従来の削り方を使います。「断面を作れず穴の壁を張れなかった面が N 枚あります。」と出たときは、その面だけ壁がありません。削り具を少し動かすと直ることがあります。

事前破砕（Blast）：割れて飛ぶ

かんたん設定で壊せるようにする

  1. Window > Destruction Editor を開き、かんたん設定 タブを選びます（「破壊」の欄の 破片を作って事前破砕を付ける でも開きます）。
  2. 割れ方（標準・木・繊維・ガラス・陶器・金属）と 破片数（4〜32、既定 8）を選び、このモデルを壊せるようにする を押します。
  3. 破片の作成が終わると、resources/Destruction/ に .replaydestruction が保存され、事前破砕・Convex Collider・Rigidbody（静的）が自動で付きます。割れ方に合った密度と衝撃しきい値も入ります。
  4. F5 で実行し、物をぶつけるか、階層・接続 タブの Blast Damageを試す を押します（編集中でも、物理 ON のプレビュー中なら試せます）。

欠損を付けた後に破片を作ると、欠けた形のまま割れます。破片を作った後に欠損を変えると、「破壊」の欄に作り直しの案内が出ます。

割れ方を細かく決める（生成タブ）

  1. Destruction Editor の 生成 タブの「破壊パターン」で、割れ方 を選びます。細胞状・衝撃放射・層割れ・木・繊維に沿う裂け・ガラス・放射ひび・陶器・不規則片・鉄板・帯状破断の 7 種類です。
  2. 分割の細かさ（軽量 8・標準 16・細かい 32）か 破片数（2〜128）を決めます。詳細設定 では、2段目の破片数、乱数シード、衝撃点、割れの方向（層割れ・木・ガラス・鉄板）、繊維に沿う裂けの長さ、Bond の強さを変えられます。
  3. 破壊パターンをプレビュー を押すと、シーンビューに破片を少し離した展開図が出ます。
  4. 破壊 Asset の名前 を入れ、プロジェクトパネルで保存先のフォルダーを開いてから プレビュー結果を破壊 Asset に保存 を押します。事前破砕の「Destruction Asset」に割り当てます。

土台を残す（固定）

「破壊」の 下から固定する高さの割合 を 0.2 にすると、モデルの下から高さの 2 割に中心がある破片は、壊れても動かずに静的な当たり判定でその場に残ります。決まった場所だけ残したいときは、破壊フィールド の「固定（Anchor）」で範囲を置きます。固定された破片は、動く破片の上限（動的Actor上限）を使いません。

壊れた状態で始める

「破壊」の 壊れた状態で始める をオンにすると、シーンの開始時に物体全体を包む範囲へ 1 回ダメージを与え、割れて崩れた状態から始まります。崩れ方は 開始時のダメージ（既定 1000）と 開始時ダメージの広さ（既定 1 で物体全体）で調整します。事前破砕が付いていない物には効きません。

実行時切断（Slice）：ゲーム中に切る

  1. 「破壊」の欄で 実行時切断（Slice） にチェックを入れます。
  2. Destruction Editor の 診断 タブの「切断メッシュ診断」で、水平（Y）・縦（X）・縦（Z） を押すか、Local Plane 法線 と Local Plane 距離 を変えて、シーンビューの橙色の面を切りたい位置に合わせます。
  3. F5 で実行し、同じ物を選んで 実切断を試す を押します。「切断完了。Sceneに2つの破片を反映しました。」と出て、2 つに分かれて落ちます。

続けて押すと、選んでいる方をさらに切れます（切断Cooldown 0.15 秒、最大破片数 16 まで）。新しくできた破片は 6 秒たつか、止まってから 1.5 秒で縮んで消えます。動くキャラクター（Skinned Mesh）も、表示中の姿勢で固まった破片になります。

カット（エディタ）：編集中に切り分ける

  1. 切りたい物を選び、「破壊」の欄の Scene View で線を引いて切る を押します。
  2. シーンビューで物体をまたぐように左ドラッグします。その線と視線の向きでできる平面で、真っ直ぐ切ります。
  3. 切れた片は別々の GameObject（「〇〇 切片1」「〇〇 切片2」）になり、元の物体は非表示で残ります。Ctrl+Z で元に戻せます。いらない片は Delete で消します。
  4. 続けて線を引くと、選ばれている片をさらに切ります。複数を選んでいると、全部を同じ面で切ります。

見た目が子にあるモデルも、子の部品ごと同じ面で切ります。切り口は塞がれ、片には欠損の Plane 削り具が入るので、あとから切り口の位置を動かせます。

破壊フィールド

コンポーネントを追加 > Destruction > 破壊フィールド を空の GameObject に付けると、その位置から破壊へ働きかけます（Unreal の Chaos の Field に当たる仕組みです）。1 つの GameObject に何個でも付けられます。

種類働き
歪み（ダメージ）範囲の中の壊せる物へダメージを与える。風船も割れる
力（押し出し）範囲の中の動く物体を外へ押し出す
爆発（両方）ダメージと押し出しを同時に与える（既定）
固定（Anchor）範囲の中に中心がある破片を、壊れてもその場に残す。常に効いている
消去（破片を片付ける）範囲の中の破片を縮めて消す

発動 は、開始時に 1 回・一定間隔で繰り返す・手動（スクリプトから Fire()）から選びます。形 は球か箱で、箱は GameObject の回転と拡縮に合わせます。ダメージと押し出しは、箱でも箱を包む球の範囲に届きます。

試し方：玉をぶつけて壊す

  1. 事前破砕を付けた物に、上から玉を落とします。階層パネルの + 作成 > 3D Object > Sphere で玉を作り、真上 3〜5 m に置いて、Sphere Collider と Rigidbody（動的）を付けます。
  2. 次のどちらかで試します。
    • 衝突で壊す：玉の Rigidbody の 質量 を 50 にします。事前破砕の「衝突で壊れる」は既定でオンです。
    • 破壊する側で壊す：玉に コンポーネントを追加 > Destruction > 破壊する側 を付けます。
  3. F5 で実行します。玉が当たった所が崩れます。

「衝突で壊れる」の Damage は、(衝撃 − 衝撃しきい値 150) × 衝撃ダメージ倍率 0.05 です。衝撃は「近づく速さ × 質量」なので、軽い物で壊したいときは衝撃しきい値を下げます。破壊する側は速さや重さに関係なく、触れるたびに接触Damage（既定 200）を与えます。

試し方：爆弾で崩し、周りも巻き込む

  1. 玉の 破壊する側 で 接触時に爆発 をオンにします。
  2. 近く（5 m 以内）に、別の壊せる物・風船・動的な Rigidbody の箱を置いておきます。
  3. F5 で実行します。玉が触れた瞬間に爆発し、半径 5 m の中の事前破砕に Damage（中心で 300）、風船を割り、動的な Rigidbody を外へ押し出します。

爆弾を使わずに決まった時刻に爆発させたいときは、破壊フィールドの「爆発（両方）」を置き、発動を「開始時に1回」にして「開始までの遅れ（秒）」を決めます。

試し方：風船を浮かべて割る

  1. + 作成 > 3D Object > Sphere で作り、Sphere Collider、Rigidbody（動的）、コンポーネントを追加 > Destruction > 風船 を付けます。
  2. これを 1 m ほど離して 4〜5 個並べます（Ctrl+D で複製）。
  3. 風船の上 3 m ほどに「針」にする小さな Cube を置き、破壊する側 を付けます。
  4. 連鎖を見たいときは、全部の風船の 連鎖圧力 を 1 にします。
  5. F5 で実行します。針に近づいた風船が割れ、連鎖圧力が 1 なら破裂半径の中の風船が次々に割れます。

試し方：斬撃で切る

斬撃は実行を始めると判定がオフに戻るので、BeginSwing() を呼ぶ短いスクリプトが 1 つ要ります。刃を Rotator で回して、周りのモデルを水平に切ります。

  1. 実行時切断を付けたモデルを用意します。
  2. 空の GameObject「Blade」を作り、モデルと同じ位置で、切りたい高さに置きます。コンポーネントを追加 > Gameplay > Rotator を付け、回転速度 を 360 にします。
  3. Blade に コンポーネントを追加 > Destruction > 斬撃 を付け、刃の根元 を 0, 0, 0、刃の先端 を 2, 0, 0 にします。
  4. 次のスクリプトを作って Blade に付けます。 
    using ReplayEngine;

namespace Game;

[ReplayGuid("（作ったときの値をそのまま使う）")]
public class SwingOnStart : MonoBehaviour
{
    bool started;

    void Update()
    {
        if (started) return;
        var blade = GetComponent<BladeSlicer>();
        if (blade != null)
        {
            blade.BeginSwing(); // 最初のフレームで振り始める
            started = true;
        }
    }
}
  5. F5 で実行します。刃が通った高さでモデルが水平に切れます。

1 回の振り（BeginSwing() から EndSwing() まで）では、同じ対象は 1 回だけ、合わせて 4 個まで切ります。刃の通り道の風船は割れ、事前破砕には「先端の速さ × 斬撃Damage倍率」の Damage が入ります。

破壊材質で音・演出・破裂を付ける

  1. プロジェクトパネルの何もない所を右クリックし、Create > Data > 破壊材質 で作ります。
  2. 作ったファイルを選び、組み込み演出 の 演出スタイル を「爆発」、破片を赤熱発光 をオンにします。
  3. 破裂 の 破壊時に破裂 をオン、破片の外向き速度 を 6、破裂爆発半径 を 4、破裂爆発Damage を 100 にします。
  4. 「破壊」の 破壊材質 にこのファイルを割り当てます。
  5. F5 で実行して壊すと、爆発の演出とカメラの揺れ・衝撃波が出て、赤く光る破片が飛び、近くの物も巻き込まれます。

Destruction Editor の かんたん設定 タブの「硬い殻の破裂」にある 一度だけ破裂する材質を作成して割り当て でも、破裂する材質を 1 回で作れます。

C# から切る・壊す

部品は今までどおり ScriptBehaviour から TryGetComponent で取り出して使います。

using ReplayEngine;

namespace Game;

[ReplayGuid("（作ったときの値をそのまま使う）")]
public class BreakAfterDelay : ScriptBehaviour
{
    float timer;
    bool done;

    public override void Update(float deltaTime)
    {
        if (done) return;
        timer += deltaTime;
        if (timer < 2.0f) return;

        if (TryGetComponent<SliceableComponent>(out var sliceable))
        {
            // ワールドの水平な面（y = 1）で切る。受け付けられるまで毎フレーム試す
            if (sliceable.Slice(new Vector3(0.0f, 1.0f, 0.0f), 1.0f) == RuntimeStatus.Ok)
                done = true;
        }
        else if (TryGetComponent<DestructibleComponent>(out var destructible))
        {
            destructible.ApplyRadialDamage(Transform.Position, 3.0f, 50.0f);
            done = true;
        }
    }
}

Slice() が RuntimeStatus.Ok を返すのは「受け付けた」という意味です。破片は別スレッドで作られ、あとのフレームでシーンに出ます。

Destruction Editor

Window > Destruction Editor で開きます。階層パネルで選んでいる GameObject が対象です。作業ごとに 5 つのタブに分かれています。

タブできること
かんたん設定割れ方と破片数を選んで、破片の作成から保存・衝突設定まで 1 回で行う。破片の軽量化（軽量・標準・長く残す）、硬い殻の破裂材質の作成
生成破壊パターン（7 種類の割れ方）のプレビューと破壊 Asset の保存、断面のテクスチャ（断面マテリアル）
階層・接続Chunk・Bond・応力の状態、Bond の図と一覧、Blast Damageを試す（Blast試験半径・Blast試験Damage）
衝突メッシュの衝突設定。地形・建物用（三角形）、動く物体用（凸形状）、凹みを残す複合凸

症状・出る文確かめること
「欠損」の状態が「元のメッシュを読み込み中です。」のままモデルの読み込み待ちです。アニメーションするモデルや生成した形は「現在の形状を固定して編集」を押します。
「他の機能が形を変えているため、欠損を付けられません。」膨張など、ほかの機能が形を差し替えています。どちらか一方を使います。
欠けを変えても事前破砕の割れ方が古い破片は作ったときの形のままです。かんたん設定で作り直します。
「切断エネルギーがCut resistanceに達していません。」斬撃なら刃を速く振るか切断エネルギー倍率を上げる。切断抵抗（破壊材質があればそちら）を下げる。
「切断Cooldown中です。」「Max fragment countに達しました。」0.15 秒待つ。破片の数が最大破片数（16）に達しています。
「Runtime切断のConvex Physicsには ATLAS_PHYSICS backendが必要です。」実行中に試します。編集中は切れません（カットはエディタ用の別機能です）。
「指定した破壊材質Assetを解決できません。…」破壊材質のファイルが消えたか移動しています。割り当て直します。
ぶつけても壊れない壊される側に Collider があるか、ぶつける物が動的な Rigidbody か、衝撃が衝撃しきい値 150 を超えているかを確かめます。
破壊する側・爆発で実行時切断が切れない仕様です。爆発やフィールドは事前破砕と風船に効きます。
固定したはずの破片が落ちる破片の中心が固定の範囲に入っているかを確かめます。大きい破片は中心が上にあることがあります。
音・演出が出ない破壊材質が無いか、演出スタイルが「なし」です。「破壊演出を自動再生」も確かめます。
重い破片数・動的Actor上限（既定 12）・シーン内の最大破片数（既定 48）を下げます。

表面をなぞって割れ目を作る

Destruction Editor で対象のモデルを選び、Scene View でなぞるを押します。シーンビューで表面を端から端まで左ドラッグすると、その線を割れ目として試し割りし、破片を色分け表示します。線は視線の向きへ物体を貫く面になります。

  • まっすぐ引くをオンにするか、Shift を押しながら引くと直線になります。
  • 最後の線を消すと線を全部消すでやり直せます。Esc でなぞり道具を終了します。
  • 結果を確認してこの線で破片を作って割り当てるを押すと、破壊アセットを保存して選択物体に割り当てます。

編集モード専用です。元のモデルのメッシュ読み込みが終わるまで操作できません。線を変えると試し割りも作り直されます。

対象：sinotake_test / cf1faf7f まで。コード確認のみ、実機未確認。
