Effekseer Emitter と エフェクト作成ウィンドウ

対象：ブランチ sinotake_test / コミット cdc0fd8（ループ再生・C# の型・ビルド時の状態表示を追加）

無料のエフェクト作成ツール Effekseer で作った .efkefc を、GameObject の位置で再生するコンポーネントと、作成・試し再生のウィンドウです。エンジンには Effekseer 1.80.7 の DirectX 12 用の再生部分が入っています。エフェクトの編集そのものは、別のアプリの Effekseer Editor で行います。

こんなときに使う

  • 爆発、魔法、ヒットの光など、凝ったエフェクトを出したいとき（Particle Emitter より表現の幅が広い）
  • Effekseer で作られた素材を使いたいとき

はじめての準備

  1. プロジェクトのフォルダーで PowerShell から .\Tools\SetupEffekseer.ps1 を実行し、再生部分（x64 Debug / Release）を作ります。CMake と Visual Studio の C++ 環境が必要です。
  2. 3dgp.vcxproj を x64 の Debug か Release でビルドします（Win32 では Effekseer は無効です）。
  3. Effekseer 公式サイト から Effekseer Editor 1.80.7 を入れます。
  4. エディターのコンソールに Effekseer DX12 ready と出れば使えます。

見本のエフェクトは resources/Effects/GpuShowcase にあります（Tools\DownloadEffekseerGpuSamples.ps1 で取得したもの）。

Effekseer エフェクト作成 / プレビュー ウィンドウ

Window > Effekseer エフェクト作成 / プレビュー、またはプロジェクトパネルの Effekseer FX ボタンで開きます。

もう一度出す・止める

Emitter が「出す状態」になった瞬間に 1 回再生します。ループしないエフェクトは、終わったらそのまま消えたままです。もう一度出すには、いったん「出さない状態」にしてから戻します。

  • 出さない状態：GameObject を非アクティブにする、Emitter を無効にする、開始時に再生 をオフにする、エフェクトを差し替える
  • C# からは、MonoBehaviour で GetComponent<EffekseerEmitter>() を取り、Play() で出し直し、Stop() で止めます。ほかに playbackSpeed、scale、loop、読取のみの isPlaying・status があります
using System.Collections;
using ReplayEngine;

public class HitEffect : MonoBehaviour
{
    public GameObject? effect;   // Effekseer Emitter を付けた子

    public void Play() => StartCoroutine(Restart());

    IEnumerator Restart()
    {
        if (effect == null) yield break;
        effect.SetActive(false);
        yield return null;          // 1 フレーム待ってから
        effect.SetActive(true);     // 出し直す
    }
}
制限
  • Win32 の構成、または準備（SetupEffekseer.ps1）をしていないビルドでは何も出ません。x64 でビルドすると、出力に「RePlay Effekseer runtime: ENABLED」か、無効の警告が毎回出るので、そこで確かめられます。msbuild に /p:ReplayAutoSetupEffekseer=true を付けると、ビルドの前に準備を自動で行います（そのビルドでは無効のままで、もう一度ビルドすると有効になります）。
  • Effekseer の再生部分は DirectX 12 用だけです。
  • エフェクトのファイルの置き場所は resources/Effects の中にしてください。テクスチャなどはエフェクトからの相対パスで読みます。

使い方の例

置いておくだけで光り続けるエフェクト

  1. ウィンドウの Project Assetsを更新 を押して、エフェクトをプロジェクトに入れます。
  2. GameObject に Rendering > Effekseer Emitter を付け、Effekseer Effect にエフェクトを入れます。
  3. 実行すると、GameObject の位置で再生されます（ループするエフェクトなら出続けます）。
