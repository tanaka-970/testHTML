Folder と Scene Note

対象：ブランチ sinotake / コミット 9eb9813

作業を整理するための、エディター専用のコンポーネントです。どちらもシーンファイルには保存されますが、ゲームの実行中の世界には作られません。ゲームの動きには影響しません。

こんなときに使う

  • 階層パネルの GameObject が増えて、目当ての物を探しにくくなったとき（Folder）
  • 「ここを直す」「ここにバグがある」など、シーンの場所にメモを残したいとき（Scene Note）
  • 直すところの一覧を、チームで同じシーンを見ながら確かめたいとき（シーンメモウィンドウ）

Folder

階層パネルで GameObject をまとめるための入れ物の印です。プロパティはありません。

項目内容
コンポーネントを追加での場所Core > Folder
作り方階層パネルの + 作成 > フォルダ。「フォルダ」という名前の GameObject が作られ、「フォルダを作成しました」と表示されます
階層パネルでの表示フォルダのアイコンで表示されます

整理したい GameObject を、階層パネルでフォルダの GameObject へドラッグして子にします（階層パネル）。フォルダの GameObject も Transform を持つので、動かすと子も一緒に動きます。

Scene Note

シーンビューに作業メモ（直すところ、バグ、アイデアなど）を文字で表示するコンポーネントです。1 つの GameObject にいくつでも付けられます。

表示名内部名種類既定値範囲説明
メモtext文字ここを修正表示する文字
カテゴリcategory選択TODOTODO、BUG、ART、PROGRAM、LEVEL、IDEA。シーンメモウィンドウの一覧に表示されます
優先度priority選択NormalLow、Normal、High、Critical
完了completedオン・オフオフ済んだメモ。シーンビューでは薄く表示されます
Scene Viewに表示show_in_viewportオン・オフオンシーンビューに文字を表示するかどうか
完了時に非表示hide_when_completedオン・オフオフオンにすると、完了したメモをシーンビューに表示しません
文字色color色黄色文字の色
文字サイズtext_scale小数10.35〜4文字の大きさの倍率
表示オフセットoffset3 つの小数0, 0.25, 0GameObject の位置から、文字を表示する位置をずらします
表示モードmode選択OverlayOverlay、World（下の表）
水平揃えhorizontal_align選択LeftWorld のときの文字の横の揃え方
垂直揃えvertical_align選択TopWorld のときの文字の縦の揃え方

表示モード

表示モード見え方
Overlay画面の手前に、いつも同じ大きさの文字で表示します。物に隠れません。カメラの後ろにあるメモは表示しません
World3D 空間に置いた板のように表示します。GameObject の向きと拡大率に合わせて傾き、遠いと小さく見え、物に隠れます

どちらも、エディターで編集しているときだけ表示されます（ゲームの実行中は表示されません）。GameObject が無効のときも表示されません。

メモを置く

  • シーンビューで右クリックし、Add Scene Memo Here を選ぶと、クリックした場所に「Scene Note」という GameObject が作られます（右クリックメニュー）。
  • Window > シーンメモ の 選択位置に新規メモ を押すと、シーンビューのカメラが回り込む中心の位置にメモを置きます。
  • 選択GameObjectにメモ追加 を押すと、選択中の GameObject に Scene Note を付けます。GameObject と一緒に動くメモになります。

シーンメモウィンドウ

Window > シーンメモ、またはシーンビューの右クリックの Open Scene Notes で開きます。

  • 上に「未完了 数 / 全 数」が表示されます。
  • メモが「カテゴリ | GameObject の名前 | メモ」の形で一覧になります。左のチェックボックスで 完了 を切り替えられます。
  • 一覧の行をクリックすると、その GameObject が選択され、シーンビューのカメラがその位置へ寄ります。

使い方の例

直すところにメモを置く

  1. シーンビューで、直したい場所を右クリックし、Add Scene Memo Here を選びます。
  2. できた「Scene Note」を選び、インスペクターの メモ に内容を書きます。
  3. カテゴリ を BUG、優先度 を High などにします。
  4. シーンを保存します。メモはシーンファイルに残り、ほかの人がシーンを開いても表示されます。

終わったメモを片付ける

  1. Window > シーンメモ を開きます（UI Workspace と Motion Workspace にいる間は出ません。基本などの Workspace で開きます）。
  2. 終わったメモの行の左のチェックボックスを付け、完了 にします。
  3. シーンビューから消したいときは、そのメモの 完了時に非表示 をオンにします。

GameObject をフォルダーにまとめる

  1. 手順は 階層パネルの使い方の例 を見てください。
