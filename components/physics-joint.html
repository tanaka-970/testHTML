Physics Joint

対象：ブランチ sinotake_test / コミット cdc0fd8（接続先アンカーの自動設定・破断・C# の型を追加）

2 つの Rigidbody を、固定・ヒンジ（回転）・スライダー（平行移動）・スプリング（ばね）のどれかでつなぎます。接続先を空にすると、ワールドの 1 点につなぎます。

こんなときに使う

  • 扉、跳ね橋、振り子を蝶番で回したいとき（ヒンジ）
  • 引き出しやピストンを、決まった向きにだけ動かしたいとき（スライダー）
  • 吊るした看板、ばねで戻る足場を作りたいとき（スプリング）
  • 2 つの物を 1 つの塊として動かしたいとき（固定）

基本情報

項目内容
コンポーネントを追加での場所Physics > Physics Joint
推奨Rigidbody（実際には必須。無いと「状態」に理由が出て、つながりません）
物理エンジンPhysX（ATLAS_PHYSICS）で動きます。PhysX を使えないときの予備の計算方式では動きません
いつ作られるか実行中、コンポーネントが有効になったとき。設定を変えると作り直します

ワールドにつなぐとき接続先を空にしたとき、接続先アンカー はワールド座標です。0, 0, 0 のままで 接続先アンカーを自動設定 がオン（既定）なら、置いた位置でつながります。自動設定をオフにして 0, 0, 0 のままにすると、物体がワールドの原点へ引き寄せられるので注意してください。

Physics Joint を選ぶと、シーンビューにアンカー・軸・接続先と、ヒンジの可動範囲が表示されます（自動設定で決まった位置も含めて表示します）。

スクリプトから使う（C#）

MonoBehaviour では GetComponent<PhysicsJoint>() で取り出せます。メンバーは jointKind（Unity 風の kind も同じ値）、connectedBody（Rigidbody）、anchorA、anchorB、axisA、axisB、useLimits、lowerLimit、upperLimit、minimumDistance、maximumDistance、springFrequencyHz、springDampingRatio、breakForce、breakTorque、読取のみの broken・currentForceMagnitude・currentTorqueMagnitude・status です。値を変えるとつながりを作り直します。

切れたときは、Physics Joint と同じ GameObject のスクリプトに OnJointBreak(JointBreakInfo info) が届きます。info.connectedObject（接続先）、BreakForce・BreakTorque（切れたときの力）、JointKind が入っています。

using ReplayEngine;

public sealed class RopeBridgePlank : MonoBehaviour
{
    // 踏み板のつなぎ目が切れたら、落ちる音を鳴らして 3 秒後に消す
    void OnJointBreak(JointBreakInfo info)
    {
        GetComponent<AudioSource>()?.Play();
        Destroy(gameObject, 3.0f);
    }
}

使い方の例

扉を蝶番で回す

  1. 扉の GameObject に Rigidbody（動的）と Box Collider を付けます。
  2. Physics Joint を付け、種類 をヒンジにします。
  3. 自分側アンカー を扉の端（例：幅 1 なら -0.5, 0, 0）、自分側の軸 を 0, 1, 0（縦軸）にします。
  4. 接続先 は空、接続先アンカー は 0, 0, 0 のままにします（自動設定で、今の蝶番の位置でつながります）。
  5. 可動範囲制限を使う をオンにし、下限 0、上限 100 にすると、片側にだけ開きます。

天井から看板をばねで吊るす

  1. 看板に Rigidbody と Collider を付け、Physics Joint の 種類 をスプリングにします。
  2. 自分側アンカー を看板の上端にし、接続先アンカー は 0, 0, 0 のままにします（今の上端の位置が吊り点になります）。別の点から吊るすときは、その点のワールド座標を入れます。
  3. 最小距離 0、最大距離 1、ばね周波数 2、ばね減衰比 0.3 から調整します。
