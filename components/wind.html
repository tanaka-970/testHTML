風場

対象：ブランチ sinotake_test / コミット cdc0fd8（2026-10-24 に sinotake_test / 28995f39に合わせて追記・修正。追記分はコードから書いた内容）

シーンに風を吹かせるコンポーネントです。1 つ置くと、布・Softbody・ワイヤー・ホース・ヘア・Rigidbody が同じ風を受けます。シーン全体に吹かせることも、置いた場所のまわりだけに吹かせることもできます。

こんなときに使う

  • 旗・カーテン・髪・ロープを、同じ向きの風でまとめて揺らしたいとき
  • 扇風機や送風口のまわりだけ、物を吹き飛ばしたいとき
  • ときどき強く吹く突風を入れたいとき

基本情報

項目内容
コンポーネントを追加での場所Physics > 風場
個数1 つの GameObject に複数付けられます。シーン内のすべての風場の風が足し合わされます
風の向き付けた GameObject のローカル軸で指定します。GameObject を回すと風向きも回ります

プロパティ

表示名内部名種類既定値範囲説明
風向き（ローカル）direction3 つの小数1, 0, 0風の吹く向き。GameObject の回転を反映します
風速speed小数0-500〜500風の速さ（m/秒）。既定 0 なので、置いただけでは吹きません。マイナスで逆向き
影響半径influence_radius小数00〜1000000 ならシーン全体。正の値なら、GameObject の位置を中心にこの半径の中だけで吹きます
風の減衰falloff小数10.1〜8影響半径があるとき、中心から離れるほど弱くなる度合い。風速 ×（1 − 距離 ÷ 半径）の「減衰」乗です
突風の強さgust_strength小数00〜1風速を ±この割合で揺らします（0.4 なら 0.6〜1.4 倍）
突風の頻度gust_frequency小数0.20〜201 秒あたりの強弱の回数。場所によって少しずつ時間がずれるので、波が通り抜けるように揺れます
突風の位相gust_phase小数0-1000〜1000複数の風場の強弱をずらすときに使います
Play中に有効enabled_in_playオン・オフオンオフにすると風を止めます（スイッチに使えます）

風を受ける部品

部品受け方を決める項目既定
XPBD布物理風の受けやすさ（wind_drag）1.5（受ける）
XPBD有限要素Softbody風の受けやすさ（wind_drag）1.5（受ける）
ワイヤー・ヘア・ホース物理風の受けやすさ（wind_drag）1（受ける）
Rigidbody風の影響（wind_response）0（受けない）。1 秒あたりに風の速さへ近づく割合で、風速と自分の速さの差に比例して押されます。PhysX のときだけ

風圧で揺れる

コンポーネントを追加 > Physics > 風圧で揺れる を付けると、その位置の風（Wind の風の場と、破裂の圧力）を受けて GameObject が傾いて揺れます。布の看板・ロープの先・吊りランプなど、物理を使わずに揺らしたい物に使います。置いたときの回転を基準に、風下へ X と Z の軸で傾きます（コミット 28995f39）。

表示名内部名既定値範囲説明
揺れの倍率sway_scale10〜10風の強さに掛ける倍率。0 で揺れません
最大角度max_angle_degrees120〜80傾く角度の上限（度）
追従速度response_speed80〜100風の変化に追いつく速さ。大きいほどすぐ傾き、小さいとゆっくり揺れます

揺れの強さは 演出設定 の風の演出が有効なときだけ掛かります。

スクリプトから使う（C#）

MonoBehaviour では GetComponent<WindField>() で取り出せます。メンバーは direction、speed、influenceRadius、falloff、gustStrength、gustFrequency、gustPhase、enabledInPlay です。

using ReplayEngine;

public sealed class FanSwitch : MonoBehaviour
{
    WindField? fan;

    void Start() => fan = GetComponent<WindField>();

    void Update()
    {
        // F1 で扇風機の入り切り
        if (fan != null && Input.GetKeyDown(KeyCode.F1)) fan.enabledInPlay = !fan.enabledInPlay;
    }
}
制限
  • パーティクル（Particle Emitter）と Effekseer のエフェクトは風場の影響を受けません。
  • 壁の陰でも風は弱まりません（障害物で遮られません）。

使い方の例

送風口のまわりだけ物を吹き飛ばす

  1. 送風口の GameObject に Physics > 風場 を付け、風向き を吹き出す向きに、風速 を 12、影響半径 を 4 にします。
  2. 飛ばしたい物の Rigidbody の 風の影響 を 1〜3 にします。
  3. 実行すると、送風口に近い物ほど強く押し流されます。
