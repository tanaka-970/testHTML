Nav Agent

対象：ブランチ sinotake / コミット 9eb9813

指定したワールドの位置まで、GameObject を移動させるコンポーネントです。障害物をよけて進む道を自動で探します。敵やお供のキャラクターを目的地へ歩かせるときに使います。

こんなときに使う

  • 敵やお供のキャラクターを、指定した場所まで歩かせたいとき
  • 壁などの障害物をよけて、目的地まで進ませたいとき（Character Motor と組み合わせます）

基本情報

項目内容
コンポーネントを追加での場所Navigation > Nav Agent
必須・推奨なし
動く場面ゲームの実行中。移動先は C# スクリプトなどから指示します

プロパティ

表示名内部名種類既定値範囲説明

旋回速度（度/秒）turn_speed_degrees小数3600〜10000進む方向へ向きを変える速さ。上下の軸（Y）のまわりにだけ回ります

動き方

  • 移動先を指示すると、当たり判定を升目ごとに調べて、障害物をよける道を探します。道が見つからないときや、上限に達したときは、目的地へまっすぐ進みます。
  • 道を探すのは、同じ GameObject に Character Motor（Gameplay 分類のテンプレート部品）があり、その移動用の Collider（球・カプセル・箱）が有効なときだけです。Collider の大きさと、Sphere Collider の 歩ける傾斜のしきい値 が道探しに使われます。
  • Character Motor があるときは、その移動（重力・接地・衝突）を使って水平方向に歩きます。移動速度 は Character Motor の移動速度に対する倍率に直して渡されます。
  • Character Motor が無いときは、道を探さず、Transform の位置を直接動かして目的地へまっすぐ進みます（上下にも動き、壁をすり抜けます）。
  • 目的地が升目の半分より小さく動いただけのときは、道を探し直さず、終点だけを動かします。毎フレーム移動先を指示して追いかけても重くなりにくくなっています。

操作

操作働き
MoveTo（目的地）ワールドの位置へ移動を始めます
Stop移動をやめます。Character Motor があれば、その移動も止めます
Arrived目的地に着いているかどうか（移動先が無いときも着いている扱いです）

C# スクリプトからの呼び出し方は「C# スクリプト」の章で説明します。Nav Agent を無効にしたときも、Character Motor の移動は止まります。

道を確かめる

シーンビューに、Nav Agent の目的地までの道（矢印）、目的地（×印と停止距離の円）、実際に通った跡（約 6 秒ぶん）を表示する仕組みがあります。ただし表示されるのは、同じ GameObject に Enemy Behaviour（Gameplay 分類のテンプレート部品）が付いているときだけです。

  • 通常は、選択中の GameObject の Enemy Behaviour の Scene View デバッグ表示 がオンのときに表示されます。
  • 「衝突の診断」ウィンドウの 非選択の AI・ステージのデバッグ表示 にチェックを付けると、選択していない GameObject の分も表示されます。

Enemy Behaviour の無い GameObject の Nav Agent は、この表示には出ません。

使い方の例

障害物をよけて歩くキャラクターにする

  1. 歩かせたい GameObject に、移動用の Collider（球かカプセル）と Character Motor を付けます。
  2. コンポーネントを追加 > Navigation > Nav Agent を付けます。
  3. 停止距離 を、目的地の手前で止まってほしい距離にします。道が細いときは 経路グリッド間隔 を小さくします。
  4. スクリプトから、目的地のワールドの位置を指定して移動を始めます（上の「操作」の MoveTo）。
  5. ゲームを実行し、衝突の診断 の 非選択の AI・ステージのデバッグ表示 などで、道の矢印を確かめます。

Character Motor が無いと、道を探さずに目的地へまっすぐ進み、壁もすり抜けます。
