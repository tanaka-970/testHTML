Text・Text Animator

対象：ブランチ sinotake / コミット 9eb9813

Text は UI に文字を表示するコンポーネントです。言語ごとの文字の切り替え（ローカライズ）や、ほかのコンポーネントの数値の表示もできます。Text Animator は、同じ GameObject の Text の文字を 1 文字ずつ動かしたり色を変えたりします。

こんなときに使う

  • タイトル、ボタンの文字、説明文などを画面に出したいとき（Text）
  • スライダーの値など、ほかのコンポーネントの数値をそのまま文字で表示し続けたいとき（数値の表示）
  • 日本語と英語など、言語を切り替えて表示したいとき（Localization Key）
  • 文章の一部だけ、色や大きさを変えたいとき（Rich Text）
  • 文字を揺らす、文字の上を光が流れる、といった文字の演出を付けたいとき（Text Animator）

Text

コンポーネントを追加での場所は UI > Text です。付けると Rect Transform も付きます。UI Workspace の UI 階層 の Text ボタンで、「Text」と書かれた 160 × 80 の GameObject が作られます。

表示名内部名種類既定値範囲説明
テキストtext文字（空）表示する文字列を指定します。 改行（\n）で行を分けます。Localization Key が設定されていて見つからないときは、この文字が代わりに表示されます。数値の接続元を使うと、この文字は毎回書き換えられます。
フォントfontアセット（フォント）（空）TTF / OTF / TTC のフォントアセット。TTC は先頭のフォントを使います。未設定、見つからない、または表示する文字がフォントに無いときは、Windows の meiryo.ttc、YuGothM.ttc、msgothic.ttc、segoeui.ttf の順に探したフォントで全体を表示します。
文字サイズfont_size小数241〜512文字の大きさを指定します。 Canvas 座標での文字の大きさ。1 行の高さの基準にもなります。
色color色1, 1, 1, 1描画する色を指定します。 文字の色。Rich Text の color タグの色と掛け合わされます。
不透明度opacity小数10〜1表示の不透明度を 0〜1 で指定します。 0 のときは描かれません。Canvas の不透明度と掛け合わされます。
文字間隔character_spacing小数0文字と文字の間隔を指定します。 文字ごとの送り幅に足す長さ（Canvas 座標）。マイナスで詰まります。
行間倍率line_spacing小数10.1〜4行と行の間隔倍率を指定します。 1 行の高さ = 文字サイズ × この値。行の中に size タグで大きい文字があると、その行だけ高くなります。
横揃えhorizontal_align選択中央文字列の横方向の揃え方を指定します。 行ごとに、範囲の幅に対して揃えます。 選択肢：左、中央、右
縦揃えvertical_align選択中央文字列の縦方向の揃え方を指定します。 全部の行の高さの合計を、範囲の高さに対して揃えます。 選択肢：上、中央、下
折り返しword_wrapオン・オフオン矩形幅を超えた文字列を折り返すか指定します。 オンのとき、次の文字が範囲の幅を超えるとそこで改行します（単語ではなく文字単位）。範囲からはみ出した文字は切り取られません。
Rich Textrich_textオン・オフオフUnity 互換: <color>, <size>, <b>, <i>。既定OFFなので既存Textの '<' は変化しません。 タグが正しくないときは、文字列全体をタグも含めてそのまま表示します。
Localization Keylocalization_key文字（空）空なら text をそのまま表示。キーが見つからない場合も text を fallback として表示します。 プロジェクト設定の Localization で選んだ表から、今の言語の文字を引きます。
数値の接続元number_sourceコンポーネントの参照（空）表示文字列へ接続する数値の取得元を指定します。 数値を読むコンポーネント。数値の接続元と数値プロパティの両方が設定されているときだけ働きます。
数値プロパティnumber_source_property文字（空）数値の取得元に使うプロパティ名を指定します。 内部名で指定します。整数・小数・選択（番号）・64 ビット整数のプロパティだけ使えます。
数値書式number_format文字（空）例: {0:0}% {0 から次の } までを数値に置き換えます。{0:0.00} のような書式指定は解釈されず、桁数は 小数桁 で決まります。空なら {0} と同じです。
小数桁number_digits整数00〜4数値の小数点以下の桁数を指定します。 小数点以下の桁数。0〜4 に収められます。
縁取り幅outline_width小数00〜32文字の縁取り幅を指定します。 画面のピクセル単位。欄には 32 まで入りますが、実際に表示される幅は 8 までです。
縁取り色outline_color色0, 0, 0, 1文字の縁取り色を指定します。 縁取り幅が 0 より大きいときに使います。
影オフセットshadow_offset2 つの小数0, 0文字の影をずらす距離を指定します。 画面のピクセル単位で、X はプラスで右、Y はプラスで下へ影をずらします。
影色shadow_color色0, 0, 0, 0文字の影色を指定します。 既定は A が 0 なので影は出ません。A を 0 より大きくすると表示されます。

文字の並び方

  • 文字は Rect Transform の範囲の中に並べます。1 行の高さは 文字サイズ × 行間倍率 です。
  • 折り返し がオンなら、次の文字で範囲の幅を超えるときに改行します。英語の単語の途中でも改行します。
  • 横揃え は行ごと、縦揃え は全部の行をまとめて揃えます。
  • 範囲に入りきらない文字も、はみ出して表示されます。切り取りたいときは親に Mask を置きます。
  • 不透明度 が 0 の Text は描かれません。

フォント

フォント にはプロジェクトの TTF、OTF、TTC ファイルを指定します。TTC に複数のフォントが入っているときは、最初のフォントを使います。

フォントを指定していないとき、フォントが見つからないとき、または表示する文字のどれかがそのフォントに無いときは、Windows に入っている次のフォントを順に探し、見つかったもので文字列全体を表示します。

  1. C:\Windows\Fonts\meiryo.ttc
  2. C:\Windows\Fonts\YuGothM.ttc
  3. C:\Windows\Fonts\msgothic.ttc
  4. C:\Windows\Fonts\segoeui.ttf

文字は、輪郭までの距離を持った画像（SDF）で描くので、大きくしてもぼやけにくくなっています。

縁取りと影

  • 縁取り幅 は画面のピクセル単位です。欄には 32 まで入りますが、見た目に反映されるのは 8 ピクセルまでです。
  • 影は 影色 の A が 0 より大きいときだけ表示されます（既定は A が 0）。影オフセット は画面のピクセル単位で、X がプラスなら右、Y がプラスなら下にずれます。縁取りがあるときは、影も縁取りの形になります。

Rich Text

Rich Text をオンにすると、文字の中にタグを書いて、一部だけ色や大きさを変えられます。

タグ働き
<b>…</b>太字風。文字を 3.5% 大きくし、送り幅を 2% 広げます（太いフォントには切り替わりません）
<i>…</i>斜体風。文字を斜めに傾けます
<color=#RRGGBB>…</color>
<color=#RRGGBBAA>		色。16 進数で指定します。色 と掛け合わされます
<color=red> など名前で色を指定。white、black、red、green、blue、yellow、cyan、magenta、gray（grey）、orange、clear（透明）。大文字でも同じです
<size=数値>…</size>文字の大きさ（1〜2048）。その行の高さも大きくなります
HP <color=#FF4040><b>12</b></color> / 100
  • 知らないタグ（<u> など）や、値が正しくないタグは、タグとして扱わず文字として表示します。
  • タグの閉じ忘れや、閉じる順番の間違い（<b><i>…</b></i>）があると、文字列全体をタグも含めてそのまま表示します。
  • Rich Text がオフのときは、< を含む文字もそのまま表示します。

ローカライズ（言語の切り替え）

Localization Key に名前を入れると、言語ごとの文字の表（Localization Table）からその名前の文字を表示します。

  1. プロジェクト パネルで右クリックし、Create > Data > Localization Table を選びます。言語「ja」「en」と、例のキー「sample.hello」（こんにちは / Hello）が入った表ができます。
  2. できた表を選ぶと、プロジェクトパネルに Localization Table Asset の欄が出ます。ここで表を編集します（下の表）。変更はすぐファイルに保存されます。
  3. 階層 で ゲームシーン > ワールド を選び、インスペクターの プロジェクト設定 を開いて、Localization の選択欄でその表を選び、既定言語 に言語の名前（例：ja）を入れます。
  4. Text の Localization Key にキーの名前（例：sample.hello）を入れます。
Localization Table Asset の項目働き
再読み込み保存されている表を読み直します
Languages (comma)言語の名前をカンマ区切りで並べます（例：ja, en）。最初の言語が、訳の無いときの代わりになります
New Key と 追加キーを追加します
左のキーの一覧選んだキーの訳が右に言語ごとの欄で表示され、編集できます
このKeyを削除選んでいるキーを消します

ゲームの実行中は表を編集できません（「Play 中は Localization Asset を編集できません」）。

文字が見つからないとき

  1. 表にキーが無い：Text の テキスト を表示します。テキストも空なら、キーの名前をそのまま表示します。
  2. キーはあるが、今の言語の訳が無い：表の最初の言語の訳を表示します。
  3. それも無い：そのキーにある、ほかのどれかの言語の訳を表示します。
  4. 表が設定されていない、または読めない：テキスト（空ならキーの名前）を表示します。

既定言語が空のときは「ja」になります。ゲーム中に言語を変えるには Language Switch を使います。

数値の表示

ほかのコンポーネントの数値を、文字として表示し続けられます。スコアや残り時間の表示に使います。

  1. 数値の接続元 で、数値を持つコンポーネントを選びます。
  2. 数値プロパティ に、そのコンポーネントのプロパティの内部名を入れます（各コンポーネントのページの表の「内部名」）。
  3. 数値書式 に {0} を含む文を入れます（例：SCORE {0}）。小数桁 で小数点以下の桁数を決めます。
  • 使えるのは整数、小数、選択（番号として表示）、64 ビット整数のプロパティです。それ以外や、見つからないときは何も変わりません。
  • {0 から次の } までが数値に置き換わります。{0:0.00} と書いても書式としては読まれず、桁数は 小数桁（0〜4）で決まります。
  • 表示のたびに テキスト が書き換わります（エディターで編集している間も反映されます）。

Text Animator

同じ GameObject の Text の文字に、範囲を決めて動きや色の変化を掛けます。コンポーネントを追加での場所は UI > Text Animator です。1 つの GameObject に複数付けられます。

表示名内部名種類既定値範囲説明
範囲開始range_start小数00〜1アニメーション対象範囲の開始位置を指定します。 文字の並びを 0（最初の文字）〜1（最後の文字）とした、効果を掛け始める位置。
範囲終了range_end小数10〜1アニメーション対象範囲の終了位置を指定します。 効果を掛け終える位置。開始より小さくても、小さい方から大きい方の範囲として扱います。
範囲オフセットrange_offset小数0アニメーション対象範囲をずらす量を指定します。 開始と終了の両方に足します。モーションで動かすと、効果が文字の上を流れていきます。範囲の外の文字には効きません。
範囲形状range_shape選択矩形アニメーション対象範囲の形状を指定します。 範囲の中での効き方。矩形はずっと 1、上りは始めから終わりへ 0→1、下りは 1→0、三角と丸は真ん中が 1、滑らかは 0→1 をなめらかに変化します。 選択肢：矩形、上り、下り、三角、丸、滑らか
境界の滑らかさrange_smoothness小数00〜1アニメーション対象範囲の境界を滑らかにする量を指定します。 範囲の両端で効き方を 0 からなめらかに立ち上げます。1 で範囲の半分ずつがなめらかな区間になります。
位置オフセットposition_offset2 つの小数0, 0アニメーション中の文字位置へ加えるずれを指定します。 効き方に比例して文字を動かします（Canvas 座標）。
回転 (度)rotation小数0UI 要素の回転角度を度単位で指定します。 効き方に比例して、文字を 基準点 のまわりに回します。
拡大率scale2 つの小数1, 1UI 要素の拡大率を指定します。 効き方に比例して、1 からこの値へ文字を拡大します。
不透明度opacity小数10〜1表示の不透明度を 0〜1 で指定します。 効き方に比例して、不透明度をこの値へ近づけます。
色color色1, 1, 1, 1描画する色を指定します。 効き方に比例して、文字の色をこの色を掛けた色へ近づけます。
文字間隔character_spacing小数0文字と文字の間隔を指定します。 文字の番号 × この値 × 効き方だけ右へずらします。後ろの文字ほど大きくずれます。
乱数の種random_seed整数0ランダムな配置や回転を再現するための種を指定します。 同じ値なら、毎回同じランダムなずれ方になります。
ランダム位置random_position2 つの小数0, 0文字へ加えるランダムな位置ずれを指定します。 文字ごとに −値〜+値 のランダムなずれを、効き方に比例して加えます。
ランダム回転random_rotation小数0文字へ加えるランダムな回転量を指定します。 文字ごとに −値〜+値 のランダムな回転を、効き方に比例して加えます。
基準点anchor選択中央文字アニメーションの基準点を指定します。 回転と拡大の中心。ベースライン左は文字の左端の上下中央、ベースライン中央は 中央 と同じ、左上は文字の左上、下中央は文字の下端の中央です。 選択肢：中央、ベースライン左、ベースライン中央、左上、下中央

効き方の決まり方

  1. 各文字の位置を、(文字の番号 + 0.5) ÷ 文字数 で 0〜1 に置きます（Rich Text のタグは数えません）。
  2. 範囲開始 ＋ 範囲オフセット から 範囲終了 ＋ 範囲オフセット までの外にある文字には、何も起きません。
  3. 範囲の中では、範囲形状 で効き方（0〜1）を決め、境界の滑らかさ で端を弱めます。
  4. 位置、回転、拡大率、色、不透明度などの値を、効き方に比例して掛けます。

複数の Text Animator があるときは、コンポーネントの並び順に重ねて掛けます。基準点は、最後に効いた Text Animator のものが使われます。

文字が流れる演出範囲形状 を 三角 などにして範囲を狭くし、範囲オフセット をモーションで -1 から 1 まで動かすと、効果が文字の上を左から右へ流れていきます。

Text Animator はエディターで編集している間も表示に反映されます。

使い方の例

背景の上でも読みやすい見出しにする

  1. UI Workspace の UI 階層で Text ボタンを押し、テキスト に見出しを入れます。
  2. 文字サイズ を 48 にし、Rect Transform の サイズ差分 を文字が入る大きさにします。
  3. 縁取り幅 を 3、縁取り色 を黒にします（8 より大きくしても見た目は変わりません）。
  4. 影も付けるときは、影色 の A を 0.5 にし、影オフセット を (3, 3) にします。右下に影が出ます。

スライダーの値を「音量 50」のように表示する

  1. 値を読みたい Slider の 最大値 を 100、整数のみ をオンにしておきます（Slider）。
  2. 表示用の Text を作り、数値の接続元 にその Slider を指定します。
  3. 数値プロパティ に value（Slider の 値 の内部名）、数値書式 に 音量 {0}、小数桁 に 0 を入れます。
  4. スライダーを動かすと、表示が変わることを確かめます。

日本語と英語を切り替える

  1. プロジェクト パネルで Create > Data > Localization Table を作ります。
  2. 表を選び、プロジェクトパネルの Localization Table Asset の欄で、New Key に title.start と入れて 追加 し、ja に「はじめる」、en に「Start」と入れます。
  3. 階層 で ゲームシーン > ワールド を選び、インスペクターの プロジェクト設定 の Localization でこの表を選び、既定言語を ja にします。
  4. ボタンの文字の Text の Localization Key に title.start を入れます。
  5. 言語を切り替えるボタンには Language Switch を付けます。

文字の上を光が流れる

  1. Text と同じ GameObject に コンポーネントを追加 > UI > Text Animator を付けます。
  2. 範囲形状 を 三角、範囲開始 を 0.4、範囲終了 を 0.6、色 を黄色にします。
  3. モーションで 範囲オフセット を -1 から 1 へ動かし、Motion Player の 終了処理 をループにします。
