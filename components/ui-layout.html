Canvas と Rect Transform

対象：ブランチ sinotake / コミット 9eb9813

ゲーム画面に重ねるメニューや HP ゲージなどの UI は、Canvas を根元にして、その子に Image や Text などを並べて作ります。UI の部品はどれも Rect Transform で、四角い範囲の位置と大きさを決めます。

こんなときに使う

  • ゲーム画面に重ねる UI（メニュー、スコア、体力ゲージなど）を作り始めるとき。最初に Canvas を置きます
  • 画面の右上や下の端など、決まった場所にくっつけて表示したいとき（アンカー）
  • 親の幅いっぱいに広げたいとき（アンカーを範囲にする）
  • 画面の大きさが変わっても、UI の見た目の割合を保ちたいとき（スケール方式、基準解像度）
  • 3D 空間の中に、看板のように UI を置きたいとき（World Space）
  • UI のまとまりを、まとめて薄くしたり消したりしたいとき（Canvas の不透明度）

基本のしくみ

  • UI が表示され、クリックなどに反応するのは、Canvas を持つ GameObject の子孫 だけです。Canvas の外に置いた Image や Text は表示されません。
  • UI の座標は、画面の 左下が原点 で、右が +X、上が +Y です。単位は Canvas の基準解像度でのピクセルです。
  • Canvas を付けると、同じ GameObject に Rect Transform も自動で付きます。Image、Text などのコンポーネントも Rect Transform が必要です。

作る

  1. Window > UI Workspaceへ で UI Workspace に切り替えます（Workspace）。
  2. UI 階層 ウィンドウの上部のボタンで追加します。ボタンは Canvas、Image、Text、Button、Mask、図形 などです（ウィンドウが狭いと ＋ UIを追加 1 つにまとまります）。
追加するもの作られる内容
CanvasCanvas と Rect Transform を持つ GameObject。Rect Transform は画面全体に広がる設定（アンカー 0,0〜1,1、サイズ差分 0）
Image、Text、Mask選んでいる UI の子（UI を選んでいなければ最初の Canvas の子）に作ります。大きさは 160 × 80
ButtonImage と Button を持つ 180 × 52 の GameObject と、その子の「Button Text」（文字「Button」、大きさ 24）

親にできる Canvas が無いときは、Canvas も自動で作られます。通常の階層パネルの作成メニューには UI の項目はありません。

Rect Transform

UI 部品の四角い範囲を、親の範囲をもとに決めるコンポーネントです。コンポーネントを追加での場所は UI > Rect Transform です。

表示名内部名種類既定値範囲説明
アンカー最小anchor_min2 つの小数0.5, 0.5UI矩形の左下アンカー位置を指定します。 0〜1 の割合（0,0 が親の左下、1,1 が右上）。X と Y それぞれ、アンカー最大と同じなら 1 点、違えば範囲として扱います。
アンカー最大anchor_max2 つの小数0.5, 0.5UI矩形の右上アンカー位置を指定します。 0〜1 の割合。アンカー最小と同じ値にすると、大きさはサイズ差分で決まります。
位置anchored_position2 つの小数0, 0アンカー基準からの相対位置です。 単位は Canvas の座標（基準解像度でのピクセル）。アンカーが 1 点ならその点からピボットまでのずれです。
サイズ差分size_delta2 つの小数100, 100アンカーが一点なら矩形サイズ、範囲なら親サイズとの差分です。
ピボットpivot2 つの小数0.5, 0.5回転や拡縮の基準になる UI 要素内の位置を指定します。 0,0 が自分の左下、1,1 が右上。位置の基準点で、回転・拡大の中心にもなります。
回転 (度)rotation小数0UI 要素の回転角度を度単位で指定します。 ピボットを中心に回します。プラスの値で反時計回りです。子の範囲の計算には影響しません。
拡大率scale2 つの小数1, 1UI 要素の拡大率を指定します。 ピボットを中心に拡大します。子の範囲の計算には影響しません（子へ回転・拡大を伝える がオンのとき、見た目だけ子にもかかります）。
描画順sort_order整数0同じ Canvas 内の兄弟 UI の描画順です。値が大きいほど手前に描きます。 同じ親の子どうしだけで比べます。同じ値なら階層の並び順です。
子へ回転・拡大を伝えるpropagate_transformオン・オフオフオンにすると、この要素の回転と拡大率を子孫の UI にも掛けます。
確定矩形resolved_rect4 つの小数UILayout が毎フレーム計算した結果です。Scene には保存しません。 左下の X、左下の Y、幅、高さの順です。 （表示のみ、実行中の値、保存されません、詳細設定）

アンカーと大きさの決まり方

アンカー最小 と アンカー最大 は、親の範囲の中の位置を 0〜1 の割合で表します（0,0 が親の左下、1,1 が右上）。

アンカーの状態位置大きさ使いどころ
最小と最大が同じ（1 点）アンカーの点から 位置 だけずらした所に ピボット が来ますサイズ差分 がそのまま幅と高さ決まった大きさのボタンやアイコン
最小と最大が違う（範囲）アンカーの範囲から 位置 だけずらしますアンカーの範囲の大きさ ＋ サイズ差分（マイナスにすると内側に余白）親に合わせて伸び縮みする背景や帯

X と Y は別々に判定します（差が 0.0001 以下なら同じとみなします）。計算した幅や高さがマイナスになると 0 になります。

アンカーが 1 点のとき
  中心 = 親の左下 + 親の大きさ × アンカー + 位置
  左下 = 中心 − サイズ差分 × ピボット

アンカーが範囲のとき
  左下 = アンカー最小の点 + 位置 − サイズ差分 × ピボット
  右上 = アンカー最大の点 + 位置 + サイズ差分 × (1 − ピボット)

回転と拡大率

  • 回転 (度) と 拡大率 は、決まった範囲の ピボット を中心にかかります。
  • 子の範囲は、親の回転や拡大率に関係なく計算されます。親の 子へ回転・拡大を伝える をオンにすると、親の回転と拡大率が子孫にもかかります（オフのときは、その要素だけが回転・拡大して見えます）。
  • クリックの判定も、回転と拡大率を反映した形で行われます。

描画順

  • 親を描いてから、その子を描きます。
  • 同じ親の子どうしは、Rect Transform の 描画順 が小さい順に描きます（大きいほど手前）。同じ値なら階層の並び順です。
  • 描画順 は兄弟どうしの順番で、別の親の子とは比べません。

Canvas

UI のまとまりの根元です。コンポーネントを追加での場所は UI > Canvas です。

表示名内部名種類既定値範囲説明
基準解像度reference_resolution2 つの小数1920, 1080Canvas が基準にする画面解像度を指定します。 スケール方式が「画面サイズに合わせる」のときの基準の画面の大きさ。World Space では板の縦横比にも使います。0 以下の値は 1920 × 1080 として扱います。
描画モードrender_mode選択Screen Space OverlayCanvas を画面へ重ねるかワールド空間へ置くかを指定します。 World Space では Canvas の GameObject の位置・回転・拡大率で 3D 空間に置きます。 選択肢：Screen Space Overlay、World Space
スケール方式scale_mode選択画面サイズに合わせる画面サイズに対する Canvas の拡縮方法を指定します。 固定ピクセルは倍率 1。画面サイズに合わせるは基準解像度との比で倍率を決めます。 選択肢：固定ピクセル、画面サイズに合わせる
幅/高さの一致match_width_or_height小数0.50〜1Canvas の基準解像度を幅と高さのどちらへ合わせるかを指定します。 0 で幅の比、1 で高さの比に合わせます。スケール方式が「画面サイズに合わせる」のときだけ使います。
描画順sort_order整数0同じ Canvas 内の描画順を指定します。値が大きいほど手前に描きます。 実際には Canvas どうしの順番です。大きいほど手前に描かれ、クリックも手前の Canvas が先に受け取ります。
不透明度opacity小数10〜1表示の不透明度を 0〜1 で指定します。 中のすべての UI に掛かります。Canvas の中の Canvas は、両方の値が掛け合わされます。

描画モード

選択肢表示のしかた
Screen Space Overlay画面にそのまま重ねます。Canvas の GameObject の位置や回転は使いません
World SpaceCanvas の GameObject の位置・回転・拡大率で、3D 空間の中の板として置き、カメラから見た位置に描きます。板の大きさは高さ 1、幅は「基準解像度の幅 ÷ 高さ」です。有効なカメラが無いと描かれず、コンソールに「カメラが無いためワールド空間 Canvas を配置できません」と出ます

スケール方式と基準解像度

Canvas の中で使う座標の広さは「画面の大きさ ÷ 倍率」です。

スケール方式倍率
固定ピクセルいつも 1。画面が大きくなると、UI は相対的に小さく見えます
画面サイズに合わせる基準解像度に対する画面の大きさの比。幅/高さの一致 が 0 なら幅の比、1 なら高さの比、その間は両方を混ぜた値（対数で補間）
倍率 = 2 ^ ( log2(画面の幅 ÷ 基準の幅) × (1 − 一致) + log2(画面の高さ ÷ 基準の高さ) × 一致 )

基準解像度の幅や高さが 0 以下のときは、1920 × 1080 として計算します。

Canvas が複数あるとき

  • Canvas の 描画順 が小さいものから描きます（大きいほど手前）。同じ値ならシーンの並び順です。
  • クリックなどの判定は手前の Canvas から行います。
  • Canvas の 不透明度 は、その中のすべての UI にかかります。Canvas の中に別の Canvas があると、両方の不透明度が掛け合わされます。
  • GameObject が非アクティブ、または Canvas が無効の Canvas は描かれません。

使い方の例

画面の右上にスコアを置く

  1. UI Workspace で Canvas を選び、UI 階層の Text ボタンで Text を作ります。
  2. Text の Rect Transform を、アンカー最小 (1, 1)、アンカー最大 (1, 1)、ピボット (1, 1) にします。親（Canvas）の右上の点を基準にし、自分の右上の角をそこに合わせる設定です。
  3. 位置 を (-20, -20) にすると、右上から左へ 20、下へ 20 離れます。サイズ差分 を (300, 60) にして文字が入る大きさにします。
  4. シーンビュー上部の解像度を変えても、右上に付いたままになることを確かめます。

画面の下に横いっぱいの帯を敷く

  1. Canvas を選び、UI 階層の Image > 通常のImageを追加 で Image を作ります。
  2. Rect Transform を、アンカー最小 (0, 0)、アンカー最大 (1, 0)、ピボット (0.5, 0) にします。横は親の幅に合わせて伸び、縦は下の辺に付きます。
  3. 位置 を (0, 0)、サイズ差分 を (0, 120) にします。高さ 120 の帯になります。
  4. 左右に 20 ずつ余白を空けたいときは、サイズ差分 の X を -40 にします。

画面の大きさが違っても同じ割合で見せる

  1. Canvas を選び、スケール方式 を「画面サイズに合わせる」（既定）にします。
  2. 基準解像度 に、UI を作るときに想定する画面の大きさ（例：1920 × 1080）を入れます。
  3. 幅/高さの一致 を決めます。横に長い画面で、縦方向の配置を崩したくないときは 1（高さに合わせる）、縦に長い画面が中心なら 0（幅に合わせる）が目安です。
  4. UI Workspace のシーンビューで解像度を切り替えて確かめます。

3D 空間に看板を置く

  1. Canvas の 描画モード を World Space にします。
  2. Canvas の GameObject の Transform の 位置、回転 (度)、拡大率 で、看板を置く場所と大きさを決めます。板は高さ 1 で、幅は基準解像度の縦横比で決まります。
