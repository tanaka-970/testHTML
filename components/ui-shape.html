Shape・Puppet Deform

対象：ブランチ sinotake / コミット 9eb9813

Shape は、画像を使わずに四角・円・多角形・線などの図形を UI に描くコンポーネントです。塗り、線、グラデーション、線の一部だけを描く Trim、破線に対応しています。Puppet Deform は、Image の画像を格子に分けて、Pin を動かしたところだけ曲げるコンポーネントです。

こんなときに使う

  • 画像を用意せずに、四角・円・星などの図形や線を UI に描きたいとき（Shape）
  • 輪郭線が少しずつ描かれていく演出や、流れる破線を作りたいとき（Trim、破線）
  • 花や歯車のような形を、モーションでなめらかに変形させたいとき（極座標式）
  • 吹き出しや矢印など、自由な形を描きたいとき（自由ベジェ Path）
  • 1 枚の絵の髪や腕などを、部分的に曲げて揺らしたいとき（Puppet Deform）

Shape

コンポーネントを追加での場所は UI > Shape です。付けると Rect Transform も付きます。図形は Rect Transform の範囲に合わせて描かれ、範囲の縦横比に合わせて伸びます（範囲が横長なら円は楕円になります）。

UI Workspace で作る

UI 階層 の 図形 ボタン（または ＋ UIを追加 > 図形を追加）から選ぶと、塗り色が水色、線色が紺の Shape を持つ GameObject が作られます。

塗り

  • 閉じた形のときだけ、塗り色 で内側を塗ります。塗り色の A が 0 なら塗りません。
  • 塗りの種類 が 線形 なら 塗りの向き の方向に、放射 なら 塗りの中心 からの距離で、色が変わります。0〜1 の途中の位置を 色 2 の位置・色 3 の位置・色 4 の位置 で決め、最大 4 色のグラデーションにできます。
  • Shape の塗りの向きと中心は、範囲の 左下が 0,0 です。そのため向き 90 度は下から上へ変わります（Image のグラデーション とは上下が逆です）。
  • 自分自身と交差する輪郭は、正しく塗れないことがあります。

線（輪郭線）

  • 線幅 が 0 より大きいとき、輪郭に沿って線を描きます。線は輪郭の上に内側と外側へ半分ずつ広がります。
  • 線は辺ごとの細長い四角でできているので、線幅を太くすると角にすき間や重なりが見えることがあります。
  • 線の色の種類 を 長さに沿う にすると、輪郭の始まりから終わりへ 線色 から 線の終端色 へ変わります。

Trim と破線

線だけに効き、塗りには効きません。輪郭の全長を 0〜1 として考えます。

  • Trim 開始 から Trim 終了 までの区間だけ線を描きます。区間の長さはそのままに、Trim オフセット で始まりをずらせます。1 を超えた部分は輪郭の最初へ回り込みます。
  • 破線の長さ と 破線の間隔 の両方が 0 より大きいと、線を破線にします。長さは Canvas 座標です。破線オフセット で模様をずらせます。
線が描かれていく演出Trim 開始を 0、Trim 終了をモーションで 0 から 1 へ動かすと、輪郭が少しずつ描かれていきます。Trim オフセットを動かすと、決まった長さの線が輪郭の上を回ります。

Puppet Deform

同じ GameObject の Image の画像を、格子に分けて曲げます。髪や腕、服などを部分的に揺らすのに使います。コンポーネントを追加での場所は UI > Puppet Deform です。

表示名内部名種類既定値範囲説明
変形を有効enabled_deformオン・オフオンPuppet 変形を有効にするか指定します。 オフにすると変形せず、ふつうの四角として描きます。
Mesh 列数grid_columns整数61〜32Puppet メッシュの列数を指定します。 画像を横に何分割して曲げるか（1〜32）。多いほどなめらかに曲がります。
Mesh 行数grid_rows整数61〜32Puppet メッシュの行数を指定します。 画像を縦に何分割して曲げるか（1〜32）。
全体強度global_strength小数1-4〜4Puppet 変形全体へ掛ける強さを指定します。 全部の Pin の動きに掛ける倍率。マイナスにすると逆向きに曲がります。

Pin 影響半径pin_radii一覧（空）Puppet Pin の影響半径を指定します。 Pin が影響する距離（範囲の幅・高さを 1 とした長さ）。追加したときは 0.35。pin[番号].radius としてモーションで動かせます。 （詳細設定）

曲がり方

  1. 画像を Mesh 列数 × Mesh 行数 の格子に分け、格子の点ごとに動かす量を計算します。
  2. 各 Pin は、Pin 基準位置 から Pin 位置 へ動いた分だけ、基準位置から Pin 影響半径 以内の点を引っぱります。近い点ほど強く、半径の端で 0 になるよう、なめらかに弱まります。
  3. 複数の Pin が同じ点に効くときは動きを足し合わせます。効き目の合計が 1 を超えるときは平均します。
  4. 最後に 全体強度 を掛けます。
  • 位置と半径は、画像の範囲の左下を 0,0、右上を 1,1 とした値です。範囲が横長でも、半径は横と縦で同じ割合として計算します。
  • Pin 位置を基準位置と同じにしておくと、画像は元のままです。
  • Image に 9 スライス、円形 360 の塗り、Shape Image、自由形状のアトラス Region があるときは、そちらが優先され、Puppet Deform は使われません（描き方が重なるとき）。

使い方の例

円が描かれていく読み込み表示を作る

  1. UI Workspace の UI 階層で 図形 > 円 を選びます。
  2. 塗り色 の A を 0 にして塗りを消し、線幅 を 8、線色 を好きな色にします。
  3. Trim 終了 を 0.3 にすると、円の 3 割だけが線で描かれます。
  4. モーションで Trim オフセット を 0 から 1 へ動かし、ループさせると、線が円の上を回り続けます。

下から上へ色が変わる角丸の板を作る

  1. UI 階層の 図形 > 角丸矩形 を選びます。
  2. 塗りの種類 を 線形、塗りの向き を 90 にします。Shape では 90 度で下から上へ変わります。
  3. 塗り色 を下の色、塗りの終端色 を上の色にします。
  4. 線幅 を 0 にすると枠線が消えます。

絵の一部を揺らす（Puppet Deform）

  1. 揺らしたい絵を 画像 に指定した Image を用意し、同じ GameObject に コンポーネントを追加 > UI > Puppet Deform を付けます。
  2. UI インスペクターの Puppet Deform 編集で Pin を追加 を 2 回押し、1 つを動かさない根元、もう 1 つを揺らす先の位置に、シーンビューで橙の丸をドラッグして置きます。
  3. 現在形状を Bind Pose にする を押し、今の置き方を「元の形」にします。
  4. 先の Pin をシーンビューでドラッグすると、その周りの絵が曲がります。選択 Pin 半径 で曲がる範囲を調整します。
  5. モーションで、先の Pin の 位置（pin[1].position）を左右に動かすと、揺れ続ける絵になります。
