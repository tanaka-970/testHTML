Normal Adjust

対象：ブランチ sinotake / コミット 9eb9813

モデルの陰影の付き方を整えるコンポーネントです。光の当たり方を計算するときに使う面の向き（法線）を、指定した球の中心から外へ向かう向きに近づけます。細かい凹凸で陰影がばらばらになるモデルでも、球のようになめらかな陰影にできます。モデルの形そのものは変わりません。

こんなときに使う

  • キャラクターの顔などで、細かい凹凸のせいで陰影がばらついて見えるとき
  • アニメ調の見た目で、影の形をなめらかに整えたいとき

基本情報

項目内容
コンポーネントを追加での場所Rendering > Normal Adjust
1 つの GameObject にいくつでも付けられます
必須・推奨なし（効果を見るには、同じ GameObject にモデルを表示するコンポーネントが要ります）

プロパティ

表示名内部名種類既定値範囲説明
Blendblend小数00〜1法線を球の向きへ近づける割合。0 では何も変わりません。最初はこの値を上げてください
Centercenter3 つの小数0, 0, 0球の中心。GameObject から見た位置です。Bone を指定したときは、その骨から見た位置になります
Radiusradius小数0.50〜10000球の半径。球の外側の面は変わりません。GameObject の拡大率（3 方向のうち最大のもの）が掛かります。0 では何も変わりません
Fallofffalloff小数0.20〜1球の外側から内側へ、効果をなめらかに弱めていく幅（半径に対する割合）。0.2 なら、半径の外側 2 割で効果が 0 までなめらかに弱まります。0 なら境目ではっきり切り替わります
Bonebone文字（空）骨の名前。指定すると、球の中心がその骨に付いて動きます（アニメーションするモデル向け）。名前の骨が見つからないときは、この Normal Adjust は使われません
対象target_slot_mode選択モデル全体モデル全体、マテリアルスロット
マテリアルスロットtarget_slot_index整数00〜31対象がマテリアルスロットのときに効果をかける部分の番号（0 から数えます）。マテリアルスロットを見てください

複数付けたとき

モデルの部分（スロット）ごとに、上から順に Normal Adjust を調べ、有効で、対象の部分に合い、Blend と Radius が 0 より大きい最初の 1 つだけが使われます。顔と髪など、部分ごとに別の球を使いたいときは、対象 を マテリアルスロット にして、部分ごとに Normal Adjust を付けます。

シーンビューでの操作

中心をドラッグで動かす

  1. Normal Adjust を付けた GameObject を選択します（ゲームを実行していないとき）。
  2. シーンビューの各 Normal Adjust の中心に、水色の点と「Normal」という文字が表示されます。マウスを乗せると黄色になります。
  3. 点をクリックすると、その点に移動用のギズモが表示されます。
  4. ギズモの軸をドラッグして中心を動かします。離すと「Normal Adjust の中心を確定しました」と表示されます。ドラッグ中に Esc を押すと取り消せます。Ctrl+Z でも戻せます。

球の範囲を表示する

  1. Window > Collision Diagnostics を選び、「衝突の診断」ウィンドウを開きます。
  2. 表示 の Normal Adjust の範囲を描く にチェックを付けます。
  3. 選択中の GameObject の Normal Adjust の球が、水色の 3 つの円で表示されます。

使い方

  1. 陰影を整えたいモデルの GameObject に コンポーネントを追加 > Rendering > Normal Adjust を付けます。
  2. Blend を 0.5 程度にします。
  3. シーンビューの「Normal」の点をドラッグして、中心をモデルの中心（顔なら頭の中心）に合わせます。
  4. 範囲を表示しながら、Radius をモデルがおおよそ入る大きさにします。
  5. 陰影を見ながら Blend と Falloff を調整します。
