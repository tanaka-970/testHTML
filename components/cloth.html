XPBD布物理

対象：ブランチ sinotake_test / コミット cdc0fd8

旗・カーテン・マントのような開いた面のメッシュを、重力・風場・シーンの Collider に合わせて揺らすコンポーネントです。実行中だけ計算し、停止すると元の形に戻ります。

こんなときに使う

  • 旗やのれんを風になびかせたいとき
  • カーテンやテーブルクロスを、置いた物に沿って垂らしたいとき
  • キャラクターのマントを揺らしたいとき（Skinned Mesh Renderer でも使えます）

基本情報

項目内容
コンポーネントを追加での場所Physics > XPBD布物理
必要なもの同じ GameObject の Mesh・Skinned・Primitive のどれかの Renderer（推奨は Mesh Renderer）。Renderer は自動では付きません
メッシュ開いた三角形メッシュ（板・帯など）。三角形が少ないメッシュ（内蔵の Plane など）は、512 枚以上になるまで自動で細かく分けてから揺らします
上限描画頂点 60,000、三角形 20,000、物理の点 20,000
計算の向き布は Collider に押し返されますが、Rigidbody を押し返しません（片方向）

プロパティ

表示名内部名種類既定値範囲説明
面密度surface_density小数0.450.001〜10001 平方メートルあたりの重さ。0 より大きい値が必要です
伸びにくさstretch_stiffness小数0.920〜11 に近いほど伸びません。下げるとゴム布のように伸びます
曲げにくさbend_stiffness小数0.180〜1上げると厚手の生地のように折れにくくなります
重力の倍率gravity_scale小数1-10〜10重力に掛ける倍率。1 で通常、0 で重力なし（その場に浮く）、マイナスで上へ落ちます。
揺れの減衰damping小数0.80〜40大きいほど早く揺れが収まります
風の受けやすさwind_drag小数1.50〜40風場 の風にどれだけ流されるか。0 なら風場を無視します
追加の風加速度wind3 つの小数0, 0, 0風場とは別に、この布にだけ常にかける加速度（ワールドの向き）
固定する辺pin_axis選択+X側固定なし・-X側・-Y側・-Z側・+X側・+Y側・+Z側メッシュのローカル軸の端の点を固定します。固定した辺は GameObject の移動・回転に付いていきます
固定辺の幅pin_edge_fraction小数0.0250.001〜0.25端からどこまでを固定するか（メッシュの大きさに対する割合）
拘束反復回数solver_iterations整数81〜24多いほど伸びにくく正確になり、重くなります
シーンのColliderと衝突world_collisionオン・オフオンシーンの Collider に当たって止まります
衝突半径collision_radius小数0.01250〜5布の点の太さ。Collider へのめり込みを減らします
衝突レイヤーcollision_maskレイヤーすべて当たる相手のレイヤー。外したレイヤーの Collider はすり抜けます。
計算点数・拘束数・準備完了・状態runtime_particles、runtime_constraints、ready、status読取のみ（実行中）うまく揺れないときは「状態」の文を見ます

スクリプトから使う（C#）

MonoBehaviour では GetComponent<ClothPhysics>() で取り出せます。メンバーは surfaceDensity、stretchStiffness、bendStiffness、gravityScale、damping、windDrag、wind、pinAxis（0 固定なし〜6 +Z側）、pinEdgeFraction、solverIterations、worldCollision、collisionRadius です。

using ReplayEngine;

public sealed class FlagGust : MonoBehaviour
{
    ClothPhysics? cloth;

    void Start() => cloth = GetComponent<ClothPhysics>();

    void Update()
    {
        // G を押している間だけ、この旗にだけ強い横風を足す
        if (cloth != null)
            cloth.wind = Input.GetKey(KeyCode.G) ? new Vector3(8.0f, 0.0f, 0.0f) : Vector3.Zero;
    }
}
制限
  • 布どうし、布と自分自身はぶつかりません。
  • Rigidbody を押し返さないので、布で物を持ち上げる・包むことはできません。
  • 閉じたメッシュ（球など）を膨らませる用途には Softbody か 膨張 を使います。

使い方の例

風になびく旗を作る

  1. GameObject を作り、Primitive Mesh Renderer（形を Plane）を付けて、旗の大きさに拡大します。
  2. Physics > XPBD布物理 を付け、固定する辺 を竿側（例：-X側）にします。
  3. 別の GameObject に 風場 を付け、風速 を 6、突風の強さ を 0.4 にします。
  4. 実行すると、竿側を残して旗がなびきます。
