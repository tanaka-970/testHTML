手続き空と体積雲（Cloud Volume・Cloud Scatter）

対象：ブランチ sinotake_test / コミット d7164091（コードから書いた内容。実機での確認はまだ）

空の画像を使わずに、大気の散乱と立体の雲で空を描く方法です。空コンポーネントの「手続き空を使う」で空全体を描き、Cloud Volume で 1 つの雲を、Cloud Scatter で雲の群れを好きな場所に置きます。

こんなときに使う

  • 空の画像を用意せずに、晴れ・曇り・雨・夕焼け・夜の空を作りたい
  • 遠くに入道雲（積乱雲）をそびえさせたい
  • 山にかかる雲、谷にたまる雲海や霧、山頂の笠雲を置きたい
  • 雲の影を地形に落としたい

基本情報

部品コンポーネントを追加での場所役割
空（手続き空）Rendering > 空空全体。大気・空一面の雲・入道雲・星・月・時刻
Cloud VolumeRendering > Cloud Volume雲 1 つ。Transform で移動・回転・拡縮できる
Cloud ScatterRendering > Cloud Scatter同じシードから毎回同じ配置で作られる雲の群れ

必要な素材：なし。大気・雲・星・月はすべて計算で描くので、キューブマップや HDR 画像は要りません。

見本のシーン（素材）

天気ごとの設定済みシーンが resources/Scenes/ProceduralSky/ にあります。開いて値を見るのが一番早い方法です。

手続き空を使う

  1. 空コンポーネントの付いた GameObject を選ぶ（無ければ Rendering > 空 を付ける）
  2. 「手続き空を使う」をオンにする。キューブマップ・パノラマは使われなくなります
  3. 雲を出すときは「雲を表示」をオンにする。「手続き空」の分類の雲の項目が出てきます
  4. 「雲量」で空を覆う割合、「雲の種類」で層雲（0 寄り）〜積雲・積乱雲（1 寄り）、「降水・荒天」で雨雲の暗さを決める
  5. 「天候を循環」をオンにすると、晴れ→曇り→雨雲を「天候変化速度」で行き来します
  6. 「時刻で太陽を動かす」をオンにすると、時間帯で太陽の向きと Directional Light の強さが連動します

手続き空の項目は、オフの機能に関係するものが隠れます（例：雲を表示がオフなら雲の項目は出ません）。

入道雲（空コンポーネントの「入道雲」分類）

「入道雲の量」を 0 より大きくすると、遠景に積乱雲を 1 つ立てます。0 なら出ません。

雲を 1 つ置く（Cloud Volume）

  1. 空の GameObject を作り、Rendering > Cloud Volume を付ける
  2. Transform で場所を決める。雲の大きさは「半径サイズ（m）」（既定 420×260×420）に Transform の拡大率を掛けたものです
  3. 「形の種類」を選ぶ：0 積乱雲、1 積雲群、2 層雲・雲海、3 霧、4 笠雲
  4. 雲海や霧を地面で切りたいときは「地表で切る」をオンにし、「地表の高さ（m）」を合わせる
  5. 雲の影を地形に落とすときは「地形へ影を落とす」をオンにし、「影の濃さ」を決める

雲の群れを置く（Cloud Scatter）

広い範囲に雲をばらまきます。配置はシードから決まるので、開き直しても同じ並びになります。

  1. 空の GameObject に Rendering > Cloud Scatter を付ける
  2. 「範囲の形」（0 箱、1 円）と「範囲サイズ（m）」で置く範囲を決める。ハイトフィールドの地形があるなら「範囲を地形全体に合わせる」をオンにするだけでよい
  3. 「雲の数」（既定 30）、「雲サイズの範囲（m）」、「最小間隔（m）」で密度を決める
  4. 「種類の割合」は 積雲・入道雲・雲海・霧 の順の比率です（既定 0.46・0.27・0.16・0.07）。笠雲は「笠雲の割合」
  5. 「高さの基準」（0 ワールド高、1 海面基準、2 地形基準）と「高さの範囲（m）」で高さを決める。「地形に合わせる」をオンにすると、地表から「地表からの高さ」だけ上に置きます
  6. 並びを変えたいときは「シード」を変える
