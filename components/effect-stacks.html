Effect Stack と Effect Preset

対象：ブランチ sinotake / コミット 9eb9813

ぼかし、発光、色調補正、ワイプなどの画面効果（エフェクト）を、上から順に重ねてかけるコンポーネントです。かける相手によって 3 種類あります。エフェクトの並びは Effect Preset というファイルに保存して、使い回すこともできます。

コンポーネントコンポーネントを追加での場所効果をかける相手1 つの GameObject に
Screen Effect StackRendering > Screen Effect Stack3D の画面全体（UI にはかかりません）1 つだけ
Model Effect StackRendering > Model Effect Stackその GameObject のモデルだけいくつでも
Effect Stack（UI）UI > Effect Stackその UI 要素（Rect Transform が必要です）1 つだけ

使えるエフェクトは 86 種類あります。種類ごとの項目は エフェクトの種類 を見てください。

こんなときに使う

  • 画面全体をセピア調にする、ぼかすなど、画面に効果をかけたいとき（Screen Effect Stack）
  • キャラクターだけを光らせる、輪郭線を付けるなど、特定のモデルだけに効果をかけたいとき（Model Effect Stack）
  • UI の画像にワイプやディゾルブをかけて、出し入れの演出を作りたいとき（Effect Stack（UI））
  • 同じ効果の組み合わせを、いくつもの場所で使い回したいとき（Effect Preset）

エフェクトを並べる

  1. GameObject にいずれかの Effect Stack を付けます。
  2. Effect 数 を 1 以上にします（最大 16）。
  3. プロパティの下に「Effect 1 / ぼかし」のような見出しが増えます。見出しを開き、種類 を選びます。種類を変えると、その種類で使う項目だけが表示されます。
  4. 項目の値を変えると、シーンビューですぐに見た目が変わります。

エフェクトは上から順にかかります。並べ替えは、インスペクターの Effect Stack (個数) エフェクトの名前… という見出しを開いて行います。見出しの中には「Surface の後へ上から順に合成。◆ を長押しして移動できます」と表示され、「Effect 1 / 種類」の行が並びます。◆ をドラッグするか、並べ替えのボタンや右クリックメニューで順番を変えます。値は、行の中ではなく、同じコンポーネントの「Effect 番号 / 種類」の見出しの中で変えます。

種類の名前の後ろに [M] が付いているエフェクトは、値を動かさなくても時間で自動的に変化します（ノイズ、揺れ、グリッチなど）。

Model Effect Stack

同じ GameObject の Mesh Renderer・Skinned Mesh Renderer などで描かれたモデルにだけ効果をかけます。表示されるモデルが無いときは何も起きません。

Effect Preseteffect_presetアセット（Effect Preset）（空）Screen Effect Stack と同じ

モデルを切り抜いて処理する条件

モデルは、次のどれかに当てはまると、ほかの物から切り抜いて別に処理されます（切り抜き）。当てはまらなければ、描かれた場所でそのまま処理されます（その場）。

  • 合成方法 が 切り抜き
  • 深度モード が Overlay
  • 対象の部分に半透明のマテリアルがある
  • 有効なエフェクトの中に、周りへ広がる種類（ぼかし、発光、揺れ、歪み、輪郭線など）か、カスタムシェーダーを使うものがある

切り抜かれたモデルは陰影の計算用のバッファから外されるため、SSAO や SSR のかかり方が変わります。

「その場」を選んでも切り抜かれることがありますこの版では、合成方法 の その場 は 自動 と同じ動きです。上の条件に当てはまると、その場を選んでいても切り抜いて処理されます。

適用範囲（3 種類共通）

エフェクトを画面の一部だけにかけるための設定です。「Effect Stack / 適用範囲」の見出しの中にあります。位置と大きさは、効果をかける相手の画面上の四角を 0〜1 とした値で指定します。

Effect Preset

エフェクトの並びを保存したファイル（拡張子 .replayeffect）です。Screen、Model、UI のどの Effect Stack からも使えます。同じ演出を複数の場所で使うときや、あとでまとめて調整したいときに使います。

作る

  1. プロジェクトパネルの何もない場所を右クリックし、Create > UI / Presentation > Effect Preset を選びます（プロジェクトパネル）。
  2. 「Effect Preset を作成しました: （ファイル名）」と表示され、ファイルができます。

編集する

  1. プロジェクトパネルで Effect Preset を選びます。インスペクターに Effect Preset Asset の見出しと、ファイルの場所が表示されます。
  2. エフェクトを追加 を押すとエフェクトが 1 つ増えます（最大 16。16 個あるとボタンは押せません）。Effect 数 を直接変えても増減できます。
  3. 「Effect 番号 / 種類」の行の左の 削除 で、そのエフェクトを消します。行をドラッグすると順番を変えられます。
  4. 下に並ぶ項目で、種類や値を決めます。

値を変えると、その場でファイルに保存され、「保存しました。参照中の UI / Model / Screen に反映されます。」と表示されます。Ctrl+Z で元に戻せます。再読み込み を押すと、保存されているファイルの内容を読み直します。ゲームの実行中は「Play 中は Effect Preset を編集できません」と表示され、編集できません。

使う

  1. Effect Stack の Preset を使用 をオンにします。
  2. Effect Preset に作ったファイルを指定します。

Preset を使っている間、その Effect Stack が自分で並べたエフェクトは使われません（消えずに残ります）。Preset が見つからないか読めないときは、自分のエフェクトが使われます。適用範囲 などのエフェクト以外の設定は、Effect Stack 側の値が使われます。

使い方

画面全体をセピア調にする

  1. 空の GameObject に コンポーネントを追加 > Rendering > Screen Effect Stack を付けます。
  2. Effect 数 を 1 にし、「Effect 1」の 種類 を 色調補正 にします。
  3. 彩度 を 0.3 程度に下げ、色の乗算 を薄い茶色にします。

キャラクターだけを光らせる

  1. キャラクターの GameObject に コンポーネントを追加 > Rendering > Model Effect Stack を付けます。
  2. Effect 数 を 1 にし、種類 を 発光 にします。
  3. 光が途中で四角く切れるときは、最大はみ出し (px) を大きくします。
