Image・Shape Image・Sprite Animator

対象：ブランチ sinotake / コミット 9eb9813

UI に画像を表示するコンポーネントです。Image は四角い範囲に画像を描き、Shape Image はその画像を自由な形で切り抜き、Sprite Animator は 1 枚の画像に並んだコマを順に切り替えてアニメーションさせます。どれも Canvas の子孫に置きます。

こんなときに使う

  • アイコン、背景、ボタンの絵など、画像を UI に表示したいとき（Image）
  • 体力ゲージや、スキルの待ち時間を表す円のように、量に合わせて表示を減らしたいとき（塗り量、塗り方向）
  • 画像に色のグラデーションを掛けたいとき（塗りの種類）
  • 画像を、四角ではない自由な形で切り抜きたいとき（Shape Image）
  • 1 枚の画像に並べたコマを、パラパラ漫画のように動かしたいとき（Sprite Animator）

Image

コンポーネントを追加での場所は UI > Image です。UI Workspace の UI 階層 で Image > 通常のImageを追加 を選ぶと、Image を持つ 160 × 80 の GameObject が作られます。

画像spriteアセット（画像）（空）AssetDatabase の Image GUID です。Atlas 未指定時に使います。
Sprite Atlasatlasアセット（スプライトアトラス）（空）不均一 Sprite Atlas。指定時は Region の Image/UV/Pivot を使います。 このビルドでは Region の Pivot は描画に使われません。使われるのは範囲、Rotated、自由形状の輪郭です。
Atlas Regionatlas_region文字（空）Sprite Atlas 内の名前付き Region。Motion の Step Key で差し替えできます。 Sprite Atlas と両方設定され、名前の一致する Region があるときだけ使います。
色color色1, 1, 1, 1描画する色を指定します。 画像の色に掛け合わせます。A は不透明度として働きます。画像が無いときはこの色の四角になります。
塗りの終端色fill_color_2色1, 1, 1, 1図形の終点側の塗り色を指定します。 塗りの種類が 線形・放射 のとき、終わり側の色。画像の色に掛け合わせます。Image の 不透明度 はこの色には掛かりません（Canvas の不透明度は掛かります）。

塗りの向きfill_angle小数0-360〜360グラデーションの向きを度単位で指定します。 線形のときの向き（度）。0 で左が 色・右が 塗りの終端色、90 で上から下へ変わります（値を増やすと画面上で時計回りに回ります）。
塗りの中心fill_center2 つの小数0.5, 0.5グラデーションの中心を正規化座標で指定します。 表示している画像の範囲を 0〜1 とした位置（0,0 が左上）。線形では色の真ん中の位置、放射では中心になります。
線の色の種類stroke_mode選択単色輪郭線の色の変化方法を指定します。 Image では、長さに沿う にすると、全体の色が左から右へ 線の終端色 に近づきます（塗りの種類の色の上にさらに掛かります）。 選択肢：単色、長さに沿う
線の終端色stroke_color_2色1, 1, 1, 1図形の輪郭線の終端色を指定します。 線の色の種類 が 長さに沿う のときの右端の色。不透明度はどちらも掛かりません。
不透明度opacity小数10〜1表示の不透明度を 0〜1 で指定します。 色の A と Canvas の不透明度に、さらに掛け合わせます。0 のときは描かれません。
塗り量fill_amount小数10〜1図形の塗り進み具合を 0〜1 で指定します。 0 のときは描かれません。水平・垂直では画像の端から隠れ、円形 360 では扇形になります。
塗り方向fill_method選択水平塗り進む方向を指定します。 水平は左から、垂直は下から、円形 360 は中心の真下から反時計回りに表示が伸びます。 選択肢：水平、垂直、円形 360
塗りを反転fill_reverseオン・オフオフ塗り進む方向を反転します。 水平は右から、垂直は上から、円形 360 は時計回りになります。
ブレンドblend_mode選択通常画像と背景を合成する方法を指定します。 通常は半透明の重ね方、加算・スクリーンは明るく、乗算は暗く重ねます。 選択肢：通常、加算、乗算、スクリーン

UV スケールuv_scale2 つの小数1, 1Sprite Sheet の1フレーム範囲を Motion から変更できます。 表示する部分の大きさの割合です。Sprite Animator があると毎回書き換えられます。 （詳細設定）
9 スライスnine_slice4 つの小数0, 0, 0, 0左、上、右、下の順に Canvas 座標の長さで指定します（範囲の半分まで）。このビルドでは見た目は通常の引き伸ばしと同じです。 （詳細設定）
比率を維持preserve_aspectオン・オフオフ9 スライスが有効な場合は 9 スライスを優先します。 余った上下または左右は空け、中央に表示します。クリックの判定も表示された部分だけになります。

表示する画像

  • Sprite Atlas と Atlas Region の両方が設定され、その名前の Region が見つかったときは、アトラスの画像の Region の部分を表示します（Sprite Atlas Editor）。
  • そうでないときは 画像 を表示します。
  • どちらも無いときは白い四角になり、色 で塗った四角として使えます。
  • UV オフセット と UV スケール は、画像（アトラスのときは Region）の中で表示する部分をずらす・広げる値です。

不透明度 が 0、または 塗り量 が 0 のときは描かれません。表示される色は、色 × 不透明度 × 親の Canvas の不透明度です。

塗り量と塗り方向

塗り量（0〜1）で、画像の一部だけを表示できます。HP ゲージなどに使います。

塗り方向塗りを反転がオフ塗りを反転がオン
水平左から右へ表示が伸びます右から左へ
垂直下から上へ上から下へ
円形 360中心から見て真下を起点に、反時計回りに扇形で表示が広がります時計回り

水平・垂直では、表示する範囲と一緒に画像の切り取る範囲も縮むので、画像は伸び縮みせずに端から隠れます。塗り量が 1 のときは、インスペクターで塗り方向と塗りを反転が選べない表示になります。

比率を維持

オンにすると、画像の縦横の比を保ったまま、範囲の中に収まる大きさで中央に表示します（余った上下または左右は空きます）。クリックの判定も、実際に表示された部分だけになります。9 スライス を使っているときは効きません。

9 スライス

4 つの値（左、上、右、下）のどれかが 0 より大きいと 9 スライスとして描きます。値は範囲の半分までに抑えられます。

このビルドでは、角が引き伸ばされないようにする効果がありません9 つに分けたときの画像の切り取り位置が、表示する範囲と同じ割合で決まるため、見た目はふつうに引き伸ばしたときと同じになります。9 スライスをオンにしたときの違いは、比率を維持 が効かなくなることと、Shape Image や Puppet Deform より優先されることだけです。

グラデーション

塗りの種類 で、画像に色の変化を掛けられます。どの場合も、決まった色を画像の色に掛け合わせます。

塗りの種類色の変わり方
単色色 だけを掛けます
線形塗りの向き の方向に、色 から 塗りの終端色 へ変わります。塗りの中心 の位置がちょうど中間の色です。向き 0 度で左から右、90 度で上から下です
放射塗りの中心 が 色、中心から範囲の角までの距離（範囲の対角線の半分）で 塗りの終端色 になります
  • 塗りの中心 は、表示している部分の左上を 0,0、右下を 1,1 とした位置です。塗り量で表示が縮んでいるときは、縮んだ範囲が基準になります。
  • 線の色の種類 を 長さに沿う にすると、上の結果にさらに、左端はそのまま・右端は 線の終端色 になるよう横方向に色を混ぜます。
  • 不透明度 は 色 側にだけ掛かります。塗りの終端色 には Canvas の不透明度だけ、線の終端色 にはどちらも掛かりません。フェードアウトさせるときは、終端色の A も一緒に下げてください。

ブレンド

背景との重ね方です。通常（半透明で重ねる）、加算（明るくなる）、乗算（暗くなる）、スクリーン（明るくなる、加算より穏やか）から選びます。

描き方が重なるとき

1 つの Image に、次のうち複数の条件がそろっているときは、上にあるものが使われます。

  1. 塗り方向が 円形 360
  2. 9 スライス が有効
  3. 同じ GameObject の Shape Image（頂点 3 つ以上）
  4. アトラスの Region が自由形状
  5. 同じ GameObject の Puppet Deform が有効
  6. ふつうの四角

Shape Image

同じ GameObject の Image を、ベジェ曲線の輪郭で切り抜くコンポーネントです。色や線は持たず、輪郭の形だけを持ちます。コンポーネントを追加での場所は UI > Shape Image です。

UI 階層の Image > 自由図形Imageを追加（狭い表示では 自由図形イメージ）を選ぶと、「自由図形 Image」という名前で、Image と Shape Image を持つ 160 × 100 の GameObject が作られます。輪郭は 4 つの頂点の四角（範囲の 12%〜88%）です。輪郭は UI Workspace の画面上で頂点をドラッグして編集します。

表示名内部名種類既定値範囲説明
Path を閉じるpath_closedオン・オフオン自由形状の末尾と先頭を接続します。Image のクリップには閉じた Path が必要です。 このビルドの描画では使われず、常に最後と最初の頂点がつながります。
Path Anchorpath_points一覧（空）正規化 0..1 の頂点配列。UI Scene View の専用コントローラーで編集できます。 Image の範囲の左下を 0,0、右上を 1,1 とした位置。最大 64 個。頂点ごとに point[番号].position としてモーションで動かせます。
Path 入力 Handlepath_in_handles一覧（空）自由形状の各頂点へ入る Bezier ハンドルを指定します。 頂点の数と同じ個数。頂点からのずれで、前の頂点から来る曲線の曲がり方を決めます（point[番号].in_handle）。 （詳細設定）
Path 出力 Handlepath_out_handles一覧（空）自由形状の各頂点から出る Bezier ハンドルを指定します。 頂点の数と同じ個数。頂点からのずれで、次の頂点へ向かう曲線の曲がり方を決めます（point[番号].out_handle）。 （詳細設定）
  • 頂点の位置は、Image の範囲の左下を (0, 0)、右上を (1, 1) とした割合です。
  • 各頂点には入力ハンドルと出力ハンドルがあり、頂点からのずれで曲がり方を決めます。頂点から次の頂点までは、前の頂点の出力ハンドルと次の頂点の入力ハンドルを使った 3 次ベジェ曲線で、1 区間を 8 つに分けて描きます。
  • 頂点が 3 つ以上あるときだけ切り抜きます。
  • インスペクターの頂点ごとの項目（「Path Point 番号」の 位置、入力ハンドル、出力ハンドル、内部名 point[番号].position など）は、モーションで動かせます。
Path を閉じる をオフにしても閉じた形になりますこのビルドの描画は、最後の頂点と最初の頂点を常につなぎます。

輪郭が自分自身と交差する形は、正しく塗れないことがあります。

Sprite Animator

コマを格子状に並べた 1 枚の画像（スプライトシート）を、決まった速さで 1 コマずつ表示します。コンポーネントを追加での場所は UI > Sprite Animator です。付けると、同じ GameObject に Rect Transform と Image も付きます。

表示名内部名種類既定値範囲説明
列数columns整数41〜256Sprite Sheet の列数を指定します。 スプライトシートの横のコマ数。1 より小さい値は 1 として扱います。
行数rows整数41〜256Sprite Sheet の行数を指定します。 縦のコマ数。1 より小さい値は 1 として扱います。
開始フレームstart_frame整数00〜65535再生する Sprite Sheet の開始フレームを指定します。 左上を 0 として右へ、行の終わりで次の行へ数えます。0〜コマ数−1 に収められます。
終了フレームend_frame整数-1-1〜65535-1 なら Sprite Sheet 全体の最後まで使います。
FPSframes_per_second小数120〜240Sprite Sheet の再生速度を 1 秒あたりのフレーム数で指定します。 1 秒に進むコマ数。0 より小さい値は 0（止まる）として扱います。時間の倍率の影響は受けません。
再生方式play_mode選択ループSprite Sheet の再生方法を指定します。 一回は最後で止まり、ループは繰り返し、ピンポンは往復、逆再生は後ろ向きに繰り返します。 選択肢：一回、ループ、ピンポン、逆再生
再生中playingオン・オフオンSprite Animator を再生するか指定します。 一回 の再生が最後まで行くと自動でオフになります。
フレームframe小数00〜65535表示する Sprite Sheet のフレーム番号を指定します。 今のコマの位置（小数）。四捨五入した番号のコマを表示します。モーションで動かしているときは、その値のコマを表示します。
  • コマの番号は、左上から右へ 0、1、2…と数え、行の終わりで次の行へ進みます。列数 × 行数 がコマの数です。
  • 毎回、同じ GameObject の Image の UV スケール を 1 コマの大きさ（1 ÷ 列数、1 ÷ 行数）に、UV オフセット を今のコマの位置に書き換えます。
  • フレーム は小数で進み、表示するコマは四捨五入した番号です。開始フレーム と 終了フレーム の範囲に収められます（終了フレームが -1 なら最後のコマまで）。
  • コマを進めるのはゲームの実行中だけです（ロード画面の表示中も進みます）。時間の倍率（Time.timeScale）の影響は受けません。一時停止メニューの中でも動きます。
  • モーションが フレーム を動かしているときは、FPS による自動の進行は止まり、モーションの値でコマが決まります。
再生方式動き
一回終了フレームまで進んで止まり、再生中 がオフになります
ループ終了フレームを越えると開始フレームから繰り返します
ピンポン開始と終了の間を往復します
逆再生フレームを減らしていき、開始フレームより前になると終了フレームへ戻ります

使い方の例

横に減っていく体力ゲージを作る

  1. UI Workspace で Canvas を選び、UI 階層の Image > 通常のImageを追加 で、ゲージの背景になる Image を作ります。色 を暗い色にし、大きさを (400, 30) などにします。
  2. Canvas を選び直してから、もう 1 つ Image を作ります（Image を選んだまま作ると、その子になります）。同じ位置・大きさにして、色 を赤などにします。これがゲージの中身です。
  3. 中身の Image の 塗り方向 を「水平」にします。塗り量 を 0.5 にすると、左半分だけが表示されることを確かめます。
  4. あとから作った中身は、同じ描画順なら背景より手前に描かれます。順番が逆になったときは、UI 階層の 前面 などで整えます。
  5. ゲームの中では、スクリプトから中身の 塗り量 を「今の体力 ÷ 最大の体力」にします（C# から UIImage を操作する）。

時計回りに埋まる円を作る

  1. 円の画像を 画像 に指定した Image を作ります。
  2. 塗り方向 を「円形 360」、塗りを反転 をオンにします。真下から時計回りに表示が広がります。
  3. モーションで 塗り量 を 0 から 1 へ動かすと、待ち時間の表示になります。

コマ送りのアニメーションを表示する

  1. コマを格子状に並べた画像（例：横 4 コマ × 縦 2 コマ）を 画像 に指定した Image を作ります。
  2. 同じ GameObject に コンポーネントを追加 > UI > Sprite Animator を付け、列数 4、行数 2、FPS を 12 などにします。
  3. ゲームを実行すると、コマが進みます（エディターで止まっている間は進みません）。
