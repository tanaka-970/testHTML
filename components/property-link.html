Property Link

対象：ブランチ sinotake / コミット 9eb9813

あるコンポーネントの数値を読み取り、範囲を変換して、別のコンポーネントの数値に書き込むコンポーネントです。プログラムを書かずに「読み込みの進み具合をゲージの長さにする」「スライダーの値をライトの明るさにする」といったつなぎ方ができます。

こんなときに使う

  • プログラムを書かずに、ある数値を別の数値につなぎたいとき（読み込みの進み具合をゲージの長さにする、など）
  • 範囲の違う値を変換してつなぎたいとき（0〜1 の値を 0〜360 度の回転にする、など）

基本情報

項目内容
コンポーネントを追加での場所Motion > Property Link
必須・推奨なし
働く場面ゲームの実行中、毎フレーム。モーションの反映が終わった後に書き込みます

値の変換のしかた

  1. 接続元の値を、元の最小値 を 0、元の最大値 を 1 とした割合に直します。
  2. 範囲内に制限 がオンなら、割合を 0〜1 に収めます。
  3. 反転 がオンなら、割合を「1 − 割合」にします。
  4. イージング のカーブを割合にかけます。
  5. 割合を、先の最小値 〜 先の最大値 の値に直します。
  6. 平滑化 が 0 より大きければ、前の値から少しずつ近づけます。
  7. 接続先のプロパティに書き込みます。接続先が整数などのときは、その種類に変換してから書き込みます。

元の最小値と最大値が同じだと、割合は 0 として扱われます。

つながらないとき

次の場合、その Property Link は何もしません。

  • 接続元または接続先のコンポーネントが未設定、または見つからない。
  • プロパティの内部名が見つからない。
  • プロパティが数値でない（数値として扱われるのは、整数・小数・選択肢・レイヤーなど）。
  • 接続先のプロパティが読み取り専用。
  • 読み取った値や変換した値が数として正しくない。
  • つながりが輪になっている：A → B、B → A のように、書き込み先から元へ戻ってくるつながりがあると、その Property Link は止まり、デバッグ出力に「PropertyLinkComponent: cyclic link disabled.」と出ます。設定を変えると、次のフレームでもう一度確かめます。

使い方

読み込みの進み具合をゲージにする

  1. 読み込み画面のシーンに Scene Loader を付けた GameObject を置きます。
  2. ゲージにする UI の Image を用意します。
  3. 空の GameObject に コンポーネントを追加 > Motion > Property Link を付けます。
  4. 接続元 Component に Scene Loader、接続元プロパティ に progress を入れます。
  5. 接続先 Component に Image、接続先プロパティ に Image の表示割合の内部名 fill_amount を入れます。
  6. 元・先の範囲はどちらも 0〜1 のままにします。読み込みが進むとゲージが伸びます。
