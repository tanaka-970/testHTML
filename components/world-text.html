ワールド文字（World Text）

対象：ブランチ sinotake_test / コミット d7164091（コードから書いた内容。実機での確認はまだ）

3D 空間に文字を置くコンポーネントです。大きさはメートルで決め、拡大しても文字の縁がにじまない MSDF 方式で描きます。Canvas を作らずに、看板の文字・頭上の名前・ダメージの数字などを出せます。コンポーネントを追加の一覧では「ワールド文字」です。

こんなときに使う

  • 建物の看板や床の案内など、場所に固定した文字を出したい
  • キャラクターの頭上に、いつもカメラを向く名前を出したい
  • 壁の向こうでも見える目印の文字を出したい

基本情報

項目内容
コンポーネントを追加での場所Rendering > ワールド文字
必要な素材フォント（.ttf / .ttc）。resources/fonts/ に meiryob.ttc（日本語）、arialbd.ttf、ariblk.ttf があります。空なら組み込みのフォント
大きさメートル単位。Transform の拡大率も掛かります
C#WorldTextComponent（Text・Height・Width・FacingMode・AlwaysOnTop・Emission・Font）

文字を置く

  1. 空の GameObject を作り、Rendering > ワールド文字 を付ける
  2. text に文字を書き、font にフォントを入れる（日本語なら meiryob.ttc）
  3. text_height で 1 文字の高さ (m) を決める（既定 0.3）。折り返す枠は layout_width×layout_height（既定 4×1.2）
  4. 向きを facing_mode で選ぶ：Transform固定（看板）、ビルボード（いつもカメラを向く）、Y軸ビルボード（縦軸だけ回る。頭上の名前向き）
  5. 暗い所でも読みたいときは outline_width と outline_color で縁取り、shadow_offset と shadow_color で影を付ける

C# スクリプトから変える

if (TryGetComponent<WorldTextComponent>(out var label))
{
    label.Text = $"残り {count}";
    label.FacingMode = 2; // Y軸ビルボード
}
