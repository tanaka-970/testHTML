XPBD有限要素Softbody

対象：ブランチ sinotake_ReplayMaster_fixed / コミット 60775ec

ゼリーやゴムのように、ぶつかるとへこんで戻る柔らかい物を作ります。メッシュの中を四面体（有限要素）に分け、XPBD で変形させて、シーンの Collider とぶつけます。

こんなときに使う

  • 落ちるとつぶれて揺れるプリン・スライム・クッションを作りたいとき
  • 叩いた所だけへこむ柔らかい的を作りたいとき

基本情報

項目内容
コンポーネントを追加での場所Physics > XPBD有限要素Softbody
必須Mesh Renderer（追加すると一緒に付きます）
もう 1 つ必要なものCPU 側のメッシュ。Sliceable か Convex Collider（頂点の元をメッシュに）を同じ GameObject に付けると用意されます。Mesh Renderer だけでは「Softbody用のCPUメッシュを待っています」のまま動きません
使えるメッシュ閉じた（穴のない）凸に近い形。中心から表面へ四面体を作るため、へこみの大きい形は「四面体が退化しています」になります。頂点・三角形とも 20,000 まで
計算のタイミング実行中の FixedUpdate
Rigidbody使いません（Softbody 自身が動きます）

スクリプトから使う（C#）

C# の型はまだありませんが、ScriptBehaviour からはプロパティを内部名で読み書きできます（型の無い部品をさわる）。叩いた所をへこませる例：

// ScriptBehaviour の中。softBody は Softbody を持つ GameObject の ObjectHandle
var found = Runtime.GetComponent(softBody, ComponentTypes.IdOf("SoftBodyComponent"));
if (found.Succeeded)
{
    var body = new ComponentAccessor(found.Value);
    body.SetVector3("impulse_position", hitPoint);          // ワールド座標
    body.SetVector3("requested_impulse", direction * 5.0f);  // 合計の衝撃
    body.SetBool("request_impulse", true);                   // 次の FixedUpdate で 1 回だけ
}
制限
  • Primitive Mesh Renderer（Cube や Sphere）には付けられません。モデルファイルの Mesh Renderer を使います。
  • 剛体（Rigidbody）とは片方向です。Softbody は Collider に押し返されますが、Rigidbody を押し動かしません。
  • Softbody どうしはぶつかりません。

使い方の例

落ちてつぶれるゼリー

  1. 丸みのある閉じたモデル（球、カプセル、角を丸めた箱など）を Mesh Renderer で置きます。
  2. Convex Collider を付け、頂点の元をメッシュにします（CPU メッシュを用意するため）。
  3. Physics > XPBD有限要素Softbody を付けます。
  4. 下に床（Box Collider）を置いて実行します。状態 が「XPBD有限要素Softbodyを実行中です。」になれば動いています。
  5. 柔らかすぎるときは ヤング率 を上げ、揺れが長いときは 速度の減衰 を上げます。
