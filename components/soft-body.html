XPBD有限要素Softbody

対象：ブランチ sinotake_test / コミット cdc0fd8

ゼリーやゴムのように、ぶつかるとへこんで戻る柔らかい物を作ります。メッシュの中を四面体（有限要素）に分け、辺の長さと体積を保つ XPBD で変形させて、シーンの Collider とぶつけます。当たった動的な Rigidbody も押し返します。

こんなときに使う

  • 落ちるとつぶれて揺れるプリン・スライム・クッションを作りたいとき
  • 叩いた所だけへこむ柔らかい的を作りたいとき

基本情報

項目内容
コンポーネントを追加での場所Physics > XPBD有限要素Softbody
必要なもの同じ GameObject の Mesh・Skinned・Primitive のどれかの Renderer。メッシュは実行開始時に Renderer から読み込みます（Sliceable や Convex Collider は不要になりました）。Renderer は自動では付きません
使えるメッシュ閉じた（穴のない）形。凸に近い形は重心から四面体を作り、へこんだ形は内部の格子に表面を埋め込んで動かします（四面体の作り方）。頂点・三角形とも 20,000 まで
計算のタイミング実行中の FixedUpdate
Rigidbody使いません（Softbody 自身が動きます）

プロパティ

表示名内部名種類既定値範囲説明
密度density小数5000.01〜100000重さ。体積 × 密度が「計算質量」になります
ヤング率youngs_modulus小数180001〜10000000硬さ。大きいほど形を保ちます
ポアソン比poisson_ratio小数0.320〜0.49つぶしたとき横へ広がる度合い。0.49 に近いほど体積を保ちます
重力の倍率gravity_scale小数1-10〜10重力に掛ける倍率。1 で通常、0 で重力なし（その場に浮く）、マイナスで上へ落ちます。
速度の減衰damping小数1.50〜40大きいほど揺れが早く収まります
風の加速度wind3 つの小数0, 0, 0風場とは別に、常にかける加速度（ワールドの向き、m/秒²）。0, 0, 0 で何もかかりません。値を大きくするほどその向きへ強く流されます。
風の受けやすさwind_drag小数1.50〜40風場 の風に流される度合い。0 なら風場を無視します
拘束反復回数solver_iterations整数51〜241 回の計算で形を戻す回数。上げるほど硬く形を保ち、つぶれにくくなりますが重くなります。
四面体の作り方tetra_mode選択自動自動・重心から・内部の格子自動なら、重心から張れない凹んだ形のときだけ内部の格子を使います。格子は表面の点で当たりを取り、押し戻しを格子点へ配ります
格子の細かさlattice_resolution整数82〜24内部の格子の 1 辺の分割数。細かいほど形に沿いますが重くなります
剛体への押し返しrigidbody_coupling小数10〜1当たった動的 Rigidbody へ返す力の強さ。0 なら以前と同じく Softbody だけが押し戻されます
シーンのColliderと衝突world_collisionオン・オフオンオンにするとシーンの Collider に当たって止まります。オフにすると通り抜けますが、計算は軽くなります。
衝突半径collision_radius小数0.0250〜5表面の点の太さ。上げるほど Collider から離れた所で止まり、めり込みにくくなります。
衝突レイヤーcollision_maskレイヤーすべて当たる相手のレイヤー。外したレイヤーの Collider はすり抜けます。
衝撃の中心impulse_position3 つの小数0, 0, 0ワールド座標。「衝撃を実行」のとき、ここから「衝撃の範囲」内の点に力を配ります。
要求する衝撃requested_impulse3 つの小数0, 0, 0範囲内の点に分ける衝撃の合計。頂点が多くても合計は同じです

スクリプトから使う（C#）

MonoBehaviour では GetComponent<SoftBody>() で取り出せます。メンバーは density、youngsModulus、poissonRatio、damping、gravityScale、wind、solverIterations、rigidbodyCoupling、読取のみの ready・totalMass・particleCount・status、ApplyImpulse(位置, 力積, 範囲 = 0.5f)、ResetSimulation() です。叩いた所をへこませる例：

using ReplayEngine;

public sealed class JellyTarget : MonoBehaviour
{
    // 弾が当たった位置（ワールド座標）と向きを受け取り、その周りだけへこませる
    public void Hit(Vector3 point, Vector3 direction)
    {
        GetComponent<SoftBody>()?.ApplyImpulse(point, direction * 5.0f, 0.3f);
    }
}
制限
  • 押し返す相手は動的な Rigidbody だけです。静的な Collider は Softbody を押し返すだけで動きません。
  • Softbody どうしはぶつかりません。

使い方の例

落ちてつぶれるゼリー

  1. 丸みのある閉じたモデル（球、カプセル、角を丸めた箱など）を Mesh Renderer で置きます。
  2. Physics > XPBD有限要素Softbody を付けます。
  3. 下に床（Box Collider）を置いて実行します。状態 が「XPBD有限要素Softbodyを実行中です。」になれば動いています。
  4. 柔らかすぎるときは ヤング率 を上げ、揺れが長いときは 速度の減衰 を上げます。
