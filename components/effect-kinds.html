エフェクトの種類

対象：ブランチ sinotake / コミット 9eb9813

Effect Stack（Screen Effect Stack、Model Effect Stack、UI の Effect Stack）と Effect Preset で使えるエフェクト 86 種類の一覧です。各エフェクトの 種類 を選ぶと、その種類で使う項目だけがインスペクターに表示されます。

どの種類にも、共通の項目として 有効、範囲へ適用、種類、カスタムシェーダー があります（Effect Stack の共通項目）。

表の「内部名」の 番号 は、上から何番目のエフェクトかを 0 から数えた数です。Motion や Property Link で値を動かすときに使います。

ここにある範囲はインスペクターで入力できる範囲です。説明は、インスペクターでマウスを乗せたときに出る説明と同じです。

こんなときに使う

  • 使いたい見た目の効果（ぼかし、ワイプ、グリッチなど）が、どの種類の名前か探したいとき
  • エフェクトの項目を、モーションや Property Link で動かすための内部名を知りたいとき
  • 値を動かさなくても、時間で自動的に変化するエフェクトを探したいとき（一覧の「時間」の列）

種類ごとの項目

ぼかし（Blur）

表示名内部名種類範囲説明
ぼかし半径effects[番号].radius小数0〜512ぼかしを広げる距離（ピクセル）。
適用量effects[番号].intensity小数0〜1元画像からぼかし画像へ混ぜる割合。

発光（Glow）

表示名内部名種類範囲説明
光の半径effects[番号].radius小数0〜512発光を広げる距離（ピクセル）。
光の強さeffects[番号].intensity小数0〜32加算する発光の強さ。 0 で光らず、上げるほど明るく光ります。1 を超えると白く飛びやすくなります。
発光しきい値effects[番号].threshold小数0〜1この明るさ以上の部分から光を作る。0 なら色を問わず光る。
光の色effects[番号].color色発光へ掛ける色と不透明度。

彩度effects[番号].radius小数0〜81 が元の彩度、0 でグレースケール。
コントラストeffects[番号].intensity小数0〜81 が元のコントラスト。
明るさeffects[番号].amount小数-1〜1RGB へ加える量。0 が中立。

使い方の例

エフェクトを選んで、値を動かす

  1. Effect Stack を付けた GameObject を選び、エフェクトを足します（エフェクトを並べる）。
  2. 足したエフェクトの 種類 で、この一覧の名前を選びます。インスペクターに、その種類の項目だけが出ます。
  3. 下の「種類ごとの項目」の表で、それぞれの項目の働きと範囲を確かめて値を入れます。
  4. 時間で変化させたいときは、モーションで、その項目（表の内部名。番号は上から何番目のエフェクトか）のトラックを作ります。
