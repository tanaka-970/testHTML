Button・入力部品・Mask

対象：ブランチ sinotake / コミット 9eb9813

押す、選ぶ、並べる、スクロールする、値を動かす、文字を入力する、切り抜く、といった UI の操作部品です。どれも Canvas の子孫に置きます。

こんなときに使う

  • 押すと処理が動くボタンを作りたいとき（Button）
  • キーボードやゲームパッドの方向キーで、メニューを選べるようにしたいとき（Selectable とフォーカス）
  • ボタンやアイコンを、横・縦・格子にきれいに並べたいとき（Layout Group）
  • 枠に収まらない長いリストや文章を、スクロールして見せたいとき（Scroll View）
  • 音量などの数値を、つまみで変えてもらいたいとき（Slider）
  • 名前などの文字を入力してもらいたいとき（Input Field）
  • 画像や UI を、枠や形の中だけに切り抜いて見せたいとき（Mask）
  • 押すと表示の言語が切り替わるボタンを作りたいとき（Language Switch）

フォーカスと入力の共通のしくみ

  • マウスの位置とクリックは、手前の Canvas から順に、各 UI の範囲（回転・拡大率を含む）で判定します。親に 矩形 の Mask があるときは、Mask の外側ではクリックに反応しません。
  • キーボードやゲームパッドでの操作は、フォーカス（今選ばれている部品）を使います。フォーカスできるのは Selectable を持つ部品です。Button、Scroll View、Slider、Input Field を付けると Selectable も自動で付きます。
  • 方向の移動は入力アクション NavigateUp、NavigateDown、NavigateLeft、NavigateRight、決定は UISubmit で行います（キーの割り当ては 入力）。

Button

押せるボタンです。コンポーネントを追加での場所は UI > Button です。UI 階層の Button ボタンで、Image と Button を持つ GameObject と、子の文字「Button Text」が作られます。

状態の決まり方

状態なる条件
無効操作可能 がオフ、または GameObject・コンポーネントが無効
押下範囲の上でマウスの左ボタンを押している、またはフォーカス中に UISubmit を押している
ホバーマウスが範囲の上にある、またはフォーカスされている
通常それ以外
  • 押下 の状態から、範囲の上でマウスを離す、または UISubmit を離すと「クリック」になります。範囲の外へ出てから離したときはクリックになりません。
  • パッド/キーでフォーカス がオンなら、マウスを乗せただけでそのボタンにフォーカスが移ります。
  • 毎回、状態に合わせて 対象 Image（未設定なら同じ GameObject の Image）の 色 を、通常色・ホバー色・押下色・無効色 で書き換えます。Image 側の色を直接変えても上書きされます。
  • Button の 操作可能、パッド/キーでフォーカス、フォーカス順 は、同じ GameObject の Selectable へ毎回コピーされます。Button がある GameObject では、Selectable のこの 3 つは Button 側で設定します。

状態ごとのモーション

ゲームの実行中に状態が変わると、その状態のモーション（通常 Motion など）を再生します。同じ GameObject に Motion Player が無ければ自動で付け、あればそれを使います。モーションはループせず、最後の値で止まります。前の状態からは 状態 Blend 秒 かけて切り替わります。

押されたことを受け取る

  • C#（ScriptBehaviour）の OnButtonClicked、OnAnyButtonClicked、OnButtonStateChanged（受け取れるイベント）
  • 同じ GameObject の Language Switch、Button Property Toggle

フォーカスの移り方

  1. フォーカスできる部品は、アクティブで、操作可能 と ナビゲーション有効 がオンで、Rect Transform を持つものです。
  2. 何もフォーカスされていないときに、方向または UISubmit を押すと、いちばん手前（描画順が最大）の Canvas の中で Tab 順 が最も小さい部品にフォーカスします。Tab 順が同じならシーンの並び順で先のものです。
  3. 方向を押すと、その方向の 上へ・下へ・左へ・右へ に指定した部品があれば、そこへ移ります（その部品がフォーカスできないときは指定が無いのと同じ）。
  4. 指定が無ければ、同じ Canvas の中から自動で探します。今の部品の中心から見てその方向の前にある部品のうち、「前への距離 ＋ 横へのずれ × 方向探索 Bias」が最も小さいものです。Bias を大きくすると、まっすぐ並んだ部品が選ばれやすくなります。

Input Field にフォーカスがあるときは、左右キーは文字カーソルに使うため移動しません。横向きの Slider では左右、縦向きの Slider では上下が値の変更に使われ、その方向には移動しません。

マウスで Scroll View、Slider、Input Field を押すと、それにフォーカスが移ります。

フォーカスの輪郭線

フォーカスされている部品の範囲に、四角い輪郭線を描きます。色・幅・表示するかは、ふつうはプロジェクト共通の設定（階層 の ワールド を選んだインスペクターの プロジェクト設定 > UI Focus Outline）を使います。Focus Style 上書き をオンにすると、この部品の 輪郭線を表示、輪郭線色、輪郭線幅 を使います。

  • 輪郭線幅は画面のピクセル単位で、範囲の短い辺の半分までです。
  • 角丸 は輪郭線の角の丸みです。Focus Style 上書き がオフならプロジェクト設定の値、オンなら部品の値が使われます。

Layout Group（横・縦・グリッド）

子の UI を自動で並べます。コンポーネントを追加での場所は UI > Horizontal Layout Group、Vertical Layout Group、Grid Layout Group です。

  • 並べる対象は、Rect Transform を持つ直接の子です。非アクティブの子も場所を取ります（表示はされませんが、並びの中の 1 つとして数えます）。
  • 子の Rect Transform に保存されている値は書き換えず、表示するときの位置と大きさだけを決めます。並べられている子のアンカーや位置の値は、表示には使われません。
  • 1 つの GameObject に複数の種類を付けたときは、Horizontal、Vertical、Grid の順に最初に見つかったものだけが使われます。
  • Padding は左、上、右、下の順の余白です。マイナスの値は 0 として扱います。間隔 もマイナスは 0 です。

作り方

  1. 枠にする GameObject に Scroll View を付け、Rect Transform で枠の大きさを決めます。
  2. その 直接の子 に、中身をまとめる GameObject（Rect Transform を持つもの）を作り、枠より大きくします。縦に並べるなら Vertical Layout Group を付けると便利です。
  3. Scroll View の Content に、その子の Rect Transform を指定します。

Content が直接の子でないときは、スクロールしません。

スクロールの動き

  • 中身が枠より大きい方向だけスクロールできます（横スクロール・縦スクロール がオンの方向）。スクロール位置 は 0 から「中身の大きさ − 枠の大きさ」までに収められます。
  • スクロール位置 の Y を増やすと中身が上へ動き、下の方が見えます。X を増やすと中身が左へ動きます。
  • マウスホイールは、縦にスクロールできればホイール 1 目盛りで ホイール感度 分だけ縦に、できなければ横にスクロールします。
  • 中身の上を押してドラッグすると、中身をつかんで動かせます。スクロールバーのつまみをドラッグしても動かせます。
  • Scroll View の中に Scroll View があるときは、マウスの下の内側の Scroll View だけが動きます。
  • キーボードやパッドでフォーカスが中身の部品に移ったとき、その部品が枠からはみ出していれば、見える位置まで自動でスクロールします。

スクロールバー

  • スクロールできる方向があり、スクロールバー表示 がオンのとき、縦は枠の右端、横は枠の下端に描きます。
  • バー幅 は画面のピクセル単位です。つまみの長さは「見えている割合」に比例し、バー幅より短くはなりません。
  • 角丸 はスクロールバー（つまみと溝）の角の丸みです。

作り方

  1. Slider を付けた GameObject の範囲が、つまみを動かせる範囲になります。
  2. 塗りで値を見せるには、同じ GameObject に Image を付けるか、Fill Image に別の Image を指定します。
  3. つまみを付けるには、子に Image を持つ GameObject を作り、その Rect Transform を Handle Rect に指定します。

動き

  • 値 は、最小値と最大値の間に収められます（最小値の方が大きくても、小さい方から大きい方の範囲として扱います）。整数のみ がオンなら四捨五入します。
  • Fill Image の Image（未設定なら同じ GameObject の Image）の 塗り量 を値の割合に、塗り方向 と 塗りを反転 を 方向 に合わせて毎回書き換えます。Fill Image を設定していてその Image が見つからないときは、何も書き換えません。
  • Handle Rect のアンカー（横向きなら X、縦向きなら Y の最小・最大の両方）を値の割合に合わせます。つまみの位置は、ピボットとアンカーで決まります。
  • 範囲の上で押すと、そこからドラッグしている間、マウスの位置の割合で値が決まります。範囲の外に出ても、離すまで続きます。
  • フォーカス中は、横向きなら NavigateLeft / NavigateRight、縦向きなら NavigateDown / NavigateUp で キー操作量 だけ値が変わります。右から左・上から下の向きでは増減が逆になります。
  • ゲームの実行中は、値が前回と変わったときに SliderValueChanged を送ります（C# の OnSliderValueChanged）。

使い方の例

押したら処理が動くボタンを作る

  1. UI Workspace で Canvas を選び、UI 階層の Button ボタンを押します。ボタンと、子の「Button Text」ができます。
  2. Button Text を選び、Text の テキスト を「START」などにします。
  3. ボタンを選び、ホバー色 と 押下色 を好みの色にします。ゲームを実行し、マウスを乗せる・押すで色が変わることを確かめます。
  4. 押されたときの処理は、ScriptBehaviour の OnButtonClicked で受け取って書きます（ScriptBehaviour）。

縦に並んだメニューを、方向キーで選べるようにする

  1. Canvas を選び、UI 階層の Image > 通常のImageを追加 でメニューの板を作り、大きさを (300, 300) などにします。
  2. 板に コンポーネントを追加 > UI > Vertical Layout Group を付け、間隔 を 10、Padding を (10, 10, 10, 10) にします。
  3. 板を選んで UI 階層の Button ボタンを押し、板の子にボタンを作ります。作ったボタンが選ばれた状態になるので、毎回板を選び直してから押し、ボタンを 3 つ作ります。上から順に並びます。
  4. それぞれのボタンの フォーカス順 を 0、1、2 にします。
  5. ゲームを実行し、方向キー（NavigateUp / NavigateDown）でフォーカスが移り、決定（UISubmit）でボタンが押されることを確かめます。

スクロールするリストを作る

  1. 枠にする Image を作り、大きさを (400, 300) にします。枠に コンポーネントを追加 > UI > Scroll View と UI > Mask を付けます（Mask の マスク方式 は 矩形）。枠の外にはみ出した中身が見えなくなります。
  2. 枠を選んで Image をもう 1 つ作り、枠の直接の子にします。これを中身（Content）にし、大きさを (400, 1000) のように枠より縦に長くして、Vertical Layout Group を付けます。
  3. 枠の Scroll View の Content に、中身の Rect Transform を指定します。
  4. 中身の子に Text などを並べます。中身の大きさは自動では変わらないので、並べた量に合わせて高さを変えます。
  5. ゲームを実行し、マウスホイールやドラッグでスクロールすることを確かめます。

音量のスライダーを作る

  1. 横長の Image（例：400 × 20）を作り、コンポーネントを追加 > UI > Slider を付けます。同じ Image が値の塗りになります。
  2. 最大値 を 100、整数のみ をオンにします。
  3. つまみを付けるときは、スライダーを選んで Image を作り、子の小さな Image（例：24 × 32）にして、Slider の Handle Rect にその Rect Transform を指定します。
  4. 値を文字で見せるには、Text の 数値の表示 を使います。
