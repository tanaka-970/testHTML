Pivot

対象：ブランチ sinotake / コミット 9eb9813

エディターのギズモで回転・拡縮するときの中心（基準点）を決めるコンポーネントです。基準点を変えても、GameObject の位置（Transform）や見た目は変わりません。

こんなときに使う

  • 扉を蝶番の位置で回すときのように、ギズモで回す・拡縮する中心を物の端にしたいとき
  • 基準点を、メッシュの頂点・辺・面にぴったり合わせたいとき

基本情報

項目内容
コンポーネントを追加での場所Core > Pivot
必須・推奨なし
働く場面エディターのギズモ操作だけ。ゲームの実行中には使われません

プロパティ

表示名内部名種類既定値説明
基準点の決め方mode選択自分の原点基準点をどう決めるか。次の表を見てください。
基準点local_pointX Y Z0, 0, 0「ローカル座標」「ワールド座標」では基準点の座標、「境界の面」ではどの面を選ぶかの向きとして使います。
対象オブジェクトtargetGameObject の参照（未設定）「別オブジェクト」のときに基準点にする GameObject。

基準点の決め方

選択肢基準点
自分の原点GameObject の位置そのもの（Pivot が無いときと同じ）。
境界の中心形の外枠（境界の箱）の中心。
境界の面形の外枠の、ある面の中心。基準点 の X・Y・Z のうち、数値の大きさ（符号を除く）がいちばん大きい軸の方向の面を使います。たとえば基準点が 0, -1, 0 なら底の面、0, 1, 0 なら上の面になります。
ローカル座標基準点 を GameObject から見た座標として使います。GameObject を動かすと基準点も一緒に動きます。
ワールド座標基準点 をシーン全体の座標として使います。GameObject を動かしても基準点は動きません。
別オブジェクト対象オブジェクト の位置。対象が未設定、または見つからないときは自分の原点になります。
「境界の中心」「境界の面」には当たり判定が必要です形の外枠は、同じ GameObject の Mesh Collider または Landscape Collider から求めます。どちらも無い（または当たり判定のデータがまだできていない）ときは、自分の原点が基準点になります。

使い方

決め方を選んで使う

  1. 基準点を変えたい GameObject を選び、コンポーネントを追加 > Core > Pivot で付けます。
  2. 基準点の決め方 を選び、必要なら 基準点 や 対象オブジェクト を設定します。
  3. ツールバーの Rotate か Scale でギズモを動かすと、選んだ基準点を中心に回転・拡縮します。

メッシュの頂点・辺・面に吸着させる

  1. Pivot と Mesh Collider（または Landscape Collider）が付いた GameObject を選びます。
  2. ツールバーの Pivot を押して Pivot:ON にします。右に 面Snap、頂点Snap、辺Snap が出ます。
  3. 吸着させたいボタンを押します。探し始める点にいちばん近い面・頂点・辺の上に基準点が移り、「Pivotを面へSnapしました」などと表示されます。探し始める点は、決め方が「ワールド座標」「ローカル座標」「境界の面」なら 基準点 の値、「自分の原点」「境界の中心」「別オブジェクト」なら形の外枠の中心です。

吸着させると、決め方が「ワールド座標」のときはそのまま、それ以外のときは「ローカル座標」に切り替わり、吸着した点が 基準点 に入ります。この操作は Ctrl+Z で戻せます。

Pivot:ON の間は、Transform を動かさずに基準点だけを編集できます。

注意

  • 移動（Move）のギズモには基準点は関係しません。
  • ゲームの実行中の回転や拡縮、モーション、スクリプトからの回転には使われません。
