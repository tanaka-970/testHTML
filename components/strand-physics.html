ワイヤー・ヘア・ホース物理

対象：ブランチ sinotake_test / コミット cdc0fd8

ひも状のものを揺らす 5 つのコンポーネントです。ワイヤー物理 と XPBDホース物理 は 3D ラインの点列（またはメッシュ）をロープやホースとして動かし、ヘア物理 はスキンモデルの髪ボーン（または骨の無いメッシュ全体）を揺らします。どれも 風場 の風を受け、Water Body の水の中では抵抗と浮力を受けます。髪・ワイヤー用の衝突形状 は髪とワイヤーだけを押し返す球・カプセル、ホースリール はホースの繰り出しと巻き取りです。どれも実行中だけ計算し、停止すると実行前の形へ戻ります。

こんなときに使う

  • 吊り橋のロープ、電線、たるんだケーブルを置きたいとき（ワイヤー物理）
  • キャラクターの髪やリボンを、動きに遅れて揺らしたいとき（ヘア物理）
  • グラップリングのワイヤー、消防ホースなど、太さのある管を伸び縮みさせたいとき（XPBDホース物理・ホースリール）

どれを使うか

やりたいこと使うもの付ける場所
軽いロープ・紐ワイヤー物理3D ライン（Line Renderer）の GameObject
太さのある管。長さを実行中に変えるXPBDホース物理（＋ホースリール）3D ラインの GameObject（リールは別の GameObject でも可）
髪・リボン・尻尾ヘア物理Skinned Mesh Renderer の GameObject
髪が頭に埋まらないようにする髪・ワイヤー用の衝突形状キャラクターの GameObject（複数可）
見本シーンresources/StrandShowcase/StrandComparison.replayscene を開いて実行すると、両端固定のロープ、片端の紐、髪付きモデルを見比べられます。シーンビューの「コライダー」で衝突形状（桃色）、「リグ」で髪ボーンを確認できます。ホースの見本は起動オプション --create-xpbd-hose-showcase で Saved/Validation/XPBDHoseVisual.replayscene に作れます。

ワイヤー物理

項目内容
コンポーネントを追加での場所Physics > ワイヤー物理
形の元同じ GameObject の Line Renderer（3D ライン、推奨）か、Mesh・Skinned・Primitive のどれかの Renderer。Line Renderer なら点列をそのまま動かし、メッシュならメッシュの長い軸に沿って点列を作り、その点列に合わせてメッシュを曲げます。部品は自動では付きません
点3D ラインに 2 点以上。閉じたラインは使えません。点はこの GameObject のローカル座標です
上限1 本 129 点まで（途中の分割数 128）
表示名内部名種類既定値範囲説明
計算品質quality選択標準軽量・標準・高精度反復回数の目安。高精度ほど伸びにくく、重くなります
重力の倍率gravity_scale小数1-5〜5重力に掛ける倍率。1 で通常、0 で重力なし（その場に浮く）、マイナスで上へ落ちます。
揺れの減衰damping小数30〜40大きいほど早く揺れが収まります
元の形へ戻る強さstiffness小数00〜10 で柔らかいロープ、上げると元の経路に戻ろうとするケーブル
風の加速度wind3 つの小数0, 0, 0風場とは別に、常にかける加速度（ワールドの向き、m/秒²）。0, 0, 0 で何もかかりません。値を大きくするほどその向きへ強く流されます。
風の受けやすさwind_drag小数10〜40風場 の風に流される度合い。0 なら風場を無視します
衝突の太さparticle_radius小数0.0250.0001〜1当たり判定の半径。見た目の太さ（3D ライン側）とは別です
シーンの物体にも当てるworld_collisionオン・オフオンシーンの Collider に当てます。オフの方が軽くなります。専用の衝突形状は常に当たります
当たるレイヤーcollision_maskレイヤーすべてシーンの Collider のうち当てるレイヤー
揺れを戻す移動距離teleport_distance小数30.01〜1001 フレームでこれ以上動いたら、ワープとみなして揺れをリセットします
途中の分割数segment_count整数242〜128物理で計算する点の数。細かい角に沿わせるなら増やします
始点を固定・終点を固定pin_start、pin_endオン・オフオン、オフ両端を吊るすなら両方オン
始点の固定先・終点の固定先start_anchor、end_anchorGameObject（空）追従させる GameObject。空ならラインの元の端
始点（終点）の固定先からの位置start_offset、end_offset3 つの小数0, 0, 0固定先のローカル座標。固定先の GameObject の中心から、端をどれだけずらして付けるか。固定先が回転・拡大すると、ずらす向きと量も一緒に変わります。
長さの余裕slack小数1.051〜41 は元の長さ。1.05〜1.3 でたるみます。両端を離しすぎると張り切ります
水の抗力・水の浮力water_drag、water_buoyancy小数3、0.150〜40、0〜2Water Body の水に入った部分にかかる抵抗と浮力。浮力は重力に対する割合です
剛体を引くpull_bodiesオン・オフオフ両端の固定先が動的な Rigidbody のとき、全長を超えて離れた分だけ引き戻します（ロープで物を吊る・つなぐ）
張力の上限（N）maximum_pull_force小数20000〜1000000「剛体を引く」で出す力の上限
現在の張力・状態current_tension、status読取のみ状態には、設定が正しくないときの理由が出ます

ヘア物理

項目内容
コンポーネントを追加での場所Physics > ヘア物理
形の元Skinned Mesh Renderer（推奨）。髪ボーンとウェイトを持つモデルでは、そのボーンを揺らします（ボーンを自動では作りません）。骨の無い Mesh・Primitive の Renderer に付けると、メッシュ全体を根元固定の 1 束として揺らします
上限1 キャラクターの髪は合計 2048 点まで。衝突形状は 128 個まで候補にします

計算品質・重力の倍率・揺れの減衰・元の形へ戻る強さ・風・衝突の太さ・シーンの物体にも当てる・当たるレイヤー・揺れを戻す移動距離はワイヤー物理と同じ意味です（既定値は 標準、0.4、5、0.35、0、0.015、オフ、すべて、2）。

XPBDホース物理

項目内容
コンポーネントを追加での場所Physics > XPBDホース物理
形の元Line Renderer（開いたラインに 2 点以上、推奨）か、Mesh・Skinned・Primitive のどれかの Renderer（ワイヤー物理と同じく、メッシュを点列に沿って曲げます）

計算固定刻みの XPBD。断面の向き・曲げ・ねじれも計算します（PositionBasedDynamics の Cosserat ロッド）

チューブ半径tube_radius小数0.0250.001〜2見た目の太さ（m）。当たり判定の太さは「衝突半径」で別に決めます。

風の受けやすさwind_drag小数10〜40風場 の風に流される度合い

ホースリール

Physics > ホースリール。XPBDホース物理の長さを一定の速さで伸ばし縮めし、ドラムの回転を合わせます。

表示名内部名種類既定値範囲説明
操作するホースhoseGameObject（空）XPBDホース物理を持つ GameObject。未設定だと動きません
回転するドラムdrumGameObject（空）空ならこの GameObject を回します。ホースの端点を持つ GameObject のときは別のものを指定します
動作mode選択停止停止・繰り出す・巻き取る停止で長さが止まり、繰り出すで「ホース速度」ずつ伸び、巻き取るで縮みます。
ホース速度line_speed小数1.50〜1001 秒に伸び縮みする長さ
ドラム半径drum_radius小数0.150.001〜10回転の速さの計算に使います
回転軸spin_axis選択ZX・Y・Zドラムを回す軸（ドラムのローカル軸）。ホースの出る向きに合わせます。

スクリプトから使う（C#）

MonoBehaviour から GetComponent<HosePhysics>()・GetComponent<WirePhysics>() で取り出せます。WirePhysics のメンバーは segmentCount、gravityScale、damping、stiffness、wind、slack、waterDrag、waterBuoyancy、pullBodies、maximumPullForce、currentTension（読取のみ）、status（読取のみ）、ResetSimulation() です。HairPhysics（gravityScale、damping、stiffness、wind、runtimePoints、ResetSimulation()）と HoseReel（mode は ReelMode、lineSpeed、drumRadius、status）もあります。衝突形状の型はまだありませんが、ScriptBehaviour からはプロパティを内部名で読み書きできます（型の無い部品をさわる。例：ホースリールの mode を 1 にして繰り出す）。

メンバー働き
paidOutLength繰り出し長さ。0.001〜maximumLength に収めて設定します
maximumLengthホース長の上限（0.001〜1000）
overstretched長さの限界を超えているか（読取のみ）
waterDrag、waterBuoyancy水の抗力・水の浮力
endAnchor、endOffset終点を付ける GameObject と、その GameObject の座標系での取り付け位置（end_anchor・end_offset）。射出したフックのモデルの柄尻に結ぶ、など実行中に付け先を変えるときに使います。変えるとホースの形を作り直すので、毎フレーム書き換えないでください
distanceCompliance、solverIterations、damping伸縮の柔らかさ、拘束反復回数、速度の減衰
using ReplayEngine;

public class Winch : MonoBehaviour
{
    HosePhysics? hose;

    void Start() => hose = GetComponent<HosePhysics>();

    void Update()
    {
        if (hose == null) return;
        // 押している間だけ巻き取る
        if (Input.GetKey(KeyCode.Q)) hose.paidOutLength -= 2.0f * Time.deltaTime;
        if (Input.GetKey(KeyCode.E)) hose.paidOutLength += 2.0f * Time.deltaTime;
    }
}

ゲーム「GrapplerClimb」の HaveHook.cs は、ワイヤーの見た目にこの方法を使っています（当たり判定と振り子の動きはスクリプト側で計算し、ホースには長さだけを渡す）。

制限
  • ワイヤー・ヘアの束同士はぶつかりません。ロープが剛体を引っぱる（双方向の連結）こともありません。剛体をつなぐときは Physics Joint を使います。
  • ワイヤー・ヘア・ホースは編集中（実行していないとき）は動きません。F1 でエディター表示を切り替えても始まりません。
  • 実行中に揺れた形は保存されません。設定を残すには停止してから編集し、保存します。

使い方の例

2 本の柱の間にロープを張る

  1. 空の GameObject を作り、コンポーネントを追加 > Physics > ワイヤー物理 を付けます。Line Renderer も一緒に付きます。
  2. Line Renderer の点を 2 つにし、始点 (0, 3, 0)、終点 (3, 3, 0) のように置きます。太さと色は Line Renderer で決めます。
  3. 始点を固定 と 終点を固定 をオンにし、始点の固定先・終点の固定先 に柱の GameObject を入れます。
  4. 長さの余裕 を 1.1 くらいにして実行します。ロープがたるみ、柱を動かすと付いてきます。

キャラクターの髪を揺らす

  1. Skinned Mesh Renderer のあるキャラクターに ヘア物理 を付けます。
  2. モデルが一度表示されたら、根元ボーンを選んで追加 から髪束の先頭のボーンを選びます（束の数だけ繰り返す）。
  3. 同じ GameObject に 髪・ワイヤー用の衝突形状 を付け、形状 を球、追従するボーン名 を頭のボーン（見本では Head）にして、頭が包まれる大きさにします。
  4. 実行して、重力・減衰・元の形へ戻る強さを調整します。髪が頭に入り込むときは、球の半径と髪の衝突の太さを少し上げます。

リールでホースを巻き取る

  1. 3D ラインの GameObject に XPBDホース物理 を付け、両端の固定先を設定します。
  2. リール役の GameObject に ホースリール を付け、操作するホース にホースの GameObject を入れます。
  3. 動作 を「巻き取る」にして実行すると、ホースが短くなり、ドラムが回ります。
