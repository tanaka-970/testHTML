デカール・面テクスチャ・電光掲示板

対象：ブランチ sinotake_test / コミット d7164091（コードから書いた内容。実機での確認はまだ）

シーンの面に画像を貼る 2 つの方法と、貼った画像を流したりコマ送りしたり、LED の電光掲示板のように見せたりする部品の説明です。

こんなときに使う

  • 壁や床に、落書き・血痕・ひび・足跡などの画像を、モデルを作り直さずに重ねたい（投影デカール）
  • 看板やモニターなど、モデルの決まった面だけに画像を貼りたい（面テクスチャ領域）
  • ビルの壁の電光掲示板に、流れる文字や LED の粒々を出したい（表示内容アニメーション / LED）

投影デカール

GameObject のローカル −Z 方向へ向けて、画像を箱の範囲に投影します。箱と交わった不透明な面に画像が重なります。

  1. 空の GameObject を作り、Rendering > 投影デカール を付ける
  2. 「画像」に貼りたい画像を入れる。アルファのある PNG なら、透明な所は下の面が見えます
  3. GameObject を壁の手前に置き、−Z が壁に向くように回す（床なら真下へ向ける）
  4. 「投影サイズ」で X/Y を画像の幅と高さ、Z を投影する奥行きにする。奥行きを壁の厚みより大きくすると、裏側の面にも映ります
  5. 斜めの面に伸びて映るときは「面の向き制限」を上げる。投影方向と向きが合わない面は除外されます

銃痕のように時間で消したいときは「寿命（秒、0は無期限）」に秒数を入れます。最後の「消える時間（秒）」でフェードアウトします。

面テクスチャ領域

モデルの UV を使って、選んだ面の範囲だけに画像を貼ります。どの面に貼るかは 頂点ペイントパネルの UV 表面ペイントで選びます。

  1. 画像を貼りたいモデル（Mesh Renderer か Skinned Mesh Renderer の付いた GameObject。Primitive Mesh Renderer は対象外）に Rendering > 面テクスチャ領域 を付け、texture に画像を入れる
  2. 頂点ペイントのパネルを開き、UV表面ペイントで「面をクリック/ドラッグで選択」をオンにする
  3. 「UV Surface Layer」で使うチャンネル（R・G・B・A）を選び、貼りたい面をクリック／左ドラッグで選ぶ。Shift+左ドラッグで外す。UV Clear 0 で全部外す
  4. UV Paintを保存 を押す（選んだ範囲はこのファイルに保存されます）
  5. 面テクスチャ領域の mask_source を、選んだチャンネル（UV Paint R〜A）に合わせる。「全体」ならマスクを使わず全面に貼ります
  6. 画像の位置は uv_scale・uv_offset・uv_rotation（度）で合わせる

モデルの UV がばらばらで画像が崩れるときは、mapping_mode を「平面投影」にします。plane_origin・plane_rotation（度）・plane_size で決めた板から投影するので、UV に関係なく真っすぐ貼れます。

表示内容アニメーション / LED（電光掲示板）

投影デカールか面テクスチャ領域と同じ GameObjectに付けると、貼る画像を動かせます。単体では何も描きません。

画像を流す・コマ送りする（content_mode：画像）

  • uv_scroll：1 秒あたりに画像をずらす量。横に流すなら X に値を入れる
  • uv_scale・uv_offset：画像の拡大と位置
  • flipbook_columns・flipbook_rows・flipbook_fps：画像を格子に区切ったコマとして、左上から順に再生する。素材は横×縦にコマを並べた 1 枚の PNG（例：4×4 で 16 コマ）。fps が 0 ならコマ送りしない

流れる文字を出す（content_mode：MSDF文字）

  1. content_mode を MSDF文字 にする
  2. text に文字を書く。日本語も使えます
  3. font にフォントを入れる。resources/fonts/ に meiryob.ttc（日本語）、arialbd.ttf、ariblk.ttf が入っています。空なら組み込みのフォントを使います
  4. text_height（表示の高さに対する文字の高さ、0.1〜1）、text_color、text_scroll_speed（1 秒に流れるピクセル数、既定 32）を決める
  5. 文字を描く画像の大きさは resolution_width×resolution_height（既定 512×128）。横長の掲示板なら横を大きくする

LED の粒々にする

  • led_enabled をオンにすると、画像や文字を LED の粒の並びとして描きます
  • led_count：横×縦の粒の数（既定 64×16、最大 512）
  • led_shape：円／四角。led_fill：粒の大きさ（0.05〜1）
  • led_gap_brightness：粒のすき間の明るさ。led_off_glow：消えている粒のかすかな光
  • emission：発光（0〜64）。夜景で光らせるときに上げる

C# スクリプトから変える

SurfaceDisplayComponent（ContentMode・Text・TextScrollSpeed・FlipbookFps・LedEnabled・Emission）と ModelTextureRegionComponent（MaskSource・MappingMode・Emission・Texture）があります。

if (TryGetComponent<SurfaceDisplayComponent>(out var board))
    board.Text = "STAGE CLEAR";

使い方の例：ビルの電光掲示板

  1. ビルの壁の前に空の GameObject を置き、投影デカールを付けて −Z を壁へ向ける。「投影サイズ」を掲示板の大きさ（例 8, 2, 0.5）にする。画像は空でよい
  2. 同じ GameObject に 表示内容アニメーション / LED を付け、content_mode を MSDF文字、text に流したい文字、font に meiryob.ttc を入れる
  3. resolution_width を 1024 程度、text_scroll_speed を 60 程度にする
  4. led_enabled をオン、led_count を 128×24 程度、emission を 4〜8 にする

2026-10-27 追記：テレビ・看板を複数レイヤーで作る

同じモデルに 面テクスチャ領域 を複数追加できます。モデリング Workspace の「画像レイヤーを追加」は、直前のレイヤーの選択面・投影位置を引き継ぎます。各レイヤーで画像・透明度・移動・回転・大きさ・重ね順・表示オン／オフを別々に設定します。

  1. モデルに面テクスチャ領域を付け、「モデルの面をクリックして画像を貼る」で表示面を選びます。複数面を選べます。
  2. 表示マスクを「選択した面」「UV 塗り R〜A」「頂点色 R〜A」から選びます。「選択面と塗りマスクを組み合わせる」で、選択面の内側だけ塗り値を掛けられます。
  3. 必要なら追加マスク画像を指定し、アルファ／輝度・反転・強さ・しきい値を調整します。画像自身の透明部分も表示範囲に反映されます。
  4. さらに画像レイヤーを追加して文字・ロゴ・画面を重ねます。重ね順は大きい数字ほど手前です。

各レイヤーの「表示内容」は 画像／文字／画像シーケンス／Presentation カメラ です。文字は表示文字・フォント・文字色・画面解像度を設定します。連続画像は画像アセットの GUID を改行・カンマ・セミコロンで区切り、FPS・繰り返し・開始位置・一時停止を設定します。カメラは、Camera Output to UI を有効にした Presentation Director の所有 GameObject を映像元に指定します。面には前フレームの映像を表示します。

「画面の電源」を切り替えると収束する消灯・点灯演出、「表示内容」を変えると砂あらしの切替演出が入ります。電源切替時間・内容切替時間、常時の砂あらし・走査線、ホログラム効果と強さを個別に調整できます。「表示状態・デバッグ」で内容、電源、面の数、画像やカメラの未設定を確認できます。

既存の 投影デカール も同じ GameObject に複数付けられます。画像・投影サイズ・色・透明度・重ね順・ホログラム効果をデカールごとに指定します。こちらは投影箱と交わる不透明面へ描く方式です。
