装備ソケット・装備アタッチ・射出アンカー

対象：ブランチ sinotake_ReplayMaster_fixed / コミット 60775ec

武器や道具をキャラクターの手や背中に持たせる部品と、撃ち出して当たった物に刺さる「アンカー」です。親子付けをしなくても、決めた位置に毎フレーム追従させられます。

こんなときに使う

  • 剣を右手のボーンに、盾を背中に持たせたいとき（装備アタッチ）
  • 「右手」「背中」など、装備を付ける場所に名前を付けておきたいとき（装備ソケット）
  • フックや銛を撃ち、動く物に刺さったまま付いていかせたいとき（射出アンカー）

装備ソケット

Physics > 装備ソケット。装備を付ける場所に名前を付けます。1 つの GameObject にいくつでも付けられます。

表示名内部名種類既定値説明
ソケット名socket_name文字Socket装備アタッチから指定する名前
ローカル位置local_position3 つの小数0, 0, 0この GameObject から見た位置
ローカル回転（ラジアン）local_rotation3 つの小数0, 0, 0向き。度ではなくラジアンです（90 度 ≒ 1.5708）
ローカル拡縮local_scale3 つの小数1, 1, 1

装備アタッチ

Physics > 装備アタッチ。装備する側（剣など）に付け、装着先の GameObject の、名前付きソケットかスキンモデルのボーンへ追従させます。

表示名内部名種類既定値説明
装着先targetGameObject（空）キャラクターなど
ソケット名socket_name文字（空）装着先の装備ソケットの名前
ボーン名bone_name文字（空）装着先のスキンモデルのボーン名。入れるとソケットの代わりにボーンに付きます
装着位置・装着回転（ラジアン）・装着拡縮local_position、local_rotation、local_scale3 つの小数0、0、1ソケット（ボーン）から見たずれ
状態status文字（読取のみ）「指定した名前のソケットが見つかりません。」「指定したボーンがモデルに見つかりません。」「ボーン姿勢を待っています。」など

追従は LateUpdate で行うので、アニメーションで動いた手の位置にずれずに付きます。親子付けではないため、装備を外したいときは装着先を空にするか、コンポーネントを無効にします。

射出アンカー

Physics > 射出アンカー。発射されると、重力を受けながら球の形で前を調べつつ飛び（高速でもすり抜けにくい）、当たった物の表面に刺さります。刺さった相手が動けば一緒に動きます。空気接続 の注入アンカーにも使えます。

表示名内部名種類既定値範囲説明
シーン開始時の状態initial_state選択装着中装着中・飛行中・命中物へ固定・切り離し「飛行中」は速度が無いため、開始時に「切り離し」に戻ります
装着先・装着ソケット名・装着ボーン名mounted_target、mounted_socket、mounted_boneGameObject、文字（空）撃つ前に付いている場所（銃口など）。装着中は自動で装備アタッチが付きます
固定先・固定位置・固定回転（ラジアン）・固定時の拡縮・固定面の法線attached_target ほかGameObject、3 つの小数（空）、0、0、1、0,1,0刺さった相手と、相手から見た位置。「命中物へ固定」で始めるときに使います
飛行中の重力gravity3 つの小数0, -9.80665, 0
掃引半径projectile_radius小数0.040.0001〜5当たりを調べる球の半径
飛行距離上限・飛行時間上限maximum_flight_distance、maximum_flight_time小数1000、30超えると切り離し
表面からのずらしsurface_offset小数0.002-1〜1刺さる位置を表面から浮かせる量
命中物へ追従固定attach_to_hit_objectオン・オフオンオフなら当たった位置で止まるだけ
衝突レイヤーcollision_maskレイヤーすべて
発射の向き（ローカル）launch_direction3 つの小数0, 0, 1「発射を実行」で使う向き。アンカーのローカル座標で指定します（保存しません）
発射の速さlaunch_speed小数400.01〜1000「発射を実行」で使う速さ（m/s、保存しません）
発射を実行request_launchオン・オフオフ実行中にオンにすると、次の LateUpdate で一度だけ発射して自動でオフに戻ります
固定回転（度）attached_local_rotation_degrees3 つの小数固定回転をインスペクターで度として表示・編集します（保存はラジアン）
現在の状態・飛行距離・状態説明state、flight_distance、status読取のみ

発射・切り離し・付け直しは、実行中であればインスペクターの 発射を実行 か、C# の Launch・Detach・Remount で行えます（下の「スクリプトから使う」）。止まっているとき（編集中）に呼ぶと UnsupportedOperation が返り、何もしません。命中すると OnAnchorAttached、切り離されると OnAnchorDetached が届きます。

スクリプトから使う（C#）

MonoBehaviour では GetComponent<EquipmentAttachment>()・GetComponent<AnchorProjectile>() で取り出せます。どの操作も実行中だけ受け付け、結果を RuntimeStatus で返します。

型メンバー説明
EquipmentAttachmenttarget、socketName、boneName、localPosition、status装着先・ソケット名・ボーン名・ずれ・状態
EquipmentAttachmentAttachToSocket(owner, socket)、AttachToBone(owner, bone)、Detach()付け替えと取り外し
AnchorProjectilestate、flightDistance、attachedTarget、gravity、maximumFlightDistance、status状態（AnchorState）・飛んだ距離・刺さった相手・重力など
AnchorProjectileLaunch(direction, speed)、Detach()、Remount()ワールドの向きと速さで撃つ、切り離す、装着先へ戻す

命中と切り離しは OnAnchorAttached(AnchorEventInfo)・OnAnchorDetached(AnchorEventInfo) で受け取れます。AnchorEventInfo には刺さった相手（targetObject）、位置（WorldPosition）、面の向き（Normal）、切り離しの理由（Reason：手動・相手が消えた・飛行の上限・Transform が不正）が入ります。

public class Hook : MonoBehaviour
{
    AnchorProjectile anchor;
    void Start() => anchor = GetComponent<AnchorProjectile>();
    void Update()
    {
        if (Input.GetMouseButtonDown(0)) anchor.Launch(transform.forward, 40.0f);
        if (Input.GetMouseButtonDown(1)) anchor.Remount();
    }
    void OnAnchorAttached(AnchorEventInfo hit) => Debug.Log("刺さった: " + hit.targetObject?.name);
}

使い方の例

剣を右手に持たせる

  1. 剣の GameObject に Physics > 装備アタッチ を付けます。
  2. 装着先 にキャラクター（Skinned Mesh Renderer の GameObject）を入れ、ボーン名 に右手のボーン名を入れます。
  3. 実行して、手の中で向きがずれていれば 装着回転（ラジアン） と 装着位置 で合わせます。

背中に「Back」という場所を作って盾を付ける

  1. キャラクターに 装備ソケット を付け、ソケット名 を Back、ローカル位置 を背中の位置にします。
  2. 盾に 装備アタッチ を付け、装着先 にキャラクター、ソケット名 に Back を入れます（ボーン名は空）。
