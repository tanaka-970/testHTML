Layered Scene Compositor（UI と 3D の重ね順）

対象：ブランチ sinotake_test / コミット d7164091（コードから書いた内容。実機での確認はまだ）

「背景の UI → 3D のキャラクター → 手前の UI」のように、UI と 3D を好きな順番で重ねる仕組みです。重ね順は Layer Composition Stack（.replaylayerstack）というアセットに書き、シーンの Layered Scene Compositor がそれを使って合成します。

こんなときに使う

  • 設定画面で、黄色い背景グラフィックの上にキャラクターの 3D モデルを立たせ、さらにその上に文字とボタンを出したい
  • 特定の 3D モデルだけを、背景の物に隠されずに一番手前に出したい
  • World Space の Canvas を 3D の物と前後関係つきで描きたい

見本（素材）

resources/Samples/LayeredCompositor/ に完成例があります。

ファイル内容
Rena_Settings.replayscene と Rena_Settings.replaylayerstack設定画面。4 層：Scene Base（3D）→ Yellow Graphic Background（Screen UI）→ Rena 3D Foreground（3D Layer）→ Settings Text and Controls（Screen UI）。操作は Settings Demo Controller
PuffPunk_Settings.replayscene別デザインの設定画面
PUFF_PUNK_LayeredMenu.replayscene・PUFF_PUNK_Menu.replaylayerstackタイトルメニュー
PUFF_PUNK_TitleToSettings.replaycomp・PUFF_PUNK_CameraReveal.replaymotionタイトルから設定へ移る演出の Composition と Motion

作り方

  1. Project で Create > Data > Layer Composition Stack を選んでアセットを作る。作るとそのまま「Layer Composition Stack」パネルが開きます（あとから開くときは Project でアセットを開く）
  2. シーンに適用 / Apply to Scene を押す。シーンに Layered Scene Compositor が無ければ GameObject ごと作られ、このアセットがつながります
  3. + Screen UI・+ World UI・+ 3D Layer で層を足す。パネルは上が奥、下が手前です。↑ 奥へ・↓ 手前へ で並べ替えます
  4. UI の層では「所属Canvas」の一覧で、その層に描く Canvas にチェックを入れる。チェックした Canvas は合成段階が「Scene Overlay」になり、層の ID でつながるので並べ替えても外れません
  5. 3D の層では、手前に出したいモデルの Mesh Renderer の rendering_layer 番号にチェックを入れる。モデルを選んで 選択3DのRendering Layerを追加 を押しても入ります
  6. Save で保存し、シーンも保存する。Validate で設定の誤りを確かめられます

層の種類と設定

種類中身
Scene3D普通のシーン全体
Scene3DLayer選んだ Rendering Layer の 3D だけ
ScreenUIScreen Space の Canvas
WorldUIWorld Space の Canvas
  • Depth Policy（3D 層）：Scene Depth は普通のシーンで見えている部分だけを手前へ戻し、照明・影・ポスト効果を保ちます。Force Foreground は選んだ 3D を別に描き、背景に隠れた部分も表示します
  • Opacity：層の不透明度。Blend：Alpha／Additive／Multiply

Layered Scene Compositor の項目

表示名内部名既定値説明
有効enabledオンシーンに 1 つだけ有効にする（適用ボタンは他を自動でオフにする）
Layer Composition Stacklayer_stack空使う重ね順のアセット
Foreground Rendering Layer Maskforeground_layer_mask0前面へ戻す Rendering Layer のビット。0 は前景の抜き出しなし
Coverage 品質quality_mode標準標準／高品質。前景の縁の抜き出し精度
半透明の扱いtransparent_policyBlend を除外半透明の物を前景に含めるか
診断表示debug_viewなしForeground Coverage で抜き出した範囲を表示

Canvas に増えた項目

表示名内部名説明
合成段階composite_stage従来の最前面／Scene Underlay（前景 3D の後ろ）／Scene Overlay（前景 3D の手前）
World Space 深度depth_mode無効／深度テストのみ／深度テストと書き込み。World Space の Canvas だけ
合成スタック順composite_orderStack の Order で所属を決める旧方式。-1 は使わない
合成レイヤーIDcomposite_layer_idパネルのチェックで入る。0 は Order 指定

Camera には「Presentation Camera Only」（presentation_only）が増えました。オンのカメラは Presentation 専用になり、ゲームの視点には使われません。
