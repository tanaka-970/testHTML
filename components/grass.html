草（Grass Procedural・Grass Brush）

対象：ブランチ sinotake_test / コミット 880398d5

地面（ランドスケープ）や、普通のモデル・基本形状の表面に、草を自動で生やす部品と、生える場所をブラシで塗って決める部品です。草は風に揺れ、風船の破裂の衝撃波でもなびきます。

2026-10-22 の変更（コミット d7164091、コードから書いた内容）草は Landscape 専用ではなくなりました。同じ GameObject の Mesh Renderer・Primitive Mesh Renderer・Landscape のどれにでも生やせます。コンポーネントを追加での分類は Rendering に移りました。メッシュに塗るときは、マスクの範囲はモデルの UV（0〜1）になります（UV が重なっている形では、重なった面が塗りを共有します）。遠くの草を間引く LOD と、草むらのまだら（群生）も増えました（下の表）。

こんなときに使う

  • 草原を作りたい。地面に生えるだけでよい
  • 道の上は草を消し、花壇の所だけ草を濃くしたい
  • 風が吹いている感じや、爆発の衝撃で草がなびく様子を見せたい

概要

部品役割
Grass Procedural同じ GameObject の Landscape の表面へ、決めた密度で草を自動で生やします。高さ・幅・色・風の揺れを決めます
Grass Brushシーンビューで塗った場所へ草を増やす・消すための「密度マスク」（.replaygrass ファイル）の場所と範囲を持ちます。Grass Procedural と一緒に使います

地面の三角形の大きさにかかわらず、1 平方メートルあたりの株の数がそろうように生えます。1 株からは放射状に数枚の葉が出ます。

草を生やす

  1. Landscape の付いた GameObject（地面）を選ぶ
  2. インスペクターの「コンポーネントを追加」から Grass Procedural（Rendering の分類。10/13 時点では Landscape の分類）を付ける。これだけで地面一面に草が生えます
  3. 「株の密度」「草の高さ」「草の幅」「根元の色」「先端の色」で見た目を合わせる

塗って草を増やす・消す（Grass Brush）

  1. 先にシーンを保存しておく（マスクのファイルの保存先がシーンのフォルダから決まるため）
  2. 地面と Grass Procedural を選んだ状態で、シーンビューの上に出る「草のマスク」の行から Grass Brush を追加 を押す
  3. マスクを作成 を押す。作るときの中身は「全面（密度 1）」「空（密度 0）」などから選べます。範囲は地面の境界から自動で決まります
  4. 草を塗る を押して、シーンビューで左ドラッグして塗る。「塗る（草を増やす）」「消す（草を減らす）」「値で置き換え」を選べます。Shift を押している間は塗る・消すが入れ替わります。半径・硬さ・不透明度・値はブラシの行で変えます
  5. 塗るときの草の長さも決められます。塗った場所はその長さを保ちます（あとから「草の高さ」を変えても、塗った場所は変わりません）。オフなら密度だけを塗ります
  6. 保存 でマスクのファイルへ書き出す。Esc で草のブラシを終わる。Ctrl・Alt を押しながらのドラッグはカメラ操作です

マスクの解像度は 256・512・1024 から選べます（1024 は Undo のメモリが大きくなります）。同じ名前のファイルがあるときは、上書きを防ぐために作成しません。作り直す は中身を作り直し、再読込 はファイルから読み直します。塗った長さをリセット は、ブラシで塗った長さの記録をすべて消します。

風と衝撃波

  • 「風向 X / Z」と「風の強さ」で、草全体がその向きへ揺れます。
  • シーンに風場（Wind Zone）があると、その風速も「風場の影響」の分だけ揺れに足されます。
  • 風船などの膨張対象が破裂すると、その衝撃波で周りの草が外側へなびきます（設定は不要です）。

重さの目安

  • 本数は「株の密度 × 面積」で増えます。広い地面では密度を下げ、「分割数の上限」で上限を抑えます。
  • 「1株の葉数」を増やすと、本数は同じでも描く葉の数が増えます。
