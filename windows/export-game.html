ゲームを書き出す

対象：ブランチ sinotake / コミット 9eb9813

プロジェクトを、エディターなしで起動できるゲームのフォルダーとして書き出すダイアログです。書き出したフォルダーをそのまま配ったり、別の PC にコピーして遊んだりできます。

こんなときに使う

  • 作ったゲームを、エディターを持っていない人に遊んでもらうとき
  • 提出や配布のために、ゲームを 1 つのフォルダーにまとめたいとき
  • エディターを使わずに起動したときの動きや、別の PC で動くかを確かめたいとき

書き出す前に

  • シーンを保存します。書き出しはディスク上のファイルをコピーするので、保存していない変更は入りません。
  • C# スクリプトをビルドして読み込んでおきます。エディターが C# の DLL を読み込んでいないと書き出せません（スクリプトを使っていないプロジェクトでも同じです）。C# スクリプトのビルド を見てください。
  • 最初に開くシーンは、プロジェクトの resources フォルダーの中に置きます。

開き方

File > ゲームを書き出す... を選びます。

ダイアログの欄

欄開いたときの値働き
ゲーム名いまのシーンのファイル名（拡張子なし）。シーンが未保存なら MyGame書き出すフォルダーと実行ファイルの名前になります。< > : " / \ | ? * は _ に置き換え、前後の空白と末尾の . は取り除きます。空なら MyGame です
書き出し先 と 選択プロジェクトの Saved\Buildこの中に「ゲーム名」のフォルダーを作ります。選択 でフォルダーを選ぶダイアログが開きます
最初の Scene と 選択いま開いているシーンのパスゲームを起動したとき最初に開くシーン。選択 で .replayscene を選ぶダイアログが開きます
書き出す—書き出しを始めます。「書き出し先\ゲーム名」が空でないフォルダーとしてすでにあると、先に 上書きの確認 が出ます
閉じる—ダイアログを閉じます

ダイアログを開くたびに、欄は上の値に戻り、前回の結果の表示は消えます。書き出しが終わるまで、エディターは操作できません（C# のビルドとシェーダーのコンパイルを含むので、時間がかかります）。

既存フォルダーの上書き

「既存フォルダーを上書きしますか？」とフォルダーのパスが表示されます。上書き で書き出し、キャンセル で何もしません。上書きしても、書き出しがすべて成功するまで前のフォルダーはそのまま残ります。

書き出されるもの

成功すると「書き出しました: パス」と表示され、エクスプローラーでそのフォルダーが開きます。

ファイル・フォルダー中身
ゲーム名.exeいま動いているエンジンの実行ファイルのコピー
ゲーム名.replaygame起動設定（下記）
resources\プロジェクトの resources フォルダーのコピー（除外するものを除く）
resources\ShaderCache.replaypackエンジンのシェーダーを書き出し時にコンパイルしてまとめたもの
resources\ScriptCatalog.replaypackC# スクリプトの一覧（Release ビルドのもの）
C# の DLL のフォルダーManaged API とゲームスクリプトの DLL（Release と Debug のビルド結果のうち、あるもの）

.replaygame の中身

REPLAY_GAME 1
NAME ゲーム名
STARTUP_SCENE resources/Scenes/Title.replayscene
WINDOW 1600 900
FULLSCREEN 0
  • STARTUP_SCENE は、最初の Scene をプロジェクトのフォルダーからの相対パスにしたものです。
  • WINDOW には、書き出したときのエディターのウィンドウの描画領域の大きさが入ります。
  • FULLSCREEN は常に 0 です。全画面にしたいときは、書き出したあとでこのファイルを書き換えます。行の意味は .replaygame による起動設定 を見てください。

書き出したゲームのセーブデータやログは、ゲームのフォルダーではなく %LOCALAPPDATA%\ゲーム名 に作られます（データ形式）。

除外するもの

resources をコピーするとき、次のものは入れません。

  • .replay_cache という名前のフォルダーとその中身
  • 拡張子が .hlsl、.hlsli、.cs、.csproj、.sln、.pdb のファイル
  • 名前が .bak で終わるファイル、imgui.ini
  • 元からある ShaderCache.replaypack と ScriptCatalog.replaypack（書き出し時に作り直します）

書き出しの手順

どこかで失敗すると、そこまでに作ったものは消し、「書き出しに失敗しました」と、理由の一覧を表示します。

  1. 書き出し先の場所を確かめます。
  2. 「書き出し先」の中に、.ゲーム名.export- で始まる作業用フォルダーを作ります。
  3. 読み込み中の C# の DLL が最新かを確かめ、C# の一覧を読み直し、Managed API とゲームスクリプトを Release でビルドして、ScriptCatalog.replaypack を作ります。
  4. エンジンのシェーダーをすべてコンパイルして ShaderCache.replaypack を作ります。
  5. 実行ファイル、resources、C# の DLL をコピーします。
  6. コピーしたマテリアル（.replaymaterial）が使うシェーダーと、C# の一覧の中身が、パックにそろっているかを確かめます。
  7. 最初の Scene が書き出した中にあるかを確かめ、.replaygame を書きます。
  8. シェーダーや C# のソースファイル、Shader・ThirdParty フォルダーが入っていないかを確かめます。
  9. 前の「ゲーム名」フォルダーがあれば一時的に別名にし、作業用フォルダーを「ゲーム名」に変えます。うまくいったら前のフォルダーを消します。

使い方の例

はじめて書き出す

  1. 開いているシーンを保存します（Ctrl+S）。
  2. C# Scripts パネルで、スクリプトがビルドされ、エラーが出ていないことを確かめます。
  3. File > ゲームを書き出す... を選びます。
  4. ゲーム名 を入れます。最初の Scene がタイトル画面など、起動したとき最初に出したいシーンになっているか確かめ、違えば 選択 で選び直します。
  5. 書き出す を押します。終わるとエクスプローラーで書き出したフォルダーが開きます。
  6. ゲーム名.exe をダブルクリックして、起動することを確かめます。
  7. 配るときは、フォルダーごと ZIP などにまとめて渡します。

直してから書き出し直す

同じゲーム名と書き出し先のまま 書き出す を押すと、上書きの確認が出ます。上書き を押すと、新しい内容に入れ替わります。書き出しに失敗したときは、前に書き出したフォルダーがそのまま残ります。
