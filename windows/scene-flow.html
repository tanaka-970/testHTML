Scene Flow ウィンドウ

対象：ブランチ sinotake / コミット 9eb9813

シーンからシーンへの移り方を、表にまとめて決めるウィンドウです。「タイトルで Start が起きたらステージ 1 へ」「ステージ 1 で Clear が起きたら、フラグ次第でステージ 2 かエンディングへ」のように書いておくと、スクリプトはイベント名を送るだけで済み、移り先のシーンをコードに書かなくて済みます。

内容は Scene Flow アセット（.replaysceneflow）に保存されます。

こんなときに使う

  • タイトル → ステージ → リザルトのように、シーンの移り先を 1 か所にまとめて管理したいとき
  • クリアしたかどうかや、フラグの値によって、移る先のシーンを変えたいとき（鍵を持っていれば別のエンディングへ、など）
  • スクリプトにシーンの名前を書かず、「Clear」のようなイベント名だけを送るようにしたいとき。シーンの順番を入れ替えても、スクリプトを直さずに済みます

使い始める

  1. プロジェクト パネルで右クリックし、Create > Data > Scene Flow を選びます（メニュー上の 名前 欄に入れた名前で作られます）。
  2. できた .replaysceneflow をダブルクリックすると、Scene Flow ウィンドウが開きます。Window > Scene Flow でも開けます（UI Workspace と Motion Workspace にいる間は出ません。基本などの Workspace で開きます）。
  3. ウィンドウ上の Set Active を押します。プロジェクトで使う Scene Flow がこのアセットになり、ボタンの場所に緑の「ACTIVE」が出ます。

使う Scene Flow は、プロジェクト設定の Active Scene Flow でも選べます。「（未設定）」に戻すか 解除 を押すと、イベントを送ってもシーンは移りません（シーンを直接指定する読み込みはそのまま使えます）。設定中のアセットが見つからないときは「[ Missing Scene Flow ]」と赤く表示され、設定は残ります。

ウィンドウの見た目

場所表示・操作
いちばん上アセットの名前。保存していない変更があると「 *」が付きます。右に Save、Set Active（または ACTIVE）
その下+ Transition：遷移を 1 つ足します
一覧「Transition #番号 イベント名」の見出しが並びます。見出しを開くと中身を編集できます。見出しをドラッグすると順番を変えられ、右クリックで Delete が出ます
いちばん下状態の文（「保存しました: …」など）

ウィンドウを閉じたときや、別の Scene Flow アセットを開いたときは、変更が自動で保存されます。ACTIVE のアセットを保存すると、ゲームの実行に使われる内容もその場で新しくなります。

アセットを開いていないときは「Project で .replaysceneflow を作成/開いてください」と表示されます。

元に戻せる操作は一部だけですScene Flow ウィンドウで元に戻す（Ctrl+Z）・やり直す（Ctrl+Y）ができるのは、Transition の追加（+ Transition）、削除、並べ替えだけです。Enabled、Event、Priority、From、To、条件の変更は元に戻せません。大きく変える前に Save しておくか、ファイルを複製しておいてください。

遷移（Transition）の項目

表示名既定値説明
Enabledオンオフにすると、この遷移は使われません
Deleteこの遷移を消します
EventNextこの遷移を起こすイベント名。大文字・小文字も区別して、完全に一致したときだけ使われます
Priority0同じイベントで使える遷移が複数あるときの優先度。大きい方が選ばれます。同じ値なら、一覧で上にある方が選ばれます
FromAny Sceneどのシーンにいるときに使うか。Any Scene はどのシーンでも
To（未選択。「Select Scene」）移り先のシーン。選んでいない遷移は使われません
Conditions (AND)なし条件。すべて満たしたときだけ使われます。条件が無ければイベントだけで使われます

From と To にはプロジェクトのシーンアセットが並びます。消えたシーンを指している場合は「[Missing] GUID」と表示されます。

条件（Condition）

+ Condition で 1 行足し、行の右の X で消します。1 行は左から次の順に並びます。

欄内容
種類Bool、Int、Float
キーフラグの名前（足したときは「Flag」）
比べ方==、!=、<、<=、>、>=
値Bool はチェック、Int は整数、Float は小数。足したときは Bool のオン
  • Float の == と != は、差が 0.000001 以下なら等しいとみなします。
  • 一度も値を入れていないフラグを使う条件は、どの比べ方でも満たしません（!= でも満たしません）。
  • フラグの値は、ゲームを動かしている間ずっと残ります。シーンを移っても消えません。

イベントを送る

イベントを送ると、次のすべてに当てはまる遷移の中から 1 つが選ばれ、そのシーンへの移動が始まります。

  • Enabled がオン
  • Event がイベント名と一致
  • To が選ばれている
  • From が Any Scene か、今のシーン
  • 条件をすべて満たす

当てはまる遷移が無いとき、Active Scene Flow が無いとき、すでにシーンを移っている最中のときは、何も起きません。

送り方書き方
C#（MonoBehaviour）SceneManager.TriggerFlow("Clear");（SceneManager）
C#（ScriptBehaviour）Runtime.TriggerSceneFlow("Clear");

フラグの値は ScriptBehaviour の Runtime.SetSceneFlowBool(キー, 値)、SetSceneFlowInt、SetSceneFlowFloat で入れます（ScriptBehaviour）。

// ScriptBehaviour の中
Runtime.SetSceneFlowBool("HasKey", true);
Runtime.TriggerSceneFlow("Clear");

例

EventFromToPriorityConditions
StartTitleStage10
ClearStage1TrueEnding10Bool HasKey == オン
ClearStage1Ending0

Stage1 で Clear を送ると、HasKey がオンなら優先度の高い TrueEnding へ、そうでなければ Ending へ移ります。

使い方の例

タイトル画面からステージ 1 へ移る

  1. プロジェクト パネルで右クリックし、Create > Data > Scene Flow で作ります。
  2. できたアセットをダブルクリックして開き、Set Active を押します。
  3. + Transition を押し、できた見出しを開きます。
  4. Event に Start、From にタイトルのシーン、To にステージ 1 のシーンを選びます。
  5. Save を押します。
  6. タイトルのボタンが押されたときに動くスクリプトで、Runtime.TriggerSceneFlow("Start");（ScriptBehaviour）または SceneManager.TriggerFlow("Start");（MonoBehaviour）を呼びます。
  7. ゲームを実行してボタンを押し、ステージ 1 に移ることを確かめます。

あとでタイトルとステージ 1 の間に説明画面を挟みたくなったら、この表の To を変えて、説明画面から先へ移る遷移を足すだけで済みます。
