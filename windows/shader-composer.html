Shader Composer

対象：ブランチ sinotake / コミット 9eb9813

ノード（箱）を線でつないで、シェーダー（色の計算の仕方）を作るウィンドウです。HLSL を書かなくても、テクスチャに色を掛ける、UV を流す、ディゾルブで消す、といったシェーダーを作れます。つないだグラフは .replayshadergraph ファイルに保存され、Ctrl+S を押すとそこから HLSL ファイルが作られ、コンパイルされます。

このバージョンでできることライティングは Unlit（光の影響を受けない）だけです。PBR やトゥーンの陰影は付けられません。

こんなときに使う

  • テクスチャを流して、水面、滝、ベルトコンベアのように見せたいとき（UV Scroll）
  • モデルのふちを光らせたいとき（Fresnel を Emission へつなぐ）
  • 少しずつ消えていく見た目を作りたいとき（Noise と Dissolve を Opacity へつなぐ）
  • 色や強さを、マテリアルのインスペクターのスライダーで調整できるようにしたいとき（Material Property）
  • UI の画像に、独自の色の加工をかけたいとき（PostProcess を Effect Stack で使う）

3 つの種類

種類使い道出力ノードHLSL の置き場所
Surfaceマテリアルのシェーダーとして、モデルの見た目を決めますSurface OutputShader\Materials\Generated
Layerマテリアルのレイヤーとして、色を重ねます（このビルドでは描画されません。下の注意）Layer OutputShader\Layers\Generated
PostProcessEffect Stack の カスタムシェーダー として、描いた画像を加工しますPostProcess OutputShader\PostProcess\Generated

作ったあとで種類は変えられません。

Layer の種類は描画されませんLayer で作ったシェーダーをマテリアルの Shader Stack に足すと、「[保存済み: カスタム Layer は DX12 描画へ未接続]」と表示され、このビルドの描画には使われません。Surface で作ったシェーダーは、マテリアルの Shader に選べば描画されます。ただし、そのマテリアルに陰影モデルやピクセレーションのレイヤーが有効だと使われません（マテリアルの編集）。

作る・開く

  • プロジェクト ウィンドウの Create > Shader > Shader Composer > Surface / Layer / PostProcess で作ります。
  • グラフのファイルは、いま開いているフォルダーに、名前欄の名前で作られます。空なら NewShaderGraph / NewLayerGraph / NewPostProcessGraph です。同じ名前があると末尾に 2、3 … が付きます。
  • 同時に「ファイル名_GUID の先頭 8 文字.hlsl」が上の表の場所に作られ、コンパイルされ、Shader Composer ウィンドウが開きます。
  • あとから開くには、プロジェクト ウィンドウで .replayshadergraph をダブルクリックします。閉じたウィンドウは、グラフを一度開いていれば Window > Shader Composer で開き直せます（UI Workspace と Motion Workspace にいる間は出ません。基本などの Workspace で開きます）。

新しく作ったグラフには、次のノードが最初から入っています。

ノード内容
UV → Texture PropertyHLSL Name「BaseMap」、Display Name「Base Map」
Color PropertySurface では「BaseColor」（Base Color）、Layer と PostProcess では「Tint」
Multiplyテクスチャの色 × Color Property
出力ノードMultiply の結果を Base Color（Layer では Color）へ

操作結果

ノードの見出し（上の帯）をクリックそのノードを選びます（オレンジの枠）
ノードの見出しをドラッグノードを動かします
右端の青い丸（Out）をクリックし、ほかのノードの左の丸（入力）をクリックつなぎます。Out を押した後は、オレンジの線がマウスについてきます。右クリックで取りやめます
入力の丸を右クリックその入力の線を外します
Delete（ウィンドウにフォーカスがあるとき）選んでいるノードと、その線を消します。出力ノードは消せません（「Output node is protected…」と出ます）
中ボタンでドラッグキャンバス全体を動かします。拡大・縮小はできません
  • 1 つの入力には線を 1 本だけつなげます。つなぎ直すと前の線は外れます。1 つの出力からは何本でも出せます。
  • つながっている入力の丸は緑、つながっていない丸は灰色です。つながっていない入力には、ノード一覧の「つながないとき」の値が使われます。

元に戻せませんShader Composer の操作は、元に戻す（Ctrl+Z）の対象になりません。大きく変える前に Ctrl+S で保存しておくか、ファイルを複製しておいてください。

マテリアルプロパティ

Float / Color / Texture Property のノードは、マテリアルのインスペクターで変えられる項目になります。

欄意味
HLSL Nameシェーダーの中での名前。英字か _ で始め、英数字と _ だけを使います。グラフの中で重なってはいけません。足したときは「Value番号」「Color番号」「Texture番号」

Tooltip項目にマウスを乗せたときの説明

Float Property は Minimum〜Maximum のスライダー、Color Property は色、Texture Property は画像の欄になります。PostProcess で Texture Property を使ったときの制限は Effect Stack を見てください。

値の型

線を流れる値は、数 1 つ（Float）か、2〜4 個の組（Float2〜Float4）です。色は Float4（R, G, B, A）、UV は Float2 です。

  • 2 つの入力をまとめる計算（Add など）では、同じ型どうし、または数 1 つと組をつなげます。数 1 つと組なら、数を組の全部に使います。Float2 と Float3 のように違う組どうしはエラーです。
  • 決まった型が要る入力に違う型をつなぐと、次のように変えます。
つないだ値要る型使われる値
数 1 つ組同じ数を並べます（0.5 → (0.5, 0.5, 0.5, 0.5)）
組数 1 つ1 つ目（X / R）

保存と自動保存

きっかけグラフ（.replayshadergraph）HLSL
Ctrl+S、Save + Generate + Compile保存作り直してコンパイル
変更したままウィンドウを × で閉じる自動保存変えません
変更したまま別のグラフを開く自動保存（できなければ別のグラフは開きません）変えません
エディターを終了する自動保存変えません

自動保存では HLSL を作らないので、途中のエラーのあるグラフで、前にうまく作れたシェーダーが壊れることはありません。Ctrl+S でも、HLSL を作れなかったときは前の HLSL ファイルをそのまま残します。自動保存に失敗すると、ウィンドウは閉じずに「Autosave failed: …」と出ます。

Ctrl+S はウィンドウが開いていれば効きますShader Composer ウィンドウが表示されていれば、ほかのウィンドウで Ctrl+S を押しても、グラフの保存と HLSL の生成が行われます（そのときシーンなどの保存も行われます）。Shader Composer にフォーカスがあるときは、シーンの保存は行われません。

使い方の例

テクスチャが流れるシェーダーを作り、マテリアルで使う

  1. プロジェクト パネルで右クリックし、Create > Shader > Shader Composer > Surface を選びます。名前欄を「ScrollTexture」にしておくと、その名前で作られます。
  2. キャンバスの空いたところで右クリックし、Effect > UV Scroll を足します。
  3. UV Scroll の右の青い丸（Out）をクリックし、Texture Property（Base Map）の左の UV の丸をクリックします。UV ノードからの線は置き換わります。
  4. UV Scroll を選び、インスペクターの Fallback Speed を (0.1, 0) にします。
  5. Ctrl+S を押し、状態が「Saved / generated / compiled」になることを確かめます。
  6. プロジェクト パネルでマテリアルを選び、インスペクターの Shader で「Project/Composer/ScrollTexture」を選びます（マテリアルの編集）。
  7. マテリアルの Base Map にテクスチャを指定し、そのマテリアルをモデルに付けます（マテリアルを付ける）。

ふちを光らせる

  1. Effect > Fresnel を足し、インスペクターの Fallback Power を 3 にします。
  2. Material Property > Color を足し、HLSL Name を RimColor、Display Name を「ふちの色」にします。
  3. Math > Multiply を足し、A に Fresnel、B に RimColor の Color Property をつなぎます。
  4. Multiply の Out を、出力ノードの Emission につなぎます。
  5. Ctrl+S を押します。マテリアルのインスペクターに「ふちの色」が出るので、光らせたい色にします。

少しずつ消えていく見た目にする

  1. Effect > Noise を足し、Fallback Scale を 20 にします。
  2. Material Property > Float / Slider を足し、HLSL Name を Amount、Default 0、Minimum 0、Maximum 1 にします。
  3. Effect > Dissolve を足し、Fallback Edge を 0.05 にします。Noise を Value、Amount を Threshold につなぎます。
  4. Dissolve の Out を、出力ノードの Opacity につなぎ、Ctrl+S を押します。
  5. マテリアルの Rendering > Alpha Mode を Blend にして、透けるようにします。
  6. マテリアルの Amount を 0 から 1 へ動かすと、ばらばらに消えていきます。モーションで Amount を動かせば、時間で消す演出になります。
