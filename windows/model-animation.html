モデルにアニメーションを追加する

対象：ブランチ sinotake_test / コミット d7164091（コードから書いた内容。実機での確認はまだ）

キャラクターなどのモデルに、待機・歩く・攻撃などのアニメーションを付けて、ゲームで再生するまでの手順です。エンジンの中で骨にキーを打ってクリップを作る方法（アニメーション Workspace）と、もともと骨のないモデルに Blender で骨を入れる方法（リグ作成ツール）をまとめています。

どの方法を使うか

モデルの状態やること見る所
骨もアニメーションも入った GLBそのまま置き、Animator の状態にアニメーションを割り当てるAnimator で再生する
骨はあるが、欲しい動きが無いアニメーション Workspace でクリップを作るクリップを作る
GLB の動きを少し直したいGLB のアニメーションを取り込んで直し、書き戻すGLB から取り込む・書き戻す
骨が無いモデル（一体物の glb など）Blender のリグ作成ツールで骨を入れてから上へ骨の無いモデルに骨を入れる

使うファイル（素材）

ファイル中身
.glb骨（スキン）付きのモデル。アニメーションも中に入れられる。Skinned Mesh Renderer で表示する
.replayrigRigClip（骨のキーの集まり＝1 本のアニメーション）、または Motion リグで保存した骨のポーズ。どの骨構成のモデル用かを覚えていて、骨構成の違うモデルには読み込めない
resources/model/Alpfa/リグ作成ツールの見本。Alpfa.glb（骨なし）、rig_joints.json（関節の候補）、rig_spec.txt（決めた関節の位置）、Alpfa_Rigged.glb（骨入りの完成品）
resources/anime_seisakuyou.replaysceneアニメーション作成用のシーン

アニメーション Workspace を開く

  1. シーンに、骨付きのモデル（Skinned Mesh Renderer の付いた GameObject）を置く。プロジェクトパネルから骨付きの GLB を置くと Skinned Mesh Renderer が付き、アニメーション入りなら Animator も付きます（置き方）
  2. メニューバーの Window の下の方にある アニメーション Workspaceへ を選ぶ（検索欄で「アニメーション」と打っても出ます）
  3. 上のバーに「モデル アニメーション」と出ます。終わるときは 通常のシーンへ戻る
パネル内容
モデル / 骨上の欄で編集するモデルを選ぶ（シーンの Skinned Mesh だけが出ます）。下は骨の木。クリックで選び、Ctrl+クリックで複数選ぶ。「骨を検索...」で絞り込み
骨のトランスフォーム選んだ骨の移動・回転（度）・拡縮の数値
Motion リグクリップの作成・保存・GLB の取り込みと書き込み、再生、骨ごとのキーのタイムライン
Animator（Workspace パネル）状態・遷移の編集。モデルの表示とカメラの設定もここ

カメラ：Alt+左ドラッグで周回、中ドラッグでパン（「Maya式 Alt ドラッグ操作」オンなら Alt+中）、Alt+右ドラッグでドリー、ホイールでズーム、F で選んだモデルへフォーカス。

背景は既定で単色と固定の平行光です。「シーンの空とライトを使う」をオンにすると、シーンの空・ライト・環境光で表示します（2026-10-20 追加。ゲームと同じ明るさで確認したいとき）。

クリップを作る

  1. 「モデル / 骨」でモデルを選ぶ
  2. Motion リグの「クリップ / 保存・GLB 取り込み」で 新規クリップ を押す。名前 NewClip、長さ 1 秒、30 FPS、ループありのクリップができます
  3. 「クリップ設定 / GLB 書き込み」で 名前（例：Idle、Attack）、長さ（秒）、FPS、ループ を決める。長さを縮めると、はみ出たキーは消えます
  4. 「時間」スライダーか 前フレーム・次フレーム（← →キー）で、キーを打つ時刻へ移る。表示の「F 12 / 30」は今のフレームと全体のフレーム数です
  5. シーンビューで骨をクリックして選び、ギズモで回す（Shift+E 回転、Shift+W 移動、Shift+R 拡縮。骨を回す操作）。数値は「骨のトランスフォーム」でも入れられます
  6. 全ボーンにキー（S キー）で、今の時刻に全部の骨のポーズをキーにする。自動キー をオンにすると、骨を動かしたときに選んだ骨へ自動でキーが入ります
  7. 時刻を変えて、ポーズを作り、キーを打つ、をくり返す。再生（Space）で確かめる
  8. 保存 で .replayrig に保存する（初回は保存先を聞かれます。別名保存 で別のファイルに）

キーの直し方

  • タイムラインの骨の行でキーをクリックして選び、キーを打つ / 更新、選択キー削除、キーをコピー・キーを貼り付け
  • キーの補間は ステップ（次のキーまで止まる）／リニア／スムーズ
  • 同じポーズを別の時刻に使うときは、選択ポーズをコピー → 時刻を移す → 選択ポーズを貼り付け → S
  • 戻す・やり直す はクリップの編集を 64 回まで戻せます
  • 保存していない変更があるままモデルを切り替えようとすると、確認が出ます

Animator で再生する

作ったクリップ、または GLB に入っているアニメーションを、Animator の状態に割り当てます。

  1. Workspace パネルの Animator の欄で、Animator が無ければ 選択 GameObject に Animator を追加
  2. 状態を追加 で状態を作り、「状態名」を付ける（Idle、Walk など）。「開始状態」で最初の状態を選ぶ
  3. 状態に動きを割り当てる：
    • GLB の中のアニメーション：「GLB アニメーション」の一覧から選ぶ（または「GLB クリップ番号」に 0 から数えた番号）
    • 作ったクリップ：「RigClip パス」の 参照... で .replayrig を選ぶ。GLB に書き込まなくても、そのまま再生できます
    どちらか片方だけが使われます（片方を入れるともう片方は空になります）
  4. 「状態をループ」「再生速度」を決め、遷移を追加 で切り替えの条件を作る（条件の種類は Animator）
  5. ゲームを実行して確かめる。C# からは AnimatorComponent.Play("Attack", 0.1f) や SetFloat で切り替えます

状態グラフの中で ◆ が付いているのが開始状態です。Animator の項目の詳しい説明は Animator を見てください。

GLB から取り込む・書き戻す

GLB のアニメーションを開いて直す

  1. Motion リグの GLB を開く... で GLB を選ぶ（編集中のモデルと同じ骨構成のもの）
  2. 「GLB アニメーション」の一覧から選び、選択アニメーションを開く。骨の移動・回転・拡縮のキーがクリップとして読み込まれます
  3. キーを直して、.replayrig として保存するか、下の方法で GLB へ書き戻す

モーフ（表情など）の重みは、プレビューには出ますが編集はできません。書き戻すときは元のモーフのアニメーションをそのまま残します。

GLB へ書き込む

  1. 「クリップ設定 / GLB 書き込み」の GLB へ書き込み... を押す
  2. 元の GLB（まだ選んでいなければ聞かれます）と、保存先の GLB を選ぶ。元のファイルとは別の名前で保存すると安全です
  3. 同じ名前のアニメーションがあるときは、「GLB の同名アニメを上書き」がオンなら置き換え、オフなら追加します
  4. 「検証済み GLB を保存しました」と出たら完了。モデルの読み込みがやり直され、Animator の「GLB アニメーション」一覧に出ます

GLB に入れておくと、ほかのツール（Blender など）でも同じ動きを使えます。エンジンの中だけで使うなら .replayrig のままで構いません。

骨の無いモデルに骨を入れる（リグ作成ツール）

手・足・耳などが別パーツになった、骨の無いモデルに骨を入れて、骨付きの GLB を作るツールが Tools/BlenderRig/ にあります。Blender（Steam 版 5.2：C:\Program Files (x86)\Steam\steamapps\common\Blender\blender.exe）をコマンドで動かして使います。

  1. 関節の候補を書く：rig_joints.json に、関節の名前・親・おおよその位置（m）・説明を書く。左右のあるものは片側（+X）だけ書けば反対側が自動で作られます。見本は resources/model/Alpfa/rig_joints.json
  2. 関節を置くページを作る： 
    blender -b --factory-startup --python Tools/BlenderRig/make_rig_page.py -- --input model.glb --joints rig_joints.json --output rig_page.html
    モデルの正面と横から見た画像が入った HTML ページができます
  3. ページで関節の位置を合わせる：ブラウザで開き、関節の丸を正面と横の画像の上でドラッグする（左右は鏡写しで一緒に動きます）。終わったら 仕様をコピー で、rig_spec.txt の形式の文字をコピーし、ファイルに保存する
  4. 骨入りの GLB を作る： 
    blender -b --factory-startup --python Tools/BlenderRig/build_rig.py -- --spec rig_spec.txt --input model.glb --output model_Rigged.glb
    子を持たない関節（○○Tip）は、親の骨の先端の位置として使われます。パーツは一番近い骨に丸ごと付きます。--squash 骨名 を付けると、その骨の下に伸び縮み用の骨を足します。--blend out.blend で Blender のファイルも保存できます
  5. できた GLB をプロジェクトに入れ、シーンに置いて クリップを作る へ

パーツが多すぎる・すき間があるモデルは、先に fuse_mesh.py で 1 つのメッシュにまとめられます（--tris で三角形を減らす、--gap で近いパーツをくっつける）。UV とテクスチャは残ります。

rig_spec.txt の形1 行目が RIG v1 モデル名、続いて「名前 親 x y z」を 1 行ずつ（Blender 座標、m。X=キャラの左、Y=後ろ、Z=上）。左右は .L・.R を付けます。

うまくいかないとき

  • 「骨構成情報がないか骨の構成が違うため、このモデルには読み込めません」：別のモデル用の .replayrig です。同じ骨構成のモデルを選んでください
  • 「GLB の骨構成が現在のモデルと違います」：取り込もうとした GLB の骨の名前・階層が違います
  • 「同じ階層パスの骨が複数あります」：同じ名前の骨が同じ親の下に並んでいるモデルは、間違って編集しないよう編集できません。Blender で骨の名前を直してください
  • 「モデルと骨を読み込み中です」が消えない：非表示のモデルは読み込まれません。通常のシーンで表示をオンにしてください
  • 骨が 256 本を超えるモデル・モーフが 2 つ以上あるモデルの制限は glTF モデルの制限 を見てください
