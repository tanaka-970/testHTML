スクリーンショット回帰

対象：ブランチ sinotake / コミット 9eb9813

画面を「基準画像」として撮っておき、あとで同じ画面を撮って、1 ピクセルずつ比べるウィンドウです。シェーダーや描画の設定を変えたときに、意図しない見た目の変化（回帰）が起きていないかを、目で見比べるのではなく機械で確かめます。Window > スクリーンショット回帰 で開きます。どの Workspace でも開けます。

こんなときに使う

  • シェーダー、ライト、ポスト処理などを変える前後で、ほかの見た目が変わっていないか確かめたいとき
  • 「なんとなく色が違う気がする」を、違ったピクセルの数と場所で確かめたいとき
  • エンジンを更新したあとに、いつもの場面の見た目が変わっていないか確かめたいとき

ウィンドウの欄

欄既定働き
名前default画像の名前（63 バイトまで）。右に保存先「Saved/Golden/名前.png」が出ます
止めるフレーム数81〜60。撮る前に待つフレーム数です。TAA などで画面が落ち着くまで待ちます
許容差00〜8。ピクセルの R・G・B のうち、いちばん大きい差がこの値を超えたら「違う」とみなします。0 なら完全に一致しないと違う扱いです。透明度（A）は比べません
基準を撮る—今の画面を基準画像として保存します
基準と比べる—今の画面を撮り、基準画像と比べます
自己診断—同じ画面を 2 回撮って、一致するかを調べます

撮っている間はボタンの代わりに「撮影中... 残り 数 フレーム」と出ます。結果はいちばん下に、成功なら緑、そうでなければ橙で表示され、コンソールにも出ます。

結果の見かた

操作表示作られるファイル
基準を撮る「基準画像を保存しました: 場所」Saved/Golden/名前.png
基準と比べる（一致）「一致 / 幅x高さ / 数 ピクセル」、コンソールに「回帰なし: …」名前_latest.png（今回撮った画像）
基準と比べる（違う）「差分あり / 違った数 / 全体 ピクセル (割合%) / 最大差 値 / 最初の差分 (x, y)」、コンソールに「回帰あり: …」名前_latest.png と 名前_diff.png（違った場所を示す画像）
基準と比べる（基準が無い）「基準画像がありません。先に「基準を撮る」を押してください: …」—
基準と比べる（大きさが違う）「大きさが違います。ウィンドウサイズを基準と合わせてください」名前_latest.png
自己診断（一致）「自己診断 OK: 2 回撮って一致しました。この設定で比較を信用してよい」—
自己診断（違う）「自己診断 NG: 同じ画面を 2 回撮ったのに一致しません。…比較結果はまだ信用できません」—
先に自己診断を通します何も変えていないのに 2 回の撮影で一致しない画面（動いている物、ちらつくエフェクトなどがある）では、比べても差分が出てしまいます。自己診断が OK にならないときは、止めるフレーム数 を増やすか、許容差 を 1〜2 にするか、動く物の無い場面で撮ります。

使い方の例

ライトの設定を変える前後で見た目を比べる

  1. 確かめたい場面をシーンビューに表示し、カメラを動かさないようにします。ウィンドウの大きさも変えないでおきます。
  2. 名前 に「light_test」と入れ、自己診断 を押して「自己診断 OK」になることを確かめます。
  3. 基準を撮る を押します。
  4. ライトの設定を変えます。
  5. 基準と比べる を押します。「差分あり」なら、Saved/Golden/light_test_diff.png を開いて、どこが変わったかを見ます。

エディターを開かずに同じことをするには、起動オプションの --capture-frame と --compare-golden を使います（起動オプション）。

起動オプションの比較は、置き場所と合格の条件が違います--compare-golden は、基準画像を Saved/Golden/reference/名前.png、今回の画像を Saved/Golden/名前.png から読み、差分を Saved/Golden/diff/名前.png に書きます。このウィンドウの 基準を撮る が書く Saved/Golden/名前.png は、起動オプションでは「今回の画像」の場所です。そのまま基準としては使われないので、基準にしたい画像は reference フォルダーへ写します。合格の条件も違い、最大差 2 以下かつ違ったピクセルが 0.1% 以下なら合格です。
名前に使う文字このウィンドウの 名前 は、そのままファイル名になります。/ や .. を入れると Saved/Golden の下に別のフォルダーができてしまうので、英数字と _、- だけにしてください。差分画像の保存に失敗したときは、結果に「差分画像: 場所」が付きません。
