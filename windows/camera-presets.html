カメラ操作プリセット

対象：ブランチ sinotake / コミット 9eb9813

シーンビューのカメラを、どのキーとマウス操作で動かすかをまとめた「カメラ操作プリセット」を、選んだり自分用に作り変えたりするウィンドウです。組み込みプリセットの違いは シーンビューとカメラ操作 を見てください。

こんなときに使う

  • シーンビューのカメラを、慣れた操作（右ボタンで見回す、中ボタンで平行移動、など）に合わせたいとき
  • カメラの移動が速すぎる・遅すぎるとき（移動速度、高速倍率、低速倍率）
  • 遠くの物が消える、近くの物が途中で切れるとき（表示設定の Near Clip / Far Clip）
  • チームで同じカメラ操作をそろえたいとき（チーム共有コピーを作る）

開く

  • カメラ > プリセット管理...
  • Window > カメラ操作プリセット（UI Workspace と Motion Workspace にいる間は出ません。基本などの Workspace で開きます）

共有と自分用

種類一覧での表示置き場所編集
共有（Shared）「名前 [Shared]」Editor/CameraPresets/（チームで共有するフォルダー）できません。選ぶだけです
自分用（Personal）「名前 [Personal]」Saved/Editor/CameraPresets/できます。変えるとすぐ保存されます
  • ファイルは 1 プリセット 1 つで、拡張子は .replaycamerapreset です。ファイル名は中の ID で、表示名を変えてもファイル名は変わりません。
  • 一覧は自分用が先、その中で名前順に並びます。
  • 今どのプリセットを使っているかは、自分だけの設定として Saved/Editor/CameraUserSettings.replaycamerauser に保存されます。

共有プリセットを選んでいるときは、「Shared preset は読み取り専用。『複製して自分用にする』で自由編集できます。」と表示され、名前、Look、Orbit、Pan、Dolly、ギズモの切り替えキーだけが表示されます。

表示設定（最初は閉じています）

カメラ メニューでの速さの変更

カメラ メニューには、今のプリセットの 移動速度 を変える項目があります。

  • 「現在: 値」の下に、0.5、1、2.5、5、10、25、50、100、250、500、1000 が並び、選ぶとその速さになります。
  • 「自由入力（上限なし）」の欄で、好きな値を入れられます。
  • 共有プリセットを使っているときに速さを変えると、自動で自分用のコピーが作られ、そちらに保存されます（「他人の Shared preset は選択だけ。編集時は My copy を作ります」）。

使い方の例

自分用のプリセットを作って操作を変える

  1. カメラ > プリセット管理... を開きます。
  2. 近い操作のプリセットを Active preset で選び、複製して自分用にする を押します。
  3. プリセット名 に名前を入れて Enter を押します。
  4. マウスナビゲーション の Look / 視点回転 や Pan / 平行移動 を、使いたいボタンに変えます。変えた内容はすぐ保存されます。
  5. シーンビューで動かして確かめます。

チームに配る

  1. 配りたい自分用プリセットを選び、チーム共有コピーを作る を押します。
  2. Editor/CameraPresets/ にできたファイルを、プロジェクトと一緒にほかの人へ渡します。
  3. 受け取った人は Active preset で「名前 Shared [Shared]」を選びます。
