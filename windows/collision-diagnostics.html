衝突の診断 ウィンドウ

対象：ブランチ sinotake / コミット 9eb9813

当たり判定（Collider）が今どうなっているかを数字で確かめ、シーンビューに Collider の形やライトの範囲などを線で重ねて表示するためのウィンドウです。「床をすり抜ける」「壁に当たらない」ときに使います。

こんなときに使う

  • キャラクターが床をすり抜ける、壁を通り抜けるとき
  • トリガーに入ったはずなのに、何も起きないとき（Trigger の数と接触ペアの数を見ます）
  • 見た目のモデルと当たり判定の形がずれていないか確かめたいとき
  • ライトや Normal Adjust の届く範囲を、シーンビューで目で見たいとき

開く

  • Window > Collision Diagnostics（ウィンドウのタイトルは「衝突の診断」）（UI Workspace と Motion Workspace にいる間は出ません。基本などの Workspace で開きます）
  • 診断パネルの 衝突の診断ウィンドウを開く ボタン

ウィンドウの中身

上から次の見出しが並びます。

問い合わせ先

「Scene Colliders Only」と「Runtime衝突はGameObject Colliderへ一本化されています。」が表示されます。当たり判定は、GameObject に付けた Collider コンポーネントだけで行われます。

色の見かた

色意味
橙Character Motor が移動に使っている Collider
緑通常の当たり判定（押し戻す）
水色Trigger（通過する。押し戻さない）
灰無効。当たり判定に入っていない
赤Mesh の Cook 失敗。当たり判定が無い状態
半透明の白境界ボックス

色は「無効 > 移動用 > Trigger > 通常」の順に優先されます。ウィンドウには「橙が出ていなければ、Motor に移動用 Collider が設定されていません。」と表示されます。

すり抜けるときに見る順番

  1. Collider の形を描く をオンにして、形と位置が見た目と合っているか確かめます。何も出ないときは、その Collider の 形状を表示 がオフになっていないか見ます。
  2. 線が灰なら Collider が無効、赤なら Mesh の当たり判定が作れていません。
  3. キャラクターの線に橙が無ければ、Character Motor に移動用の Collider がありません。
  4. 「直近の Hit 元」で、何に当たっている（当たっていない）かを確かめます。

使い方の例

トリガーに入ったかを確かめる

  1. Window > Collision Diagnostics を開きます。
  2. Collider の形を描く をオンにします。トリガーの Collider は水色で描かれます。水色が見えなければ、Collider の Trigger がオフになっていないか確かめます。
  3. ゲームを実行し、キャラクターをトリガーの中へ動かします。
  4. 接触ペア の数が増えれば、トリガーに入ったと判定されています。増えないときは、キャラクター側にも有効な Collider があるか（灰になっていないか）を見ます。
