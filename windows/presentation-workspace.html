Presentation Workspace（メニュー・起動ロゴ・ロード画面）

対象：ブランチ sinotake_test / コミット d7164091（コードから書いた内容。実機での確認はまだ）

ポーズメニュー、起動ロゴ、ロード画面、画面全体のワイプなど、ゲーム本編とは別の 3D モデル・UI・カメラで見せる画面（Presentation）を作る作業場です。1 つの Presentation は「識別子（ID）＋専用の 3D モデルのルート＋UI のルート＋必要なら Motion Composition」でできていて、ゲーム側は ID で呼び出すだけです。

こんなときに使う

  • ポーズ中に、キャラクターの 3D モデルが回るメニュー画面を出したい
  • 起動時のロゴ画面や、シーン切り替えのロード画面を作りたい
  • 画面全体をワイプして切り替える演出を作りたい
  • 作ったメニューを別のシーンでも使い回したい

開き方

メニューバーの Window の下の方にある Workspace の一覧から Presentation Workspaceへ を選びます。「Presentation 一覧」「Presentation 設定」「Presentation タイムライン」と Game View が並びます。

テンプレートから作る

  1. 「Presentation 一覧」の「作成テンプレート」で種類を選ぶ
  2. + テンプレートから作成 を押す。Presentation Director の付いた GameObject、3D モデルのルート、専用カメラ、UI のルートが作られ、同時に <ID>Timeline という Motion Composition も作られて割り当てられます
  3. 文字や 3D モデルを差し替える（「UIを編集」で UI Workspace、「完成画面を見る」で仕上がりを確認）
  4. 「Presentation タイムライン」で + Motion/Precompレイヤー を足して、開くときの動きを付ける。キーの細かい編集は「キー編集を開く」で Motion Workspace から行います
  5. ▶ 表示・■ 閉じる で、F5 で実行しなくてもエディター上で開閉を確かめられます

同じ ID が既にあるときは、末尾に 2、3… を付けた ID になります。ID が重複すると呼び出し（Play）が失敗するので、「詳細設定（識別子・描画順・解像度）」で直します。

再利用・起動ロゴ・ロード画面として保存

「再利用 / ロゴ / ロード画面」の欄で、選んだ Presentation だけを書き出します。保存先は resources/Presentations/ です。

  • Prefabとして保存（他のSceneで再利用）：Prefab_<ID>.replayprefab。別のシーンでは「既存Prefabから再利用」の Presentation Prefabを配置 で置けます
  • 起動ロゴSceneとして保存・設定：BootLogo_<ID>.replayscene を作り、Project Settings の起動ロゴに自動で登録します（見本：resources/Presentations/BootLogo_BootLogo.replayscene）
  • ロード画面Sceneとして保存・設定：Loading_<ID>.replayscene を作り、ロード画面に自動で登録します

同じ名前のファイルがあるときは上書きせず、_2 などを付けて保存します。背景・文字・ロードバーはウィンドウの縦横比に合わせて伸び縮みします。

3D モデルを UI の中に表示する

既定では 3D は画面全体に合成されます。メニューの枠の中だけにモデルを出したいときは、「3DカメラをUI画像として描画」をオンにし、+ カメラ映像のUIImageを作成 を押します。UI Image の Presentation Camera Output に Director が入り、専用カメラの映像がその画像に映ります。解像度は「カメラ映像の解像度」（0.25〜1、既定 0.5 で画素数は 1/4）。

ゲームから呼び出す

C++ からは ID を渡すだけです（Presentation 設定に呼び出し例が表示されます）。

ReplayEngine::Presentation::Play(scene, "PauseMenu");
ReplayEngine::Presentation::TransitionTo(scene, "LoadingScreen");
ReplayEngine::Presentation::Close(scene, "PauseMenu");
ReplayEngine::Presentation::CloseAll(scene);
制限2026-10-22 時点では C# 用の呼び出しはまだありません。C# から開くときは、Director の show_on_start を使うか、C++ 側で上の関数を呼びます。

Cinematic Menu Flow（旧方式）

Project の Create > Data > Cinematic Menu Flow で作る .replaymenuflow と、Cinematic Menu Controller による「状態から状態への遷移」の方式もあります。ボタン名を押すと Composition を再生して次の状態へ移り、最後にシーン読み込みや終了ができます。互換のためだけに残っているので、新しいメニューは Presentation で作ってください（Controller はコンポーネントの追加一覧に出ません）。見本：resources/Samples/LayeredCompositor/PUFF_PUNK_Menu.replaymenuflow。
