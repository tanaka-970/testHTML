Sprite Atlas Editor

対象：ブランチ sinotake / コミット 9eb9813

1 枚の画像の中に並んだ部品（アイコン、ボタンの絵、キャラクターのパーツなど）に、名前付きの範囲（Region）を付けるウィンドウです。UI Image は Region の名前を指定して、その部分だけを表示できます。

内容はスプライトアトラス アセット（.replayatlas）に保存されます。保存するときに画像が圧縮されてアセットの中に入るので、元の画像ファイルが無くなってもアトラスは表示できます。

こんなときに使う

  • 1 枚の画像にまとめて描いたアイコンやボタンの絵を、部品ごとに UI Image で表示したいとき
  • 数字や表情のように、同じ場所に出す絵を切り替えたいとき（モーションで Atlas Region を差し替えます）
  • 四角ではない輪郭で、絵を切り抜いて表示したいとき（自由形状）

作る・開く

  1. プロジェクト パネルで右クリックし、Create > UI / Presentation > Sprite Atlas を選びます。
  2. できた .replayatlas をダブルクリックすると、Sprite Atlas Editor が開きます。
  3. 画像を設定します。次のどちらかです。
    • プロジェクトパネルで画像を選ぶと、ウィンドウ上部に 選択画像をAtlasに設定 ボタンが出るので押す。
    • プロジェクトパネルから画像を、ウィンドウの「Image GUID: …」の行へドラッグ＆ドロップする。

アセットを開いていないときは「Sprite Atlas を Project Browser から開いてください。」、画像が無いときは「Atlas画像を設定してください。」と表示されます。

色意味

四角の Region

操作結果
矩形作成: ON にして、画像の上を左ドラッグその範囲に Region を作ります（画面上のドラッグの幅か高さが 2 ピクセルより小さいと作りません。拡大表示しているときは、画像の 2 ピクセルより小さい範囲も作れます）。名前は「Region番号」

白いハンドルをドラッグ大きさを変えます。Shift を押しながらだと縦横の比を保ちます

Delete または Backspace（ウィンドウを選んでいるとき）、削除選んでいる Region を消します

Pixel Snap をオンにすると、作る・動かす・大きさを変えるときに、画像のピクセルの境目にそろえます。Region は画像の外へは出ません。

自由形状の Region

右の欄で 自由形状 にチェックを入れると、四角の 4 つの角が頂点になり、形を自由に変えられます。UI Image で表示すると、この形の外側は切り取られます。

操作結果
頂点をドラッグ頂点を動かします
辺の近くをクリックそこに頂点を足し、そのままドラッグできます
形の内側をドラッグ形ごと動かします
頂点を選んで Delete または Backspace頂点を消します。3 つより少なくはできません（「自由形状は3頂点未満にできません」）
自由形状 のチェックを外す四角に戻します（範囲は形を囲む四角）

元に戻す

ウィンドウを選んでいるときの元に戻す・やり直す（Ctrl+Z など）は、アトラスの編集に対して働きます。128 回まで戻せます。

保存

保存 を押すと、設定した画像を圧縮（DDS）して、アセットの中に入れてから保存します。

  • 元の画像が .dds のときは、圧縮せずにそのまま入れます。元の PNG などが無くても、同じ名前の .dds が隣にあればそれを使います。
  • 元の画像が見つからなくても、すでに入っている画像があれば、それを使い続けます。
  • どちらも無いと保存できず、「Atlas画像またはDDSが見つかりません」と表示されます。圧縮に失敗すると「DDS埋め込み作成失敗: 理由」と表示されます。
  • 画像を設定していないアトラスは、画像なしで保存されます。

UI Image で使う

UI Image の atlas（内部名）にこのアセットを、atlas_region に Region の名前を設定すると、その Region の部分が表示されます。UI Image の uv_offset と uv_scale は、Region の範囲の中でさらにずらす・拡大する値として働きます。

使い方の例

アイコンを 1 つずつ表示する

  1. プロジェクト パネルで右クリックし、Create > UI / Presentation > Sprite Atlas で作ります。
  2. できたアセットをダブルクリックして開きます。
  3. プロジェクト パネルでアイコンをまとめた画像を選び、選択画像をAtlasに設定 を押します。
  4. Pixel Snap と 矩形作成: ON にし、1 つ目のアイコンの範囲をドラッグで囲みます。
  5. 右の欄の Name を「Heart」のような分かりやすい名前にします。ほかのアイコンも同じように囲みます。
  6. 保存 を押します。
  7. アイコンを出したい UI Image を選び、インスペクターの Sprite Atlas にこのアトラス、Atlas Region に「Heart」を入れます。

表示する絵を時間で切り替える

  1. 上の手順で、切り替えたい絵ごとに Region を作っておきます（「Face_Normal」「Face_Smile」など）。
  2. Motion Workspace で UI Image を選び、選択からトラックを追加 で Atlas Region を選びます（「［段階］」の項目です）。
  3. キーごとに 値 へ Region の名前を入れます。キーの時刻で絵が切り替わります。
