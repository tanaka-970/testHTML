Motion Workspace

対象：ブランチ sinotake / コミット 9eb9813

コンポーネントのプロパティ（位置、色、不透明度など）を時間で変化させる「モーション」を作る画面構成です。作ったモーションは .replaymotion ファイルに保存し、Motion Player などで再生します。複数のモーションを並べて 1 つにまとめたものが「コンポジション」（.replaycomp）です。

こんなときに使う

  • UI の画像や文字を、ふわっと表示したり消したりしたいとき（不透明度）
  • ボタンを押したときに少し大きくして戻す、揺らす、といった演出を付けたいとき（拡大率、回転）
  • 物をずっと回し続ける、上下にゆらゆら動かし続けたいとき（ループ、式、Wiggle）
  • ライトの明るさや色を、時間に合わせて変えたいとき
  • いくつかの動きを時間差で並べて、1 つの演出にまとめたいとき（コンポジション）
  • 決まった時刻に、効果音やスクリプトの処理を起こしたいとき（イベントトラック）

用語

用語意味
モーション（Motion Asset）トラックとイベントトラックをまとめたファイル。長さ（秒）を持ちます
トラック1 つの GameObject の、1 つのコンポーネントの、1 つのプロパティを動かす行
キートラック上の「この時刻にこの値」という点。キーとキーの間は補間されます
イージングキーから次のキーまでの変化の仕方（一定の速さ、ゆっくり始まる、など）。前側のキーが持ちます
イベントトラック決まった時刻に名前付きのイベントを送る行。値は持ちません
再生位置（再生ヘッド）いま表示している時刻。キーの追加や貼り付けの基準になります

開く・作る・保存する

作る

  • プロジェクト ウィンドウの Create > Animation > Motion Asset：いま開いているフォルダーに、名前欄の名前（空なら「NewMotion」）で長さ 1 秒のモーションを作り、開きます。
  • Create > Animation > Motion Composition：同じように長さ 1 秒のコンポジション（空なら「NewComposition」）を作り、開きます。
  • Motion レイヤー の 新規：いまのフォルダーに「NewMotion」を作って開きます。
  • UI インスペクター の Motion を作成：モーションを開いていなければ「UIMotion」を作り、Motion Workspace に切り替えます。

開く

プロジェクト ウィンドウで .replaymotion か .replaycomp をダブルクリックするか、右クリック > 開く を選ぶと、読み込んで Motion Workspace に切り替わります。Window > Motion Workspaceへ は画面を切り替えるだけで、ファイルは開きません。

モーションとコンポジションは同時に 1 つだけ開けます。開き直すと、編集の履歴（元に戻す）は消えます。

保存する

  • Motion レイヤー の 保存：開いているモーションまたはコンポジションを保存します。
  • Motion Workspace でモーションを開いているときは、File > Save Motion と Ctrl+S もモーションの保存になります。
  • 名前の横の「 *」は、保存していない変更があるしるしです。
コンポジションは Ctrl+S で保存されませんコンポジションを開いているときの Ctrl+S と File > Save は、シーンの保存になります。コンポジションは Motion レイヤーの 保存 ボタンで保存してください。
ファイルのないモーションは保存できません何も開いていない状態で 選択からトラックを追加 を押すと、ファイルのない「UnsavedMotion」ができます。これは保存できず、「Project Browser の Create > Motion Asset から作成してください。」と表示されます。先にモーションを作ってからトラックを足してください。

画面の並び

Window > Motion Workspaceへ で切り替えると、次のウィンドウが表示されます。閉じたウィンドウは、Motion Workspace にいる間だけ Window メニューに出る項目から開き直せます。

場所ウィンドウ
左（幅の約 16%）Motion レイヤー、階層
右（幅の約 26%）Motion インスペクター、イージングカーブ
下（高さの約 40%）タイムライン、グラフエディター、Motion プレビュー、プロジェクト、コンソール
中央シーンビュー

ほかの Workspace へ切り替えると、再生中のプレビューは止まり、動かしていた値は元に戻ります。

基本の流れ

  1. プロジェクト ウィンドウで Motion Asset を作ります。
  2. 階層 ウィンドウ（UI なら UI Workspace）で、動かしたい GameObject を選びます。
  3. Motion レイヤーの 選択からトラックを追加 を押し、動かすプロパティを選びます。時刻 0 と終わりの 2 つのキーが入ったトラックができます。
  4. タイムラインでキーを選び、Motion インスペクターで 値 と イージング を決めます。
  5. Motion プレビューの 再生 で動きを確かめ、復元 で元の値に戻します。
  6. 保存 を押します。

  • 何も選んでいないときは「ゲームオブジェクトが選択されていません。」、実行中などで編集できないときは「いまは編集できません（実行中などの理由）。」と出ます。

項目値
名前「GameObject 名.プロパティの表示名」
バインド起点自分（バインド起点）
1 つ目のキー時刻 0、いまのプロパティの値

トラックの一覧

モーションを開いていると「アセット: 名前」と、トラックの一覧（左に型名）が出ます。クリックで選び、ドラッグで並べ替えます。並び順は、同じプロパティを複数のトラックが動かすときの合成の順番に関わります。

コンポジションの編集

コンポジションを開くと、Motion レイヤーは次の内容になります。

項目働き

+ モーションレイヤー「Motion Layer 番号」を足します。入点 0、出点 = 長さ

レイヤーの見出しを開くと、次の欄が出ます。見出しを右クリックして 削除 もできます。

欄働き
チェックボックス、名前、削除オフのレイヤーは再生されません
「モーション / コンポジションをここへドロップ」プロジェクト ウィンドウから .replaymotion か .replaycomp をドロップして割り当てます。開いているコンポジション自身は割り当てられません。見つからないと「アセットが見つかりません」
クリア割り当てを外します

マーカーは名前、時刻、X（削除）で編集します。

コンポジションの時刻 t で、レイヤーは「有効、ウェイトが 0 より大きい、入点 ≤ t ≤ 出点」のときだけ働き、割り当てたモーションを「(t − 開始) × 時間倍率」秒（0〜モーションの長さに収めます）で評価します。入れ子のコンポジションではウェイトが掛け合わされ、16 段より深い入れ子と、自分を含む循環は無視されます。

コンポジションの多くの編集は元に戻せません元に戻す（Ctrl+Z）の対象になるのは、レイヤーの追加・削除・並べ替えだけです。長さ、マーカー、レイヤーの名前・有効・割り当て・時間の欄の変更は記録されません。また、レイヤーの有効（チェックボックス）を切り替えただけでは、保存していない印の「 *」が付きません。切り替えたら 保存 を押してください。
コンポジションは再生ボタンで再生できませんMotion プレビューと Space キーの再生はモーションだけが対象です。コンポジションはタイムラインの ← 1F / 1F →、PageUp / PageDown、Home / End で再生位置を動かして確かめます。

揺れには時間リマップを通す前の時刻を使います。

ループ

ループは「最初のキーから最後のキーまで」を 1 回分として、最後のキーより後ろの時刻に効きます。キーが 2 つ未満なら効きません。

選択肢最後のキーより後ろ
なし最後のキーの値のまま
繰り返し最初のキーに戻って、同じ動きを繰り返します
往復最後まで行ったら逆向きに戻り、これを繰り返します
オフセット継続繰り返すたびに「最後のキーの値 − 最初のキーの値」を足していきます。回転し続ける、横に進み続けるといった動きに使います

式 / エクスプレッション

有効 をオンにして 式 欄に計算式を書くと、キーで決まった値を式の結果に置き換えます。小数、ベクトル、色だけに効き、ベクトルと色は成分ごとに 1 回ずつ計算します。書き間違いは「式エラー: …」と赤で表示されます。

変数意味
vキーで決まった値（ベクトルと色ではその成分）
t評価に使う時刻（時間リマップとループを通したあと）
rt時間リマップを通す前の時刻
dモーションの長さ
i成分の番号。X（R）が 0、Y（G）が 1 …。小数では 0
n成分の数。小数 1、Vector2 は 2、Vector3 は 3、Vector4 と色は 4

使える記号は + - * / %、比較 < <= > >= == !=、&&、||、条件 ? A : B、かっこです。

関数結果
abs(x) sign(x) floor(x) ceil(x) round(x) sqrt(x) exp(x) log(x)ふつうの数学関数（log は自然対数）
sin(x) cos(x) tan(x) asin(x) acos(x) atan(x) atan2(y, x)三角関数。角度はラジアン
min(a, b) max(a, b) pow(a, b) mod(a, b)小さい方、大きい方、a の b 乗、a を b で割った余り
clamp(x, 最小, 最大)x を範囲に収めた値

例：v + sin(rt * 6.28) * 10（1 秒周期で ±10 揺らす）、i == 3 ? v : v * 0.5（色の RGB だけ半分にする）。

計算結果が無限大や非数になった成分は、元の値のまま使い、コンソールに警告を出します。かっこや関数の入れ子は 32 段までです。

イベントは、ゲームの実行中に Motion Player が再生して、その時刻を通り過ぎたときに送られます。1 フレームで時刻をまたいだときや、ループで何周もしたときも、通り過ぎた回数だけ送られます。イベント名 が空のイベントは送られません。送信先を決めていて、その GameObject が見つからないときも送られません。

受け取る方法は Motion Player と ScriptBehaviour（OnAnimationEvent）を見てください。

トラックの行

  • トラック順 の一覧は、ドラッグでトラックを並べ替えます。
  • その下が時間の目盛りと行です。黄色の縦線が再生位置です。
  • 左の名前をクリックすると、そのトラックを選びます。
  • キーは ◇、選んでいるキーは ◆ で表示されます。クリックで選び、Ctrl+クリックで選択に足したり外したりします。
  • キーをドラッグすると、選んでいるキーがまとめて動きます（0〜長さの範囲）。離すとキーが並べ直され、選択は外れます。
  • 行の空いているところをダブルクリックすると、その時刻に、トラックをその時刻で評価した値のキーを足します。
  • イベントトラックは茶色の線の行で、「イベント: ID」（送信先がなければ「イベント: ブロードキャスト」）と表示されます。イベントは ○（選択中は ●）で、クリックで選び、ドラッグで時刻を動かします。イベントトラックもドラッグで並べ替えられます。

目盛りをクリックしても再生位置は動きません。再生位置は Motion プレビューの 時間、← 1F / 1F →、ショートカットで動かします。

グラフエディター

選んでいるトラックの値の変化をグラフで表示し、キーのイージングを編集します。トラックを選んでいないときは「トラック / キーを選択してください。」と出ます。

欄既定働き
速度グラフオフ値の代わりに、1 秒あたりの変化量（値/秒）を表示します
他トラックを重ねるオフほかのトラックの線を薄い色で重ねます（選んでいるチャンネルを持つトラックだけ）
チャンネルX / Rベクトルや色のとき、表示する成分（X Y Z W、または R G B A）を選びます
  • 縦軸は表示している線の最小〜最大に 10% の余白を足した範囲で、下に「範囲 最小 .. 最大」と出ます。横軸はモーションの 0 秒〜長さです。
  • 白い点がキー（選んでいるキーは黄色で大きい点）、黄色の縦線が再生位置、その上の点と数字が再生位置での値です。
  • 値のグラフは、キーとイージングだけから描きます。式か時間リマップを使っているトラックは、実際の評価結果を 256 か所で計算して描きます。
値のグラフに出ないもの式も時間リマップも使っていないトラックでは、Wiggle とループの効果は線に描かれません。再生位置の点は実際の評価結果なので、線から外れて表示されることがあります。

キーのイージング

キーを選ぶと、グラフの下にイージングの欄が出ます。キーを選んでいないときは「キーを選ぶと補間ハンドルを編集できます。」と出ます。

イーズアウトCustomBezier、出力ハンドル (0, 0)、入力ハンドル (0.58, 1)

イージングが CustomBezier のときは、出力ハンドル と 入力ハンドル の数値欄（−2〜2）と、ハンドルの図が出ます。図の横軸は区間内の時間の割合、縦軸は値の割合（0 が今のキー、1 が次のキー）です。オレンジの点が出力ハンドル、赤みのある点が入力ハンドルで、点の近く（10 ピクセル以内）をドラッグして動かします。縦に 0〜1 の外へ出すと、行き過ぎてから戻る動きや、反対へ少し動いてから進む動きになります。

値の決まり方

1 つのトラック

  1. 時間リマップがあれば時刻を置き換えます。
  2. ループの設定で、最後のキーより後ろの時刻を置き換えます。
  3. 最初のキーより前は最初のキーの値、最後のキーより後ろは最後のキーの値です。キーが 1 つならその値です。
  4. キーとキーの間は、前のキーのイージングで補間します。Step なら前のキーの値のままです。
  5. ループがオフセット継続なら、繰り返した回数ぶんの差を足します。
  6. 式が有効なら、式で置き換えます。
  7. Wiggle が有効なら、揺れを足します。

合成（ブレンドモード）

同じコンポーネントの同じプロパティを、複数のトラック（コンポジションでは複数のレイヤー）が動かすとき、次の順に合成します。「元の値」は、そのフレームにモーションを当てる前のプロパティの値です。

順番モード計算
1OverrideOverride のトラックの値を、ウェイトで重み付けした平均にします。1 本もなければ元の値から始めます
2Blendここまでの結果から、トラックの値へウェイト（0〜1）の割合だけ近づけます。ウェイト 1 なら置き換えです
3Additive結果 ＋ (トラックの値 − 元の値) × ウェイト
3Multiply結果 × (トラックの値 ÷ 元の値) をウェイトの割合で効かせます。元の値がほぼ 0 のときは、トラックの値へ近づけます

Additive と Multiply は、トラックの並び順に 1 つずつ効きます。「［段階］」のプロパティ（切り替わるだけのもの）は常に Override として扱い、いちばんウェイトが大きいトラックの値になります（同じなら後のトラック）。

Override が 2 本あると平均になります1 つのモーションの中で、同じプロパティを Override のトラック 2 本で動かすと、両方の値の平均になります。後のトラックで上書きしたいときは、後のトラックを Blend にします。

Motion リグ

骨を持つモデルの骨を選んで、移動・回転・拡縮のポーズを付け、.replayrig に保存・読み込みするウィンドウです。レイアウトでは左の Motion レイヤーと同じ場所に置かれます。

Motion Workspace にいるとき、Window > Motion リグ のチェック、または Workspace パネルの Motion リグを開く ボタンで開きます。

使い方の例

ロゴをフェードインさせ、ゲーム開始時に再生する

  1. プロジェクト パネルの Create > Animation > Motion Asset でモーションを作ります。作ると開いて Motion Workspace に切り替わります。
  2. 左の 階層 ウィンドウでロゴの GameObject（UI の Image を持つもの）を選びます。
  3. Motion レイヤーの 不透明度フェードを作成 を押します。
  4. Motion プレビューの 再生 で確かめ、復元 で元に戻します。
  5. Motion レイヤーの 保存 を押します。
  6. ロゴの GameObject に コンポーネントを追加 > Motion > Motion Player を付け、Motion Asset に作ったモーションを指定します。きっかけ は既定の「開始時」のままにします。
  7. ゲームを実行すると、ロゴがフェードインします。

物をずっと回し続ける

  1. Motion Asset を作って開きます。
  2. 回したい GameObject を選び、選択からトラックを追加 で Transform の 回転 (度) を選びます。
  3. タイムラインで 2 つ目のキー（終わりのキー）をクリックし、Motion インスペクターの 値 の 2 つ目（Y）を、1 つ目のキーの Y ＋ 360 にします。
  4. イージングは両方のキーとも Linear（既定）のままにします。
  5. 保存し、GameObject に Motion Player を付けて、終了処理 を「ループ」にします。

1 周の長さは モーションの長さ で決まります。長さを変えたら、終わりのキーの 時刻 も同じ値にそろえます。

上下にゆらゆら動かし続ける（式を使う）

  1. Motion Asset を作って開き、モーションの長さ を 2 にします。
  2. 動かしたい GameObject を選び、選択からトラックを追加 で Transform の 位置 を選びます。
  3. Motion インスペクターの 式 / エクスプレッション を開き、有効 をオンにして、i == 1 ? v + sin(rt * 3.14159) * 0.2 : v と書きます。Y（成分 1）だけを、2 秒で 1 往復、±0.2 動かす式です。
  4. Motion プレビューで ループ をオンにして再生し、確かめます。
  5. 保存し、Motion Player の 終了処理 を「ループ」にします。

X と Z も不規則に揺らしてよいなら、式の代わりに Wiggle（揺れ） の 有効 をオンにして 振幅 を入れるだけで済みます。

ボタンを押したら少し大きくなる

手順は Motion Player の使い方 を見てください。モーションは、ボタンの Rect Transform の 拡大率 のトラックに、キーを 3 つ（元の大きさ → 1.2 倍 → 元の大きさ）置いて作ります。

2 つの動きを時間差で並べる（コンポジション）

  1. 先に、並べたいモーションを 2 つ作って保存しておきます。
  2. Create > Animation > Motion Composition でコンポジションを作ります。
  3. Motion レイヤーの + モーションレイヤー を 2 回押します。
  4. それぞれのレイヤーを開き、プロジェクト パネルからモーションを「モーション / コンポジションをここへドロップ」の欄へドロップします。
  5. 2 つ目のレイヤーの 開始 / 入点 / 出点 の開始を 0.5 にすると、2 つ目の動きが 0.5 秒遅れて始まります。
  6. タイムラインの 1F → や PageDown で再生位置を動かして確かめます。
  7. Motion レイヤーの 保存 ボタンで保存し（Ctrl+S では保存されません）、Composition Player に指定します。
