マテリアルの編集

対象：ブランチ sinotake / コミット 9eb9813

マテリアル（.replaymaterial）は、物の見た目を決める「シェーダー」と、その値（色、テクスチャ、粗さなど）をまとめたアセットです。プロジェクトパネルでマテリアルを選ぶと、インスペクターで編集できます。作ったマテリアルは Mesh Renderer などに付けて 使います。

こんなときに使う

  • 物に色やテクスチャを付けたいとき（基本色、基本色マップ）
  • 金属っぽい、つるつる、ざらざら、といった質感を変えたいとき（PBR の金属度・粗さ）
  • アニメ調の陰影や輪郭線を付けたいとき（Toon、輪郭線のレイヤー）
  • 葉っぱや柵のように、画像の透明な所をくり抜きたいとき（Alpha Mode の Mask）
  • ガラスのように半透明にしたいとき（Alpha Mode の Blend）
  • Shader Composer で作ったシェーダーを、物に使いたいとき

作る・開く

  • プロジェクトパネルの Create > Data > Material で、いま開いているフォルダーに、名前欄の名前で作ります。同じ名前があると名前が変わります。作ったマテリアルは選ばれた状態になります。
  • 作ったばかりのマテリアルは、シェーダーが PBR、Alpha Mode が Opaque です。
  • プロジェクトパネルでマテリアルを選ぶと、インスペクターに Material Asset の見出し（開いた状態）と、ファイルの場所が出ます。ダブルクリックでは別の画面は開きません。

Shader

いちばん上の Shader 欄で、使うシェーダーを選びます。一覧には、マテリアル用（Surface）のシェーダーだけが「分類/名前」の形で並びます。下に「ファイル名 | surface | ライティング」が表示されます。

一覧の表示見た目
BuiltIn/PBR光の当たり方を物理的に計算する、ふつうの質感。金属度・粗さ・法線マップなどを使えます
BuiltIn/標準取り込んだモデルの既定の見た目（PBR の簡易版。基本色とマップだけ）
BuiltIn/Toonアニメ調の段階的な陰影。影の色、リム、ハイライト、階調数を決めます
BuiltIn/GGST Toon2 値の陰影と ILM マップを使う、格闘ゲーム風のキャラクター向けトゥーン
BuiltIn/Unlit光の影響を受けず、基本色と基本色マップをそのまま表示します
BuiltIn/Flat Fill光の影響を受けない単色
BuiltIn/Pixelate四角いセルでピクセル化した見た目
Sample/Standard Lit（見本）自分でシェーダーを書くときの見本
Project/Composer/名前 などShader Composer や Create > Shader で作った、プロジェクトのシェーダー

シェーダーを切り替えても、前のシェーダーで入れた値は消えずにマテリアルに残ります（Advanced の「Retained / unknown properties」に数が出ます）。元のシェーダーに戻すと、その値がまた使われます。

シェーダーが見つからないとき

シェーダーの一覧にその GUID が無い（シェーダーのファイルを消した、など）ときは、欄が「Missing Shader」になり、赤で「Missing Shader - 保存済み Property は保持されています」と GUID が出ます。

次のどれかに当てはまると、物は赤紫（マゼンタ）の Unlit で表示され、コンソールに「Material Shader を解決できないため Unlit/Magenta へフォールバック: …」と理由が出ます。

  • シェーダーの一覧に、その GUID が無い
  • マテリアル用でないシェーダー（Layer、PostProcess）を指している（欄にはそのシェーダーの名前が出ます）
  • シェーダーのコンパイルに一度も成功していない（欄の下に橙で「Shader Compile に成功していません」と出ます）

前にコンパイルに成功したあと、直近のコンパイルに失敗したときは、橙で「直近の Compile に失敗。最後に成功した bytecode を使用中」と出て、前にうまくいった結果で表示を続けます。

Advanced

開くと、Shader GUID（古い形式のマテリアルでは「(legacy / empty)」）、シェーダーのファイルの場所（Source）、Schema Revision、「Retained / unknown properties 数」が表示されます。今のシェーダーが使わない値も、シェーダーを切り替えたときや見つからないときに消さずに残しておき、その数を表します。

Shader Stack（レイヤー）

Shader Stack の見出し（閉じた状態）を開くと、マテリアルにレイヤーを重ねられます。輪郭線やワイヤーフレームなど、描き足すものに使います。「陰影モデルは最後の有効な1枚、追加パスは上から順に描画します。ドラッグで順番を変更できます」と表示されます。

保存と割り当て

欄働き
Save Material保存します。保存していない変更があると「Save Material *」になり、右に「未保存」と出ます。成功すると「MaterialをAtomic Saveしました: 場所」
Assign to Selected Rendererこのマテリアルを、選んでいる GameObject の Renderer に付けます
  • 値を変えると、保存する前からシーンビューの見た目に反映されます。
  • 保存していない変更は、別のマテリアルを選んだときと、エディターを終了するときに自動で保存されます。GameObject など、マテリアル以外を選んだだけでは保存されません。
値の変更は元に戻せませんマテリアルで元に戻す（Ctrl+Z）の対象になるのは、Shader Stack のレイヤーの並べ替えだけです。色やテクスチャ、シェーダーの切り替えなどは記録されないので、試す前に保存しておき、戻したいときは保存し直す前の値を入れ直してください。

使い方の例

赤いつやのあるプラスチックにする

  1. プロジェクトパネルの Create > Data > Material でマテリアルを作ります。
  2. Shader が BuiltIn/PBR になっていることを確かめます。
  3. 基本色 を赤、粗さ を 0.25、金属度 を 0 にします。
  4. Save Material を押し、マテリアルを物にドラッグして付けます。

葉っぱの画像をくり抜いて表示する

  1. 透明な部分のある葉っぱの画像を、基本色マップ のボタンへドロップします。
  2. Rendering の Alpha Mode を Mask にします。
  3. ふちが欠けすぎるときは アルファ閾値 を下げます。板の裏からも見えるように 両面を描く をオンにします。

アニメ調の陰影と輪郭線を付ける

  1. Shader を BuiltIn/Toon にし、影の色 と 階調数（2 や 3）を決めます。
  2. Shader Stack を開き、Layerを追加... > BuiltIn/Outline を選びます。
  3. 足した「輪郭線追加パス」の見出しを開き、輪郭の色や太さの値を調整します。
  4. Save Material を押します。

Shader Composer で作ったシェーダーを使う

  1. Shader Composer で Surface のシェーダーを作り、Ctrl+S で生成・コンパイルします。
  2. マテリアルの Shader で「Project/Composer/名前」を選びます。Material Property のノードで作った値が Shader Properties に並びます。
  3. Shader Stack に陰影モデルやピクセレーションのレイヤーが入っていないことを確かめます。
