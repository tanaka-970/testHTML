Validation と Diagnostics

対象：ブランチ sinotake / コミット 9eb9813

開いているシーンに、よくある設定ミス（操作対象が無い、モデルのファイルが見つからない、Collider の設定がおかしい など）が無いかを自動で調べて一覧にするパネルです。シーンの数や、C# から触れるプロパティの一覧も見られます。Window > Validation / Diagnostics で表示を切り替えます（最初から表示されていて、ふだんの画面では下段のタブにあります）。ウィンドウの名前は「Validation & Diagnostics」です。

こんなときに使う

  • シーンを保存する前や、ゲームを実行する前に、設定の抜けが無いかをまとめて確かめたいとき
  • 物が表示されない、キャラクターが動かない、床をすり抜けるといったときに、原因の手がかりを探したいとき
  • ライトを増やしたのに明るくならないなど、数の上限にかかっていないか確かめたいとき
  • C# スクリプトや Text の数値の表示から触れるプロパティの内部名を調べたいとき（Component API タブ）

Validation タブ

表示働き
再検証今のシーンを調べ直します
「Error 数 / Warning 数 / Total 数」見つかった問題の数
問題の行左に種類（ERROR は赤、WARN は橙、INFO は水色。ただし今のルールで INFO になるものはありません）、右に内容。GameObject に結び付いた問題は、行をクリックするとその GameObject が選ばれます。下に薄い文字で「修正案: …」が出ます
「現在検出できる問題はありません。」問題が 1 つも無いとき（緑）

GameObject やコンポーネントを足す・消すなど、シーンの構成が変わったときは自動で調べ直します。値を変えただけのときは、再検証 を押して調べ直します。

GameObject を 1 つ選ぶと、インスペクターの上のほうにも、その GameObject の Error と Warning が「この GameObject の診断」の見出し（開いた状態）で「[コード] 内容」と、その下に薄い文字の修正案（「修正案:」の文字は付きません）の形で出ます。こちらは表示するたびに調べ直すので、値を直すとすぐ消えます。

Diagnostics タブ

今のシーンの状態を数字で表示します（表示のみ）。

表示内容
Sceneシーンの名前
GameObjectsGameObject の数

Dirty保存していない変更があるか（Yes / No）

シーンが無いときは「Sceneがありません」と出ます。当たり判定をもっと詳しく見るときは 衝突の診断 を使います。

表示される WorkspaceUI Workspace と Motion Workspace にいる間は、このウィンドウは描かれません（Window メニューで切り替えても出ません）。基本などの Workspace に戻すと出ます。インスペクターの「この GameObject の診断」も、ふだんのインスペクターが出る Workspace でだけ見られます。

Component API タブ

エンジンに登録されているすべてのコンポーネントと、そのプロパティの内部名と型の一覧です。

  • 上に 検索 欄と、「Component 数 種 / Property 数 個。C# から触れるのは 数 個」が出ます。検索はコンポーネントの型名で絞り込みます。
  • 「型名 [分類] 数 個」の見出しを開くと、プロパティが「内部名 型」の形で並びます。書き換えられないものには「読取のみ」が付きます。
  • 一覧（Array）の型のプロパティは C# から触れないため、薄い文字で「C# 未対応」と出ます。

ここに出る内部名は、Text の数値プロパティ や Property Link で使う名前と同じです。

使い方の例

保存する前にシーンを点検する

  1. 下段の Validation & Diagnostics タブを開き、Validation タブで 再検証 を押します。
  2. ERROR の行から順に、行をクリックして該当の GameObject を選びます。
  3. 「修正案」とインスペクターの「この GameObject の診断」を見ながら直します。インスペクターの表示が消えれば直っています。
  4. もう一度 再検証 を押し、Error が 0 になったら保存します。

ライトを増やしたのに明るくならない

  1. 再検証 を押し、LIGHT_LIMIT_EXCEEDED が出ていないか見ます。
  2. 出ていたら、遠くて目立たない Point Light を消すか、1 つの大きな範囲のライトにまとめて、Point は 8 個、Spot は 4 個以下にします。

Text に表示したい値の内部名を調べる

  1. Component API タブの 検索 に、コンポーネントの型名の一部（例：Slider）を入れます。
  2. 見出しを開き、表示したい値の内部名（例：value）を探します。
  3. その名前を Text の 数値プロパティ に入れます。
