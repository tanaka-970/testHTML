UI Workspace

対象：ブランチ sinotake / コミット 9eb9813

ゲーム内の UI（メニュー、HP ゲージなど）を作るための画面構成です。シーンビューに Canvas を選んだ解像度で表示し、UI 部品を直接つかんで動かしたり、大きさや角度を変えたりできます。UI のコンポーネントそのものの説明は Canvas と Rect Transform から始まる UI の章を見てください。

こんなときに使う

  • タイトル画面のメニュー、体力ゲージ、スコアの表示など、ゲームの画面に重ねて出す UI を並べるとき
  • 画面の大きさや縦横比が変わったときに、UI がどう見えるかを確かめるとき（上部の解像度を切り替えます）
  • ボタンや画像の手前・奥の順番を整えるとき
  • 画像を円や星の形、自由な輪郭で切り抜いて表示したいとき
  • UI にフェードや拡大の動きを付ける前に、対象の部品を選んで準備するとき

切り替える

  • Window > UI Workspaceへ で切り替えます。元に戻すには Window > Scene Workspaceへ です（Workspace）。
  • UI Workspace にいる間、Window メニューに UI 階層 と UI インスペクター が出ます。閉じたウィンドウはここから開き直します。

画面の並び

場所ウィンドウ
左（幅の約 18%）UI 階層
右（幅の約 30%）UI インスペクター
下（高さの約 20%）プロジェクト、コンソール
中央シーンビュー（UI の表示と操作）

この並びは、レイアウトを作り直したとき（Window > レイアウトを初期化 など）の配置です。

シーンビュー

シーン タブを表示しているとき、中央に Canvas の範囲が白い枠で表示され、その中に UI が描かれます。3D のカメラ操作やギズモの代わりに、UI 用の操作になります。

上部の欄

表示既定働き
解像度（選択欄）1920 x 1080UI を並べる画面の大きさ。1920 x 1080、1280 x 720、1080 x 1920、カスタム から選びます。カスタムでは右に W と H の欄が出ます（初期値 1920 × 1080、1 以上）
拡大0.50表示の倍率（0.10〜2.00）
グリッドオンCanvas 座標の 100 ごとに線を表示します

ここで選んだ解像度で Canvas の スケール方式 などが計算されるので、画面の大きさが違うときの見え方を確かめられます。

表示を動かす

操作結果
マウスホイールカーソルの下の位置を中心に拡大・縮小（1 目盛りで 0.05）
中ボタンでドラッグ、または Shift を押しながら左ドラッグ表示位置を動かす（Canvas の外をつかんでもよい）

選ぶ・動かす

  • クリックすると、カーソルの下にある UI 部品を選びます。手前の Canvas、後から描かれる子ほど先に選ばれます。非アクティブの部品と、Image・Text・Button・Mask を持たない Canvas は選ばれません。
  • 選んだ部品をそのままドラッグすると、Rect Transform の 位置 が変わります（2 ピクセル以上動かしたときから）。
  • 選んでいる部品は黄色の枠で表示されます。

大きさを変える

  • 黄色の枠の四隅と各辺の真ん中に白い丸（ハンドル）が出ます。ハンドル、または枠線の近くをドラッグすると大きさが変わります。つかめる距離はハンドルが 14 ピクセル、辺が 9 ピクセルで、小さい部品では内側をつかめるよう短くなります。
  • 四隅のハンドルを Shift を押しながらドラッグすると、縦横比を保ちます。
  • Alt を押しながらドラッグすると、反対側も同じだけ動き、中心を保ったまま大きさが変わります。
  • 1 より小さくはなりません。結果は、今のアンカーのまま 位置 と サイズ差分 に書き直されます。
  • 図形マスク（Mask の方式が形状）の枠を変えると、中の子の位置と大きさも同じ割合で変わります。

回す

  • 枠の上辺の 30 ピクセル外に、丸矢印の回転ハンドルが出ます。ドラッグするとピボットを中心に回ります。
  • 回している間は、ピボットに十字、カーソルの横に「加算値（保存される回転の値）」と「向き（0〜360 度）」が表示されます。
  • Shift を押している間は 15 度刻みになります。

自由図形の頂点を動かす

自由ベジェ Path の Shape か、Shape Image を選ぶと、大きさ・回転のハンドルの代わりに輪郭の編集ができます。

表示操作
ピンクの線輪郭。線の上をクリックすると、その位置に頂点を足し（形は変わりません）、そのままドラッグできます（最大 64 個）
黄色の丸頂点（選択中は大きい丸）。ドラッグで動かします
青い小さな丸入力ハンドル。ドラッグで前から来る曲線の曲がりを変えます
ピンクの小さな丸出力ハンドル。次へ向かう曲線の曲がりを変えます

Shape の選んだ頂点は、UI インスペクターにフォーカスがあるときに Backspace で消せます。Shape Image の頂点は Backspace では消えないので、UI インスペクターの 自由図形Image コントローラー にある 選択 Point を削除 を使います。

Puppet Deform の Pin を動かす

Puppet Deform を持つ部品を選ぶと、変形した格子が水色の線で表示されます。

表示操作
橙の丸Pin の今の位置（選択中は黄色）。ドラッグで動かすと画像が曲がります
灰色の小さな円Pin の基準位置。橙の丸との間に線が引かれます
基準位置のまわりの円と、その右の小さな丸影響半径。右の小さな丸をドラッグすると半径が変わります

Effect の適用範囲

UI の Effect Stack を持つ部品を選ぶと、有効な適用範囲がピンク（画像マスクは水色）の枠で表示され、「EFFECT 1 / RECT」のように、番号と形（RECT、ELLIPSE、MASK、FREEFORM）が表示されます。

  • 矩形・楕円・画像マスクの範囲は、8 つのハンドルで大きさを、上に突き出たハンドルで回転を変えます。
  • 自由形状の範囲は、頂点をドラッグで動かし、線の上をクリックで頂点を足します。選んだ頂点は、シーンビューにフォーカスがあるときに Delete または Backspace で消せます（閉じた形は 3 つ、開いた形は 2 つより少なくできません。消せないときの表示は、どちらも「閉じた適用範囲は3頂点未満にできません」です）。

Track Matte のつながり

Mask の方式が Object Alpha / Object Luma の部品を選ぶと、Matte に使う GameObject へ線が引かれ、PRIMARY（1 つ目）、ADD、SUB、INTERSECT（演算）の名前が表示されます。

UI 階層

シーンの中の UI だけを木の形で表示し、UI を追加・並べ替えするウィンドウです。

追加のボタン

上部に次のボタンが並びます。作られる内容は Canvas と Rect Transform と Shape も見てください。

ボタン働き
Canvas、Text、Button、Maskその部品をすぐ作ります
Imageメニューを開きます（下の表）
図形矩形、角丸矩形、円、三角形、六角形、星形、線 から選んで Shape を作ります
図形イメージImage を選んでいるときだけ押せます。選んでいる Image を形で切り抜くメニューを開きます（下の表）

自由図形イメージ「自由図形 Image」（Image と Shape Image を持つ GameObject）を作ります

ウィンドウの幅が 250 ピクセルより狭いときは、＋ UIを追加（すべての追加をまとめたメニュー）、図形イメージ、自由図形イメージ の 3 つに変わります。

選択中の順番

UI を選んでいると、次の欄が出ます。

表示働き
↑ 階層 / ↓ 階層同じ親の中で 1 つ上 / 下へ移します（階層の並び順）
描画順（数値欄）Canvas なら Canvas の描画順、それ以外は Rect Transform の描画順を直接入れます
最背面 / 背面 / 前面 / 最前面比べる相手（Canvas はシーンのすべての Canvas、それ以外は同じ親の兄弟）の描画順をもとに値を決めます。最前面は「一番大きい値 ＋ 1」、前面は「すぐ上の値 ＋ 1」です

「階層の順番と描画順は別々に保存されます。描画順は値が大きいほど手前です。」と表示されます。

木の表示と並べ替え

  • フォルダ / フィルター の 名前で検索... と、種類の選択欄（全て、Canvas、Image、Text、Button、図形、Mask）で表示を絞り込めます。
  • 各行は「[描画順] 名前」です。クリックで選びます。
  • 行をドラッグして、ほかの行の上半分で離すとその前、下半分で離すとその後ろへ移します。Ctrl を押しながら離すと、その行の子にします。
  • 一番下の「ここへドロップ: シーン直下へ移動」に離すと、親をなくします。
  • 行を右クリックすると、その行を選んだうえで Image を追加、Text を追加、Button を追加、Mask を追加、図形を追加、描画順（最背面へ、背面へ、前面へ、最前面へ）、シーン直下へ移動 が出ます。

UI図形イメージ の枠

次のどれかを選ぶと、UI 階層の中に「UI図形イメージ」の枠が出ます。中身は選んだものに合う見出しだけが出ます。

  • 形状方式の Mask を持つ部品
  • Image を持ち、一番近い親の Mask が形状方式の部品
  • UI の Effect Stack を持つ部品
見出し項目
Effect適用範囲（複数可）範囲制限を有効、追加範囲数。追加範囲ごとに 有効、形状（矩形、円 / 楕円、画像マスク（投げ縄）、自由形状）、中心、サイズ / 半径、回転
マスク枠の配置（形状方式の Mask があるとき）マスク枠の位置、マスク枠のサイズ（枠だけ変わり、中の画像は変わりません）、全体の拡大率（枠と中の子をまとめて拡大・縮小）、子Imageをマスク枠に合わせる（子の Image を枠の中央・同じ大きさにそろえます）
図形マスク（UI編集）（形状方式の Mask そのものを選んでいるとき）形状（矩形、円、多角形、星形、角丸矩形）、頂点数（多角形・星形）、星形の内側、角丸量、形状の回転、境界の柔らかさ、切り抜きを反転
切り抜き Image（UI編集）子の Image を選んでいるとき。映す位置、映すサイズ、画像のUV位置、画像のUV範囲
全体の拡大率 は切り抜きの形に 2 回掛かりますこのビルドでは、全体の拡大率を変えると、枠の大きさと Mask の「図形イメージの拡大率」の両方が同じ割合で変わります。描画では図形の大きさが「枠 × 図形イメージの拡大率」になるため、切り抜く形は枠より大きく（または小さく）なります。大きさを変えるときは、シーンビューで枠のハンドルを使ってください。

UI インスペクター

選んでいる UI 部品を編集するウィンドウです。UI 部品を選んでいないときは「UI 要素を選択してください」と Canvas を作成 ボタンが表示されます。上から次の順に並びます。

欄内容
アンカー左上（アンカーとピボットを左上に）、中央（中央に）、全体（アンカーを 0,0〜1,1、ピボットを中央に）
Puppet Deform 編集Puppet Deform があるとき（Pin の編集）
自由図形コントローラー / 自由図形Image コントローラー自由ベジェ Path の Shape、または Shape Image があるとき（自由ベジェ Path の編集）
Track Matte 編集Mask が Object Alpha / Object Luma のとき。「Primary + Extra: 数」、Matte を追加、選択 Extra Matte を削除、選択 Extra Matte
コンポーネントふつうの インスペクター と同じ、コンポーネントとプロパティの一覧
Motion を作成モーションを開いていなければ「UIMotion」を作り、Motion Workspace に切り替えます

UI インスペクターにフォーカスがあるとき（文字の入力中を除く）、Backspace で、選択中の Pin、なければ Shape（自由ベジェ Path）の選択中の頂点を消します。Shape Image の頂点は消えません。

使い方の例

画面の上のほうの中央にタイトルを出す

  1. Window > UI Workspaceへ で切り替えます。
  2. UI 階層で Canvas を選び、Text ボタンを押します。Canvas が 1 つもないときは、Text を押すと Canvas も作られます。
  3. できた Text を選んだまま、UI インスペクターの アンカー で 中央 を押します。
  4. インスペクターの Text の テキスト にタイトルを入れ、Rect Transform の 位置 を (0, 300) にします。Canvas の中では上が ＋ です。
  5. シーンビュー上部の解像度を 1280 x 720 や 1080 x 1920 に切り替え、どの大きさでも中央の上に出ることを確かめます。

アイコン画像を円形に切り抜く

  1. UI 階層の Image > 図形で切り抜いたImageを追加 > 円で切り抜く を選びます。「Circle Image Mask」と、その子の「Masked Image」ができます。
  2. Masked Image を選び、インスペクターの Image の 画像 にアイコンの画像を指定します。
  3. UI 階層に出る「UI図形イメージ」の枠の 映す位置 と 映すサイズ で、円の中に見せる部分を合わせます。
  4. 円の大きさを変えるときは、Circle Image Mask を選び、シーンビューのハンドルをドラッグします。中の画像も同じ割合で大きさが変わります。

ボタンをほかの UI より手前に出す

  1. ボタンを選びます。
  2. UI 階層の「選択中の順番」で 最前面 を押します。同じ親の中で、いちばん手前に描かれます。
  3. 別の Canvas の UI よりも手前にしたいときは、ボタンの入っている Canvas を選んで 最前面 を押します。

画像にフェードインを付ける

  1. フェードさせたい Image を選びます。
  2. UI インスペクターのいちばん下の Motion を作成 を押します。Motion Workspace に切り替わります。
  3. Motion レイヤーの 不透明度フェードを作成 を押すと、1 秒で見えてくるトラックができます。続きは Motion Workspace の使い方の例 を見てください。
